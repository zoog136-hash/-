## 원본 소스 보유 여부 1차 검사
업로드된 `a3.zip` 경로명에서 faith(신념)은 주로 시스템 스킬 용어이고, albino·escaros 한글 및 영문 매칭 파일은 발견되지 않았다. domination 관련 클래스는 있지만 지배의 탑 정상 2D 원본 배치라고 증명하지 못했다. **A3의 mapcache 숫자 ID만으로 지배/신념/알비노/에스카로스의 원본 지형을 임의 지정하지 않는다.** 직접 플레이 캡처, 지도 UI 확대 비교와 판본 검증을 먼저 수행한다.

## 제작 절차
1. 지역 1개씩 실제 리니지M 지도 UI와 플레이 영상의 지형 기준점·카메라 각도/줌·판본을 기록한다. 각 층/구역 개별 근거 요구.
2. 캡처를 기준으로 **새 좌표계/지형 아웃라인/통행 엣지**를 작성한다. 확보되지 않은 구간을 임의 직선으로 메우지 않는다. 불확실 구간은 미확인으로 남긴다.
3. 바닥 텍스처, 벽/기둥/장식/물/절벽/식생 아트는 해당 권리 허용 자료 또는 고유 제작 아트로 별도 구축한다. 실제 인게임 자료는 비교용으로만 보존한다.
4. `content/newmaps/lineagem_reference/{map_id}` 아래 새 지형/렌더/충돌 정의와 단독 2D 검증 씬을 만든다. 기존 폴리곤 재사용 금지.
5. Godot 실화면에서 동일 카메라 비교, 통행/충돌/시야/스폰/보스/포털 동작 검증. 스크린샷·로그를 PR 아티팩트에 올린다.
6. 사용자 승인 후 기존 맵을 덮어쓰지 않는 선택식 전환을 **별도 PR**로 준비한다.

## 현재 단계
지금은 자료 식별 및 경계 조건 작성까지. **신규 14개 맵 제작 완료나 스크린샷 확보를 주장하지 않는다.** 근거 불충분한 상황에서 기존 맵을 복제하는 일을 막기 위해 우선 분리 브랜치로 시작한다.
