# 523 몬스터 드랍 연결

최신 main `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`에서 독립 작업했다.
PR218 (`804f88f9583f91ec4ab62c6a5e1fe6a65fdd0e53`)의 508 드랍 연결과
PR230 (`2920e576df706eb2b246fe5b32d466f30cfc5b95`)의 지도·출현 정의를
먼저 대조했다. 두 PR을 병합하거나 원본 출현을 새로 활성화하지 않는다.

## 게임과 UI

- 실제 `Monster.setup`의 검증 가능한 `source_m_npc_id`·원본 ID·Sprite·Name을
  사용한다. 508/523 네임스페이스만 허용하며 이름이나 스프라이트만으로
  기존 몬스터를 다른 원본 NPC에 대응시키지 않는다. NPC 변형 ID도 별개다.
- `World._roll_drop` → 기존 확률·횟수 → 523 후보 → 월드 바닥 → 습득을
  사용한다. 인벤토리에 즉시 지급하지 않는다. 원본 몬스터 생성과 픽셀 팩은
  기존 원본 몬스터 연결의 조건을 그대로 따른다.
- main의 기존 485개 드랍용 아이템 풀과 더 큰 도감을 구분한다. 원본 후보는
  도감의 별도 ID 검증 조회를 사용해 기존 몬스터의 후보 풀을 넓히지 않는다.
- 설정 → **523 드랍 자료 ZIP 설치**에서 별도 자료를 설치한다. 압축·해시·버전
  검증 후 해시별 새 경로에 기록하며 세이브나 기존 팩을 덮어쓰지 않는다.
- 아이템 도감 상세에 원본 ID로 검증된 드랍원·축복·퀘스트 조건을 표시한다.
  일반·축복·저주 장비의 바닥 툴팁, 물리 ID와 저장에도 출처를 보존한다.
- 자료 미설치/해시 불일치/ID 불일치는 원본 드랍을 차단한다. 출현·확률을
  보장하는 목록으로 표시하지 않는다. 기본 게임의 다른 드랍은 유지한다.

## 규칙과 남은 범위

원문 `NpcItemDropView`는 확률·수량·추첨 횟수를 제공하지 않는다.
확률표 숫자는 변경하지 않았고 별도의 등급 차단만 제거했다.
일반 몬스터의 전설·신화·유일 가중치 0은 기존 규칙대로 유지된다.

| 구분 | 현재 TWILIGHT 규칙 |
| --- | --- |
| 장비 | 일반 1회 / 보스 3회, 기존 등급별 가중치 |
| 물약 | 일반 45% / 보스 90%, 후보가 있을 때 1개 |
| 재료 | 일반 28% / 보스 65%, 후보가 있을 때 1개 |
| 후보 선택 | 서로 다른 아이템을 균등 선택한 뒤 서로 다른 지원 축복 상태를 균등 선택 |
| 동일 표시 중복 | 원문 ID·행 위치 전부 보존, 선택 가중치·수량 증가 없음 |
| 퀘스트 조건 | 78행 보존·표시, 드랍에서는 제외. 퀘스트 재도입 없음 |
| 미지원 상태 | Lost 등과 구분 보관할 수 없는 축복 스택은 제외, 일반 상태로 변경하지 않음 |
| 화폐 | 원문 수량 추론 없음. 이 어댑터에서 새 화폐 추첨을 만들지 않음 |

선택·수량 규칙은 호스트 게임의 적용 정책이며 원작 서버 확률이 아니다.
원래 비원본 NPC용 L1J/게임 자체 제작·화폐 드랍 경로는 유지한다.
추후 PR218 통합 시 508·523 어댑터를 동시에 추첨하면 안 된다.

원본 46,854행 / NPC 4,848개 / 아이템 ID 2,379개를 저장한다. 서로 다른
조건 payload는 44,272개, 완전히 동일한 추가 표시행은 2,582개다.
축복 또는 퀘스트 조건이 다른 (NPC, 아이템) 쌍 1,858개를 합치지 않는다.
기존 아이템 DB에 정확한 ID·출처 URL·한국어 이름·유일한 인벤토리 키로
검증한 ID는 999개(19,615행), 미연결 ID는 1,380개다. 미연결 아이템을
이름 유사도나 임의 옵션으로 생성하지 않는다. 퀘스트·미지원 상태·NPC
활성 조건 때문에 19,615행 모두가 실제 드랍되는 것은 아니다.

스폰 시간·서버집합·영역·IsSpawn은 이 드랍 표로 활성화하지 않는다.
퀘스트 TeleportTerritoriesID를 드랍 맵 제한으로 전용하지 않는다.
PR230은 원본 출현 정의 조회이며 실제 생성수·좌표·주기를 복원했다는 뜻이
아니다. 같은 스탯·공격·위치의 NPC 변형에도 서로의 드랍을 복사하지 않는다.

## 원본과 재현

Library 정식 materialize 후 실제 ZIP 읽기·CRC 검사를 통과했다.
사용한 원본은 `lineagem_patch523_all_content_validated_and_508_520_deltas.zip`
(SHA-256 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`)이다.
사용한 6개 표는 원본 `index.json`의 SHA-256·CRC32·크기·행 수와 일치한다.
추가 NPC 조건 보고서와 뷰 다중성 보고서를 함께 읽고 반영했다.
원문 데이터는 공개 Git에 포함하지 않고 별도 Library 설치 ZIP으로 전달한다.

```sh
python3 tools/monsters/build_patch523_monster_drops.py \
  --source /private/validated523 --catalog data/catalog_v19.json \
  --output /private/patch523-drops
python3 -m unittest discover -s tests -p test_patch523_monster_drops.py -v
```

설치 데이터 `monster_drops.bin`: 643,286 bytes,
SHA-256 `4455cbbd2e6dc5392ccb2f142d99124ad2b5966e2dbca6d5fd3bb1f7b0cde0a3`.
실행 때 `--patch523-drop-root=/private/patch523-drops`도 지원한다.
기본 설치 위치는 `user://lineagem_patch523_drops/<SHA>/monster_drops.bin`이다.

실제 원본 데이터 검증은 격리한 XDG 사용자 폴더와 검증된 현재 맵 팩에서
`tests/patch523_monster_drops_test.gd`를 실행한다.
`TWILIGHT_PATCH523_DROP_ZIP`을 원본 설치 ZIP 경로로 주면 실제 설치·바닥
장비·습득·저장·도감을 검사한다. CI에서는 원문을 포함하지 않는 합성
회귀와 실제 Main의 누락 팩 거부·설정 진입을 검사한다. 합성 데이터 검사를
원본 데이터나 원본 픽셀 검증으로 집계하지 않는다.

전체 원본 이미지·애니메이션, 모든 아이템 매핑, 실제 서버 조건, Android
실기기 플레이를 완료한 작업이 아니다. 사용자 세이브에는 접근하지 않는다.

## 이번 로컬 검증 결과

- 원본 ZIP 3개 정식 반입·실제 읽기·CRC 통과. 원문 6표의 인덱스 정합 및
  46,854개 원문행·ID·배열 위치의 전수 보존을 별도로 확인했다.
- Python 컴파일러 회귀 5개, 기존 core-staging 회귀 7개 통과.
- Godot 4.7.2의 실제 생산 리소스 그래프 7,449파일 임포트 오류 0.
  실제 Main/현재 지도/세이브 이전 32개 검사와 동일 내용 저장·지연 저장 통과.
- 신규 Godot 규칙 1,550개, 실제 Main에서 미설치 팩 거부·세이브 보존·설정
  진입을 포함한 검사 1,555개 통과. 기존 드랍 밸런스 회귀도 통과했다.
- 실제 원본 ZIP 설치·재설치·손상 ZIP 거부, 정확한 NPC382/아이템582의
  일반·축복 분리, 바닥 소유권·850ms 표시 후 습득·저장/재로드, 실제 피해의
  사망 신호·중복 보상 방지, 도감 검색·설정 UI를 포함한 **1,577검사 오류 0**.
  희귀 드랍 경로는 기존 추첨 함수로 성공 seed를 찾아 재현했으며 확률이나
  원문을 바꾸지 않았다. 물리적 장비 전송 검사는 실제 축복 행을 선택했다.
- Xvfb/llvmpipe/OpenGL Compatibility 1280×720에서 실제 도감·설정 캡처를
  확인했다. 원본 NPC 픽셀 팩은 미설치 상태이며 외형·애니메이션 동등성이나
  실제 Android 장치 검증을 뜻하지 않는다.
- 723개 기존 시트 / 41,442프레임의 Git 추적·SHA 검사 통과.
  저장소의 고정 구형 원본 ZIP 검사 옵션은 별도 `a1.zip` 부재로 실패하며,
  이번523 ZIP의 실제 CRC/SHA·행 보존 검증과 구분한다. 구형 아트 복원은
  수행하지 않았다.
- 사용자 지시로 커밋에 `[skip ci]`를 사용한다. 수동 CI 실행·재실행을
  요청하지 않으며 원격 CI 통과나 병합 완료로 보고하지 않는다.

실제 게임 검증은 격리한 임시 사용자 저장소에서 했다. 모든 실제 원본
몬스터의 출현·전투·아이템을 플레이 검증한 것이 아니다. 남은 1,380개
아이템 ID 매핑과 원본에 없는 확률·수량은 이번 작업에서 만들지 않았다.
