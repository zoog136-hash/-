# 누적523 몬스터 드랍·아이템 연결

전체 ItemClass 교체의 최신 구현·검증·미완료·팩 상태는 [PATCH523_FULL_ITEMS.md](../../docs/PATCH523_FULL_ITEMS.md)를 따른다. 이 문서의 드랍 부분집합과 이전 단계 수치를 전체 아이템 범위로 해석하지 않는다.

main `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6` 기준 독립 PR238이다.
PR218의508 드랍 어댑터와 PR230의 출현 정의를 대조했으며 다른 PR이나
main은 병합·수정하지 않는다. 기존 원본·사용자 세이브·이전 커밋은 보존한다.

선택 상자21종의 실제 선택·수령과 원본 스킬서350개 카드/주문 ID·정의 SHA 계약을 포함한다. 스킬 실행 엔진은 PR245 소유이며 이 PR에서 복제하지 않는다.

최신 사용 효과·전용 슬롯·보완 규칙·팩 식별은 [상세 연결 문서](../../docs/PATCH523_DROP_ITEMS.md)에 기록한다.

## 게임과 UI

- 검증된 원본 NPC ID·Sprite·Name으로만 후보를 고른다. NPC 변형·축복·
  RequiredQuestID를 합치지 않으며, 이름 유사도로 기존 몬스터에 연결하지 않는다.
- 실제 Monster/World의 추첨 → 바닥 → 습득 → 장비 물리 ID·저장 경로를 쓴다.
  문양·퀘스트·혈맹·공성 등 다른 시스템을 재도입하지 않는다.
- 설정의 **523 드랍 자료 ZIP 설치**에서 데이터 해시·ZIP 구조·크기·버전을
  검사한다. 설치 직후 도감과 실제 드랍용 조회를 갱신한다. 기존 팩은 덮어쓰지
  않고 해시별 경로에 남긴다. 최초999 매핑 팩도 읽을 수 있다.
- 아이템 도감에서 원본 드랍원·축복/퀘스트 조건·실제 지원 기본 옵션·원본
  직업/레벨 제한·미지원 효과를 표시한다. 원본에 없는 아이콘을 만들지 않는다.
- 기존485 아이템 드랍 풀을 넓히지 않는 별도 원본 조회를 사용한다. 새 원본
  아이템은 `m523:item:<ID>` 및 원본 ID가 포함된 독립 소지 키로 등록한다.
  기존의 같은 이름 스택을 다른 원본 ID로 이전하거나 덮어쓰지 않는다.
- 장비는 물리 ID별 축복·출처를 보존한다. 새 원본 스택의 축복·저주 상태도
  소지 키와 sourceId를 구분해 일반 스택에 섞지 않는다.

## 등급 제한 수정과 확률 정책

일반과 보스 모두 일곱 등급의 양수 추첨 구간을 사용한다. 일반 몬스터의
누락/0이던 상위 등급도 실제로 추첨할 수 있다.

원본 NpcItemDropView에는 드랍 확률·수량이 없다. 새 원작 확률을 만들지 않고
이미 게임 코드에 정의된 보스의 해당 등급 확률을 일반 몬스터의 빠진 등급에
재사용한다. 기존 일반의 양수 확률과 보스의 모든 확률·횟수는 유지한다.

| 등급 | 일반 / 회 | 보스 / 회 |
| --- | ---: | ---: |
| 일반 | 0.1% | 0.1% |
| 고급 | 0.1% | 0.1% |
| 희귀 | 0.1% | 0.1% |
| 영웅 | 0.015% | 1% |
| 전설 | 기존 보스값 0.2% 재사용 | 0.2% |
| 신화 | 기존 보스값 0.025% 재사용 | 0.025% |
| 유일 | 기존 보스값 0.001% 재사용 | 0.001% |

일반은1회, 보스는3회다. 일반 장비 등급 추첨 합계는0.315%에서0.541%가 된다.
상위 등급을 양수로 열면서 기존 양수 구간을 유지한 결과이며 원작 서버 수치가
아니다. 추첨한 등급이 해당 NPC의 원본 후보에 없으면 다른 아이템으로 바꾸지
않고 해당 추첨을 비운다. 다른 몬스터의 고등급 아이템을 끌어오지 않는다.

물약45%/90%, 재료28%/65%, 별도 화폐28%/65% 및 각 일반/보스 정책을
기존 코드에서 재사용한다. 수량1은 기존 일반 후보·화폐 행의 호스트 정책이다.
원문 중복행으로 추첨 횟수·수량을 늘리지 않는다. 새 원본 스킬서·주문서·보상
소모품의 표준등급은 기존 제작 주문서와 같은 등급 추첨을 사용하며 웨어러블로
취급하지 않는다. 회복 물약·실제 재료·화폐는 각자의 기존 추첨 경로를 쓴다.

원본 아데나26 및 코인3242/3252/3631/246058은 ID·분류·표시명을 검증하고,
일반 상태·퀘스트 조건0일 때만 기존 아데나/코인 재화로 습득 정산한다. 기존
currency_drops.gd의 코인 명칭 별칭을 재사용한다. 다른 상태나 이벤트 화폐를
임의로 같은 재화에 합치지 않는다. 원본 화폐 수량을 알아냈다는 뜻은 아니다.

## 전체 아이템 정의 연결

원본46,854행 / NPC4,848개 / 아이템 ID2,379개를 전부 보존한다. 조건 payload는
44,272개, 동일 추가 표시행2,582개이며, 축복/퀘스트가 다른 쌍1,858개를 분리한다.

기존 도감의 정확한 ID·출처 URL·한국어 이름·유일 소지 키로999개를 재사용한다.
기존 도감에 없는1,380개는 최신523 ItemClass를 직접 등록해 **미매핑 ID0개**다.
이는2,379개 아이템의 모든 특수 사용 효과를 구현했다는 뜻은 아니다.

원본 ItemClass/Category/Grade/EquipSlot/Class/WeaponType 및 ItemBonus→
Bonus→BonusType→Unit을 해시 검증 후 연결한다.2,379개의 독립 원본 정의,
보너스7,793행, 장착782행, 직업2,322행을 보존한다. 확인된 무조건·정수·정확한
단위의 기본 장비 옵션을 적용하고1,915개 옵션 행의 적용 근거를 남긴다.
HP 회복14정의는 원본의 고정값과 주사위를 보존하고 사용 시 실제로 주사위를
굴린다. 평균 회복량이나 발동 확률을 추정하지 않는다. 소모품의 기존 호스트
재사용 대기·보정 규칙은 유지한다. HP 수치만 떼어 쓰지 않으며 원본 기간·영토·
동시 버프 등 추가 조건을 지원하지 않는 회복 아이템은 소비하지 않는다.

미지원 발동·특수·조건부·소지 효과와 미확인 단위는 원문과 제외 사유를 남긴다.
원본 무게 단위를 임의로 호스트 무게로 바꾸지 않는다. Item323353은
원본 부위293의 전용 지배석 슬롯과 장비창3쪽을 사용하며 MR +2·경험치 +1%를
적용한다. 탑 이동·퀘스트·세트 활성화는 별도 조건으로 남긴다. Item188384의
ClassID0/빈 직업명도 그대로 보존하며 전체 직업 허용으로 바꾸지 않는다.
확인된 장비 직업·레벨 조건은 실제 장착 경로에서 추가 검사하며 기존 호스트
무기 허용 조건도 유지한다.

퀘스트 조건78행과 테스트 아이템 정의는 보존·표시하고 해당 드랍에서는 제외한다.
스폰 IsSpawn·서버집합·시간표·영역을 드랍 표로 활성화하지 않는다. PR230도
실제 개체 수·좌표·주기를 완성했다는 뜻이 아니다. 원본 NPC 픽셀 팩 설치와
검증된 생성 문맥은 기존 원본 몬스터 경로의 별도 조건이다.

## 재현·전달

Library 정식 materialize로 원본523 ZIP과 기존 분석 인계2ZIP을 실제 읽고 CRC를 확인했다. 최신 원본
`lineagem_patch523_all_content_validated_and_508_520_deltas.zip` SHA-256:
`d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`.
사용한 모든 표는 index.json의 SHA·CRC·바이트·행 수를 확인한다.
공개 Git에는 코드·합성 검사·문서만 담으며 원문은 별도 Library 설치 ZIP이다.

```sh
python3 tools/monsters/build_patch523_monster_drops.py \
  --source /private/validated523 --catalog data/catalog_v19.json \
  --output /private/patch523-drops
python3 -m unittest discover -s tests -p 'test_patch523*py' -v
```

새 monster_drops.bin:1,806,317B,
SHA-256 `bec901d26a7766f2c77e9781ce636f17c14e7ba1b33617840eb5a5d5123bafd3`.
실행 옵션 `--patch523-drop-root=/private/patch523-drops`를 지원한다.
기본 설치는 `user://lineagem_patch523_drops/<SHA>/monster_drops.bin`이다.

## 검증과 한계

확률 구간 경계 검사와 실제 PCG RNG seed501/2607/67649로 일반 몬스터의
전설/신화/유일 획득을 검사한다. 난수나 확률 함수를 덮어쓰지 않는다.
실제 원본 NPC 행의 새 전설 무기126592를 일반 추첨으로 선택해 실제 Main에서
바닥·습득·원본 옵션·장착·저장/재로드까지 검사한다. 기존 축복 장비와
원본 화폐·HP 회복 물약도 실제 바닥 습득·기존 재화·사용 경로를 확인한다.

미설치 팩 거부, 실제 원본 설치/손상 거부, 기존 드랍 회귀와723시트/41,442
