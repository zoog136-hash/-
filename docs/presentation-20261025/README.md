## 실제 연결한 변경

- 창고/제작/판매·이동/컬렉션 전용 아이콘과 알 수 없는 이름의 중립 아이콘. 기존 아이템/스킬 ID·아이콘 원본은 유지한다.
- 공통 창의 절제된 표면, 버튼/탭/입력칸의 명암 테두리와 눌림/비활성 상태. 재질은 팔레트별 캐시를 사용한다.
- 854×480 카드 상세에서 원화/설명 영역이 사라지던 기존 문제를 최소 높이·스크롤 너비로 수정했다. 변신·인형·성물 원화/프레임은 그대로다.
- 실제 일반 공격 신호·명중/피격·성공한 바닥 드랍/습득·버튼/창 전환에 기존 자체 WAV를 연결했다. 월드4/UI2 음성의 고정 풀과 동종 중첩 제한을 사용한다. 기존 스킬 음향/뽑기·강화 효과는 보존한다.
- 미니맵 정적 지형을 실제 화면 픽셀 크기로 한 번 렌더해 재사용한다. 기존 모든 보스 점·지형을 유지하고 플레이어/몬스터/카메라 표시와 입력은 원래 경로에서 갱신한다. 지도·크기·표시 배율·소수점 위치 변경 시 재생성한다.
- 정적 미니맵 polygon 교차 캐시, 정지 native 카메라의 반복 가시성 작업 생략, 도달 가능한 AUTO 후보의 가까운 순서 탐색. 통행·타깃 선택 결과·거리/속도·피해·경제 규칙은 바꾸지 않는다.

## 검증과 남은 범위

사전/사후 필수 리소스723시트·41,442프레임 SHA 검사를 실행했다. 국소 검사 원본·첫 실패·재검사와 각 summary는 `evidence/`에 보존한다. 기존 assertion이나 임계값을 삭제·완화하지 않았다. 새 테스트의 `_RESULT` 출력은 기존 runner가 요구하는 JSON으로 고쳤고, 화면 캡처 중 임시 기준 파일 교체와 겹친 음향 검사 한 건은 현재 파일로 다시 실행했다. 이후 기준 캡처는 별도 overlay로 분리했다.

[국소 검사 집계](validation.json): 선택한 **16개 검사 각각의 최종 결과 PASS**. 이는 여러 국소 실행/재검사의 최신 결과를 합친 것이며 한 번의 전체 suite16/16 또는 전체 CI 통과가 아니다. 새 재질37·작은 상세25·AUTO 선택106 단언, 실제 음향/드랍/전투 타이밍·기존 UI·창고 회귀를 포함한다.

[성능 측정](performance/README.md)과 [현재 실행 경로 점검](PERFORMANCE_SCOPE.md)을 함께 읽어야 한다. 초기 CPU 반복 작업 수정만으로는 p95/max 개선을 입증하지 못했다. 이어 같은 실행 인스턴스에서 미니맵의 정적 렌더 비용을 분리하고 캐시로 수정했다. 동일 정지 장면의 draw call은 2467→272, 중앙 프레임 시간은 33.067→12.036ms(반복 26.427→13.371ms)였다. 생존용 HP를 테스트에서만 높인 16초 고정 시뮬레이션 전투의 교대 구간 비교는 p95 50.361→28.109ms, p99 59.632→34.133ms, 최대 66.908→49.012ms였다. 전투는 같은 월드에서 서로 다른 시점의 448프레임씩이며 전환 후 8프레임을 제외했다. 첫 활성화/로딩 끊김 해결의 증거는 아니다. 초기 악화/첫 실패 결과도 보존한다. Android 실기·GPU 하드웨어·장기 전투·장기 대량 드랍 검증은 미수행이며 전체 렉 해결을 주장하지 않는다.
