# 구현된 범위와 남은 표현 작업

구현: 공통 창/버튼/탭/입력 재질, 서비스 아이콘, 작은 카드 상세 표시, 일반 전투·드랍/습득·버튼/창 전환 음향. 기존 실제 메뉴 31상태의 전후 화면과 대표 사냥 흐름을 검증했다. 이는 각 메뉴의 원작 전체 재현 완료가 아니다.

- **메뉴:** 모든 장착/잠금/비활성/긴 이름 조합의 전수 시각 검수, 전체 상세창의 원작 재질·장식 일치는 미완료다. 기존 아이템 이미지에 포함된 워터마크/글자도 보존되어 남아 있다.
- **전투/카메라:** 새 평타·마법·원거리 VFX 아트, 원작 영상 프레임별 방향/타이밍 비교, 맵 구조물 비례·가림·그림자의 추가 시각 보정은 이번 PR에서 구현하지 않았다. PR122 계약 및 PR153/155 전용 작업과 분리한다.
- **각성/문양/수호성:** PR152/154 미병합 기능을 중복 제작하거나 가져오지 않았다. 해당 전용 외형·연출 개선은 별도 담당 작업이다.
- **뽑기/합성/강화:** 기존 등급·번개·확정 순서·확률과 음향을 유지했다. 새 원작 고증 연출로 교체하지 않았다.
- **음향:** 기존 자체 WAV를 실제 이벤트에 연결한 개발 근사다. 원작 음색 대조·실청취·Android 오디오 지연 검증은 미수행이다.
- **성능:** 미니맵 렌더 비용, 정지 visibility와 성공 AUTO 탐색을 다룬다. 동적 문 지도/계속 움직이는 좌표의 도달 불가 AUTO 탐색, 첫 전투의 최대 순간 비용, 장시간 드랍/전투 및 Android GPU 검증은 남는다. 개체/화질/전투 규칙을 낮추지 않는다.

전체 CI는 최신 사용자 지시로 보류한다. Library 저장은 기존 HTTP401 인증 차단이 해소되지 않아 재시도하지 않았다.

후속에서 native 불변 그래프의 동일 좌표 실패 재사용과 지도 구성 중 중복 안전 판정을 구현했다. 장착/선택/잠금 및 상점 구매불가·긴 이름·가격 정렬도 실제 화면으로 보완했다. 자세한 측정·검사는 [후속 결과](followup/README.md)를 참고한다.

첫 전투의 경로 밖 비용은 연속 프로파일에서 2D 물리 서버 구간으로 확인했고, 새 개체를 최종 스폰 좌표에서 등록하도록 수정했다. 동일 장면 두 쌍의 첫 프레임은495.879→307.963ms,501.782→306.535ms였고 물리 구간 최대는179.325→3.215ms였다. 이후 cold 경로 탐색의 큰 지연은 계속 남는다. [측정·실제 수정·남은 제한](performance/spawn-registration/README.md).
