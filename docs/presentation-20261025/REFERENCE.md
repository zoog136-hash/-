# 표현 기준과 확인 범위

기준 소스는 2026-10-25 직접 확인한 main `cba19558`이다. 리니지M 공식 [메뉴 및 UI 소개](https://lineagem.plaync.com/guidebook/view?title=메뉴%20및%20UI%20소개), [아이템 소개](https://lineagem.plaync.com/guidebook/view?title=아이템%20소개)의 실제 CDN 화면을 다시 내려받아 열었다. URL·날짜·SHA는 `sources.json`에 있다. 분석용 타사 이미지는 공개 자산으로 추가하지 않았다.

2021 가방/2022 HUD의 역사적 화면 계열을 기본 표현 참고로 삼았다. 이 둘을 동일 클라이언트 빌드나 2026 최신 화면으로 단정하지 않는다. 성물은 후대 시스템이므로 모든 비교 대상을 같은 역사적 버전으로 입증하지 못했다. 공식 영상 채널은 확인했으나 영상 프레임 분석은 미수행이다. 아래 구현의 색상·음량·타이밍은 개발 선택이며 원작 측정치가 아니다.

| 비교 대상 | 확인한 기준 / 구현 목표 | 측정·보존 한계 |
|---|---|---|
| 일반·보스 사냥 / HUD | 중앙 필드를 크게 유지, 얇은 HP/MP, 가장자리 조작부, 절제된 작은 글자 | 공격 프레임·발 기준·캐릭터 아트·몬스터 스케일은 변경하지 않음 |
| 전체 메뉴 / 창 | 어두운 갈색 표면, 위/아래 명암이 다른 얇은 테두리, 사각 버튼 | 실제 원작 텍스처 복제 아님; 현재 창 위치와 터치 정책 유지 |
| 가방 / 상세 | 우측 약 30% 폭·4열, 검은 슬롯 속과 밝은 아이콘·숫자 | 기존 외곽 378×508/1280×720 유지; 모든 픽셀 동일 주장 없음 |
| 캐릭터 / 장비 / 스탯 | 제목→항목→보조 수치 위계, 장비 상태와 선택 구분 | 기존 24부위·수치·ID·스크롤 데이터 유지 |
| 스킬 / 퀵슬롯 | 선명한 아이콘·어두운 홈·독립 페이지와 사용 상태 | 공격 속도·쿨타임·프레임·스킬 시각 작업 PR153 보존 |
| 변신 / 인형 / 성물 | 공통 창 표면·선택/비활성 구분 적용 | 카드 원화·애니메이션·등급색·뽑기/합성 규칙 보존; 동일 버전 원본 비교 미완료 |
| 컬렉션 / 강화 | 공통 위계와 버튼 상태 적용 | 기존 강화 확률·비용·등급별 결과 효과 유지 |
| 상점 / 창고 / 제작 / 판매 | 서비스별 구별되는 아이콘, 실제 목록/거래 흐름의 공통 표면 | 상품·제작·경제 규칙 미변경; 문양/수호성 PR154 미이식 |
| 상태 / 전환 | 눌림은 안쪽 그림자, 선택은 얇은 밝은 변, 비활성은 낮은 대비 | 원작 전환 밀리초 미측정; 인위적인 지연 추가 없음 |

공식 화면의 안내용 청록색 사각형과 번호 원은 게임 UI가 아니므로 구현하지 않았다. 네온·유리·둥근 대시보드 효과나 금박 장식을 추가하지 않는다. 기존 밝은 치명타/드랍 및 유일 에메랄드·카드 내부 번개/확정 순서는 이번 변경 범위 밖에서 보존한다.
