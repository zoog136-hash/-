# 최신 맵 기준 몬스터·보스 재배치 — 1차 구현 / 실행 검증 대기

기준: `main@f759112bca672ef909cc695a98fa99b1b123e1d3`. 작업 브랜치: `feature/renewed-map-spawns-20261012`.

이 문서는 구현된 규칙과 실제 검증을 구분한다. **Python 규칙 검사 7개만 실행해 통과했다. Godot 파싱, 실제 25개 맵의 생성·동선·수용량, 전체 게임 회귀, 리소스 무결성 재검증은 이 변경에 대해 통과가 확인되지 않았다. 병합·배포 완료가 아니다.** 로컬 작업 환경에 Godot 및 전체 저장소 체크아웃이 없었으며 최초 GitHub Actions 실행은 runner 대기 상태였다. Draft PR의 최종 SHA에 대한 CI 결과가 승인 기준이다.

## 적용 구조

기존 `world_spawn_profiles.json`을 역사적 입력으로 보존하고, `TwilightMonsterCatalog.apply_map()`에서 현재 맵 정의를 읽은 뒤 `renewed_map_spawns.gd`가 재배치 규칙을 적용한다. **이 브랜치에서는 기존 JSON만 읽으면 실제 배치를 알 수 없다.** 최종 배치는 기본 프로필 + 현재 지형/진입점 + `data/monsters/renewed_map_spawn_rules.json`의 결합이다. 검증 실행은 이 결합 결과를 `renewed-map-spawns.json`으로 출력한다.

옛 문서의 사각 좌표를 최신 맵에 복사하지 않는다. 맵 ID, bounds, 지형·충돌, NPC·포털·도착점, 기존 스폰 ID는 유지한다. 기존 보스의 저장 키도 유지하며, 보스 저장 데이터 자체를 삭제하거나 새 게임으로 초기화하지 않는다. `l1_4` 등 별도 원본 맵 팩은 대상에서 제외한다. 몬스터 DB·전투 수치·AI·드롭 테이블·바닥 드랍 경로는 변경하지 않는다.

## 배치 정책

| 범위 | 구현된 변경 |
| --- | --- |
| 아덴 | 지역별 종 구성을 유지하면서 총 132마리를 구역별 10~14마리로 재분배. 흑장로는 용의 계곡, 데스나이트는 폐허의 현재 구역 범위에 상대적으로 배치한 전용 보스로 분리한다. 기존 드레이크·샌드 웜·피닉스의 ID와 시간은 유지한다. |
| 오만 1층 | 층 전체 제니스 퀸 출현을 제거하고 최신 맵 `review_points.boss` 중심의 960×720 월드 픽셀 범위로 제한한다. 지형 충돌과 진입점 제외 규칙을 추가 적용하므로 실제 유효 면적은 더 작을 수 있다. |
| 오만 2~10층·신념·에스카로스 | 현 사냥 구역 범위를 유지하되 입구와의 거리 순서에 따라 일반몹 수와 종 조합을 재분배한다. 각 맵의 기존 일반몹 총수는 유지한다. |
| 알비노 4구역 | 중복 알비노 데몬 슬롯을 일반 사냥 구역으로 전환하고, 1~3구역의 기존 일반 몬스터 풀을 조합한다. 일반몹 총수는 42마리로 유지한다. 새로운 보스 이름·능력치는 만들지 않는다. 기존 `boss` 구역 ID는 보존하되 mode가 normal이므로 예전 보스 상태는 사용하지 않는다. |
| 지배 정상 | 흑장로·데스나이트를 일반몹 목록에서 제거한다. 남은 같은 맵의 일반 몬스터 풀로 24마리를 재분배하고 그림 리퍼 전용 보스는 유지한다. |
| 전체 | 전투·보상이 사용하는 `loot_drop.gd::is_boss_record`와 같은 판정으로 모든 일반/폭젠 목록에서 보스를 제외한다. |

입구 원점에서 구역 중심까지의 **직선 거리**로 초기 진행 순서를 정한다. HP·공격 주기·원거리·선공·동료 호출을 고려한 점수로 종을 정렬하되 이는 초기 배치용 휴리스틱이며 최단 이동 거리나 실제 플레이 난도 검증이 아니다. 미배치 141종을 전부 억지로 투입하는 작업도 아니다.

| 아덴 구역 | 일반몹 상한 |
| --- | ---: |
| 초원 / 숲 / 동부 | 각각 10 |
| 강변 / 폐허 / 산적 / 오렌 / 풍룡 | 각각 12 |
| 사막 / 용의 계곡 / 화룡 | 각각 14 |
| 합계 | 132 |

설정상 전체 예산은 일반 **1,072**, 폭젠 **96**을 유지한다. 전용 보스는 기존 27슬롯에서 알비노 중복 1슬롯을 빼고 아덴 2슬롯을 더해 **28슬롯 / 28종**을 기대한다. 실제 생성 수는 반드시 런타임 검사 결과로 확인한다. 모든 맵의 개체가 동시에 활성화되는 수치가 아니다.

기존 일반·폭젠·전용 보스의 재출현 간격은 유지한다. 일반 사냥터로 전환된 알비노 4의 옛 보스 슬롯만 25초로 바뀌며, 새 아덴 보스 두 종은 600초다. 현실 시간표가 아닌 기존 게임 내 경과시간 정책을 사용한다. 드롭 데이터를 유지해도 종 조합·보스 출현 방식 변화로 시간당 보상은 달라질 수 있다.

## 출현 제외 영역과 호환성

현재 맵의 진입점, NPC, 포털 및 다른 맵에서 지정한 도착점을 보호한다. 안전지대 경계는 96픽셀 더 넓게 잡고 주요 도로 중앙 140픽셀 폭에는 직접 생성하지 않는다. 일반몹은 폭젠 구역 바깥 48픽셀, 일반·폭젠 몬스터는 보스 구역 바깥 96픽셀 여유를 둔다. 이는 **직접 생성 위치**를 제한하는 것으로 일반몹이 전투 중 통로로 이동하지 않는다는 보장은 아니다.

`map_region_geometry.gd`에 제외 영역(holes) 판정을 추가한다. 기존 `PlayableField`의 후보 셀 생성·샘플링·저장된 보스 원점 검사와 같은 판정을 공유한다. 보스의 patrol/encounter도 현재 영역으로 제한한다. 영역 밖에 저장된 과거 위치는 기존 유효성 검사에서 거절되어 새 유효 위치를 사용하고, 기존 HP·리스폰 상태를 초기화하지 않는다.

기존 지형 캐시 서명은 실제 스폰 정의를 포함하므로 새로운 규칙에서는 옛 캐시가 자동으로 무효화된다. **첫 맵 로딩 시간과 캐시 재생성 비용은 아직 측정하지 않았다.** 최종 적용 전 25개 맵의 새 캐시 생성 또는 실제 로딩 시간 확인이 필요하다. 원본 아트·바이너리·배포 팩은 변경하거나 새로 전달하지 않았다.

## 검증
