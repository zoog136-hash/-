# 아덴 플레이어블 필드

기준: `zoog136-hash/-`의 `main` HEAD `e08f8523311aa773657216ee8244a0e47c785da9`.
기존 ZIP이나 다른 작업 폴더의 프로젝트 코드는 사용하지 않았다.

## 실행

Godot **4.7.2**에서 이 저장소의 `project.godot`를 가져온 뒤 F6가 아닌 **F5**로 실행한다.
첫 실행은 에셋 가져오기를 마칠 때까지 기다린다. 실행 맵은 기존 ID `aden_world`다.
다른 맵에 저장된 캐릭터는 기존 맵 메뉴에서 `아덴 · 은빛 변경`으로 이동하면 된다.

- WASD/방향키 또는 기존 조이스틱: 직접 이동. 수동 조작은 자동사냥을 해제한다.
- 필드 클릭/터치 및 미니맵 클릭: 해당 지점까지 경로 이동.
- T / AUTO: 기존 전투·경험치·드랍에 연결된 자동사냥.
- F7: 이동 제한 격자 표시. 캐릭터 반경을 포함한 경로탐색 여유 공간까지 표시한다.
- 마을 청록 이동석: 폐허로 이동. 폐허 이동석: 마을로 복귀.
- 동부 탑 입구: 기존 `oman_01`. 탑의 청록 귀환 원: 아덴 복귀.
- 마을 상인 근처에서 상인을 누르면 기존 상점, 순찰대장은 길 안내를 연다.

## 구현 범위

아덴 한 지역을 우선 구현했다. 기존 나머지 **24개 맵과 그 데이터/메뉴를 보존**했다.
오만의 탑의 기존 맵을 포탈 목적지로 연결했으며, 다른 맵의 고품질 재제작이 완료된 것은 아니다.
이 필드는 독자적으로 설계한 게임 지형이다. 공식 리니지M 지형이나 자산의 추출본은 아니다.

건물·나무·바위·벽의 도형과 강 도형이 물리와 내비게이션의 공통 원본이다.

## 검증 기록

1. 작업 전: 기존 11개 smoke test 모두 통과, Git 작업 트리 변경 없음.
2. 구현 후: Godot headless import, `Main.tscn` 실행, 기존 11개, 신규 필드 테스트 통과.
3. 필드 검사 **1,452항목**: 두 다리의 장애물 우회, 물리 ray 및 강 진입 차단, 실제 클릭/조이스틱 이동,
   자동사냥 접근·처치·경험치, 4개 뷰포트 크기 × 2개 줌의 Android 터치 변환,
   미니맵 역변환, 6구역 스폰, 재생성 지연, 포탈 왕복, 현재/과거 저장 호환.
4. 실제 OpenGL 렌더링: 마을·초원·다리·폐허·숲 화면 확인. 한글 누락, 도로 텍스처 곱셈,
   최초 import 전 프로젝트 글꼴 로딩 오류를 수정했다.
5. `.godot` 및 import 메타데이터가 없는 새 checkout에서도 import/boot/12개 테스트 전부 통과했다.
6. 참조하는 scene/field 리소스 경로 누락 없음. `git diff --check` 통과.

```bash
python3 tools/test_project.py --godot /path/to/Godot_v4.7.2-stable_linux.x86_64
# 개별 필드 검사
godot --headless --path . --script res://tests/field_world_test.gd
# 실제 화면 확인 (GL 디스플레이 필요)
godot --path . --script res://tests/capture_field.gd
```

CPU 소프트웨어 렌더러 **Mesa llvmpipe, 1280×720**의 5개 화면에서 프레임 간격 중앙값
**22.7ms**, 95백분위 **37.6ms**를 관측했다. 화면별 draw call은 **241–299**,
생성된 소품은 **140–266개**였다. 이는 Android 기기 성능 측정이 아니다.

## 남은 확인과 다음 확장

- Android 실기기의 발열·배터리·30–60 FPS 지속성, 실제 손가락 조작은 아직 검증하지 않았다.
- 물리 도형과 내비게이션 격자는 활성 맵 전체를 유지한다. 소품은 구역별로 제한하며,
  몬스터는 AI sleep을 사용한다. 개체 pooling은 아직 적용하지 않았다.
- 환경 에셋은 제한된 변형을 사용하는 첫 아트 세트다. 최종 상용 수준 판정에는
  사용자 플레이 리뷰와 지역별 추가 아트가 필요하다.
- 다음 순서는 오만의 탑 → 지배 → 에카 → 알비노 → 신념이다. 기존 맵을 그대로 유지하며
  각 지역에 별도 동선, 색조, 소품 세트와 검증 데이터를 적용한다.
