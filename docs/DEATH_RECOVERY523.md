# 사망 패널티·복구·부활 연결

기준 main은 `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`이다. 기존 사망 처리는 즉시 HP/MP를 회복하고 아데나500을 차감했다. 이 변경은 실제 독/출혈/피격 사망을 저장되는 사망 상태와 손실 보관, 무료 시작 지점 부활, 복구 확인 화면으로 연결한다. **사용자가 지정한 무료 경험치 복구 기본2회**를 레벨에 관계없이 유지한다.

## 사용

- 사망 화면에서 손실을 확인한 뒤 **현재 지역 시작 지점에서 부활**한다. 이 지점은 기존 게임의 `_spawn_position()`이며 원작 마을이나 원작 귀환 좌표라고 주장하지 않는다. 기존 위치·통행 검사를 유지한다.
- 전체 메뉴 → **사망 복구**에서 경험치 또는 물리 장비를 선택한다. 무료/구호증서/아데나/다이아 중 가능한 방식을 고르고 확인 또는 취소한다. 무료 횟수와 구호증서는 경험치에만 적용한다. 무료 기본2회를 모두 사용한 뒤24시간 이내에는 잠금 없는 영구 구호증서를 사용할 수 있다.
- 같은 화면에서 경험치/아이템 복구 슬롯을 각각 다이아50개로1칸 확장한다. 기본5칸·추가45칸 한도는 **자체 설정값**이다. 슬롯 초과 내역도 삭제하지 않고 앞선 내역 복구 또는 확장 후 이용하게 한다. 비용/대상/확인/취소와 실패 시 보존을 실제 거래로 연결한다.
- 화면의 **원본523 규칙 ZIP 불러오기**로 기존 `lineagem_patch523_all_content_validated_and_508_520_deltas.zip`을 설치한다. SHA256 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`,25,031,173bytes를 고정한다. 게임은 `user://source_rules/death523.zip`에 복사하고 다음 실행에 다시 읽는다. 다른 ZIP은 기존 팩과 저장을 보존하며 거부한다.
- 원본 미설치 시에는 화면에 추정 정책을 표시한다. 경험치 손실5%/레벨²×12아데나를 자체 기본값으로 사용하고, 원본ID를 검증할 수 없는 아이템은 사망 추첨에서 제외한다. 원본 팩은 공개 Git에 넣지 않는다.

## 저장과 중복 방지

사망별 증가ID, 손실된 실제 경험치, 물리 장비 전체 사본, 시각, 당시 비용, 부활/복구 완료 영수증을 기존 Main 저장의 `death_recovery523`에 함께 저장한다. 인벤토리·장비·재화·경험치·레벨 상승·스탯과 무료 횟수는 기존 원자 저장이 성공한 뒤 공개한다. 레벨 상승은 기존 곡선·증가량을 사용한다. 장비는 원래 물리ID·강화·속성·불투명 사용자 필드를 유지한다.

사망 저장 실패는 하나의 보류 거래를 유지하며 무관한 자동 저장을 막고 화면에서 재시도한다. 같은 사망 콜백은 추가 추첨·차감을 하지 않는다. 부활 저장 실패는 위치와 사망 상태를 유지한다. 복구 확인 시 최신 revision/기한/비용/잔액/중량/소유권을 다시 확인한다. 중복 복구는 지급하지 않는다. 만료 기록도 감사와 복제 방지를 위해 보존한다.

과거 저장은 진행도 적용 전에 SHA 이름의 `.pre-death523-<sha>` 백업을 만들고 바이트를 확인한다. 손상된 새 상태는 로드·덮어쓰기 전에 거부한다. 보관 장비ID는 신규 장비 할당에서 예약하며 현재 장비·창고·바닥·컬렉션 영수증과 충돌하는 복구는 거부한다. 기존 원본/저장 파일·리소스 장부를 바꾸지 않는다.

## 검증 및 범위

재현용 검사는 `tests/death523_main_test.gd`이다. 실제 Main/current source-map와 별도 XDG 저장을 사용한다. 원본 규칙은 `--death523-source=<verified ZIP>` 인자로 읽을 수도 있다. `tools/ci_core_map_pack.py`와 `tools/ci_core.py --prepare-only`로 정확한 현재 main 리소스에서 실행 단계를 만든다. 전체 CI·워크플로·보호 규칙을 바꾸지 않는다.

현재 검증 결과와 실행 로그 SHA는 `docs/death523_validation.json`에 기록한다. 미실행 결과를 통과로 표시하지 않는다. Android/Windows 실기기·오디오·원작 전체 UI/사망 효과 동등성은 검증 범위가 아니다.

기존 열린 PR26개를 제목·본문으로 대조한 시점에 플레이어 사망 복구 전용 PR은 없었다. PR243의 탐험 카드 사망/부활은 별도 기능이라 변경하거나 병합하지 않았다. main 및 다른 PR은 병합하지 않으며 이 기능의 독립 브랜치/Draft PR만 게시한다. 투기장·지구라트·혈맹·공성·펫·일반퀘스트·M 엔진/APK 분석은 추가하지 않았다.

남은 범위: M 지역 지리 연결, 성향/PvP 환급·랭크 추가 무료횟수·장비 파괴, 원본 미수출 실행식과 이벤트 구호증서의 시즌별 만료/서버 계약, 타인 대상 부활·네트워크 부활 요청, 원작 확률·최종 비용·원본 아트 동등성. 작업 브랜치 및 후속 관측 main `fd3ef6bad12bd030cb40946bf9b96a5a35bf8d94`의 실제 world에는 성향 저장·살해자/피해자 계약이 없으므로 별도 PvP 도메인을 만들지 않았다. 현재 장착 물리 장비의 Death-stat 로컬 적용은 위의 검증된 하위 범위다. 카드/버프/랭크의 Death-stat 소유자는 이 하위 범위의 완료로 확대하지 않는다.

후속 구현도 PR253의 동일 브랜치·환경에서 수행했다. 관측된 main의 갱신을 병합/리베이스하지 않았으며, PR의 충돌/병합 가능 여부는 원격 스냅샷과 별도로 보고한다. 로컬 검증은 명시된 기반7d550a78 위의 이 PR 코드에 대한 결과다.
