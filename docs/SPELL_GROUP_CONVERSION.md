# 직업 내 스킬 계열 전환

Main의 전체 메뉴 또는 스킬 화면에서 ‘스킬 계열 전환’을 연다. 현재 직업의 원본 후보를 선택하고 비용을 확인한 뒤 확인하거나 취소한다. 저장에 성공한 경우에만 선택 계열과 실제 비용을 반영한다. 장비 교환과 전체 직업 변경은 별도 기능이다.

## 원본과 실행 지원 범위

검증된 최신 누적 523 ZIP을 `TWILIGHT_SPELL_GROUP_SOURCE` 또는 `--spell-group-source`로 지정한다. 원본 ZIP, 원문 표, 아트와 심화보고서는 공개 저장소에 포함하지 않는다. 잘못된 버전이나 SHA는 사용하지 않는다.

| 원본 범위 | 현재 적용 | 실행 제한 |
| --- | --- | --- |
| 직업 계열 설정 16행 | 현재 직업 후보, 학습 확인 조건, 효과 참조를 읽는다. | 다른 직업 선택으로 바꾸지 않는다. |
| 비용 1,200행 | 계열·회차·재료의 복합 키로 정확한 원값을 사용한다. | 정의가 없는 계열과 51회 이후를 무료 또는 임의 가격으로 보완하지 않는다. |
| 계열 구성 193행 | 원본 ID가 명시된 보유스킬의 mastery 사용 조건에 연결한다. | 구성원 전체를 배우게 하지 않는다. |
| 총사 대체 정의 4행 | 원본 정의를 보존하고 후보에서 구성을 표시한다. | 해당 계열의 비용과 기존 스킬 실행 연결이 없는 상태에서 대체 효과를 지급하지 않는다. |
| 심화 분석 28스킬과 관련 33표 | 전체 표와 원문 참조를 독립 감사한다. | 감사 통과는 원본 발동 RNG와 전체 전투 연산을 복원했다는 뜻이 아니다. |

현재 Main의 요정 `schools` 계약과 연결해 기존에 배운 물·땅 계열 패시브의 실제 활성 조건과 능력치가 바뀐다. 기존 학습 기록, 슬롯 배치와 자동사용 설정은 유지한다. 새 스킬은 지급하지 않는다. 로그인 때 안정적인 스킬 ID를 추가하는 기존 슬롯 마이그레이션은 유지한다.

다른 직업은 원본 선행 보유스킬을 확인할 수 있을 때만 진행한다. 어댑터는 `source_spell_class_id`, `spell_class_id` 또는 `domain=SpellClass.ID`와 `status=VERIFIED`가 명시된 기존 ID를 받는다. 이름이나 해시 ID로 원본 ID를 추정하지 않는다. 현재 Main에 이 대응이 없는 선행스킬은 보유 확인 불가로 차단한다. PR245를 병합하거나 해당 스킬 구현을 복제하지 않는다.

투사·총사 8개 설정에는 원본 비용행이 없다. 선택 화면은 이 사실을 표시하며 전환을 차단한다. 복수 속성 및 모든 속성 활성화의 원문 정의를 단일 속성 선택으로 대체하거나 미보유 스킬을 지급하지 않는다. 해당 특수 능력의 실행은 실제 보유스킬·보너스 어댑터가 제공될 때 별도로 연결해야 한다.

## 비용과 자체 정책

아데나는 기존 Main의 실제 `gold`를 사용한다. 촛불은 이름이나 아이콘이 아니라 정확한 523 품목 ID, 원문 품목, 실제 개체·수량과 잠금을 확인한다. 이름만 있는 과거 스택을 새 원본 개체로 바꾸지 않는다. 비용에 등록된 품목을 상점이나 드롭으로 임의 공급하지 않는다.

출발·도착 열이 없는 비용표를 선택할 계열의 키로 조회하는 방향, 회차를 캐릭터의 직업별로 누적하는 방식, 정의된 재료 중 한 결제 방법을 선택하는 방식은 명시적인 TWILIGHT 실행 정책이다. 요정의 아데나 또는 촛불 변경은 [공식 가이드](https://lineagem.plaync.com/guidebook/view?title=%EC%9A%94%EC%A0%95+%EB%A7%88%EB%B2%95)의 설명을 참고했다. 기존 캐릭터의 선택 계열은 보존하고 이전 전환 횟수는 만들어 내지 않는다. 기존 기본 물 속성을 유지한 상태에서 다음 변경에 원본 1회차 비용을 적용한다. 원본 성공률이나 서버 카운터를 복구했다고 주장하지 않는다.

원본 `TestItem=true` 재료는 기본적으로 사용할 수 없다. 별도 검토에서 필요한 경우에만 `--spell-group-policy`로 지정한 로컬 JSON의 `allow_test_materials`를 설정한다. 같은 설정의 `payment_mode`는 `alternatives` 또는 `adena_only`를 받는다. 설정은 소유권, 원문 ID, 비용과 잠금 검사를 우회하지 않는다. 기존 전투 수치는 현재 Main의 TWILIGHT 밸런스를 유지한다. 전환 효과 Sprite 참조를 실제 원본 연출이 있는 것처럼 재생하지 않는다.

## 저장과 검사

`spell_group_conversion` 네임스페이스에 버전과 `patch523` 식별자, 직업별 계열 및 회차를 보관한다. 원자 저장에 성공한 후에만 live 상태를 반영한다. 중복 확인과 변경된 견적은 다시 지불하지 않으며, 손상된 네임스페이스는 다른 진행도에 적용하기 전에 거부하고 저장을 보호한다.

전용 XDG 프로필에서 다음을 실행한다. 실제 플레이어의 저장 파일을 사용하지 않는다.

- `tests/spell_group_conversion_test.gd`는 비용 1,200행 전부, 복합 키, 원자 쓰기 실패, 중복·부족·잠금·정확한 촛불 차감 및 손상 상태를 검사한다.
- `tests/spell_group_conversion_main_test.gd`는 커밋에 추적된 기본 Aden 입력으로 실제 Main 메뉴, 기존 책 구매·습득, 확인·취소, 비용, 패시브 방어력, 원자 쓰기 실패, 슬롯·자동사용 보존, 새 Main 인스턴스 재접속과 손상 저장 복구를 검사한다. 촛불 소비는 격리 프로필에 준비한 원문 개체 fixture를 사용하며 실제 게임에 재료를 새로 공급한 것으로 계산하지 않는다.
- `tools/audit_spell_group_conversion_source.py`는 원본 ZIP과 보고서 ZIP을 받아 관련 33표의 전체 바이트·행 및 원문 참조를 대조한다. 결과는 비공개 경로에 보관한다.

로컬 검증 기준은 main `1d8bd5e0`와 Godot 4.7.2이다. 원격 전체 CI, Android 실기기와 원작 동등성 검사는 실행하지 않았다. Main 검사의 기본 Aden 의존성 검증은 전체 84개 지도 승인과 구분한다.
