# 바닥 아이템 종류별 대표 이미지

이 변경은 `main ca90291`에서 시작한 바닥 표시 전용 개선이다. 전체 아이템을 원본과 1:1 대응시키는 작업이 아니라, 드랍된 물건의 종류를 구분할 수 있도록 기존 리소스를 대표 그림으로 재사용한다.

## 표시 경로

`ItemVisualResolver.describe(..., ground=true)`에서만 새 규칙을 적용한다. 기존 검수된 바닥 그림과 별도 L1J 바닥 후보는 그 경로와 출처를 유지한다. 그 외 아이템은 `scripts/ui/ground_item_icons.gd`의 종류·슬롯 규칙과 `data/ground_item_icons.json`을 사용한다.

장비의 슬롯과 종류를 이름 검색보다 먼저 검사한다. 따라서 미스릴 갑옷은 광석이 되지 않고, 마력의 지팡이는 물약이 되지 않는다. 체인소드/체인 소드, 핸드캐넌/핸드 캐넌, 마검/룬소드와 반지·귀걸이·인장의 슬롯 변형을 처리한다.

대표 분류에는 무기, 투구, 갑옷, 각반, 티셔츠, 망토, 장갑, 신발, 방패, 견갑, 장신구, 물약, 주문서, 음식, 엘릭서, 드래곤 보석, 아데나, 제작 재료, 탄약 등이 포함된다. 분류하기 어려운 재료·기타 항목은 명시적인 공용 물품 대표 그림을 사용하며 특정 원작 아이템과 동일하다고 표시하지 않는다.

## 그림과 원본 보존

기존 바닥 전용 PNG가 있는 대표 종류는 해당 소스를 사용한다. 나머지는 저장소에 이미 있는 L1J 또는 인벤 이미지에서 표시용 그림을 만든다. 원본 PNG 파일은 수정하지 않는다. 파생 PNG는 `assets/ground_categories/`에만 저장한다.

이미지 경계와 연결된 단색 배경을 투명하게 하고, 물건의 가로·세로 비율을 유지하여 64×64 투명 캔버스에 배치한다. 드랍 렌더러의 기존 32×32 표시 영역을 사용하며, 등급별 빛기둥·입자·선택 고리는 바꾸지 않는다. 출처 경로·이름·SHA-256과 파생 파일 SHA-256을 연결표에 기록한다. 대표 이미지의 참조 ID는 게임 아이템의 sourceId로 복사하지 않는다.

## 변경하지 않는 것

인벤토리/퀵슬롯/상세정보용 이미지, 아이템 이름·등급·수량, 능력치·강화·속성, 드랍 확률, 소유권·물리 아이템 ID, 수동/AUTO 습득 및 저장 데이터는 유지한다. 이름은 기존 선택 정보창과 툴팁에서 실제 이름으로 표시된다. 검사용 캡처에 추가한 항목별 이름 자막은 테스트에만 존재하며 게임 UI를 변경하지 않는다.

## 검증

`tests/ground_category_probe.gd`는 실제 Main의 런타임 도감·기본 DB·자연 드랍 풀을 검사한다. 최초 적용 전/후 인벤토리의 이미지 조회 결과와 픽셀 SHA를 대조한다. 실제 드랍 생성, 원래 이름 표시, 등급 이펙트 설정, 드랍 저장·복원, 잘못된 원본 ID 거부를 확인한다.

기존 인벤토리·바닥 드랍·습득·창고·아이템 인스턴스 및 실제 입력 상호작용 회귀도 실행한다. `tests/capture_ground_categories.gd`는 실제 Main에서 장비와 소모품 두 묶음의 화면을 생성한다. 가짜 전투 장면이나 새 3D 장면을 사용하지 않는다. Android 실기기 테스트를 대신하지는 않는다.

그림과 연결표를 오프라인 검사하려면:

```sh
python3 tools/ground_icons/build.py
```

소스를 의도적으로 바꾼 뒤 표시용 PNG와 연결표를 재생성하려면:

```sh
python3 tools/ground_icons/build.py --write
```

Godot 실행·검증·캡처:

```sh
python3 tools/ground_icons/verify.py --godot /path/to/godot --output /tmp/ground-icons
```

이미지 생성/검사에는 CI에서 고정한 Pillow 버전을 사용한다. Linux 화면 검증에는 Xvfb가 필요하다. CI는 실제 오디오 장치가 없으므로 명시적인 Dummy 드라이버로 실행하며 게임의 오디오 설정은 수정하지 않는다.
