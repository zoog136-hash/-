Implementation-only, with no additional tests, parsing, game execution, rendering, quality checks or source audit. Actual generated-byte reproduction and model acceptance remain unobserved. Historical pass counts and the58/146 bounded item record are unchanged.

These are the data owner's existing parser/projection code, not a second loader or compiler. Integration merges only the input/contract hooks and preserves its existing transaction methods and quest gate/reward changes.

World._load_patch523_equipment keeps every explicit equipment environment selection (including empty/SHA-only) and existing active index on the file loader path. It keeps the original slot/source row/item/amount/blessing/enchant and recipe qualification/failure policies. Integration's separate physical quest choices, source proof, remaining quantities, immutable first-consumer receipt, source output lineage, fees, RNG, usage/log and common save remain. The existing source-row and typed physical selection maps are both reset on a genuine accepted install; invalid replacements retain the prior registry/ownership. Existing equipment option refresh and source identity rules stay with their current owner.
