## 원본 대조

현재 환경에서 최신523 ZIP **25,031,173바이트**, SHA256 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`, 전체 ZIP CRC를 검증했다. 원본 1,065개 Content 표/2,323,700행의 바이트 SHA·행 수·타입을 읽어 가호와 재료의 참조를 검사했다. 전체 원문은 ZIP에 보존하고, 게임은 관련 행만 검증된 별도 실행 캡슐로 추출한다. 원문 읽기와 실제 지원 기능을 구분한다.

- ItemClass7개 중 정상6개를 실행한다. 327823/제작222693은 사용 안함으로 보존한다.
- ItemBonus60행·9타입은 정상6종52행과 사용 안함1종8행이다. 사용·보유·재료·재사용·제작 호칭·시각 효과 ID를 분리한다.
- 직접 BuffClass14개·BuffBonus14행·Appellation7개를 대조했다. 이 경로의 **Appellation.RewardID는 BuffClass**이며 일반 Reward로 조인하지 않는다.
- 정상 제작 View/Output/Restriction 각6행, 재료12행을 실행한다. 사용 안함 출력1행은 활성 View가 없고 실행하지 않는다.
- Group604 전체21버프/23아이템 관계도 읽었다. 정상의 가호·발록 계열 등 기존 버프와 중첩을 차단한다. 이23종을 새로 공급/활성화했다는 뜻은 아니다.

전용 심층 보고서는 `TWILIGHT_523_immortal_destruction_protection_growth_layers_20261104.zip`으로 식별했다. Library 다운로드 헬퍼는 HTTP401로 실패했고 반복하지 않았다. Library 텍스트 읽기에는 본문이 없었다. 보고서 바이트를 직접 읽었다고 주장하지 않는다. 부모가 전달한 층/네임스페이스/제외 사실을 원본과 재대조했다.

공식 공개 검색에서도 [9월23일 안내](https://lineagem.plaync.com/board/update/view?articleId=6ab2d738fa34c1011d6278ab), [10월29일 개선](https://lineagem.plaync.com/board/update/view?articleId=50539052), [7월16일 제작](https://lineagem.plaync.com/board/update/view?articleId=6876ac380b9023678f8eca3d)의 제작·보유/사용 구분을 확인했다. 실행 수치는 고정된523 표에서 가져온다.

보유 효과는 현재 소지권에서 계산한다. 설치만으로 지급하지 않는다. 바닥에 내려놓으면 보유 효과가 빠지고 실제 습득으로 돌아온다. 일반 창고 보관·매입은 거부한다. 과거 보관품의 출고는 허용한다. 원본 IsDroppable=true의 플레이어 바닥 이동을 유지한다.

인벤토리 활성화 → 확인 → 명예 코인3631 10개 차감 → 버프/해당 아이템 재사용3600초를 함께 저장한다. **Category10204 본체는 소모하지 않는다.** Group604 버프는 하나다. 사망/기존 부활은 본체·코인을 소비하거나 버프를 지우지 않는다. 사망 면제·부활권으로 만들지 않는다.

제작 성공에만 영구 호칭을 부여한다. 기존 소지품으로 과거 제작/호칭을 발명하지 않는다. Group841의 이6종 호칭은 최고 단계 하나를 적용한다. 일반 리덕션은 기존 물리 경로와 별도 마법 피격 경로에 한 번씩 연결한다. 기존 독/출혈 피해 규칙은 보존한다.

재료·결과·호칭·횟수·코인·버프·재사용은 Main 원자 저장기에 사본으로 먼저 기록한다. 실패하면 메모리/이전 파일을 보존한다. 재접속 JSON 숫자는 호칭 ID 배열로 정규화한다. 손상·중복 확인·시간 역행·기한·잠금·물리 정체 충돌을 검사한다. 구형 저장은 변경 전 정확한 SHA 이름의 `.pre-protection523-<SHA>` 백업을 남긴다. 기존 quest_state와 즉시 완료 정책을 보존한다.

## 조정 가능한 TWILIGHT 정책

`data/protection/protection523_policy.json`은 원값과 다음 결합 규칙을 분리한다.

- 기존 단독 전투의 PvP→PvE 호환을 기본 유지한다. UI에서 원문 PvP 전용으로 바꾸면 몬스터 피해에 가호 PvP 층을 적용하지 않는다. 원본 수치·백분율 정밀도는 유지한다.
- 보유 여러 단계의 결합은 원문에서 확정하지 못했다. 기본 `highest`, 별도 `sum_distinct` 설정이다. 수량 중복으로 같은 단계를 여러 번 더하지 않는다.
- Group604 비중첩은 원본이다. 교체 순서만 `keep_stronger`/`replace`로 확인 후 선택한다. 기존 일반 Group604 효과는 만료까지 보류하여 근거 없는 효과를 덮지 않는다.
- 기본 시간은 게임 종료 중에도 경과한다. `elapsed_while_closed=false`는 실행 중 시간 정책이다. 이를 원작 오프라인 동작으로 주장하지 않는다.
- PR227 명예 코인 지갑은 이름·slot/type/weight/stackable/거래·드랍 플래그·설명 전체 계약이 맞을 때만 호환한다. 원본3631로 전역 재태그하거나 다른 스택과 합치지 않는다. 모호한 복수 소지키는 보류한다.

## 공급과 통합 잔여

가호7개의 일반 NpcItemDropView/상점/직접 Reward 공급은 없다. LuckyBagEntityView의 정상5개 참조는 테스트 LuckyBag80548이며 활성화하지 않는다. 정상 공급은 위6식이다.

최초 재료 정상3단123373의 상위 공급은 제작47273(정상2단75764 + 축복의 두루마리96014)이다. 두루마리200698은 퀘스트77992/81108/82768/85598/92713/92794/96201/101748의 보상 참조다. 표시 레벨91/92/93/94/95/95/96/97이며, 95의92713은 종료2016인 이전 행이다. 정상95는92794다. 목표/전제/기간·다른 보상도 감사에 보존한다.

**일반 원본 퀘스트 전체 및 그 전체 보상 지급은 이 작업에 추가하지 않는다.** 기존 임시10퀘스트를 삭제/비활성화하거나, 두루마리만 무료 지급해 퀘스트를 완료했다고 만들지 않았다. 신규 캐릭터가 일반 플레이만으로 정상3단/두루마리를 얻는 상위 공급까지 완료됐다는 뜻은 아니다. 이 공급은 일반 제작/퀘스트 담당과의 별도 의존이다.

PR239의 `patch523:<ID>`와 `patch523_crafting_usage.recipes`를 읽기 전용 대조했다. 정확한 기존 로그·중첩 장부·손상/blocked 상태가 있으면 중복 제작하지 않는다. 자체 영구 장부는200개 일반 로그가 잘려도 유지된다. PR239가 현재 이6식의 영구 제한 실행을 지원한다고 확인되지 않았다. 미래 활성화 시 가호 장부도 같은 거래 권위로 통합해야 한다. PR238 native ID/축복/proof 경계는 읽어 대조했지만 두 PR의 합친 실행은 하지 않았다.

원본 ItemConsumeEffectSpriteID107은 보존하되 네이티브 연출은 복원하지 않았다. 성공 표시는 기존 TWILIGHT 상태 글자다. 원본 아트·실제 오디오·Windows/Android 검증은 별도다. 엔진/APK·투기장·지구라트·혈맹·공성·펫을 추가하지 않았다.

## 설치와 재현

게임에서 검증된523 ZIP을 선택하거나 `--protection523-source-zip=/private/current523.zip` 인자를 사용한다. 보존 ZIP은 `user://protection523/source/<source SHA>.zip`, 실행 데이터는 `user://protection523/runtime/<capsule SHA>.json`, 활성 포인터는 `user://protection523/active.json`이다. 캡슐 SHA는 `a94475ac15454668ad1983de0b326b0c4be7e149bca02c342d913d5eef6bfa2d`로 고정한다. 다음 프로세스는 이를 검증해 복원한다. 원문·캡슐·감사는 공개 Git에 넣지 않고 새 외부 업로드도 하지 않았다.

    python3 tools/protection/audit_protection523.py \
      --source-zip /private/current523.zip --output /private/protection-audit

로그·화면·파일 해시는 로컬 `validation.json`과 `/workspace/protection523-private`에 기록한다. 원격 전체/수동 CI는 실행하지 않았다. Git 리소스723시트/41,442프레임/233,420,026바이트 검사는 통과했다. 과거 전체 `--source-dir` 검사는 a1.zip 부재로 실패하며 현재523 ZIP의 검증된 SHA/CRC와 구분한다.
