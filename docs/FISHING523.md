# 낚시, 자체 대회와 장비 교환

Main 메뉴의 **낚시·대회·장비 교환**에서 낚싯대 구매, 낚시 공간 입장, 챔질과 릴링, 물고기 획득, 장비 교환, 보상 사용을 진행합니다. 획득물은 원본 아이템 ID별 보관함에 기록하며 기존 캐릭터 세이브와 함께 저장합니다. 원본 지도의 물 셀은 검증되지 않았으므로 낚시 공간은 명시적인 TWILIGHT 자체 화면입니다. 입장 중 배경 월드를 정지하고 창을 닫으면 복귀합니다.

## 비공개 입력 설치

권한을 가진 사용자가 보유한 누적 523 ZIP을 다음 도구로 변환합니다. 도구는 다운로드하거나 암호를 해제하지 않습니다. 1,065개 표의 버전과 사용하는 표의 SHA를 검증합니다. 출력과 원본은 공개 저장소 밖에 둡니다.

```sh
python3 tools/import_fishing523.py OWNER_SOURCE.zip PRIVATE_RUNTIME.json
python3 tools/audit_fishing523.py OWNER_SOURCE.zip > PRIVATE_AUDIT.json
```

실행 시 `TWILIGHT_FISHING523_PACK`를 변환한 파일 경로로 지정하거나 해당 프로필의 `user://private_content/fishing523.json`에 설치합니다. 입력이 없으면 낚시 화면에서 필요한 입력을 안내하며 무료 보상이나 대체 원본을 생성하지 않습니다.

## 원본과 자체 실행 정책

- 낚시 분포 44행, 풀 확률 670행, 물고기 41행과 관련 낚시 표를 모두 읽습니다. 시간과 낚싯대 우선순위, 야간 경계, 난이도와 AI 매개변수, 직접 획득 아이템을 사용합니다. 미사용 풀과 확률 0행은 삭제하지 않습니다.
- 교환 6표 35행을 보존합니다. 낚시 `SystemType=1`의 확정 주화와 추가 확률 보상을 분리하고 다른 시스템의 같은 입력 ID를 합치지 않습니다. 강화 장비는 선택한 물리 ID로만 차감합니다. 잠금, 장착, 축복·저주, 각인, 기간, 수량 불일치를 거절합니다.
- 호스트의 기존 Inven 카탈로그 ID는 원본 ItemClassID가 아닙니다. 기본적으로 교환하지 않으며 사용자가 화면에서 명시적으로 허용한 경우에만 기존 호스트의 등급과 판매 규칙을 적용합니다. 이 선택은 자체 호환 정책입니다.
- 폴 카드 네 종은 정확한 원본 카드와 보너스 정의가 현재 호스트 정의와 일치할 때만 등록합니다. 중복은 같은 카드의 여분으로 저장하며 기존 합성·교체 제한을 유지합니다. 낚시의 네 상자 정의는 확정 보상과 확률 보상을 구별합니다.
- 대회는 원본 대상 어종, 최대 길이 N마리 합산, 순위 구간과 보상을 사용합니다. 참가자는 가상 점수이며 실제 서버 순위가 아닙니다. 낚시 길이는 원본 지역 범위·기본 길이 범위·낚싯대 가중치·수동 보너스를 자체 결합식으로 사용합니다. 원본 운영 일정은 보존하지만 자체 대회는 수동으로 시작합니다. 운영체제 시간은 바꾸지 않습니다.
- 클라이언트 표로 확인되지 않는 교환의 독립 판정 여부와 분모, 미니게임 게이지 적분식, 자동 판정 보간식, 길이 생성식, 자체 대회 기간과 가상 참가자 생성은 원본 서버 구현으로 주장하지 않습니다.

`user://private_content/fishing_policy.json`에서 자체 정책을 조정할 수 있습니다. 지원 키는 `host_equipment_exchange`, `simulate_opponents`, `game_hour`, `contest_seconds`, `exchange_denominator`, `independent_extras`, `cast_cost`, `length_min_coefficient`, `length_max_coefficient`, `gauge_rate_scale`, `auto_power_probability_step`, `minigame_timeout_seconds`입니다. 잘못된 정책 파일은 거래를 차단합니다. 게임 시간과 대회 기간, 호스트 장비 허용은 화면에서 변경하고 세이브에 저장할 수 있습니다.

## 보존과 남은 경계

확인 전 취소는 차감하지 않습니다. 중복 요청과 오래된 선택을 거절하고, 저장 실패 시 메모리의 비용·보상을 변경하지 않습니다. 중단된 낚시는 이미 쓴 낚싯대를 환급하거나 물고기를 추가하지 않습니다. 손상된 낚시 저장은 다른 상태를 적용하기 전에 거절하고 자동 저장으로 덮어쓰지 않습니다. 기존 퀘스트와 다른 기능의 상태는 유지합니다.

원본 아이템과 호스트의 정확한 연결이 없는 물고기·물약·장비 보상은 ID별 보관함에 보존합니다. 이름이 같다는 이유로 기존 아이템에 합치거나 장착 효과를 만들어 내지 않습니다. 따라서 해당 보상의 일반 가방 이동·장착·효과 전체가 구현됐다고 볼 수 없습니다. 원본 맵 이동, 서버 경쟁·우편, 원본 화면·음원 재현도 이 변경의 완료 범위가 아닙니다.

## 검증

`tests/fishing523_source_test.gd`는 실제 비공개 입력의 전행 참조와 확정 보상 분리를 검사합니다. `tests/fishing523_main_test.gd`는 격리 XDG 프로필에서 실제 Main 메뉴, 확인·취소, 비용, 물리 ID 보존, 쓰기 실패, 물고기 획득, 카드·상자·순위 보상 및 재접속을 검사합니다. 검사에서 사용하는 보유 장비와 보상은 명시적인 테스트 fixture이며 일반 플레이에 지급하는 경로가 아닙니다. 현재 원본 지도 팩도 필요하며 누락을 성공한 검사로 처리하지 않습니다. 헤드리스 통과는 시각 검수나 원본 엔진과의 동일성 증명이 아닙니다.
