# TWILIGHT UI 재작업 — 2026-10-12

기존 대형 공통 창과 사이드바를 창별 배치로 바꾸고, 마우스·터치 드래그를 실제 게임 상태에 연결했다. 가방과 스킬은 우측 소형 창, 캐릭터는 좌측 장비/스탯 창, 상세 스탯은 옆 창, 카드 계열은 등급·목록·미리보기·적용 영역, 일반 상점과 NPC 거래는 서로 다른 화면을 사용한다.

- 후속 통합: 작업 도중 들어온 최신 main `0258f413b756fb78106803b87f9525ec4c675372`를 작업 브랜치에 충돌 없이 통합했다. 키 바인딩·실패한 로드 상태 보존·제작 귀속·보호막 복원·CI 수정은 upstream 그대로 유지했다.

## 실제 변경

1. HUD의 무거운 상태 박스를 줄이고 실제 HP/MP·아데나·경험치·전투 상태를 유지했다. 퀵슬롯은 좌우 5칸, 각각 5페이지다. 가방·스킬의 우측 창 아래에서 계속 접근할 수 있다.
2. 가방은 기본 4열/확장 8열, 별도 상세 창, 정렬·검색·수동 순서·인스턴스별 강화/장착/잠금을 연결했다. 상세의 일반 사용과 장착 해제, Q등록도 동작한다. 장비·재료는 소비형 퀵슬롯 등록을 거부한다.
3. 모든 드래그는 `pointer_transfer.gd`의 단일 포인터 상태에서 처리한다. 화면상의 실제 대상에 놓아야 실행한다. 기존 가로 스와이프만으로 장착하던 동작은 제거했다.
4. 스킬은 실제 습득 여부와 ID, 사용 조건, MP/HP, 기본/보정 재사용 시간을 표시한다. 원작 확인·추정·TWILIGHT 자체 수치의 구별을 보존한다. 패시브·미습득·다른 직업 스킬은 등록을 막는다.
5. 변신·인형·성물은 실제 카드 DB와 별도 적용 상태를 읽는다. 선택과 적용을 분리하고, 적용/해제에 확인 창을 거친다. 클래스별 변신 추가 효과와 기존 옵션 정책을 바꾸지 않았다.
6. 캐릭터는 기존 화면에 빠져 있던 부위를 포함해 게임의 24개 장비 슬롯을 두 페이지로 제공한다. 기본 스탯은 최종값(기본+추가), 상세 스탯은 실제 계산 스냅샷을 표시한다.
7. 구매·판매·창고 수량 이동·강화·제작에는 확인 절차를 연결했다. 구매 가격·보유 수량·무게·장비 ID 검사는 기존 world 서비스가 실행 직전에 재검증한다. 확인 버튼을 연속 호출해도 한 번만 처리한다.
8. 검색창 입력 중 게임 단축키가 발동하지 않도록 UI 입력 초점을 존중한다. 맵·몬스터·충돌·전투 공식·강화 확률·가격 데이터는 변경하지 않았다.

## 조작 재현

마우스는 아이콘을 8px 이상 움직이면 드래그한다. 터치는 0.30초 길게 누른 뒤 움직이면 등록/이동이며, 그 전에 목록을 밀면 스크롤한다. 실제 경과 시간을 사용하여 느린 렌더 프레임에서도 길게 누르기를 판정한다. 포인터는 한 번에 하나만 소유한다.

| 동작 | 재현 방법 | 기대 결과 |
| --- | --- | --- |
| 아이템 등록 | 가방의 HP 물약을 하단 슬롯에 놓기 | 물약 수량은 줄지 않고 해당 슬롯에 등록 |
| 스킬 등록 | 습득한 액티브 스킬을 하단 슬롯에 놓기 | 이름이 아닌 정규화된 스킬 ID로 연결 |
| 버튼 등록 | 상세의 Q등록 → 실제 하단 슬롯 클릭 | 현재 좌/우 페이지의 해당 슬롯에 등록, 아이템은 사용하지 않음 |
| 이동/교환 | 퀵슬롯을 다른 퀵슬롯에 놓기 | 빈 곳이면 이동, 차 있으면 교환. 자동 사용 설정도 함께 이동 |
| 자동 사용 | 같은 슬롯에서 아래 28px / 위 28px 끌기 | 지원 항목만 AUTO 켜기 / 끄기 |
| 등록 해제 | 드래그 중 나타나는 ‘슬롯 해제’에 놓기 | 슬롯만 비움. 아이템·스킬 소유는 유지 |
| 페이지 | 각 묶음 아래 1~5 버튼 또는 빠른 가로 터치 스와이프(42px) | 다른 묶음 페이지는 유지. 슬롯·페이지를 직업별로 저장 |
| 장비 | 가방의 ‘장비’ → 해당 부위에 놓기 | 정확한 물리 ID로 장착. 다른 부위는 거부 |
| 추가 장비 | 장비 페이지 2 → 귀걸이/인장 등 부위에 놓기 | 선택한 좌/우 장신구 슬롯에 장착 |
| 순서 | 가방 아이템을 다른 가방 칸에 놓기 | 표시 순서만 바뀜. 수량·강화·ID·잠금 유지 |
| 창고 보관 | 메뉴 → 창고 → 함께 열린 가방에서 창고 목록으로 드래그 | 수량 확인 후 기존 창고 서비스로 보관 |
| 창고 찾기 | 창고의 찾기 목록에서 가방으로 드래그 | 수량 확인 후 무게/개체 ID 검사를 거쳐 찾기 |
| 판매 | 메뉴 → 판매 → 가방에서 판매 목록으로 드래그 | 수량 선택 → 최종 금액 확인 → 판매. 잠금/장착/판매 불가 검사 |
| 취소 | 빈 월드, Esc, 터치 취소, 초점 이탈, 창 닫기, 해상도 변경 | 등록/소모/장착을 하지 않고 미리보기·포인터 상태 해제 |

같은 스킬을 여러 슬롯에 등록해도 실제 쿨타임 사전을 공유한다. 소모품은 기존 수량/쿨타임을 공유하고, 수량 0은 어두운 아이콘과 0으로 남는다. 존재하지 않거나 삭제 정책에 해당하는 저장 참조는 정리한다. 사용자가 비운 슬롯을 다시 기본값으로 채우지 않는다. 기존 8칸 저장 데이터는 위치를 보존하여 50칸으로 확장한다.
