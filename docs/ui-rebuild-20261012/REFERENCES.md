# 한국어 공식 UI 대조 근거

사용자가 올린 통합 프롬프트를 작업 기준으로 삼았다. 사용자 게임 화면 첨부는 없었다. 저장소의 이전 UI 캡처와 실제 `main`을 먼저 실행한 다음 아래 공식 한국어 가이드를 확인했다.

| 공식 자료 | 페이지 메타데이터 갱신일 | 사용한 화면 |
| --- | --- | --- |
| [메뉴 및 UI 소개](https://lineagem.plaync.com/guidebook/view?title=메뉴%20및%20UI%20소개) | 2022-02-03 | HUD, 퀵슬롯 두 묶음과 각각의 페이지, 스킬, 변신, 인형, 캐릭터·스탯, 상점 |
| [아이템 소개](https://lineagem.plaync.com/guidebook/view?title=아이템%20소개) | 2021-12-30 | 우측 4열 가방, 수량·장착 표시, 하단 액션 |
| [성물 시스템](https://lineagem.plaync.com/guidebook/view?title=성물%20시스템) | 2026-09-11 | 성물 적용/소환 흐름 및 관련 화면 |

실제 이미지의 CDN URL, 픽셀 크기, SHA-256은 [reference-sources.json](reference-sources.json)에 보관했다. 공개 API `/api/v2/lineagem/guide/{제목}`의 `paragraphList`에서 연결된 이미지를 확인했다. 페이지 갱신일과 개별 이미지 업로드 시점은 다를 수 있다. 서로 다른 연도의 화면을 **2026년 최신 클라이언트의 동일 버전**이라고 주장하지 않는다.

참고 이미지는 분석용 `/tmp/twilight-ui-references`에만 내려받았다. 타사 스크린샷·원본 UI 텍스처를 공개 저장소의 게임 자산으로 추가하지 않았다. 실제 구현에는 기존 저장소의 허용된 아이콘·캐릭터 아트와 Godot 컨트롤을 사용했다.

## 좌표와 배치

`아이템 소개-0-0`의 1260×710 이미지에서 가방 외곽은 대략 `(875,80)–(1248,586)`이다. 안내용 청록색 테두리를 포함해 읽었으므로 가장자리 판독 오차가 약 2px 있다. 이를 1280×720으로 정규화하면 `(888.9,81.1,378.9,513.1)`이다. 구현 기본 가방 외곽은 `(890,82,378,508)`. 시작점 오차는 화면 너비/높이의 0.09%/0.13%, 너비/높이 차이는 0.07%/0.71%다. **이 외곽 한 항목의 비교 결과를 전체 UI 유사도나 모든 요소의 1% 오차 달성으로 확대하지 않는다.**

기준 화면에 따라 슬롯 수가 다른 자료가 있다. 퀵슬롯은 `메뉴 및 UI 소개`의 등록/스와이프 설명에서 확인한 좌우 독립 5칸×5페이지를 채택했다. 이전 8개 저장 항목은 앞의 8개 위치에 유지하고, 나머지는 빈 슬롯으로 확장한다. 기능 삭제 정책에 따라 퀘스트·채팅·파티 등은 배치에서 제외했다.

| 요소 | 이번 구현의 1280×720 논리 좌표/구성 | 근거와 남은 차이 |
| --- | --- | --- |
| 기본 가방 | x890, y82, 378×508 / 4열 | 위 공식 가방 외곽 대조. 검색·정렬과 추가 서비스 접근은 TWILIGHT에 맞춤 |
| 확장 가방 | x576, y82, 692×508 / 8열 | 같은 슬롯 규격을 확장. 동일 버전의 확장 화면 직접 대조는 추가 필요 |
| 스킬 | 가방과 같은 우측 선반 / 4열 | 공식 우측 스킬 선반. 작은 창에서 상세는 탭으로 전환 |
| 퀵슬롯 | 좌 x456, 우 x928 / y612 / 62×62, 간격5 | 공식 두 독립 묶음. 빠른 가로 터치 스와이프와 페이지 버튼 제공 |
| 캐릭터 | x12, y82 / 378×610 | 좌측 장비/기본 스탯. 실제 24개 장비 부위를 두 페이지로 노출. 기본 스탯은 STR/INT·DEX/WIS·CON/CHA 2열 |
| 상세 스탯 | x402, y82 / 680×508 | 기본 스탯 옆 별도 두 열 창, 긴 내용은 스크롤 |
| 변신·인형·성물 | 전체 화면, 등급 열 + 카드 목록 + 미리보기/옵션/하단 적용 | 각각의 실제 DB·아이콘·적용 상태. 등급 순서는 공식 참조처럼 높은 등급부터. 원작 카드 소유·합성 모델은 현 프로젝트에 없음 |
| 일반 상점 / NPC 상점 | 전체 상품 카드 / 중형 목록·거래 창 | 현 프로젝트의 아데나 상품만 사용. 유료 상품·서버 거래를 추가하지 않음 |

위 숫자는 `reference_layout.gd`, `renewal_window.gd`와 실제 캡처의 `layout_logical`에서 대조할 수 있다. 모든 글자 폭·모서리·아이콘·색상·카드 크기를 원작과 1% 이내로 재현한 상태는 아니다. 창별 추가 근거와 원본 스킨 제공 없이 픽셀 단위 동일성을 완료로 표시하지 않는다.

## 해상도 해석

검증 요청 크기는 1280×720, 1920×1080, 2400×1080이다. 기존 프로젝트의 `canvas_items` + `aspect=keep`을 보존했다. 따라서 2400×1080 창의 실제 게임 렌더 텍스처는 1920×1080이며 좌우가 레터박스다. 2400 전폭 UI로 검증했다고 보고하지 않는다. 렌더 JSON에 요청 창 크기, 활성 논리 뷰포트, 실제 PNG 크기를 각각 기록한다.

Windows/Android 실기기의 DPI, 터치 드라이버, 긴 플레이 세션은 이번 Linux 소프트웨어 OpenGL 검증과 별개다.

## 남아 있는 눈에 보이는 차이

- 창의 프레임·버튼은 Godot 컨트롤과 기존 테마를 사용한다. 공식 원작의 장식 텍스처·글리프·광택을 그대로 가져온 스킨은 아니다.
- 일부 기존 아이템 아이콘에는 워터마크나 숫자가 이미지 자체에 들어 있다. 별도로 표시하는 수량은 실제 인벤토리 값이지만, 이미지에 이미 포함된 글자를 모두 정리한 상태는 아니다. 해당 아이콘 원본 정리는 남은 리소스 작업이다.
- 캐릭터의 실제 지원 부위 24개는 두 페이지로 나눴다. 원작 참조 한 페이지와 항목 수가 다르며, 기본/추가 스탯 표기도 TWILIGHT 실제 데이터를 함께 표시한다.
- 카드 소유·각성·합성·컬렉션 서비스가 없어 원작의 소유 수, 중복 수, 각성 상태를 표시하지 않는다. 카드 검색 및 직접 적용은 기존 TWILIGHT 기능을 유지한 것이다.
