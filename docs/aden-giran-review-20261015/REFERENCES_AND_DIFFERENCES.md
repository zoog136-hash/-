## S32 분석

동일 해시의 A3에서 기란 검수 구역과 겹치는 normal/4 S32 12개만 분석했다.
기존 파서 `formats.read_s32/write_s32`를 재사용하여 선택한 파일을 바이트
왕복 대조했다. 결과는 [S32_ANALYSIS.json](S32_ANALYSIS.json)에 있다.

- floor half-tile 98,304, cover 816, attribute cell 49,152.
- object group 6,890, **object tile fragment 167,311**. 이는 건물 167,311개가 아니다.
- opacity record 23,849, portal record 2, effect 82.
- 바닥 tile ID 64종, object fragment tile ID 347종.
- A3의 `.til`·`tile.pak`·`tile.idx`는 0개다. ID/index 쌍에서 원래 그림으로
  대응하는 단계는 수행할 수 없었다. S32 포털 필드를 최신 M 목적지나
  일반 Godot 포털로 자동 등록하지 않았다.
- S32 3611–3614 계열의 위치를 광장 화단 후보 패치로 사용했다. 이미지가
  없는 상황에서 원본 화단 재질이나 종류를 식별했다고 주장하지 않는다.

원본 전체 격자·768청크를 다시 만들지 않았다. 시각 오브젝트의 발 위치,
아틀라스 슬롯, 크기와 출처 판정은 `data/aden_giran_review/layout.json`에
남겼다. 성분 바운딩 박스에서 만든 건물 후보는 실제 건물 이름/모델 식별과
다르다. 안쪽 성분을 별도 집으로 겹쳐 그렸던 첫 화면은 수정했다.
