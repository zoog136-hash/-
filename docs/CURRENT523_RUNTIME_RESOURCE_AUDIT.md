# 실행 중인 원본 리소스 경로 점검

변경 전 비교는 main `051ee892b1493ea198ff1ffc5efff972a73967b9`에서 실행했다. 실제 Main을 격리 저장 경로로 실행하고 메뉴 진입, 별도 원본 창, 보유 상태가 필요한 진입을 점검했다. 대체 리소스 검사는 추적 파일과 로더를 대상으로 실시했다.

| 영역 | 확인한 경로 |
| --- | --- |
| 패키지·이전 APK | 저장소의 그림 파일은 이전 승인 목록의 런처 아이콘이다. 과거 내장 지도·액터·아이템 그림은 `retired_assets.gd`에서 차단한다. OTA가 이전 APK에서 해당 파일을 지우지 못하는 경우에도 같은 검사를 사용한다. |
| 지도·액터·이펙트 | 현재 523 지도는 등록된 원본 타일·정적 SPR을 읽는다. 액터·전투 연출은 원본 SP2 또는 검증된 변환 팩을 사용한다. 주요 자체 효과는 원본 모드에서 숨겨지거나 코드에서 비활성화돼 있다. 전체 지도와 액터 뱅크의 실전 렌더에는 각각 설치 팩이 필요하다. |
| 아이템 그림·바닥 드랍 | 현재 ItemClass/Sprite 연결과 이미지 팩이 그림을 공급한다. 바닥 전용 그림이 없는 경우의 인벤토리 아이콘 표시와 글자 표기는 기존 동작이다. 원본 드랍 광원은 등록된 효과 ID 경로를 사용한다. |
| 화면·대화상자 | 원본 전용 창은 기존 상태와 동작을 사용한다. 전투 기록은 검증된 `Chat_All`의 패널과 닫기 버튼, 원본 글꼴로 최근 120건을 표시한다. 가방에서 기존 형식 하프 엘릭서를 사용하는 경로도 저장된 문맥이 유효할 때 원본 엘릭서 화면으로 연결한다. |
| 로컬 기능 화면 | 판매·조합·96레벨 보상·필드 활동·아이템 검색의 기능과 데이터는 기존 코드가 담당한다. 공통 창틀·입력 영역·버튼·확인창·글꼴은 설치 팩의 `Common_MessageBox` 및 `Chat_All`이 공급한다. 수량, 확인, 취소, 자동 정비 규칙은 기존 흐름을 따른다. |
| 시작·효과음 | 원본 UI를 읽을 수 있을 때 로딩 표시가 `Fx_Loading`을 사용한다. 캐릭터 계정 관리는 로컬 기능이다. 부팅 이전 글꼴과 런처 아이콘은 기존 설치 방식으로 남는다. 효과음은 기존 설치 정책에 따라 제외된다. |

검증한 정의 ZIP의 SHA-256은 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`이며, ZIP CRC는 1,075개 멤버에서 일치했다. 실행에 장착한 UI 매니페스트는 `47e593f4fa682dc4a8e839fd0af181687926e757ce57d1e09dddd190cd44c407`이다. 공통 리소스는 그 안의 원본 씬 SHA와 원본 아틀라스 파일 SHA를 확인한 뒤 사용한다.

## 확인이 남은 경로

- 장착 팩에는 전용 `Store_Sale`, `Store_SaleInventory`, `Totem_Popup_Enchant` 씬 레코드가 없다. 해당 기능을 여는 경로에서는 공통 리소스를 사용할 수 있다. 실제 전용 화면 연결에는 동일 스냅숏의 원본 씬과 그 참조 리소스가 필요하다.
- TJ 쿠폰은 실패 이력과 적용 문맥이 있는 저장에서, 몬스터 도감은 해당 기능이 활성화된 실행에서 확인해야 한다. 원본 팩이 없거나 SHA가 맞지 않으면 확인 가능한 기존 입력 화면과 누락 안내가 적용된다.
- Android에서는 원본 팩이 실제로 설치된 상태에서 재현해야 한다. 이 점검에서 사용자 저장과 원본 파일을 수정하거나 원본 파일을 저장소에 추가하지 않았다.

## 재현

원본 팩과 이미지 선택을 설정한 격리 프로필에서 `tools/audit_main_ui_buttons523.gd`를 실행하면 직접 진입과 원본 창의 실행 결과가 출력된다. `original_chrome`은 기존 기능이 원본 공통 외형을 사용했다는 값이다. `original`은 해당 전용 원본 씬이 열렸다는 값이다. `tests/original_shared_chrome_main_test.gd`는 같은 환경에서 화면 동작을, `--without-ui`로 실행하면 팩이 없는 상태의 기능을 검사한다.
