기준 main: `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`. PR233의 같은 브랜치에서 진행한다. 게임 메뉴 → 설정 → 전투 연출에 연결하며 원본 자료·픽셀은 Git 밖에 둔다.

## 기존 표시 설정과 세이브

기본값은 전체 표현·인형 표시·기존 표시량이다. 기존 `effect_detail=low` 설정을 보존한다. 현재 게임 맵별로 세부 표현·동시 이펙트 수·인형 숨김을 따로 저장하고, 별도 설정을 끄면 전역 선택으로 돌아간다. 강도·움직임 줄이기는 기존 전역 설정이다. 선택은 `twilight_ui_settings.cfg`의 `visual` / `visual_regions`에 기록하며 캐릭터 JSON 스키마를 바꾸지 않는다.

| 기능 | 기존 main | 연결한 동작 |
| --- | --- | --- |
| 세부 표현 | 전체/간소화, 상세 타격32/6·발사체64/24·스킬160/64 | 재사용, 게임 맵별 선택 |
| 동시 표시량 | 기존 고정 예산 | 사용자가 켜면 타격24·발사체24·스킬64. 원본 수치로 주장하지 않음 |
| 인형 숨김 | 사용자 제어 없음 | 주/추가 인형과 부착 연출을 함께 숨기며 장착·보너스 유지, 숨긴 주 인형 추종 계산 중지 |
| 잘못된 옵션 | 기존 형변환 | 새 옵션의 잘못된 값은 기본 유지, 지역 설정에서 강도/움직임 변경 불가 |

새 타격 표시량 제한은 피해 숫자·범위 링·죽음 트랙의 레코드를 지우지 않는다. 발사체의 수명·피해 콜백은 시각 예산과 독립적이다.

## 195개 원본 구역의 실제 UI 연결

1. 설정의 **원본 지역 권장 설정**에서 검증된523 자료 ZIP 또는 추출된 `content/` 폴더를 선택한다. 제공 ZIP은 전체 SHA와 크기를 먼저 확인한 뒤 필요한4표만 메모리에서 읽으며 이미지·전체 표를 추출하지 않는다.
2. 실제195행/99 Land 전부가 구역 선택 목록에 나온다. 원본 구역 ID를 보존하고 기본 표시량·인형 숨김, 공성/라스타바드 조건 분기 값을 화면에 표시한다.
3. **선택한 구역의 기본 권장값 적용**을 누르면 원본 `DefaultLowEffectCount`와 `DefaultHideMagicDoll`을 현재 게임 맵의 별도 설정으로 적용한다. 상세 외형은 기존 사용자 선택을 유지한다. 결과를 화면에 표시하고 ZIP/폴더 경로와 선택 행을 별도 설정에 기억하며 재시작 후 복원한다.

이 경로는 사용자가 선택한 기본값 적용이다. 현재 PC 계열 플레이 맵을 M의 Land/좌표와 같다고 간주하지 않는다. 폴더·ZIP 로딩 실패는 기존 원본 데이터와 표시 설정을 유지한다.

자동 적용은 기본으로 꺼져 있다. 필드가 `lineagem_m_presentation_context(world_position)`으로 `source_snapshot=patch523`, `coordinate_space=lineagem_m`, boolean `verified=true`, 정수 `land_id` 및 유한 Vector2 `point`를 제공할 때만 공간 조회를 허용한다. 기존 source_map84 필드는 이 계약을 제공하지 않아 UI에서 자동 적용이 비활성이다. 명시적 게임 맵별 사용자 설정은 원본 자동 기본값보다 우선한다.

공간 조회는 원본 사각형 내부만 처리한다. 경계 소유권을 추정하지 않고 경계는 보류한다. 중첩 행은 모두 보존하며 어떤 우선순위라도 결과가 같은 경우만 공통값을 적용한다. 조건 분기의 실행 의미는 추정하지 않는다. 실제195행 중심 검사 결과161개는 공통 기본값,15개는 조건 대기,19개는 경계/퇴화 사각형 대기다. 195개 모두 UI에서 원본 기본값을 선택 적용할 수 있으며 미해석 조건을 활성화하거나 공성 기능을 도입하지 않는다.

## 간소화 원본 이펙트 선택

원본 `EffectSpriteSimplify`의 유일한24941→29044 매핑을 기존 `original_source_preview.spawn_source_overlay` 실행 경로에 연결했다. 원본4표가 로딩되고 사용자가 간소화를 선택했을 때만 이 정확한 효과 ID에 적용한다. PC SPX 그룹·캐릭터 본체·다른 효과는 바꾸지 않는다.

작은 효과의 원본 ID·one-shot 모델·기존 효과와 동일한 원본 action ID·8방향 트랙·필수 파일·누락 부착물 여부를 확인한다. 후보가 없거나 불완전하거나 구성에 실패하면 기존 효과로 돌아간다. 기존 strict/compatible 모드와 원본 프레임·좌표·재생/블렌드 정책을 유지한다. 새로운 픽셀·FPS·합성 규칙은 만들지 않는다.

실제 SPR 선언을 추가 확인했다.24941은 부착24942/24943,29044는 부착29045를 참조하며 두 본체 모두 action0/3과 명시적인36/24 프레임율 선언을 가진다. 수집된 분류별 SP2 입력 목록에는 이5개 접두사의 파일이0개다. 이는 해당 전달 목록의 한계이며 전체 원본의 전역 부재 증명이 아니다. 실제 두 효과/부착물 픽셀을 이 환경에 설치·렌더한 결과는 없다. factory probe는 픽셀 없이 선택·실패 시 원복 경로만 검사하며 원본 시각 검증으로 집계하지 않는다.

`UIFlashEffectHideList`90행은 보존하지만, 원본 UI 레이아웃/노드 이름을 TWILIGHT에 임의 대응시켜 숨기지 않는다.
