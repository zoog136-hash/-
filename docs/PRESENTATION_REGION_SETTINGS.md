표시 설정·원본 경로·원본 선택 행은 저장 후보를 만든 뒤 같은 폴더의 임시 파일을 검증하고 파일 교체가 성공한 경우에만 메모리와 게임에 반영한다. 원본 선택은 새 데이터를 먼저 검증하되 설정 저장이 실패하면 기존 원본 인스턴스를 유지한다. 지역 기본값과 선택 행은 한 번에 저장한다. 실패 시 결과를 UI에 표시하고 체크박스·슬라이더를 기존값으로 복원한다. 기존 캐릭터 저장과 무관한 설정도 보존한다.

새 타격 표시량 제한은 피해 숫자·범위 링·죽음 트랙의 레코드를 지우지 않는다. 발사체의 수명·피해 콜백은 시각 예산과 독립적이다.

## 195개 원본 구역의 실제 UI 연결

1. 설정의 **원본 지역 권장 설정**에서 검증된523 자료 ZIP 또는 추출된 `content/` 폴더를 선택한다. 제공 ZIP은 전체 SHA와 크기를 먼저 확인한 뒤 필요한4표만 메모리에서 읽으며 이미지·전체 표를 추출하지 않는다.
2. 실제195행/99 Land 전부가 구역 선택 목록에 나온다. 원본 구역 ID와 숫자 좌표를 보존하고 기본 표시량·인형 숨김, 공성/라스타바드 조건 분기 값을 화면에 표시한다. 단일 좌표 정의와 조건 전후 동일한 값도 구분해 표시한다.
3. **선택한 구역의 기본 권장값 적용**을 누르면 원본 `DefaultLowEffectCount`와 `DefaultHideMagicDoll`을 현재 게임 맵의 별도 설정으로 적용한다. 상세 외형은 기존 사용자 선택을 유지한다. 결과를 화면에 표시하고 ZIP/폴더 경로와 선택 행을 별도 설정에 기억하며 재시작 후 복원한다.

이 경로는 사용자가 선택한 기본값 적용이다. 현재 PC 계열 플레이 맵을 M의 Land/좌표와 같다고 간주하지 않는다. 폴더·ZIP 로딩 실패는 기존 원본 데이터와 표시 설정을 유지한다.

자동 적용은 기본으로 꺼져 있다. 필드가 `lineagem_m_presentation_context(world_position)`으로 `source_snapshot=patch523`, `coordinate_space=lineagem_m`, boolean `verified=true`, 정수 `land_id` 및 유한 Vector2 `point`를 제공할 때만 공간 조회를 허용한다. 기존 source_map84 필드는 이 계약을 제공하지 않아 UI에서 자동 적용이 비활성이다. 명시적 게임 맵별 사용자 설정은 원본 자동 기본값보다 우선한다.

공간 조회는 원본 사각형 내부만 처리한다. 경계 소유권을 추정하지 않고 경계는 보류한다. 중첩 행은 모두 보존하며 어떤 우선순위라도 결과가 같은 경우만 공통값을 적용한다. 조건 분기의 실행 의미는 추정하지 않는다. 조건15행 중 원본 구역242488·243638은 조건 전후 표시값이 같아 활성 여부를 추정하지 않고 공통값을 적용한다. 실제195행 중심 검사 결과163개는 공통 기본값,13개는 조건 대기,19개는 경계/단일 좌표 정의 대기다. 남은13행은 SiegePlay4행과 LastavardHotTime9행이며 관련 핫타임·일정·공성 상수 표에도 이13행의 실제 활성 신호가 제공되지 않는다. 단일 좌표19행은 Land46964의17행,47232/47804의 각1행으로 원본 반경이나 경계 포함 규칙을 만들지 않는다. 195개 모두 UI에서 원본 기본값을 선택 적용할 수 있으며 미해석 조건을 활성화하거나 공성 기능을 도입하지 않는다.

## 현재 게임에서 사용하는 자체 영역

검증된 M 투영을 기다리는 동안 현재 게임의 지역별 자동 표시를 사용할 수 있도록 별도의 **자체 영역 자동 적용**을 연결했다. 처음에는 영역이 없으며 자동으로 품질을 낮추지 않는다.

- 현재 게임 위치를 중심으로 정사각형 영역을 저장한다. 반폭은16~4096 게임 좌표 단위로 조절하며256은 편의용 초기값이다. 원본 경계나 M 거리라고 주장하지 않는다.
- 원본195구역 중 선택한 행의 기본 표시값 또는 조건값을 사용한다. 조건값은 사용자의 명시적인 자체 선택이며 공성/핫타임이 활성화됐다는 판정이 아니다. 단일 좌표19행과 조건13행도 이 독립 경로에서 원본 플래그를 활용할 수 있다.
- 영역 안에서는 이 명시적 자체 선택이 게임 맵의 표시 설정보다 우선하고, 밖에서는 기존 지역/전역 설정으로 복원한다. 원본 M 좌표 자동 옵션은 별도로 유지한다. 맵별 한 영역, 사용/해제·삭제·저장·실패 복구·재시작 UI를 제공한다.
- 자체 영역은 별도 설정에만 저장하며 원본 좌표/조건·맵 지형·충돌·스탯·캐릭터 저장을 변경하지 않는다. 원본 설정이 사라지면 자체 영역의 표시값을 적용하지 않고 기존 표시로 돌아간다.

공개 근거도 확인했다. [공식2019년3월13일 패치 노트](https://lineagem.plaync.com/board/update/view?articleId=5c87dcb5402b620001b9b9b4&page=28&size=20&viewMode=list)는 라스타바드의 인형/일부 이펙트 제한을 설명하고, [공식11월8일 패치 노트](https://lineagem.plaync.com/board/update/view?articleId=5a01cf22d7a85c00017e8e3c)는 공성 중 인형 표시 제한 범위 확대를 설명한다. 정확한 도형·점 반경·현재 게임 좌표 투영 규칙은 제공하지 않아 자체 범위로 명시했다. 원본 활성 신호를 현재 게임의 임의 일정이나 이벤트로 위장하지 않는다.

## 간소화 효과 후보의 실제 로딩·표시

원본 `EffectSpriteSimplify`의 유일한24941→29044 매핑을 기존 overlay factory에 연결했다. 사용자가 간소화를 선택할 때 이 정확한 효과에만 적용한다. PC SPX 그룹·다른 효과·카드 본체로 확대하지 않는다. 작은 효과의 원본 ID·동일 action ID·8방향 후보 트랙·필수 파일·부착물 완전성을 확인하고 불완전하면 전체 효과로 돌아간다.

필요한 본체24941/29044와 부착24942/24943/29045의10개 SP2 원문을 모두 실제 수신했다. 각 ZIP과 멤버의 SHA/CRC·역사적 인덱스의 크기/CRC·표준Brotli 입력 종료를 확인했다. 원문 컨테이너의 현행523 동일성은 공급자 확인 근거이며 소비 환경에서 전체 DAT를 재해시한 것은 아니다. 보유 SPR29는 과거본임을 발견해 현행523 명세가 선택한 원문으로 대조했다. 해당5개 선언·틱·FPS·부착물은 동일했고, 현재 컴파일 입력은 현행 선택 SPR24/29다.

`build_presentation_effect_candidate.py`는 이 원문으로4개 후보 모델(action0/3 × 전체/간소화),736개 후보 PNG와 원본 설정4표를 별도 적용팩으로 만든다. FPS와 틱은 원문을 유지한다. 기존 RLE/기하 해독·블렌드·방향 대응·한 번 재생·배치는 **TWILIGHT 자체 해석**으로 남기며 리니지M 엔진/화면/실전 트리거가 복원됐다고 주장하지 않는다. 기존 upstream의 표준 확정 PNG2개와 이736개 후보를 합산하지 않는다. 엔진/APK/XAPK는 사용하지 않는다.

설정의 **간소화 효과 · 자체 해석**에서 후보 폴더를 선택한다. 파일 명세·크기·SHA와 두 action의 완전한 본체/부착물을 검사한 다음에만 경로를 저장한다. 원본 action0 또는3을 명시적으로 선택하고 현재 전체/간소화 설정으로 실제 효과를 볼 수 있다. 중간 프레임 고정과 화면에 맞춘 확대율은 미리보기용 동작이다.

실제24941/29044 효과 호출에 후보를 사용하는 옵션은 기본 꺼짐이다. 켠 경우에만 해당 쌍에 적용하며 기존 배우의 strict/compatible 모드·매니페스트·트랙을 교체하지 않는다. 호출 동안 후보를 구성한 뒤 원래 상태를 복구한다. 기존 전투 스킬이나 발동 타이밍을 새로 부여하지 않으며 명시적 효과 호출과 실제 UI 미리보기에서 동작을 검증했다. 전투 판정·재화·아이템·스탯·캐릭터 저장은 변경하지 않는다. 후보 폴더/설정 저장 실패는 이전 선택을 유지한다.

`UIFlashEffectHideList`90행은 보존하지만 원본 UI 노드 이름을 현재 게임 노드에 임의 대응시키지 않는다.

## 원본 접근 증거와 남은 입력

- 523 원본 ZIP과30개 SPR 선언을 정식 경로로 수신하고 크기·SHA·전체CRC를 확인했다. 원본4표는 `source_optimization.gd`와 `audit_territory_optimization.py`의 고정 SHA로 검증한다. 195행 기본 플래그는 저효과/숨김 동시176, 모두 해제15, 저효과만1, 숨김만3이다. 원본에는 수치 예산이 없다. 508/520의193행을523의195행으로 가장하지 않는다.
- 기존 전체 인벤토리의 Library 전송은 tools/list HTTP401 이후 재시도하지 않았다. 이후 사용자가 승인한 별도 Drive 사본을 실제 수신했고 기대 크기/SHA·전체CRC·내부 gzip/JSON 해시가 일치했다. 이 인벤토리는 base508과 과거 패치 조사 자료이며 최신523 전수 목록으로 간주하지 않는다.
- 사용자가 지정한 Drive의 SP2 묶음과 checkpoint01~04도 수신했다. 분할 조각과 재조립 ZIP의 SHA·크기·전체CRC, 각 패키지 명세 및69개 DAT 원문 proof SHA·내부CRC가 일치했다. 재업로드·권한·인증 변경은 하지 않았다. 공개 문서는 집계만 포함하고 정확한 접근 식별자·원문·수신 명세는 비공개 작업 자료로 보관한다.
- 이 Drive 묶음의 표준 확정 PNG는 upstream이 전달한 `normal_cloud.png`와 `Map_Icon_Forge.png`2개뿐이다. SP2 전체의 픽셀·알파·프레임·원본 렌더 해석은 검증되지 않았다. 두 효과에 대신 사용하지 않는다.
- `PRESENTATION_SOURCE_HANDOFF.json`은 집계·한계다. 재현: `python3 tools/audit_presentation_source_handoff.py <수신 폴더> --manifest <비공개 소유자 기대명세> --output <비공개 결과 JSON>`. 기대명세는 `archives`에5개 파일의 `filename`·`bytes`·`sha256`을 제공한다. 도구는 네트워크 없이 실제 ZIP/명세와 DAT 내부를 확인한다. 잘못된 SHA·경로 이탈은 거부하며 정확한 파일 지문을 공개 코드에 박아 넣지 않는다.
- 추가 과거3 ZIP도 확인했다. `source-inventory-delta`는 전체 리소스 인덱스가 아닌 인벤토리 UI 코드/검증 증분이다. base508 각성 addon v2의877파일·v3의2068파일은 index/payload/논리파일 SHA를 전수 확인했지만 해당5개 ID의 경로·참조와 SP2 원문은 없다. 과거 코드를 가져오거나 픽셀을 최신523으로 승격하지 않았다.
- 전체 인벤토리에서 필요한5개 ID의 위치는 찾았다. 원본 `Client/Data/Sprite484.dat`에는24941/24942/24943, `Client/Data/Sprite609.dat`에는29044/29045의 `-0.sp2`·`-8.sp2`가 있다. 패치520까지의 예상 컨테이너 지문과 원본 멤버 크기/CRC가 기록돼 있지만 전체 DAT 원문은 이 환경에 없지만 필요한10개 SP2는 이후 별도 인계로 모두 수신했다. 최초69개 DAT와 SP2 묶음에 없다는 사실을 전역 부재로 해석하지 않았다. 공급자의 현행523 컨테이너 근거와 소비한 멤버 지문을 구분하며 렌더 해석은 자체 후보로 명시한다. 대용량 Git 이력이나10GB 전체 클라이언트가 이10파일의 위치 확인에 필요한 것은 아니다.
- 역사적6 ZIP용 `--source-dir` 검사는 기존 `a1.zip` 부재로 실패한다. 제공523 ZIP의 독립 검증과 구분하며 원본 아트 변환·배포 완료를 주장하지 않는다.

## 적용팩과 원본 백업의 구분

최신 적용 후보v1과 원본 보존 백업v1을 서로 다른 비공유 프로젝트 폴더에 저장했다. 기존 인계 파일을 덮어쓰지 않았다. 두 ZIP을 새 소비 폴더에서 다시 받아 SHA·전체CRC를 확인했다. 적용팩만 풀어 게임의 실제 파일 선택·로드·표시·재진입을 검증했다. 백업은 게임에 적용하지 않았다. 정확한 크기·지문·보관 링크·소비 경로는 비공개 인계 명세에 둔다. 캡처/조사 보고서는 외부로 업로드하지 않았다.

적용 방법: PR233 코드에서 적용 후보 ZIP을 개인 폴더에 푼다. 원본 지역 권장 설정에서 `<적용폴더>/source_settings`를, 간소화 효과 자체 해석에서 `<적용폴더>`를 선택한다. 실제 효과 호출에 사용할지는 별도 옵션으로 선택한다. Drive 보관만으로 게임에 자동 적용되지 않는다. 원본 백업 ZIP은 별도 보관용이며 적용팩으로 선택하지 않는다.

재생성은 도구의 `--inventory`(원래 ZIP 또는 백업의5개 ID JSON 부분 인덱스), `--source`(SP2 폴더), `--spr`, `--settings`, `--output`으로 수행한다. 원문을 공개 저장소에 넣지 않으며 새 출력 폴더만 생성한다.
