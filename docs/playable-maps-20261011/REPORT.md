# 실게임 맵 적용 상태

저장 브랜치: `feature/twilight-playable-maps-20261011`. PR #83. 최신 main `2f5ae101`에서 작업했고 다른 PR과 main을 변경하지 않았다.

## 실제 구현 성과

**A3 본토 `l1_4` 1개는 임시 그래픽으로 PLAYABLE 검증을 마쳤다.** 실제 Main.tscn과 지도 메뉴를 사용한다. 원본 타일 그래픽은 복원하지 못했다. 이 별도 A3 지역을 기존 `aden_world`와 동일한 판본으로 확정하거나 기존 필드를 교체하지 않았다.

첫 맵은 렌더·클릭 이동·충돌·A* 장애물 우회·원본 위치 NPC 상점·몬스터·임시 오프라인 커츠·AUTO 이동/피해·자동 포털 진입·미니맵/월드맵·재접속 위치·보스 HP 저장을 검사했다. 팩이 빠진 저장을 덮어쓰는 것도 막았다. 원본 NPC 서비스/몬스터 전투값/보스 일정은 TWILIGHT 임시 연결이며 UI와 코드에 표시했다.

## 검증 근거

- 최초 전체 실행: 89/93 PASS. 3개 선택적 어댑터 fixture 누락, 기존 25개 지역용 검사의 998개 원본 지역 순회로 인한 시간 초과 1개가 발생했다. 원본 로그를 보존했다.
- 실패 3개 어댑터는 별도 합성 fixture 환경에서 각각 PASS. 25개 기존 지역 검사는 기존 25개 목록을 순회하도록 범위를 바로잡아 9,323 조건 PASS. 검사를 삭제하거나 데이터 조건을 완화하지 않았다.
- 별도 원본 지역 23개 게임 검사 201 PASS. 첫 맵 headless 22 PASS, OpenGL 32 PASS. 새로 생성한 A3 팩의 독립 실행 환경에서도 32 PASS. 화면 5장 첨부.
- 누락 팩: 전용 3개 검사는 SKIP으로 표시. 기존 맵은 부팅 가능하다. 잘못된 팩 JSON 12조건 거부 검사 PASS.
- 공개 CI의 첫 L1J Runtime 실행은 기존 main이 포함한 이미지에 합성 이미지를 덮어쓰려 해서 중단됐다. 이미지 보호 규칙을 유지하고 합성 이미지 경로를 `_ci_fixture` 하위로 분리했다. 원본 보존 검사와 실제 L1J 런타임 78조건 PASS. 최종 CI는 별도 상태를 확인해야 한다.
- 첫 맵에서 캐릭터가 경로 중간에 멈추던 실제 버그를 재현했다. float32 Vector2로 DDA 경계를 계산하던 것을 스칼라 double 계산으로 고쳐 대각선 교차를 보존했다.
- 엔진 4.7.2, Compatibility, Linux llvmpipe. Windows GPU/실기기 조작 검증 없음. GL 5개 지역의 draw chunk ≤9, navigation cache ≤64.

## 자료·배포·다음 작업

첨부 16개 모두 접근·SHA 확인했고 PR81 입력과 16/16 일치한다. 중첩 ZIP 33개와 타일 검색은 동일 해시의 이전 결과를 재사용했다. 원본 지형 타일 그래픽은 새로 발견되지 않았다.
원본 바이트는 공개 Git에 넣지 않았다. 새 설치 시험에서 검증된 A3 멤버 1,000개로 로컬 팩을 만들었고 2,016파일·120,986,251바이트를 검사했다. 이전 전체 팩 2,770파일·161,549,593바이트도 로컬 검사했다. [설치 절차](INSTALL.md)를 통해 기존 업로드에서 재구성한다. 이 수치는 온라인 팩 전달 완료가 아니다.
남은 작업: 목표 25개 각각의 원본 판본/ID 확정, 원본 시각 타일 팩 및 팔레트/레이어 매핑, 미매핑 NPC 서비스와 몬스터/보스·포털 검증, 나머지 지역의 전체 플레이 검사, Windows 실기기 확인. 확인되지 않은 지역을 임의 원본 위치/그래픽으로 채우지 않았다.
