# TWILIGHT: Skill icon art attribution

The 125 fallback skill visuals in `assets/skills/styled_icons/` are **not NCSOFT Lineage M original skill bitmaps**.

Based on icon glyphs by **Lorc** and **Delapouite** from [Game-icons.net](https://game-icons.net), under the [Creative Commons Attribution 3.0 license](https://creativecommons.org/licenses/by/3.0/). Source repository: https://github.com/game-icons/icons (tree 82d948812bfe3f269ef8f731dcdb07b08160edc4).

Each glyph has been reframed as an SVG for 64×64 skill slots, with color gradients, alternate backgrounds, subtle edge treatments and rarity colors. Its author and source file are recorded per skill in `data/skills/styled_icon_provenance.json`. Credits also appear in the Settings UI. Attribution is retained with the game package.

A separately licensed original Lineage M icon pack (if legally obtained) can be installed via the existing private, gitignored PNG override. No proprietary NCSOFT skill icon is included in this PR.
