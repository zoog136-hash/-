# 문양 / 수호성 선택 흐름 정정 (2026-10-24)

## 혼동 원인

`e0cc9ffe`의 문양 화면에는 카드 선택/뒤집기 연결이 없었다. `growth_view.gd`의 emblems 분기는 문양 diagram만 만들고, 강화 성공 시 단계 점등/발광을 재생한다. CardFace 생성은 guardians 분기에 있었다.

잘못된 것은 전달한 미리보기와 수호성 결과 구성이다. `motion-preview.mp4`는 30fps/90프레임으로, 0~44프레임(앞 1.5초)은 문양 강화, 45~89프레임(뒤 1.5초)은 수호성의 단일 카드 공개 화면이다. `capture_growth.gd`가 두 메뉴를 전환하며 같은 프레임 번호에 이어 찍었다. 여러 카드가 기다리고 사용자가 선택하는 장면 없이 단일 결과로 넘어가 두 기능과 핵심 흐름을 혼동시켰다. 기존 영상은 초기 증거로만 남기며 현재 동작 소개로 사용하지 않는다.

뒤집기 동작을 입증하는 원작 영상은 확보하지 못했다. 공식 가이드의 카드 선택/결과 확인 설명과 정지 화면을 보고 자체 뒤집기를 추가한 것이며, 이는 원작 고증의 근거가 되지 않는다. 초기 문서의 타이밍 미검증 표기만으로 동작 자체까지 검증된 것처럼 보이게 한 부분을 정정한다.

## 대조 자료

- [NC 공식 수호성 가이드](https://lineagem.plaync.com/guidebook/view?title=수호성+시스템): 비활성 슬롯, 활성화, 카드 선택, 결과 확인, 성공 후 개방 순서와 슬롯 타입별 카드 수 차이. 공개 API의 정지 스크린샷을 확인했다. 뒤집기 애니메이션을 증명하는 영상은 아니다.
- [2020-12-14 수호성 설명/실제 화면](https://gallo44.tistory.com/59): 우주 배경에 달·별 카드 3장, ‘카드를 선택해주세요’, 나가기 표시를 직접 확인했다. 과거 사용자 자료이며 최신 노드별 전체 카드 수·비용 또는 뒤집기 동작의 확정 근거가 아니다. 이미지는 재배포하지 않는다.

## 현재 수정

- 문양: 단계 강화와 기존 단계 점등/발광/결과만 유지한다. 문양 화면에 GuardianCards가 생성되지 않는지 검사한다. 카드 장면이 포함되지 않는 별도 문양 영상으로 전달한다.
- 수호성: 활성화 견적 승인/비용 차감 후 여러 카드가 기다린다. 시간 경과만으로 선택/결과/추가 비용이 발생하지 않는다. 실제 네이티브 터치로 한 장을 고르면 그 카드 결과를 저장하고, 같은 배열에 성공/실패 상태를 표시한다. 임의 뒤집기와 확대된 단일 결과 화면을 제거했다.
- 실패 카드는 회색/‘실패 · 제외’로 표시한다. 재도전 비용 승인 후에도 실패 카드는 선택 불가, 남은 카드 수와 숨은 정답/실패 이력을 그대로 복원한다. 모든 결과 카드 버튼은 비활성화해 중복 선택/차감을 막는다. 닫기/재시작으로 이미 지불한 선택 대기가 사라지지 않는다.
- 카드 화면에서는 일반 수호성 탭을 감추고 카드 배열에 집중한다. 전체 카드 목록/재도전/나가기 경로를 유지한다. 자체 카드 이미지를 재사용했으며 원작 미술 복제나 새 임의 연출을 추가하지 않았다.
- 문양/수호성 프레임을 각기 다른 디렉터리에 기록해 영상을 분리한다. 수호성 영상에는 선택 대기 → 직접 탭/실패 → 재도전·로드/남은 카드 → 직접 탭/성공을 보여준다.

공식 전체 노드 카드 수/비용은 여전히 미확인이다. 실제 화면의 3장을 모든 노드에 적용하지 않는다. 개발 모드만 기존의 근사 3장·수호석 1개를 사용하고 일반 모드 잠금은 유지한다. 실제 Android 기기 검증과 원작 영상 프레임 고증은 미완료다.

## 실행 결과 / 전달

변경 부분만 검사하여 성장 104개/연출 5개, 두 검사 2/2 통과. 실제 Main에서 1280×720·854×480의 각 시스템 화면 및 카드 선택 대기/실패/복원/성공 총 8장을 저장했다. 문양 45프레임/1.5초와 수호성 180프레임/6초를 별도 디렉터리에 `--fixed-fps 30`으로 촬영하고 H.264/yuv420p로 인코딩했다. 엔진 고정 시간으로 재현한 것이며 실제 Android GPU 성능을 입증하지 않는다. 원작 애니메이션 영상과 프레임 일치 검증도 아니다.

현재 미리보기: [문양 단계 강화](evidence/selection-flow/emblem-enhancement.mp4), [수호성 직접 카드 선택](evidence/selection-flow/guardian-selection.mp4). [화면](evidence/selection-flow/screens/)에는 실패 카드가 선택 불가인 상태와 남은 2/3 표시, 같은 배열에서 선택 결과가 확인되는 장면이 있다. 카드 선택 전 상태/비용이 자동 변경되지 않는 검사도 포함했다.

기존 Library 문양/수호성 이미지 및 혼합 영상 항목은 동일 ID의 새 버전으로 갱신했다. 특히 기존 혼합 영상 링크는 이제 문양만 담는다. 수호성 직접 선택 영상은 별도 항목으로 저장했으며 네 파일 모두 저장 성공과 로컬 메타데이터 반영을 확인했다. 실제 파일 식별자는 개인 전달 기록에 남기고 공개 저장소에 넣지 않는다.
