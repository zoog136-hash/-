# 문양·수호성 시각/연출 후속 보완 — 2026-10-24

원작 가이드의 실제 화면을 다시 대조했다: [문양](https://lineagem.plaync.com/guidebook/view?title=문양+시스템), [수호성](https://lineagem.plaync.com/guidebook/view?title=수호성+시스템). 본문은 기존 공개 가이드 API 응답 및 스크린샷을 참고했으며 공식 원본 이미지는 저장소에 재배포하지 않았다. 동적 웹 페이지 자체는 iframe만 반환하는 제한이 있다. 원본 애니메이션 프레임/시간은 확보하지 못했으므로 아래 타이밍은 자체 연출이다.

## 바뀐 화면과 자산

- 자체 sigil atlas를 이미지 생성 도구로 다시 제작: 두꺼운 보석 테두리 축소, 발광하는 문장 실루엣, 얇은 청동 문양, 잠금 자물쇠 대신 비활성 석재 소켓. 기존 생성 이미지를 참조해 편집했으며 Python으로 래스터를 편집하지 않았다. 생성 원본과 SHA는 `assets/growth/PROVENANCE.json`에 기록했다.
- 문양 30칸 중 매 3단계를 마름모와 로마 숫자 I~X로 구분. 중앙 문장/확률 막대/효과 패널/하단 고정 강화 버튼으로 위계를 바꿨다. 강화·5회·확률 변경·초기화의 색과 실제 견적 비용을 표시한다.
- 작은 창에서 링이 잘리는 문제를 실제 렌더로 확인해 상태·개발 안내를 한 줄로 합치고 링 높이를 조정했다. 자세한 자료와 미확인 효과는 스크롤로 확인한다. 일반/개발 수치 정책은 변경하지 않았다.
- 수호성 사각 버튼 배경 제거, 능력치 노드와 스킬 노드 크기 구분, 어두운 미개방 소켓과 활성 금빛 노드, 선택된 노드의 회전 광륜, 연결선의 이동 광점.
- 카드 앞뒷면 원본 생성 자산은 재사용. 중앙 폭이 좁아졌다 펴지는 뒤집기, 성공 광점/앞면, 실패의 어두운 뒷면, 선택 강조를 연결했다.

## 저장과 연출

강화는 실제 이전 단계부터 새 단계까지 약 0.62초에 순서대로 점등하고 약 0.4초에 잦아든다. 카드 뒤집기는 0.65초, 후광은 0.62초이며 원작과 동일한 프레임/타이밍이라고 주장하지 않는다. 성공한 거래가 먼저 저장되고 화면 효과만 재생한다. 연출 중 요청을 막고 닫기/메뉴는 사용할 수 있으며, 다시 열어도 결과를 재추첨하지 않는다. 새 타이머/빛 효과는 경제·확률·능력치 계산을 변경하지 않는다.

## 검증과 한계

- Godot 4.7.2 import 및 Main 부팅, 실제 성장/저장/터치 검사 92개, 연출 시간 검사 9개, 기존 UI fidelity 88개 통과. 최종 묶음 4/4. 초기 카드 비율의 정수 나눗셈으로 렌더 경고가 나왔으며 float 나눗셈과 작은 크기 방어로 수정한 뒤 연출/실제 렌더를 재확인한다. 원래 경고 로그도 보존한다.
- 실제 OpenGL 작은 화면과 큰 화면, 카드 선택/공개, 강화와 뒤집기 연속 프레임을 촬영한다. 프레임은 실제 Main에서 개발 fixture 상태로 시작하여 실제 개발 거래를 수행한 화면이다. 원작 수치 검증, 자연 플레이 획득 또는 실기기 검증은 아니다.
- 실제 Android 기기, 프레임 성능·발열·배터리, 원작 효과음/동영상 프레임 일치는 미검증이다.
- 기존 공식 수치 미확인 잠금과 `--growth-lab` 분리는 유지한다. 이 변경은 원작 전체 구현 완료가 아니다.

최종 실제 Main 렌더는 `evidence/refinement/screens/` 7장, `capture.txt`의 `GROWTH_CAPTURE_OK`로 보존했다. 비율 수정 후 연출 검사 9개 재실행 로그는 `presentation-fixed.txt`이며 렌더의 비유한 수 경고는 재발하지 않았다. 92개 성장 검사에는 연출 중 중복 요청/닫기/다시 로드 검증이 포함된다. 854×480 지정 시 일부 캡처 텍스처는 엔진 반올림으로 실제 폭 853px이다.

`motion-preview.mp4`는 실제 Main의 강화/카드 공개 장면을 90개 샘플 프레임으로 촬영해 30fps로 인코딩한 3초 미리보기다. 실시간 녹화나 Android 성능/원작 프레임 타이밍 증거가 아니다. H.264/yuv420p 854×480으로 Android 호환성을 고려했으며 홀수 폭에 오른쪽 검은 1px만 패딩했다. 실제 샘플별 타임스탬프를 저장하지 않았으므로 미리보기 재생 길이로 게임 연출 시간을 측정하면 안 된다.

개별 스크린샷 두 장과 미리보기는 Library 저장 성공을 확인했다. 이전 HTTP 401은 helper의 독립 HTTP 호출에서 발생했다. 이번에는 bundled helper 파일을 변경하지 않고 좁은 전송 어댑터에서 현재 세션에 연결된 Library 앱의 prepare/finalize를 호출했다. helper가 준비·바이트 전송·완료·파일 메타데이터 적용을 처리했으며 세 항목 모두 `succeeded`, `local_metadata_applied: true`였다. 인증 정보 복사나 변경은 하지 않았다. 개인 Library ID는 공개 저장소 문서에 넣지 않는다.
