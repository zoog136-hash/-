## 화면 근거와 변경

- [NC 문양 가이드](https://lineagem.plaync.com/guidebook/view?title=문양+시스템)의 실제 화면을 공개 가이드 API와 연결된 이미지로 다시 확인했다. 가로 탭, 왼쪽 단계 링, 오른쪽 효과, 흰색/청색/적색 확률과 하단 동작의 위계를 참고했다. 과거 화면의 비용·서버 개방 상태를 최신값으로 가져오지 않았다.
- [NC 수호성 가이드](https://lineagem.plaync.com/guidebook/view?title=수호성+시스템) 및 [2020-12-14 실제 선택 화면](https://gallo44.tistory.com/59)을 대조했다. 얇은 금속 테두리의 달·별 카드, 중앙의 여러 선택지, 위 제목과 하단 안내를 참고했다. 카드 3장은 기존 **개발 설정**이며 모든 원작 노드의 카드 수라는 의미가 아니다. 공식/보조 원본 이미지는 저장소에 복제하지 않았다.
- 전용 `growth_palette.gd`/`growth_surface.gd`로 석재 인셋·금속 모서리·탭 밑줄·버튼 눌림을 정리했다. 공통 테마는 수정하지 않았다. 변수 폰트의 가독성 있는 굵기와 제목/단계/확률/효과/보조 문구의 크기·색을 분리했다. 축복 포인트/수호석의 작은 자체 SVG 아이콘을 추가했다.
- 기존 자체 카드 atlas를 이미지 생성 도구로 편집했다. 큰 보석과 가시 장식을 줄이고 어두운 카드 바탕·새 초승달/별자리 문장·가느다란 금빛 테두리로 바꿨다. 원본 생성 PNG는 보존하며 실제 런타임 PNG와 SHA는 `assets/growth/PROVENANCE.json`에 있다.
- 여러 카드는 계속 사용자의 선택을 기다린다. 누르기/마우스 진입 시 약 0.12초의 테두리 반응, 실패한 카드의 어두운 문장과 X/선택 불가 문구, 성공의 별빛과 청록 테두리를 구분했다. 뒤집기·자동 선택은 추가하지 않았다. 이 반응 시간은 자체 표현이며 원작 영상 고증값이 아니다.
- 작은 화면의 결과 재도전/목록 버튼을 하단 고정 영역에 배치했다. 미개방 수호성은 소켓만 어둡게 처리해 노드 이름의 가독성을 유지했다. 개발 근사 안내와 원작 미확인 잠금은 유지한다.
