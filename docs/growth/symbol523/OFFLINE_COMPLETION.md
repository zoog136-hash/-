# 문양 단독플레이 후속 적용

PR #242의 기존 브랜치에서 절대 옵션35/35개 묶음과 일반485/485행을 연결했다. 원본 정의·기존 소비자에 대응하는 절대26개 묶음/일반470행과 **자체 근사가 필요한 절대9개 묶음/일반15행**을 구분한다. 자체 근사는 사용자의 ‘소스→기존 보고서→공개 검색→없으면 추정 적용’ 지시에 따른 TWILIGHT 설정이다. 원작 서버 수식 완성이나 모든 재료 획득·성장 과정 검증을 뜻하지 않는다.

## 새로 확인한 원본과 기존 소비자

- 누적523의 SymbolBonus·Bonus·BonusType·단위·조건을 다시 조인하고 선택 원본 표22개의 SHA/바이트를 보존했다. 원본 ZIP 두 개의 전체 CRC도 확인했다. 원본 비용140행, 확률87행, 일반485행과 절대46행/35묶음을 변경하지 않는다.
- 실렌 일반 옵션의 `InvokeOption / application10 / target15333`는 `InvokeOption15333 → InvokeOptionType5 Defence_DamageReduction`다. `IsDefence=true`, Param1=300, Param3/6=0이며 증분7행의 발동 가중치는 합계7%다. 실제 피격 RNG에서 리덕션300을 적용하고 HUD에 발동 결과를 표시한다. 타입이 사용하지 않는 Param2=86923을 별도 주문·재료로 추측하지 않는다. 원본 이펙트25196의 새 아트를 전달했다고 주장하지 않는다.
- main의 `world._normalize_option_policies`는 이미 PvP 수치를 PvE로 바꾼다. 마프르 II의5/ V의2%, 파아그리오 I의세 공격 유형3을 이 소비자로 연결했다.
- 기존 정수 감소 무시→추가 피해, 회피 무시→유형별 명중 정책도 재사용한다. 파아그리오 II/IV, 실렌V를 연결했다. 일반 공격과 원본 고정 위력 주문에 각 효과가 한 번씩만 적용되는지 검사했다. 원작 PvP나 대상 리덕션 수식을 재현한 것으로 표현하지 않는다.

## 명시적인 자체 전투 모델

`data/growth/symbol_combat_policy.json`에서 조절하며 UI 상단과 개별 설명에 ‘자체 근사·설정 가능’을 표시한다. 모든 보너스 원문 행은 변환값과 별도로 남는다.

| 적용 항목 | 기본 로컬 동작 | 조절 필드 |
| --- | --- | --- |
| 죽음 | 원본 포인트당 피해1 추가 | death_damage_per_point |
| 일반·유형별 %감소 무시 | 해당 원본 %를 공격 피해 증가로 근사 | ignore_percent_damage_scale, outgoing_percent_cap |
| 그랑카인 DamageDampOption13 | 1000ms 안의 다음 피격에 원문 합계9% 적용 | damage_damp_window_ms |
| 연사 피해 감소 | 기존 보스 volley를 연사 문맥으로 연결, 원문5 | rapid_fire_boss_kinds |
| 아머 브레이크 감소 | 기존 보스 charge 문맥에서 해당 공격 유형18%를 한 번 적용 | armor_break_boss_kinds |
| 감소 무시 효율 | 기존 보스 nova의 자체 무시10%를 원문 효율7%만큼 상쇄, 자기 감소량 이상으로 방어를 추가하지 않음 | npc_ignore_percent_by_boss_kind |

아머브레이크 세 번째 원문 행의 UnitValue 스케일은 주변 두 Percentage 행과 공식18% 설명을 바탕으로 한 자체 해석이다. 방어는 기존 최소피해1/감소상한90%를 유지한다. 기존 공격 판정·투사체 생명ID·세대·LOS 검사를 유지하며 보스 문맥은 개별 타격 동안만 전달한다. 연속피격 시각은 세이브로 이월하지 않는다.

자체 모델을 사용하는 절대 묶음은 **그랑카인 II/III/IV/V, 아인하사드 II, 실렌 I/II/IV, 파아그리오 V**다. 일반15행은 그랑카인 죽음5행/연속피격7행, 아인하사드 감소무시3행이다. `estimates_enabled=false`이면 이 효과와 새 등급 개방을 멈춘다. 기존 보유 등급은 유효하게 저장·로드하며 삭제·환급·중복 지급하지 않는다. 그 외 원본·기존 소비자 효과는 유지한다.

## 다른 지역 기억 이동

에바III에서 기억한 **실제 방문 좌표**를 사용한다. 기존 source84 런타임·NPC 입장 정책·충돌·layout/source SHA·세이브 후보 활성화 API를 재사용한다. 원본 M좌표를 추정하지 않는다. 목적지 팩 부재, 지형 변경, 막힌 지점, 레벨·아데나 부족, 보류 중인 세이브 전환을 거부한다. 같은 맵 이동은 기존 경로를 유지한다.

확인 창은 주문서/기존 마법의 MP·HP·재료·쿨타임과 지역 입장료를 보여준다. 이동 전 현재 전체 세이브를 확정한 뒤 SHA 검증 백업과 별도 목적지 후보를 만들고, 실제 정상 로드 후 기존 활성 파일 포인터를 바꾼다. 후보 작성·포인터 활성화가 실패하면 이전 전체 세이브로 복구한다. 복구마저 실패하면 원본/후보를 보존하고 저장을 차단한다. 재시도로 중복 비용을 차감하지 않는다. 입장 아데나 이력은 문양 강화 환급과 분리한다.

실제 검증은 아덴↔오만1층의 기존 NPC 방문→기억→주문서/공용 텔레포트 선택→네이티브 확인→이동→재로드다. 오만1층의 기존 레벨25/입장료1500을 그대로 사용한다. 설치·방문·지형 검증을 통과하는 다른 source84 목적지도 동일 경로를 쓰지만84개 지역 전체를 실행·시각 검증한 결과는 아니다.

## 근거와 검증 경계

우선순위는 실제 제공된523 소스, main 코드와 기존 `docs/growth/RESEARCH.md`·인계 분석, 공개 자료 순서다. [공식 문양 가이드](https://lineagem.plaync.com/guidebook/view?title=%EB%AC%B8%EC%96%91+%EC%8B%9C%EC%8A%A4%ED%85%9C), [절대 옵션 개선](https://lounge.plaync.com/feed/62455?country=KR&locale=ko-KR), [공식 확률](https://probability.plaync.com/lineagem/view?probCategoryId=683568e3068cf65296bc535e), [기억 장소 선택 설명](https://lounge.plaync.com/feed/80914?country=KR&locale=ko-KR)을 대조했다. 공개 자료의 효과 이름·값만으로 확인되지 않은 정확한 서버 전투 수식을 확정하지 않는다. 반지 전용 MP면제·할인을 문양으로 복사하지 않는다.

격리 XDG의 실제 Main/current-map/save, Godot4.7.2와 Linux llvmpipe X11 네이티브 터치로 검사했다. 전투 fixture는 필요한 상태·RNG를 통제하고 UI 때 배경 시뮬레이션을 정지한다. 전체 테스트 수와 파일 SHA는 `validation-offline.json`, 로그는 `evidence/offline/`에 기록한다. 캡처는 로컬 검증 디렉터리에만 보존하며 새 외부 아트 팩으로 배포하지 않는다. Windows/Android/오디오·전체84맵·원작 동등성 검증은 수행하지 않았다.

원작 별도 강화정보 저장/복구 상품과 서버 가용성·일일 초기화 정책은 미확정이다. 기존 일반 세이브 저장/재로드와 다르다. 다른 기능 PR/main은 병합하지 않으며 원격 CI 수동 실행·재실행 없이 `[skip ci]`를 유지한다. 원본 백업/최신 문양 데이터 적용팩/로컬 맵 검증용 사본은 각각 별도 보관 영수증으로 구분한다.
