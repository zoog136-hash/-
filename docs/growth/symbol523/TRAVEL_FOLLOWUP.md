# 에바 III 기억 장소 순간이동 후속 적용

현재 절대 옵션은 효과 연결20/35개 묶음, 순차 신규 개방13/35개 묶음이다. 에바 I~V와 사이하 I~V, 마프르·그랑카인·아인하사드 I를 처음부터 순서대로 개방할 수 있다. 상위 효과만 연결된 기존 보유 등급과 새로 획득할 수 있는 등급은 구분한다. 이전 `792def740`의19/10개 결과는 과거 검증 기록이다.

## 원문과 공개 자료에서 확인한 것

523의 에바 III은 `SymbolAbsoluteBonusView → Bonus505854 → BonusType154 TeleportControl`이고 값1이다. 같은 이름의 무작위 순간이동이나 무료 NPC 이동으로 바꾸지 않는다. [공식 문양 가이드](https://lineagem.plaync.com/guidebook/view?title=%EB%AC%B8%EC%96%91+%EC%8B%9C%EC%8A%A4%ED%85%9C)에는 에바 특화 효과로 순간이동 조종이 있다. [2026-09-10 공식 설명](https://lounge.plaync.com/feed/80914?country=KR&locale=ko-KR)은 조종 효과에서 주문서 또는 텔레포트 마법으로 자기 기억 장소를 선택하는 동작을 설명한다. 해당 반지의 MP 면제·지역 이동 할인은 별개 항목이므로 문양에 복사하지 않았다.

원본의 절대 강화 비용·성공률과 일반 옵션 수치는 그대로 사용한다. 에바 III/IV/V를 막던 미연결 소비자를 추가해 뒤의 물약 회복량10·회복률10%도 순서대로 획득할 수 있다. 원본 전체 재료 획득/육성 과정을 재현했다는 뜻은 아니다.

## 실제 동작과 로컬 범위

- 기존 문양의 에바 탭에서 ‘기억 장소’를 열어 현재 위치를 이름으로 등록·삭제한다. 실제 인벤토리/퀵슬롯 순간이동 주문서와 기존 일반 텔레포트 마법을 사용하면 장소 선택 화면이 열린다.
- 선택 후 화면에 소비할 주문서/MP/HP를 표시하고 확인 버튼을 누를 때만 이동한다. 창을 닫거나 목적지를 고르지 않으면 비용을 소비하지 않는다. 기존 MP·HP·재료·재사용 대기, 습득·직업·레벨 제한을 다시 검사한다. 레거시 직업 텔레포트도 같은 선택 경로를 연결하되 실제 UI 검증은 현재 공용 텔레포트로 했다.
- **현재 맵 안의 기억 장소만 지원한다.** 다른 맵은 기존 입장·비용·일일/던전 조건을 우회하지 않는다. 이 범위와 최대16개/이름40자는 `data/growth/symbol_travel_policy.json`의 명시적인 TWILIGHT 설정이다. 원본 서버의 기억 슬롯 수로 주장하지 않는다.
- 맵ID와 지형 revision/source SHA를 저장한다. 지형이 바뀌거나 착지점이 막히면 재등록을 요구하며 좌표를 자동 보정하지 않는다. 현재 원본 규칙을 사용하는 맵의 순간이동 제한, 스턴·공포·사망 상태도 확인한다. 현재 TWILIGHT source-map의 기존 로컬 여행 가용성은 유지한다.
- 일반 세이브 schema1에 선택 필드 `growth.teleport_bookmarks`를 추가한다. 기존 세이브에는 빈 목록으로 적용하고 정상 진행·인벤토리를 자동 지급/초기화하지 않는다. 잘못된 좌표·형식과 용량 초과 저장은 거부해 원본 바이트를 보호한다.
- 목적지·MP/HP·재사용 대기·재료·성장 revision을 함께 저장한 뒤 화면/이동을 반영한다. 저장 실패 때 실물ID·기억 목록·좌표·재료·MP·쿨타임·버프를 보존한다. 관련 없는 버프/소환을 없애는 전체 스킬 초기화는 호출하지 않는다. 텔레포트 마법의 은신 해제는 저장과 실행 상태에 함께 반영한다.

## 검증과 남은 것

Godot4.7.2의 실제 Main/current source-map과 격리 XDG 프로필에서 검사한다. 실제 네이티브 터치로 등록→주문서 선택→확인→결과→삭제→작은 화면 취소 경로를 사용한다. 현재 일반 텔레포트 마법의 실제 소비 경로, 부족한MP, 재사용 대기, 오래된 요청, 변경/막힌 지형, 교차 맵 거부, 저장 실패와 바이트/버프 보존도 검사한다. 원본30단계·에바 I/II 보유 상태는 명시적인 fixture이며 III~V는 실제 거래로 획득한다.

네이티브 화면·거래47개, 동일 headless 경로43개, 기존 문양 거래753개·절대 전투/저장75개·실제 Main/current map/save32개가 통과했다. Python staging7개와723시트/41,442프레임 리소스 SHA도 통과했다. 현재 결과·출력 SHA와 화면3장은 `validation-travel.json`, `evidence/travel/`에 보존한다. 테스트의 배경 시뮬레이션을 정지하므로 멀리 옮긴 필드의 배경 스트리밍/프레임 성능/오디오·Windows·Android 승인을 의미하지 않는다. 새로운 원본 아트 팩을 전달하지 않았으며 기존 원본 장부도 변경하지 않았다.

다시 조사한 나머지 절대15개 묶음은 PvP 전용(마프르 II/V, 파아그리오 I/IV/V, 실렌 II/IV/V), 실제 감소 항/공격 종류가 필요한 감소 무시(파아그리오 II, 아인하사드 II, 실렌 I), 연사·아머 브레이크·죽음·감소 무시 상쇄(그랑카인 II~V)다. 원문 값은 있지만 현재 게임에는 필요한 PC 전투/대상 감소 항/해당 상태 소비자가 없거나 서버 수식이 미확정이다. 이를 공격력 가산으로 대체하거나 경제 수치 자체 설정 승인으로 활성화하지 않았다. 일반 미연결22행, 원작의 별도 강화 정보 저장·복구 상품도 남는다.
