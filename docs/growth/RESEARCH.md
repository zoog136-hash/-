공식 가이드 스크린샷에서 확률 변경 비용 1과 강화 7/20회 상태의 다음 강화 비용 3,840만 읽을 수 있었다. 이는 역사적 스크린샷 근거이며 현재 서버 경제의 독립 검증은 아니다. 나머지 19개 비용, 초기화 개수, 자동 축복 포인트 환산 비율, 특화 강화 비용은 `null`/보류다. 공식 자료의 표기 '-'나 오타를 임의 보정하지 않고 `reference_table`에 사실표로 남겼다.

## 구현한 흐름

- 기존 메뉴 → 문양/수호성 → 항목 선택 → 효과/조건/재료 확인 → 확인/취소 → 원자적 저장 → 결과 표시.
- 자체 원형 30칸 문양 도형, 3단계 강조, 짧은 광륜 결과 연출. 기존 테마·한글 폰트·창·스크롤·터치 전달 재사용.
- 문양 7종의 확인된 HP/MP/AC/MR/무게/물약 회복/경험치/대미지/명중/SP/일부 치명타를 기존 전투 계산에 연결. 분리된 미지원 효과를 화면에 명시. 원본 단계표는 설정의 `reference_table`에 보존.
- 1회/5회 거래, 30단계 조기 종료와 실제 시도 비용만 차감, 강화 횟수 상한, 확률 변경의 비환급 비용, 초기화 강화 포인트 환급.
- 수호성 6종 스킬 목록과 미확인 노드 조건 표시. 설정이 검증된 경우 사용할 선행 조건/재료/카드 결과/대표 설정 거래 경로. 이미 지불한 카드 결과는 저장하여 닫기·재실행으로 다시 뽑히지 않음.
- 수호석 제작(주문서 2 + 마력의 돌 100), 성수(중) → 100포인트. 기존 실제 인벤토리만 사용하며 무료 재료 지급/실제 결제는 없음.
- 기존 전체 저장 파일에 `growth` 필드 추가. 구버전은 빈 성장 상태로 읽음. 손상/미래 버전은 저장 보호. 저장 실패 시 성장/재료 미변경. revision 검사로 중복 클릭/오래된 확인 차단.

## 원작과 다른 점 / 미완료

- **수호성은 원본 노드 트리 복원이 아니라 조사된 스킬 목록**이다. 선행 관계·노드 수·카드 수·해금 성공률·개별 스탯/비용 미확인. 최초 활성화도 기본 설정에서 차단된다. 임의의 트리와 확률을 만들지 않았다.
- 문양 최초부터의 실플레이 강화 경로는 비용 조사 부족으로 잠김. 모든 강화/초기화 규칙이 플레이 가능한 완성본이라고 볼 수 없다.
- 수호성 발동 확률은 일부 확인했지만 피해량/회복량/범위/대기시간이 없어 전투 스킬 발동·퀵슬롯 연결은 미구현. 대표 변경 대기시간도 미확인이라 첫 선택 이후 변경 차단.
- 문양 특화/절대 옵션, 그랑카인 피해감소·죽음, 아인하사드 복합/충전 옵션, 실렌 장막, 물약 쿨타임, 축복 소모 감소, MP 자연회복 등의 미지원 효과는 다른 스탯으로 바꾸지 않음.
- 확률 변경 시 기본 +2/+3 확률이 1% 미만인 경계에서 공식 처리 규칙을 확인하지 못했으므로 그 구간의 변경 차단.
- 계정/동일 서버 공유 대신 기존 오프라인 저장 범위만 사용. 서버·계정 연동 없음.
- 신규 재료의 원작 획득처/드랍/가격을 만들어 넣지 않았다. 기존 저장에 재료가 없다면 부족 메시지로 중단된다.
- 실제 Android 기기 및 APK 실행은 미검증. Linux에서 화면 크기/네이티브 터치 이벤트 검증은 별도 기록한다.

## 후속 재개

공식 최신 회차별 문양 비용과 초기화 개수, 수호성 노드별 선행·비용·카드/성공률·스탯 데이터 확보가 우선이다. `lineage_growth.json`의 null을 근거와 함께 대체하고 기존 테스트 전용 fixture와 분리하여 검증해야 한다. 미확인 값을 로컬 임의 밸런스로 활성화하지 않는다.

서버별 개방 차이: [공식 서버 설정](https://lineagem.plaync.com/guidebook/view?title=서버+설정) 검색 노출에는 리부트 월드가 조우/아툰/질리언/크리스터 및 에바/파아그리오/마프르/사이하로 제한된 표가 있다. 이번 목록은 공식 가이드의 조사 합집합이며 모든 서버에서 최신 제공된다고 주장하지 않는다. TWILIGHT는 서버 선택을 지원하지 않으므로 서버별 개방 시뮬레이션도 구현하지 않았다.

## 2026년 변경 대조

[2025-06-18 공지](https://lounge.plaync.com/feed/35343?country=KR&locale=ko-KR), [2026-05-22 이전 정책](https://lounge.plaync.com/feed/69734?country=KR&locale=ko-KR)도 대조했다. 수호성 개방/시도 이력은 구별되는 정보다.
