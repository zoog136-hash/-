# 문양·수호성 조사 / 구현 경계 (2026-10-24)

기준: `zoog136-hash/-` main `e0a14f07da7764598822be669d05b3c2985d13eb`.
공식 자료를 읽어 확인된 사실만 설정으로 옮겼다. **전체 원작 구현 또는 완성된 성장 경제가 아니다.**
특히 기본 배포 설정에서 최초 문양 강화 비용과 수호성 노드 개방 규칙이 미확인이므로 해당 버튼은 잠긴다. 별도 `--growth-lab` 개발 모드에서만 명시된 근사 설정으로 실제 거래를 실행할 수 있다. 일반 설정에 근사 비용을 섞지 않는다.

검색 결과만 노출되는 동적 페이지는 공식 웹 클라이언트의 공개 read-only API로 가이드/확률 본문을 확인했다. URL, 응답 해시, 조회일은 `data/growth/sources.json`에 있다. 패치 공지는 검색 노출 범위에서 확인했으며 전체 본문 재현으로 주장하지 않는다. 원본 API HTML·공식 스크린샷을 저장소에 재배포하지 않는다.

공식 가이드 스크린샷에서 확률 변경 비용 1과 강화 7/20회 상태의 다음 강화 비용 3,840만 읽을 수 있었다. 이 화면은 **그랑카인**이므로 그랑카인의 8회차만 기록한다. 다른 문양의 동일 회차 비용으로 일반화하지 않는다. 역사적 스크린샷 근거이며 현재 서버 경제의 독립 검증은 아니다. 나머지 공식 비용 전체표, 자동 축복 포인트 환산 비율, 특화 확률 강화 비용은 `null`/보류다. [2019-12-11 공식 공지](https://lineagem.plaync.com/board/update/view?articleId=5defcaecd389e90001d2c52b)의 검색 노출 본문에서 초기화 두루마리 1장으로 문양 1종 초기화를 확인하여 수량 1을 사용한다. 최신 모든 서버의 운영값 재검증은 아니다. 공식 자료의 표기 '-'나 오타를 임의 보정하지 않고 `reference_table`에 사실표로 남겼다.

## 구현한 흐름

- 기존 메뉴 → 문양/수호성 → 항목 선택 → 효과/조건/재료 확인 → 확인/취소 → 원자적 저장 → 결과 표시.
- 자체 생성 래스터 문장 7종·금속/석재 배경·카드 앞뒷면과 원형 30칸 링, 3단계 강조, 광륜 결과 연출. 기존 테마·한글 폰트·창·스크롤·터치 전달 재사용.
- 문양 7종의 확인된 HP/MP/AC/MR/무게/물약 회복/경험치/대미지/명중/SP/일부 치명타를 기존 전투 계산에 연결. 분리된 미지원 효과를 화면에 명시. 원본 단계표는 설정의 `reference_table`에 보존.
- 1회/5회 거래, 30단계 조기 종료와 실제 시도 비용만 차감, 강화 횟수 상한, 확률 변경의 비환급 비용, 초기화 강화 포인트 환급.
- 수호성 6종 스킬 목록과 미확인 노드 조건 표시. 설정이 검증된 경우 사용할 선행 조건/재료/카드 결과/대표 설정 거래 경로. 이미 지불한 카드 결과는 저장하여 닫기·재실행으로 다시 뽑히지 않음.
- 수호석 제작(주문서 2 + 마력의 돌 100), 성수(중) → 100포인트. 기존 실제 인벤토리만 사용하며 일반 플레이의 무료 재료 지급/실제 결제는 없음. 개발 모드만 최초 별도 저장에 시험 재료를 지급한다.
- 기존 전체 저장 파일에 `growth` 필드 추가. 구버전은 빈 성장 상태로 읽음. 손상/미래 버전은 저장 보호. 저장 실패 시 성장/재료 미변경. revision 검사로 중복 클릭/오래된 확인 차단.

## 원작과 다른 점 / 미완료

- **수호성은 원본 노드 트리 복원이 아니라 조사된 스킬 목록**이다. 선행 관계·노드 수·카드 수·해금 성공률·개별 스탯/비용 미확인. 최초 활성화도 기본 설정에서 차단된다. 일반 모드에서 임의 트리/확률을 원작으로 제공하지 않는다. 개발 모드는 아래 합성 연결도로 동작을 검증한다.
- 문양 최초부터의 실플레이 강화 경로는 비용 조사 부족으로 잠김. 모든 강화/초기화 규칙이 플레이 가능한 완성본이라고 볼 수 없다.
- 수호성 발동 확률은 일부 확인했지만 피해량/회복량/범위/대기시간이 없어 전투 스킬 발동·퀵슬롯 연결은 미구현. 대표 변경 대기시간도 미확인이라 첫 선택 이후 변경 차단.
- 일반 모드의 절대 옵션, 그랑카인 죽음, 아인하사드 복합 옵션, 실렌 장막 등은 미구현이다. 후속 변경에서 확인된 그랑카인 피해 감소, 아인하사드 충전, 에바 물약 쿨타임, 사이하 축복 소모 감소/MP 회복 수치를 연결했다. MP 회복 간격은 TWILIGHT 기존 회복 주기를 사용하며 원작 주기 재현으로 주장하지 않는다. 전투 피해의 반올림/효과 합산 순서도 기존 TWILIGHT 규칙이다.
- 확률 변경 시 기본 +2/+3 확률이 1% 미만인 경계에서 공식 처리 규칙을 확인하지 못했으므로 그 구간의 변경 차단.
- 계정/동일 서버 공유 대신 기존 오프라인 저장 범위만 사용. 서버·계정 연동 없음.
- 신규 재료의 원작 획득처/드랍/가격을 만들어 넣지 않았다. 기존 저장에 재료가 없다면 부족 메시지로 중단된다.
- 실제 Android 기기 및 APK 실행은 미검증. Linux에서 화면 크기/네이티브 터치 이벤트 검증은 별도 기록한다.

## 후속 재개

공식 최신 회차별 문양 비용과 절대 옵션 전체 효과, 수호성 노드별 선행·비용·카드/성공률·스탯 데이터 확보가 우선이다. `lineage_growth.json`의 null을 근거와 함께 대체하고 기존 테스트 전용 fixture와 분리하여 검증해야 한다. 일반 플레이에 근사 밸런스를 적용하려면 사용자에게 차이를 설명하고 선택받아야 한다.

서버별 개방 차이: [공식 서버 설정](https://lineagem.plaync.com/guidebook/view?title=서버+설정) 검색 노출에는 리부트 월드가 조우/아툰/질리언/크리스터 및 에바/파아그리오/마프르/사이하로 제한된 표가 있다. 이번 목록은 공식 가이드의 조사 합집합이며 모든 서버에서 최신 제공된다고 주장하지 않는다. TWILIGHT는 서버 선택을 지원하지 않으므로 서버별 개방 시뮬레이션도 구현하지 않았다.

## 2026년 변경 대조

[2026-03-18 공식 패치](https://lounge.plaync.com/feed/62455?country=KR&locale=ko-KR)를 원문으로 확인했다. 절대 옵션 V 및 확률/확정 강화의 별도 버튼, 축복의 열쇠 확정 강화가 추가되었다. I~V 열쇠 비용은 기존 6종 40/66/132/200/400, 실렌 60/100/200/300/600이며 열쇠 1개는 1,000 축복 포인트다. 설정과 화면에 표시했으나 전체 절대 효과 및 초기화 처리의 구현이 없어 일반 모드 절대 강화는 잠근다. 개발 모드에서는 정확히 확인된 열쇠 비용과 명시적인 합성 HP 효과로 I~V 확정 거래를 검증한다. 구가이드만으로 최신 절대 옵션을 구현했다고 주장하지 않는다.

[2025-06-18 공지](https://lounge.plaync.com/feed/35343?country=KR&locale=ko-KR), [2026-05-22 이전 정책](https://lounge.plaync.com/feed/69734?country=KR&locale=ko-KR)도 대조했다. 수호성 개방/시도 이력은 구별되는 정보다. [2020-12-14 보조 설명](https://gallo44.tistory.com/59)의 실패 카드 제거·마지막 카드도 재료 소모 흐름을 참고하여 남은 카드/실패 카드/시도 횟수/고정된 숨은 정답을 저장하는 엔진을 작성했다. **이 카드 선택 방식은 최신 공식 전체 노드 규칙 확인이 부족한 잠정 모델**이며 `card_rule: null`로 기본 활성화 차단한다. 개발 모드와 테스트에서 명시적인 합성 노드로 이력 보존을 검증한다. 무한 독립 확률 추첨 방식으로 원작을 대체하지 않는다.

같은 2026-03-18 공지의 절대 V 사실표도 `absolute_v_reference`에 기록했다: 에바 물약 회복률 10%, 파아그리오 PVP 감소 무시 2%, 마프르 PVP 감소 2%, 사이하 경험치 15%, 그랑카인 감소 효율 7%, 아인하사드 스턴 내성 5%, 실렌 PVP 근/원거리 회피 무시 각각 2. 이 사실표 추가가 해당 효과의 실행 구현을 의미하지 않는다.


## 별도 개발 모드 (후속 구현)

디버그 엔진에서 `godot --path . -- --growth-lab`으로 명시적으로 시작한다. 배포 release 빌드에서는 작동하지 않는다. 저장은 `user://twilight_growth_lab_v1.json`이며 일반 파일 경로와 다르다. 저장의 profile 값도 검사하므로 파일을 복사해도 서로 읽지 못한다. 신규 개발 저장만 100만 포인트, 수호석/초기화 두루마리/성수 각 100개, 열쇠 5,000개를 제공한다. 화면에 원작 수치가 아닌 개발용이라고 표시한다.

- 비용: [김영곤 사용자 표, 2023-09-28](https://www.inven.co.kr/board/lineagem/5056/21764)를 직접 확인했다. 기본 4종/아인하사드·그랑카인/실렌의 1~20회 표를 `lab_profile.json`에 분리했다. **공식 미검증 과거 자료**이며 최신 원작 비용이라고 주장하지 않는다.
- 수호성: 조사된 목록을 일렬 선행 관계로 잇는 합성 트리. 모든 노드 수호석 1개/카드 3장/HP +5. 대표 수호성 그룹의 열린 노드 효과를 합산한다. 대표 교체 대기는 개발 모드 0초다. 실제 원작 노드 비용·카드 수·효과가 아니다.
- 절대 옵션: 30단계 이후 I~V 확정 강화, 확인된 열쇠 비용 차감, 단계별 합성 HP +5. 원작 I~V 효과의 대체 구현으로 주장하지 않는다. 개발 초기화는 절대 단계도 삭제하고 열쇠는 환급하지 않는 **검증용 규칙**이다. 일반 플레이는 잠김.
- 공식 V 사실표는 별도 보존하고, 개발 HP 값과 구분한다. 확률 절대 강화 10%는 표에만 보존; 비용·세부 처리 미확인으로 실행 미구현.
- [수호성 이력 이전 공지](https://lounge.plaync.com/feed/74960)는 시도/잔여 이력 지속의 보조 확인 대상이다. 노드별 초기 카드 수·재료 개수나 자유 초기화 버튼의 근거로 사용하지 않는다. 원문 전체 대조 여부는 sources 기록을 따른다.

## 시각 자산

공식 가이드의 실제 문양 원형 링/중앙 문장/우측 수치, 수호성 어두운 별자리/연결 노드/카드 화면을 직접 보고 구성 참고만 했다. 공식 이미지·로고는 저장소에 복사하지 않았다. 이미지 생성 도구로 자체 문장 atlas, 석재 별자리 배경, 카드 앞·뒷면 atlas를 제작했다. `assets/growth/PROVENANCE.json`에 생성 방식과 해시를 기록한다. UI는 기존 한글 폰트·네이티브 터치·테마를 재사용한다. 원작과 픽셀 단위 일치 또는 정식 미술 자산이라고 주장하지 않는다.
