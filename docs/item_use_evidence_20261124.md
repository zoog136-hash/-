# 원본 523 아이템 사용/가방 확인

## 구분

- 원본 정의 ZIP의 ItemClass 34,743개를 읽었다. TestItem을 제외한 30,398개 중 수정 전 30,274개가 게임 카탈로그로 투영되고 124개는 투영되지 않았다. 이는 정의/실행 소유자 대조이며 34,743개를 직접 눌렀다는 뜻은 아니다. 장비, 재료, 서버 조건 미확인, 내부 발사체는 독립적인 가방 사용으로 분류하지 않았다.
- 미투영 124개 중 사용자가 비활성화한 정확 94개는 새 획득/사용에서 걸러 냈다(기존 17 + 추가 38 + 이동 주문서 39). 같은 이름의 다른 ID나 일반 이동 주문서/이동 부적 종류 전체가 대상이 아니다. 원본 표와 기존 보유 기록은 삭제하지 않는다.
- 드래곤의 다이아몬드 #139581의 원본 설명은 기본 충전량 100을 명시한다. 기존 아인하사드 충전 소유자와 원본 레벨 보너스 그룹 12가 그대로 적용된다. 과거 이전 기록의 차감 수량만 한 번 복구한다. 차기 계정에 임의 지급하지 않는다.

## 이번에 확인한 실게임 경로

- 원본 선택 상자의 확인 시 소비 소유자에 저장용 영수증을 ItemClass 레코드로 넘기던 오류를 수정했다. 검증된 실물 레코드의 원본 행, 원본 표 행, 영수증, 수량을 각각 비교한다. #307971은 최초 원본 Reward #328841, SelectReward #10671의 네 원본 자식 상자(#307931/307941/307951/307961)를 선택할 수 있다. 후보·자식 보상 비율은 만들지 않았다.
- 데스 큐브 선택 상자 #189834와 특별한 뿔피리 선택 상자 #353592의 원본 획득 후 수명을 기존 소유자와 연결했다(각각 24시간·72시간). 실제 가방의 선택창 열기 및 확정에서 모두 검증하여, 창을 열어둔 사이 기한이 지나도 보상이나 수량이 바뀌지 않는다. 유효본의 정확 선택과 재로드는 확인했다.
- 마녀의 마력 회복제 일반/원정대 #2501, #183493는 원본 설명과 일치하는 즉시 MP 1000 및 30분 재사용을 연결했다. 별도 원본 1초 소비 메타데이터와 재사용을 혼동하지 않는다. 기존 게임 내 경과/저장 규칙을 사용하며, 강제 저장 실패에서는 물약·MP·재사용 상태가 모두 이전대로 남는다.
- 원본 자체는 재사용 이동 효과를 제공하지만 재료 슬롯이라 가방에서 사용 표시가 사라진 정확 34개 부적을 찾았다. 이 부적만 기존 이동 소유자가 승인하면 사용을 표시한다. 동일 카테고리이더라도 원본 효과가 없는 #200742는 제작 재료로 남는다. #19372와 #122424는 실제 원본 가방과 기본 가방에서 레벨/지도 조건과 잔량 보존을 확인했다. 본 테스트에는 목적지 맵을 설치하지 않았으므로 실제 맵 이동을 새로 확인한 것은 아니다.
- 에스카로스 바로가기는 원본 523 Mission_Dungeon_All 및 Mission_DungeonSpecial_Btn의 #314 행을 사용한다. 원본 Img_Special ImageView에 원본 WorldDungeon_Escaros.png를 텍스처로 연결한다(원본 위치/크기). 조건은 기존 에스카로스 런타임과 동일한 85레벨·아데나 100,000·비탄의 동굴 Land #47954다. 원본 UI 미설치 시 디버그 화면 대신 안내/기존 진입만 제공한다. 요정 숲·영지 및 도착 이후 에스카로스 현장 활동은 별도로 유지한다.

## 미확인 범위

- 29개 Arrow 행은 일반 가방 탄약으로 공개하지 않았다. 원본 SpellBonus의 AmmoClassID 관계에서 20개, 그중 11개의 현 플레이어 카탈로그 주문 연결을 확인했다(변형 참조/실제 발동과는 별개). 하트 시커는 SpellBonus #552978 → Bonus #1570568 → ItemClass #261738의 정확 연결과 Spell #86758의 출발 스프라이트 #25373/액션 0을 이용한다. 실제 Main에서 기존 시전·발사·충돌 사이에 원본 스프라이트가 표시되며, 시각 선택 전후 모두 11틱·발사 1·충돌 1, HP/MP·RNG·상태·재사용이 동일했다. 새 장비/탄약 수량·피해·조건을 만든 것은 아니다. 다른 발사체의 원본 실전 발동은 별개 검증 항목이다.
- 이전 일지 등의 원본 아이콘 연결은 중간 커밋의 증거다. 이후 요청으로 정확 424개 퀘스트 전용 항목을 새 공급·활성 가방·직접 사용에서 제외했다(일반 206, TestItem 218, 앞선 94개와 겹침 없음). 이 정책으로 일반 검토 대상은 30,098개다. 퀘스트에서 주는 일반 물약·장비·카드 및 일반 레벨/선행 조건은 유지하며 원본 표와 과거 보유 기록을 지우지 않는다. 식별할 수 없는 일반 슬롯에는 대체 아이콘을 만들지 않는다.
