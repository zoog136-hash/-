메뉴의 **출석·패스·생활**에서 기존 비공개 공통523 ZIP을 설치하고 완전히 재시작합니다. 설치기는 고정 크기·SHA와 1,065표의 목록을 확인하며, 표를 사용할 때 원본 해시를 검사합니다. 원본 JSON·이미지·보고서는 이 PR에 포함하지 않습니다. 기존 팩을 재사용하고 별도 리소스 팩을 만들지 않습니다.

작업 기준은 main `f4cc0138613a6c98898c57d479b5247a849b96ab`입니다. 세공·제련·연금·장비 세트·발동 스킬 교체는 최신 사용자 지시에 따라 이번 PR에서 제외했습니다. 오림·시련의 탑, 일반 퀘스트와 다른 진행 PR을 복제하지 않습니다. 혈맹·공성·펫·투기장·지구라트는 제외합니다.

## 확인된 규칙과 자체 정책

원본 표의 수치·서버·등급·슬롯·기간·후보를 유지합니다. `data/unconfirmed523/twilight_policy.json`의 다음 값은 **조절 가능한 TWILIGHT 추정**입니다.

- `luckybag_random_mode=source_weights`: 원본 후보와 원시 가중치를 사용한 한 번의 가중 추첨입니다. 서버의 추첨 횟수·미명명 결과를 복원했다는 뜻이 아닙니다.
- `random_reward_weight_mode=equal_estimate`: 원본에 후보만 있고 확률이 없는 RandomReward를 동일 가중치로 실행합니다. 공식 확률이 아닙니다.
- `attendance_blessing_base=200`: 원본의 수량 0인 출석 축복 보상에 기존 TWILIGHT 레벨별 충전 배수를 적용합니다. 원작의 내부 축복 수식이 아닙니다.
- `luckybag_final_scope=source_item`, `luckybag_final_completion=once`: 이 실행기에서 관측한 동일 원본 아이템의 소비를 합산하고 한 번 완료합니다. 원본 서버의 과거 개봉 이력·초기값·리셋 범위는 확인되지 않았습니다. 명시적 풀별 정책을 둘 수 있지만 확인된 8951의 7회 임계값과 원본 사용 간격은 바꾸지 않습니다.
- `conditional_percent_mode=percentage_points_estimate`: 성배의 공격 종류별·PvP 리덕션 무시를 기존 전투기의 감소 예산에서 한 번만 차감합니다. PvP 감소는 실제 PvP 표식이 있는 공격에만 적용합니다. 원본 서버 계산 순서를 복원한 수식이 아니며 `disabled`로 끌 수 있습니다.
- `undead_damage_mode=uniform_1_to_max_estimate`: 실제 언데드 대상의 근거리·원거리 타격에 원본 최대값까지 1 이상 균등 추첨합니다. 원본은 최대값을 명시하며 이 분포·계산 순서는 자체 추정입니다. 마법·일반 대상에는 적용하지 않으며 `disabled`로 끌 수 있습니다.
- 시간대 미지정 원문 일정은 실행 장치의 로컬 시간대를 기본으로 해석합니다. `time_policy.utc_offset_minutes`로 고정할 수 있습니다. 절대 Unix 만료 시각에 시간대를 다시 더하지 않습니다.

## 남은 범위

원본 던전 지형·서버·멀티플레이, 시험용·만료 또는 최종 보상 임계값이 확인되지 않은 상자, 범위 밖 보상·특수 소비, 모든 원본 아이템의 자연 공급·사용·연출은 완료 범위가 아닙니다. 미지원 보상을 가진 청구와 상자는 소유·청구 상태를 보존하고 실행을 거절합니다. 성장 패스는 해당 원본 퀘스트 완료 ID가 없으면 잠김을 유지합니다. 카드 소유권·합성 및 원본 카드 룰렛 연출은 기존 카드 담당 범위이며, 여기서 연결한 추첨은 보유 상자와 선택·복합 보상의 소비 경로입니다. 기존 오림의 원본 캐릭터·스킬·맵도 이 PR에서 복원하지 않습니다.

Reward 36,038행의 구조 검사를 기능별 도달 경로와 따로 집계했습니다. 출석·패스·일반 시련의 보상 경로에는 새 범용 보상 엔진이 필요한 종류가 없었습니다. 보상 없음(NoReward)은 정상 빈 결과로 처리합니다. 혈맹·일반 퀘스트의 버프·퀵슬롯·유료 보상 강화, 시험용 상자의 복합 반복 추첨을 이번 기능으로 재구현하지 않습니다. 전체 리졸버 검사에서 지원 결과가 증가한 것은 15개 NoReward이며, 검사 문맥에서 해석된 결과 수를 현재 캐릭터의 청구 가능 수나 자연 획득 수로 표시하지 않습니다.

## 발견·수정한 저장 회귀

기존 `core_runtime_save_test.gd`의 `migrated save commits and activates safely` 검사가 최초 실행에서 실패했습니다. 기대는 역사적 세이브를 현재 지도 형식으로 이전한 뒤 `_save_game(true) == OK`였고, 실제로는 새 콘텐츠의 저장 보호가 켜져 저장을 거절했습니다. 다른 43개 검사는 통과했습니다.
