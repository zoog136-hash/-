# 원본 상점의 스킬서·회복제 소비 연결

기존 PR247에 마법상인 구매품의 습득과 체력 회복제 소비를 추가한다. 다른 스킬/카드/던전 PR을 병합하거나 새로운 스킬 효과를 복제하지 않는다. 기존 사용자 물약·가격·각성 규칙과 저장 ID를 보존한다.

## 스킬서 공급과 기존 습득

원본 ItemBonus의 BuffCardID → BuffCard의 SpellClassID를 PR245 `d0410e0f0269caad4b3bfe278bc467e65086711b`의 공개된 안정 ID 바인딩과 대조했다. 빌더는 원본 ZIP SHA·CRC와 각 검토 SpellClass의 정규화 SHA를 확인한다. 마법상인137행 중130종의 정확한 아이템/카드/스킬 연결을 기능 계약으로 컴파일했다. 검토 ID가 없는7행을 이름으로 접합하지 않는다. 현재 런타임에서 없는 스킬·차단된 스킬, 서버/기간 조건이 있는 카드는 등록하지 않는다. 계약130종이 실행 완료130종이라는 뜻은 아니다.

명시된 원본 객체111 → 판매행 연결 → 자동 스폰53 경로를 기존 원격 NPC 목록에 추가한다. Range 속성은 명시 설정에서 확인한 id15/이름Range/양수 정수만 원격 목록에 대응하며 다른 권한 속성은 허용하지 않는다. 원본 NPC 좌표나 새 지도를 만들지 않는다. 기존3NPC의 개별 정책 해시는 유지한다.

구매 전 원본 SpellLearnLimit의 비튜토리얼 직업·최소 레벨을 확인하고 선행 카드/변신 등급이 미연결인 조건은 차단한다. 기존 스킬의 직업·레벨·선행 스킬·실행 가능 여부도 함께 검사한다. LimitRepeatedBuyCardID가 가리키는 학습 카드와 현재 습득 ID가 정확히 대응하는 경우, **TWILIGHT 중복 습득 방지 정책**으로 이미 배운 스킬의 재구매를 차단한다. 이것을 모든 원본 카드 플래그의 서버 의미를 복원한 것으로 설명하지 않는다. 다른 LimitBuffCardID·혈맹·서버 조건은 계속 보존한다.

실제 지급 키는 원본 각인 이름이며 기존 일반 스킬북 키와 합치지 않는다. 인벤토리 사용 버튼은 기존 `skill_catalog.learn`에 검증된 공급 키만 전달한다. 원래 습득 ID·선행조건·버프 갱신·습득 화면을 사용한다. 원본 스택 감소·습득·활성 버프 갱신을 함께 저장하며 쓰기 실패 시 스택·습득/버프 상태를 복구한다. 원래 일반 스킬북 경로와 가격은 변경하지 않는다.

## 일반 체력 회복제3종

체력/고급/강력 체력 회복제의 기본 회복20/45/80과 각각2d6은 원본 ItemBonus·Bonus·BonusType의 값이다. 빌더는3종의 모든 보너스를 확인하고 미지원 영토·지속 조건이나 새 효과가 나타나면 거부한다. 원본 ItemConsumeDelay1000과 기존 공유 물약 소비자의1초 대기가 맞는 범위만 연결한다.

최종 회복의 `기본값 + 균등 주사위 합`, 기존 장비 물약 보정·공유 대기·호스트 무게는 TWILIGHT 호환 정책이다. `data/shop/source523_restoration.json`에 수치와 적용 정책을 분리하고 인벤토리 설명에 출처를 표시한다. 공개 자료에서 완전한 최종식을 확인하지 못했으므로 원작 최종 회복 수식이라고 주장하지 않는다. 기존 `HP 물약` 등의 사용자 밸런스와 스택을 바꾸지 않는다. 사용은 기존 실물약 소비자를 거치고 저장 실패 시 HP·각인 수량·공유 대기·난수를 복구한다. 잘못된 축복·가득 찬 HP·공유 대기에는 소비하지 않는다. 삭제된 해독제는 재도입하지 않는다.

## 재현과 검증 경계

원본 자료는 기존 비공개 사본을 사용한다. 공개 Git에는 빌더·기능 계약·코드·테스트와 간단한 설명만 포함한다. 새 원본/실행팩/보고서/캡처를 외부 업로드하지 않는다.

```sh
python3 tools/shop/build_source523_books.py /private/source.zip /private/reviewed-skill-bindings.json /private/book-contract-check.json
python3 tools/shop/build_source523_restoration.py /private/source.zip /private/recovery-check.json
```

실제 Main 검사는 공식 Godot4.7.2, 검증된 상점/NPC v2의 네 CLI 인자와 기존 맵 팩을 사용한다. 사용자 저장과 분리한 XDG 프로필이 필요하다. `source523_skill_books_main_test.gd`는 `TWILIGHT_SOURCE_BOOK_TEST=1`, `source523_restoration_main_test.gd`는 `TWILIGHT_SOURCE_RECOVERY_TEST=1`도 요구한다. 스킬서 검사는13직업의 통제된 QA 프로필에서 원본 가격 구매→보관함→수령→인벤토리 습득→재구매 차단→저장/재로드와 실패 원복을 확인한다. 모든 스킬의 전투 효과·원본 지역 플레이 검증으로 집계하지 않는다.

나머지 범위는 명시 객체 참조가 없는71그룹, 제외/활성 미확정 콘텐츠, 다른 공급자·소비자 및 실제 지도 의존으로 구분한다. 이미 제외한 혈맹·공성·펫·투기장·지구라트와 종료 행사를 활성화하지 않는다. 두 M 연구실 지형/진입은 PR232 맵 담당의 입력·복원이 필요하며 이 환경에서 별도 지도 제작을 시작하지 않는다.

## 지혜의 물약과 현재 검사

추가로 원본376/버프39의 SP+2·MP회복+2·300초를 기존 버프/스탯/회복 틱에 연결한다. 모든 ItemBonus와 BuffBonus, 조건·대상·중복·생명주기 플래그를 확인하는 별도 빌더를 제공한다. 원본에 새 미지원 조건이 있으면 거부한다. 회복 틱30초와 사용 대기0.5초는 구분된 TWILIGHT 설정이며 수치를 원본 최종식으로 표시하지 않는다. 버프 그룹5는 중복 합산하지 않고 갱신한다. 원본 비영구 버프는 만료/기존 부활 훅에서 제거하며 저장 실패 시 스택·버프·대기를 복구한다. 다른 기존 버프는 제거하지 않는다.

실제 Main/OpenGL 스킬서65종665검사, 별도 프로세스65종의 습득/수령·원본 메타데이터197검사, 체력 회복제3종52검사, 양 NPC의 지혜 물약 구매/사용/틱·만료·사망/저장23검사가 통과했다. 지혜의 틱/사망은 제어된 생명주기 probe이며 원본 전체 전투 검증으로 표현하지 않는다. 원본 Normal·각인 키·등급·단일 스택 한도·보관/드랍 속성과 원래 무게 값도 보존한다. 호스트의 물약/책 무게 단위는 기존 호환값이며 원본 무게 단위를 복원한 것으로 표시하지 않는다.
