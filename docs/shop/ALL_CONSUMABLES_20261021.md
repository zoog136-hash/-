기존 20종 가격은 변경하지 않는다. 새 상품에는 다음 개발용 가격을 부여하며 원작 공식 상점 가격으로 표시하지 않는다. 아래 값이 기존 등급별 매입가의 2배보다 낮으면 2배를 적용하여 **새로 추가하는 상품**의 구매→되팔기 이익을 방지한다. 기존 매입 정책과 기존 상품 가격은 이번 작업 범위에서 변경하지 않는다.

- 마나 재생 1,500 / 마녀 즉시 회복제 8,000 / 요리 2,500 / 일반 버프 3,000 아데나.
- 귀환 100 / 순간이동 300 / 축복 부여 250,000 아데나.
- 속성 강화 30,000 / 속성 변경 60,000 / 속성 초기화 5,000 아데나.
