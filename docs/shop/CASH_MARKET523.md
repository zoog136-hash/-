# 원작 현금 상품 → 다이아 판매 (2026-11-09)

원본 상점의 **상품** 탭에서 원작의 현금(스토어) 결제 상품을 게임 다이아로 판다. 사용자 지정 환산 비율은 **2000다이아 = 55,000원**이고, 다이아는 올림해 계산한다.

## 범위

- 대상: 원본523 마켓에 진열되어 있고 판매 중인 현금 결제 상품 29종. 대상 탭은 `패키지`와 `월간&재화`다.
- 원작은 같은 상품을 구글·애플·웹 스토어마다 행으로 따로 둔다. 구글 행 하나만 판매하고, 나머지 스토어 행은 목록에서 숨긴다. 구매도 거부한다.
- 제외: 다이아 충전 5종(120/400/1200/2000/4000 다이아). 다이아끼리 맞교환이 되기 때문이다(사용자 결정).
- 구성품 속 다이아: 원작 상품 구성에 들어 있는 다이아(무형 아이템 2)는 지급하지 않는다(사용자 결정). 가격은 환산값 그대로다.
- 서버·기간: 원작의 스토어 서버 그룹(512/722/732/1662/1672)과 판매 기간은 오프라인 단일 월드에 적용하지 않는다. 원작의 기간별 구매 제한(예: 크리스터의 수련 상자, 주 4회)은 유지한다. 초기화 시각은 정책이 따로 없으면 05시 KST다.

## 가격 출처

`data/shop/source523_cash_market.json`의 각 상품에 원화 가격과 출처 URL을 기록했다.

- NC 공식 공지 "[안내] … 상품 안내": 28종. 공지에 적힌 가격은 구글 플레이 스토어 기준이다. 같은 상품의 공지가 여러 개면 가장 최근 공지를 쓴다.
- App Store 앱 내 구입 목록: 1종(빛나는 드래곤의 다이아몬드 상자 패키지, 55,000원). 해당 상품의 공지를 찾지 못했다.
- 다시 만들기: `python3 tools/shop/build_cash_market_prices.py /private/shop523.json data/shop/source523_cash_market.json`

## 상자 내용물: 원본 정의 우선

원작 상품을 사면 상자 아이템이 지급된다(`[BM][럭키백]`, `[BM][선택상자]`). 상자 구성은 설치된 원본523 정의에서 실행 시 직접 읽는다. 공지의 구성품 목록은 쓰지 않는다. 비공개 원본 데이터는 저장소에 넣지 않았다.

- `LuckyBagClassID` → `LuckyBagEntityView`
  - `IsGiven` 항목은 모두 지급한다.
  - `Probability` 항목은 직업별 가중치로 1개를 뽑는다. 분모는 10,000,000이다.
  - `LimitClass`(10000은 전 직업)를 지킨다.
- `SelectRewardClassID` → `Reward(SelectReward)` → `SelectRewardEntity` → `Reward(Item)`
  - 현재 직업이 받을 수 있는 항목 중에서 1개를 고른다.
- 중첩된 상자는 다시 열 수 있는 상자로 들어온다.
- 지급 대상:
  - 카드 아이템(`BuffCardID`): 원본 카드 ID가 일치하는 카드를 카드 보유에 바로 지급한다(`receive_source_card`). 대상 카드 169종이 모두 원본 카드와 연결된다.
  - 게임에 이미 있는 아이템: 원본 ID나 이름으로 연결해 인벤토리에 넣는다. 장비는 물리 개체로 지급한다.
  - 그 밖의 원본 아이템: 원본 이름·무게·등급으로 인벤토리에 넣고 "TWILIGHT 사용 기능 연결 대기"로 표시한다. 대표적으로 스킬 카드 뽑기팩, 신비한 뽑기팩, 합성 포인트 주문서, 무기 수련의 서, 신탁서, 성장 물약·비약, 던전 시간 충전석, 각종 증표가 있다.
- 원작 상자 내부 이름의 삭제 예정일(`- 26/11/11삭제` 등)과 `DeleteTime`은 오프라인 게임에 적용하지 않는다.
- 빛나는 드래곤의 다이아몬드 상자(97424)와 일부 카드 아이템은 원본에서 `TestItem`으로 표시돼 있다. 하지만 원작 마켓에서 판매 중인 상품이라서 이 경로에서만 허용한다.
- 저장: 상자 1개 차감과 보상 지급을 한 번의 저장으로 처리한다. 저장에 실패하면 상자와 기존 보유 상태를 그대로 둔다.

## 검증

```sh
TWILIGHT_PATCH523_CONTENT=/private/lineagem_patch523_all_content_validated_and_508_520_deltas.zip \
godot --headless --path . --script res://tests/source523_cash_market_test.gd -- \
  --source523-shop-pack=/private/shop523.json --source523-shop-sha256=<팩 SHA>
# 같은 인자로 실제 Main 검사
godot --headless --path . --script res://tests/source523_cash_market_main_test.gd -- (같은 인자)
```

- 단위 검사(`source523_cash_market_test.gd`): 비공개 입력이 없으면 가격표 계약만 확인한다. 입력이 있으면 29종 각각을 구매 → 수령 → 상자 개봉까지 실행하고, 중첩 상자도 모두 연다. 결과는 600검사 통과였다. 기사 기준으로 상자 114개를 열었고, 카드 아이템 중 원본 카드와 연결되지 않은 것은 0건이었다.
- 실제 Main(`source523_cash_market_main_test.gd`): 241검사 통과. 기사로 29종을 모두 구매·수령했고, 인벤토리 사용 경로로 상자 104개를 열었다.

## 알려진 제한

- 라라의 진귀한 보급 상자와 보랏빛 성장 재화 지원 상자는 상급 축복의 가루를 3,000개, 20,000개 지급한다. 게임의 기존 무게 규칙(재료 기본 2)으로는 무게 한도를 넘어서 열 수 없고, 상자는 보존된다. 원본 무게는 0이다.
- 실제 Main 기준으로 원본 아이템 67종은 TWILIGHT 사용 기능이 아직 연결되지 않았다. 인벤토리 보관만 된다. 대표적으로 스킬 카드 뽑기팩, 신비한 뽑기팩, 합성 포인트 주문서, 무기 수련의 서, 신탁서, 성장 물약·비약, 던전 시간 충전석, 각종 증표가 있다.
