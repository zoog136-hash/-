# 원본 523 카드 합성 실패 포인트

- 대상은 변신·마법인형·성물의 희귀/영웅/전설 합성이다. `BuffCardRuleMergeView` 9개 행이 각각 20점, 상위 등급, 실패 보상 ID를 제공한다. `MarketPurchase_Korean` → `MarketPayment_Korean`은 비용 0, `MarketPurchaseProduct` → `MarketProduct`는 1회 추첨, `GotChaEntityView`는 정확한 원본 카드와 백만 단위 가중치다. 보상에 필요한 전체 카드/서버 조인이 맞지 않으면 차감·추첨하지 않는다. 일반 가방 마일리지나 유료 몰 거래를 거치지 않는다.
- 자기 등급에 1점 추가하는 원본 주문서: 변신 `146442/146452/172251`, 마법인형 `146462/146472/172261`, 성물 `267911/267921`. 스킬 카드 `180082/180092`는 현 원본 Spell 덱의 해당 두 행이 0점·실패 보상 없음이므로 보관한다. 성물 전설 라인은 합성 실패 수령 경로 자체는 검증 대상이나, 이 목록에는 해당 주문서가 없다.
- 원본 `Change_DetailView_Mix`의 수령 버튼에서 보상을 받는다. 20점은 그대로 저장되며 수령 전 추가 주문서나 합성으로 지출하지 않는다. 알맞은 원본 팩 없이도 기존 0–19점 저장과 기본 합성 규칙을 보존한다. 한 번 원본으로 활성화된 라인은 팩 누락 시 자동 보상으로 돌아가지 않는다. 보상 RNG, 카드 지급과 포인트는 저장 실패 시 원상 복구한다.
- 기존 TWILIGHT 일반 합성의 확률/중복 재료/실패 결과는 바꾸지 않았다. 원본 릴리스 환경에서도 보상 단계에만 위 정확한 원본 풀을 적용한다. 합성 UI가 열릴 때 큰 몰/추첨 표를 준비하지 않고 21행의 등급·보상 규칙만 확인한다. 큰 풀의 최초 실제 사용/수령 준비는 별도 경계다.
- 출처: 설치된 핀 검증 523 원본 표·UI44 및 주문서 종류를 명시한 [NC 공식 5월 13일 공지](https://lounge.plaync.com/feed/68527?country=KR&locale=ko-KR). 원본 이미지·아카이브는 저장소에 추가하지 않는다.
