## 원문 효과가 비었거나 현재 제외한 예

- **숫돌 (각인) #845**: ItemClass와 ‘아이템 수리 시 필요’ 설명은 있다. 이 아이템의 ItemBonus 행은 없다. 무기 손상·수리 가능 대상과 회복량을 증명하는 실행 근거가 필요하다. 내구도 없는 아이템에 임의 소모하지 않는다.
- **태고의 옥새 #1185**: ItemBonus에 SlotIncreaseAmount +1이 있지만, 한국어 원문 설명은 **캐릭터 생성 슬롯 확장**이다. 가방 슬롯 확장으로 해석하면 안 된다(2026-11-23 점검 문서 정정). 우리 계정의 캐릭터 슬롯 확장은 미연결이며 원본 상한 확인 전 보류한다. 이벤트 변형 #123672·#140181·#146842·#156051·#186111·#221061에는 고정 삭제 시점이, #288992에는 조건부 삭제 선언이 있다.
- **엘릭서 #146342 / 카르마스탯 열매 #175712**: 공개 표시명과 별개로 원본 내부 이름이 명시적으로 ‘[테스트]’를 포함한다. 기존 테스트 제외 유지.
- **기부의 성배 #338438 / 맹세의 성배 #338448 / 헌신의 성배 #338458**: 원본 행은 모두 소지 중 효과이며 직접 사용 아이템이 아니다. 직접 사용 불가를 구현 누락으로 집계하지 않는다. 소지 효과의 이행 여부는 이 점검과 별개다.
- **몬스터 도감**: 사용자 요청으로 진행 기능이 꺼져 있다(`twilight/monsterbook/progression_enabled=false`). 아이템 사용의 원문 누락으로 세지 않는다.
