## 확인됐지만 장비 드랍이 적용되지 않은 ID
- 몬스터 ID `45573`(巴風特→바포메트), `46123`(底比斯 賀洛斯→테베 호루스), `46124`(底比斯 阿努比斯→테베 아누비스): 원본 명칭과 대응 NPC를 확인했지만, 연결 가능한 원본 장비가 TWILIGHT 카탈로그와 충분히 교차 검증되지 않아 **실제 장비 드랍 추가 없음**.
- 원본 아이템 ID `40308`(金幣→아데나): **화폐**, 장비 추첨에서 제외. 원본 기반 아데나 바닥 지급은 미구현이며 기존 로컬 재화 규칙을 유지.
- 검증되지 않은 다른 L1J 아이템을 임의 장비로 대체하거나 신규 도감에 추가하지 않았다.

## 이번 원본 전체 드랍표의 실제 커버리지
- 등록된 L1J 몬스터 ID: **6개** (전체 1,001개 중).
- 등록된 L1J 아이템 ID: **8개** (장비 7개, 화폐 1개).
- 실제 게임에 연결된 드랍 행: **7행 / 9,857행**; 해당 TWILIGHT 몬스터 **3종**.
- 아직 적용되지 않은 드랍 **9,850행**의 1차 배제 사유(각 행 1개로 분류): 원본 몬스터 매칭 없음 **9,677**, 몬스터는 매칭됐으나 아이템 ID 미매핑 **169**, 장비 외 아이템 **4**.
- 제외 행의 대다수는 단순히 다른 장비로 대체할 수 없으며 추가 데이터 매칭/장비 외 지급 경로가 필요하다.
- TWILIGHT에 없는 아이템과 추가 조사 대상은 별도 전수 분류가 **미완료**다.

## 테스트 / 보존 보장
- 직접 원본 ZIP SQL 구문 파싱·7개 원본 드랍 행 ID/수량/가중치 확인 **수행**.
- `tools/validate_l1j_live_mapping.py`는 L1J↔TWILIGHT 맵, 실제 드랍 레지스트리, TWILIGHT 카탈로그의 이름·타입·중복·수량을 검사한다. `--zip /path/to/L1j-TW-main.zip`을 추가하면 원본 SQL 행을 기준으로 전체 레지스트리를 재생성해 일치를 확인한다.
- GitHub Actions `l1j-selective-validate.yml`에 카탈로그 검사를 추가하고 Godot 드랍 회귀 테스트에 스파토이·데스나이트 실데이터 체크를 추가했다.
- 기존 장비 등급 확률과 보스 최대 3회, 물약 판정, 바닥 드랍/자동습득, 저장 스키마는 코드상 변경하지 않았다. **최신 SHA의 CI 및 실제 실행 성공 여부는 GitHub Actions에서 확인해야 한다**.
- 신규 원본 ZIP/원작 이미지·바이너리 자체는 GitHub에 커밋하지 않았다. 추후 외부 리소스의 저작권/라이선스를 별도 확인해야 한다.
