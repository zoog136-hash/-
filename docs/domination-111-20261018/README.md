# 111.png 기준 TWILIGHT 지배의 탑 — 2026-10-18 KST

사용자가 **오만 정상 원본 111.png를 우리 지배의 탑 기준으로 사용**하도록 명시했다.
게임 ID는 `domination_summit`, 원본 이름/지도 ID는 오만 정상/111로 보존한다.
원본 12862 지형을 대신 연결하지 않는다. 별도 게임을 만들지 않고 기존 Main,
World, Player, 몬스터, HUD, 미니맵, 길찾기 및 전투 경로를 사용한다.

## 실제 연결

- 원본 PNG: 17,694×7,372, 42,449,419바이트,
  SHA-256 `f5c4549298e586d3839246d736b61b6106851af07cde8c5a21522d046ff38f87`.
- 실제 A3 지도 111: 원점 `[32576,32768]`, 통행 격자 256×256,
  행 우선 SHA-256 `2fde4743bc2b6edc5551c62ef458a60298c9f2a099fba59094373a2e7e35c565`.
  원본에서 통행 가능한 21,370셀 모두 같은 연결 성분에 속한다.
- 실제 원본 방향별 통행 16청크와 PNG 그림 64청크를 연결했다.
  기존 아덴 768청크와 기존 오만 10층의 정의·내비게이션 파일은 바꾸거나 재생성하지 않았다.
- 현재 TWILIGHT의 4개 몬스터 구역과 그림 리퍼, NPC 1개 및 포털 5개를 원본 연결
  셀로 옮겼다. 몬스터 종류·수·레벨·보스 ID·가중치·리스폰 시간은 유지한다.
- 캐릭터는 scale=1, 이동속도 210, 이 원본 필드의 발 충돌 원 반경 4를 유지한다.
  몬스터도 같은 지형 통과 규칙과 실제 4픽셀 발 도형을 사용한다.

## 원본 정체와 좌표 정합은 별개

사용자의 이미지 채택은 확정됐다. 그러나 PNG와 A3 격자의 정밀한 공간 대응은
아직 확정되지 않았다. 원본 경계와 PNG의 시각 표면을 비교한 아핀 후보의 진단
거리는 중앙값 약 145 PNG픽셀, 90백분위 약 359픽셀이다. 이것은 검증된 고유
기준점 잔차가 아니며 통과 수치로 보고하지 않는다. 후보 변환과 미확정 상태는
`data/maps/domination_111_calibration.json`에 기록했다. 지역별 정합/판본 차이,
절벽·구멍·기둥과 실제 PNG 위치의 대응 및 전경 가림이 남았다.

그래서 이 팩은 명시적인 PNG 검수 세션에서 실행한다. 원본 통행을 이미지 색으로
대체하지 않는다. PNG의 흰 뷰어 바탕과 문자 무늬를 없애는 별도 시각용 알파
마스크는 **그림에만 적용**한다. 해당 도구는 내비게이션 파일을 읽거나 쓰지 않는다.
원본 PNG 파일은 그대로 보존하며 마스크의 경계는 추가 검수 대상으로 기록한다.
현재 후보에서는 일부 포털 표시가 PNG의 빈 공간과 겹친다. 원본 격자에서 연결된
셀이라는 사실만으로 PNG 바닥과 일치한다고 판정하지 않는다.

## 실행

개인 팩의 `map_png/`와 `topology/`를 기존 팩과 같은 루트에 놓고 실행한다.

```bash
bash tools/run_png_review.sh /개인/팩/루트 /공식/Godot_4.7.2 --png-map=domination_summit
```

`--png-collision-overlay`를 추가하면 실제 PNG 위에 원본 통행 경계를 표시한다.
실행기는 세션 저장을 분리하며 검수 모드는 일반 저장 파일을 덮어쓰지 않는다.
기존 authored 지배의 탑 저장을 읽을 때는 새 리비전의 안전한 시작 셀을 사용한다.
캐릭터 진행 상태·보스 생명/쿨다운 정체와 기존 좌표를 구분한다.
검수 시작 맵을 명시하면 다른 맵의 세션 저장을 읽은 뒤에도 지정한 지배의 탑으로
시작한다. 저장된 캐릭터 진행은 읽고, 다른 맵의 픽셀 위치는 가져오지 않는다.

재생성할 경우 `tools/map_restore/export_current_layouts.gd`로 현재 게임플레이를
먼저 내보낸다. `build_domination_111.py --a3 ... --layouts ... --base 기존오만통행팩
--output 새개인팩/topology`는 기존 통행 파일을 복사하고 지도 111만 추가한다.
`make_domination_void_mask.py`의 선택적 표시용 마스크를 만든 뒤
`build_png_review_pack.py --domination 원본/111.png --domination-void-mask 마스크.png
--topology 새개인팩/topology --output 새개인팩/map_png`로 원본 RGB 청크를 만든다.
이미 같은 해시로 확보된 원본을 재다운로드하거나 기존 오만 통행을 재생성하지 않는다.

바닥 드랍 경로, 보스 쿨다운 및 포털 5개와 저장 파일 보존을 검사한다.

초기 게임플레이 검사의 2개 실패는 보존했다(`GAMEPLAY_FIRST_RUN.json`). 공격 접근
위치가 실제 무기 셀 사거리 밖이었던 테스트 설정과 JSON 시간 비교의 부동소수점
정밀도를 바로잡았다. 전투 수치·사거리·보스 저장 코드를 바꾸어 통과시키지 않았다.
격리 경로를 지정하지 않은 추가 import 실행에서 환경 쓰기/소켓 오류가 있었으며,
모든 XDG 경로와 실행 권한을 지정한 최종 import에서 오류 0을 확인했다.

직전 커밋 `3b9004e`의 공개 CI에서는 이번 브랜치에서 생긴 3종 실패를 확인했다.
PNG 미설치 SKIP 출력의 콜론 누락, `data/maps/`의 정합 메타데이터를 일반 맵으로
잘못 열던 `map_id` 키, 발 여유 검사에서 벽 접선 이동까지 0으로 만들던 회귀다.
메타데이터 키를 `game_map_id`로 바꾸고 기존 CI 결과 형식을 준수했다. 물리는
실제 `test_move`가 벽을 확인한 경우 기존 `move_and_slide`가 해결하게 하며,
충돌이 스트리밍되지 않은 원거리에서는 원본 경계를 계속 지킨다.

동일한 기존 변신/AI 케이스는 기준 main 60,067검사/실패 0, 수정 전 59,995검사/
동쪽 추격·접촉 2실패, 수정 후 60,061검사/실패 0이었다. 테스트 단언을 완화하거나
지형을 바꾸지 않았다(`AI_REGRESSION_COMPARISON.json`). 메타데이터·검수 도구의
공개 팩 미설치 경로는 기존 실행기로 도로 메시 통과/개인 팩 검사 2개 명시적
SKIP을 확인했다(`PUBLIC_PACK_CONTRACTS.json`). **새 HEAD의 전체 원격 CI와
10케이스 변신 배치 전체를 통과했다고 집계하지 않는다.**

원본 PNG 64청크의 RGB, 통행 16청크를 재구성한 원본 격자 SHA, 기존 오만 팩의
바이트 보존은 `INTEGRITY.json`에 기록한다. 실제 화면·영상의 크기와 SHA는
`PRIVATE_EVIDENCE.json`, 로컬 ZIP 검증은 `LOCAL_ARCHIVE_RECEIPT.json`에 기록한다.
이 ZIP은 이전 아덴·오만 PNG 팩에 합칠 수 있는 지배의 탑 추가 팩이다.

추가 정합에 필요한 자료는 PNG와 같은 판본의 지도 111 S32/오브젝트·속성 자료,
서로 대응하는 고유 기준점 최소 3개(가능하면 5개 이상), 원본 전경/바닥 분리 자료다.
현재 A3에서 지도 111의 해당 S32/TIL은 찾지 못했다. 마스크 가장자리의 남은 흰
문자 무늬, 포털 착지점의 PNG 바닥 대응도 수동 검수가 필요하다.

**현재는 PNG 기준 구현과 실행 검수 단계이며, 정확한 지형 복원 완료가 아니다.**
정밀 정합, 전경 가림, Android 실제 기기 및 개인 팩의 장기 호스팅 전달은 미완료다.
