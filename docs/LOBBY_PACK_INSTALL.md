# 원본 로비 팩 로컬 설치

캐릭터 로비의 **원본 로비 리소스 팩 설치** 버튼에서 내려받은 전체 ZIP 또는 `.zip.001`, `.zip.002`, `.zip.003` 세 파일을 함께 선택한다. 분할 파일 순서는 무관하다. Android는 시스템 파일 선택기를 사용한다. 설치 성공 뒤 직업/성별을 선택하면 원본 로비 연출을 연다. 인터넷 자동 다운로드나 공개 리소스 배포는 하지 않는다.

- ZIP: `TWILIGHT_original_Spine_lobby_applied_20261112.zip`
- 크기: 548,837,574 bytes
- SHA-256: `2a3dee048bbca5f85450d3e0cf514f270ef8704affed7d46e290dcbd155baba0`
- 압축 해제: 1,370,872,368 bytes, 243 entries
- manifest: `original_ui.json`
- manifest SHA-256: `5a252befd85166b587e067fbd0839a90a774c162fab598da500959d9682a6700`

기존 다운로드 파일 외에 약 2GB 여유 공간을 확보한다. 손상된 설치를 교체하는 경우 보존되는 이전 팩만큼 추가 공간이 필요하다. 분할 결합/검증/압축 해제는 작업 스레드에서 수행한다. 화면은 현재 작업 단계만 표시하며 측정하지 않은 시간이나 백분율을 약속하지 않는다.

전체 ZIP의 고정 크기·SHA를 확인한 뒤 압축을 연다. 임시 디렉터리에 추출하고 manifest 및 파일 무결성을 검사한 후 선택 정보를 교체한다. 기존 계정 저장은 변경하지 않는다. 검증된 기존 설치는 재사용한다. 손상된 기존 팩은 새 팩 검증 후 보존한 채 교체한다. 실패 시 파일/여유 공간을 확인하고 다시 선택한다. 설치 중 종료 버튼은 잠겨 있다.

명시적인 CLI/환경변수 로비 경로는 저장된 설치 선택보다 우선한다. 잘못된 명시 경로를 조용히 숨기지 않는다.

## 검증 범위

Godot 4.6.3 Linux headless에서 원본 ZIP 최초 설치, 재사용, 저장된 선택 읽기, worker Thread 경로, 잘못된 파일 거부, UI 실패/재시도 및 기존 캐릭터 로비 42검사 통과. 최초 설치 측정 약10초/최대 RSS209MB는 이 환경의 값이며 휴대폰 예상시간이 아니다. Android 실제 기기의 시스템 파일 선택기 URI 접근, 저장공간 부족, 강제 종료 및 최종 APK 실행은 별도 확인이 필요하다. 저장소 기준 버전 4.7.2 검증으로 대체하지 않는다.

## Android 분할 선택 오류 수정

시스템 파일 선택기는 표시 파일명 대신 확장자 없는 `content://` URI를 반환할 수 있다. 분할 선택은 문자열 끝의 `.001` 검사 대신 위 전달 팩의 각 부분 크기와 SHA-256으로 식별하고 순서를 결정한다. 이름 변경이나 선택 순서 변경은 내용을 바꾸지 않는다. 중복 파일·다른 내용·읽기 권한 실패·크기 불일치를 서로 다른 오류로 표시한다. 경로나 개인 폴더명은 오류 메시지에 기록하지 않는다.

Linux Godot 4.6.3에서 실제 전달된 3분할을 숫자 이름으로 읽고 역순 선택해 정확한 SHA 순서로 복원하는 식별 테스트를 통과했다. `content://` 문자열에 대한 식별 메타데이터 회귀도 통과했다. 이는 Android URI 자체를 실제로 열어본 시험이 아니며, 사용자 기기의 권한/프로바이더 접근은 별도 확인해야 한다. 기존 설치의 `three_matching_split_parts_required` 하나만으로 파일 손상이나 재다운로드 필요성을 단정하지 않는다.
