# Twilight 몬스터 드랍 밸런스 (2026-10-08)

## 몬스터 처치당 장비 획득 확률

| 장비 등급 | 일반 몬스터 | 보스 몬스터 |
|---|---:|---:|
| 일반 | 8% | 12% |
| 고급 | 3% | 8% |
| 희귀 | 0.7% | 5% |
| 영웅 | 0.03% | 2% |
| 전설 | 0% | 0.4% |
| 신화 | 0% | 0.05% |
| 유일 | 0% | 0% |
| **합계** | **11.73%** | **27.45%** |

- **물약은 독립 판정:** 일반 몬스터 45%, 보스 90%, 처치당 최대 물약 1개.
- **장비는 처치당 최대 1개.** 물약과 장비는 같은 처치에서 동시에 드랍될 수 있다.
- **아데나와 경험치:** 기존 지급 방식 유지. 장비/물약 확률과 무관.
- **기존 드랍 목록 존중:** 해당 몬스터에 등록된 동일 등급 장비를 우선 추첨한다. 그 등급이 없으면 등록 장비와 같은 종류를 아이템 DB에서 선택하며, 장비 등록 자체가 없는 몬스터는 해당 등급의 DB 장비를 선택한다. 유일 장비는 전체 드랍 대상에서 제외한다.
- **물약 종류:** 몬스터에 설정된 회복 물약을 우선하며 없으면 일반은 `HP 물약`, 보스는 `강력 HP 물약`을 사용한다. 유일 등급 물약도 드랍하지 않는다.
- **보스 판정:** 몬스터 DB `is_boss` 명시값이 최우선. 없으면 보스 설명, `~의 지배자` 이름, 지정된 네임드 보스 이름을 참조한다. 몬스터 자체 등급(`영웅`, `전설`, `신화`)만으로 보스로 취급하지 않는다.
- **수정 위치:** `scripts/loot_drop.gd`, `scripts/world.gd`, `scripts/monster.gd`. 지도 렌더링, 충돌, 스폰 배치 데이터는 수정하지 않았다.
- **테스트:** `godot --headless --path . --script res://tests/loot_balance_smoke_test.gd`.

이 값은 로컬 플레이용 첫 번째 밸런스 안이며 실측 킬/아이템 통계를 통한 후속 조정이 가능하다.
