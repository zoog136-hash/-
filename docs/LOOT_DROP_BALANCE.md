# Twilight 몬스터 드랍 밸런스 (2026-10-08, 2차 조정)

## 장비 등급별 확률

아래 수치는 **장비 추첨 1회당 확률**이다. 일반 몬스터는 처치당 **1회**, 보스는 처치당 **3회 독립 추첨**한다. 보스는 동일한 장비가 중복 드랍될 수도 있다.

| 장비 등급 | 일반 몬스터 (1회 추첨) | 보스 (각 추첨당) |
|---|---:|---:|
| 일반 | 0.1% | 0.1% |
| 고급 | 0.1% | 0.1% |
| 희귀 | 0.1% | 0.1% |
| 영웅 | 0.015% | 1% |
| 전설 | 0% | 0.2% |
| 신화 | 0% | 0.025% |
| 유일 | 0% | 0.001% |
| **1회 추첨 장비 획득 합계** | **0.315%** | **1.526%** |

- 일반 몬스터: 0~1개 장비, 최대 영웅 등급.
- 보스: 0~3개 장비, 최대 유일 등급. 3회 모두 실패하면 0개, 2개 이상 성공하면 여러 장비 드랍.
- 보스가 장비를 1개 이상 드랍할 확률: `1 - (1 - 0.01526)^3 ≈ 4.5087%`. 기대 장비 개수는 처치당 `3 × 0.01526 = 0.04578개`.
- 보스의 유일 등급 0.001%는 **추첨 1회당** 확률이며, 보스 한 번 처치 시 하나 이상 등장할 확률은 `1 - (1 - 0.00001)^3 ≈ 0.003%`.
- **물약은 별도 독립 판정:** 일반 몬스터 45%, 보스 90%. 처치당 물약 최대 1개.
- 최대 최종 드랍 수: 일반 몬스터 2개(장비 1 + 물약 1), 보스 4개(장비 3 + 물약 1).
- 아데나/경험치 지급 수치는 변경하지 않는다.
- 이전 `drop` 테이블의 해당 등급 장비를 우선하며, 없으면 같은 장비 종류의 해당 등급 DB 아이템, 그것도 없으면 해당 등급 DB 아이템을 선택한다. 보스에만 유일 장비를 허용한다.
- 물약은 `heal > 0`인 회복 소모품만 드랍하며, 유일 등급 물약은 기존대로 제외한다.
- 보스 분류는 기존 `is_boss` 명시값, 이름, 설명에 따른 판정 유지.
- 수정 파일: `scripts/loot_drop.gd`, `tests/loot_balance_smoke_test.gd`, `docs/LOOT_DROP_BALANCE.md`만. 월드·몬스터·맵·UI 코드는 수정하지 않는다.
- 실행 테스트: `godot --headless --path . --script res://tests/loot_balance_smoke_test.gd`.
