# 원본 523 가방 터치 연결

UI44의 `Inventory_All.csb`를 그대로 사용한다. 정렬(`Btn_Array`, 19772)은 그 아래의 원본 메뉴 `Nd_Option/Nd_Array`를 연다. **삭제일**(8004)은 기간 정렬이며, **삭제**(24648)와는 별개다. 무게(4764), 분류(2864)도 원본 위치·글자·화살표를 렌더링한다.

정렬 규칙은 원본 클라이언트 처리로 확인된 것이 아니다. TWILIGHT는 원본 확정 삭제 날짜(가까운 날 우선)·ItemClass 무게(큰 값 우선)·CategoryID(오름차순)를 읽어 한 번 정렬한다. 삭제일과 무게는 같은 버튼으로 방향을 바꿀 수 있다. 값이 없으면 뒤에 두고, 같은 값은 기존 가방 순서를 유지한다. 필터는 저장 순서를 바꾸지 않으며, 다음 획득품은 그 뒤에 놓인다. 게임 전체의 무게 환산이나 획득 조건은 변경하지 않는다.

선택한 슬롯에만 `Common_Slot.csb`의 원본 `Btn_Detail`(1328)과 `Img_Detail`(1380)을 표시한다. 원본 쇼핑 슬롯의 투명 버튼은 68×68이지만 가방에서 그 전체를 차지하면 해당 아이템을 쓰거나 끌 수 없으므로, 보이는 아이콘 영역만 상세 버튼으로 쓴다. `ToolTip_CommonType.csb`에서 기존 아이템 기본 정보와 원본 **획득목록** 및 삭제 입구를 연결한다. 가운데 터치와 길게 누르기는 기존 가방 동작이다.

삭제는 원본 `IsDeletable == true`가 확인된 현재 일반 원본 아이템만 허용한다. 장착/잠금된 아이템, 모호한 동명 재고, 출처를 확인할 수 없는 아이템, 전용 소유자가 등록되지 않은 물리 형식, 테스트 및 제외 대상은 건드리지 않는다. 확인을 열 때 선택한 정확한 UID·기록·수량을 고정하고, 실제 확인과 저장 전 다시 확인한다. 물리 수량 및 사용 장부는 기존 원자 저장으로 함께 쓰며, 성공 전에는 가방에 반영하지 않는다. 저장 실패·취소 시에는 삭제하지 않는다. 바닥 내려놓기나 용해로 바꾸거나 새 보상을 생성하지 않는다.

원본 수량 키패드 및 확인 창 외형은 공유 `Common_Calculator`, `Common_MessageBox_Dissolution`에서 온다. 확인 문구만 영구 삭제용으로 따로 적용했다. 별도 정식 삭제 확인 CSB의 호출 근거는 미확인이다. 잠금 버튼은 기존 가방 잠금과 같은 상태 소유자를 쓴다. 잠금이나 정렬을 눌러도 선택 테두리는 보존하지만 ‘사용/장착’ 대기는 풀어, 그 뒤 슬롯을 한 번 다시 누를 때 뜻하지 않게 사용·장착되지 않는다. 원본의 `Btn_Move`, 다중 삭제 및 용해 모드 진입 규칙은 확인되지 않아 새로 연결하지 않았다. 기존 드래그 재정렬·별도 용해 화면은 변경하지 않는다.

## 원본에서는 보이지만 새로 활성화하지 않은 조작

- **이동**: `Menu_Button/Btn_Move`(28988)에는 그림과 클릭 사운드가 있지만 저장된 콜백명/전용 애니메이션이 없다. 한 아이템인지 선택 모드인지, 다른 화면으로 옮기는지 자료만으로는 확정할 수 없다. 기존 실제 가방 슬롯 간 드래그 재정렬은 그대로 동작한다.
- **다중 삭제**: `Btn_Delete_Multi`(22748)와 `Btn_Cancel_C`(17760)는 원본에서 기본 숨김이다. 한국어 UI 문자열 59944·59964(삭제할 아이템과 수량 선택/완료)는 확인했지만, 이 씬에서의 모드 전환·개별 표시·묶음 조건은 확인되지 않았다. 따라서 위의 단일 선택만 지원한다.
- **용해**: `Nd_Sub/Btn_Dissolve`(14108)와 `Btn_Cancel`(15940) 역시 기본 숨김이다. 한국어 UI 문자열 11222·59934 및 기존 `bless_refine523_service`의 원본 축복가루/용해제 소유자는 있지만, 가방에서 이 버튼을 보이게 하는 원본 계약은 확인되지 않았다. 기존 축복 강화/용해 화면과 확인 창은 계속 쓴다. 일반 삭제를 용해로 대체하지 않는다.

UI44의 이 씬에서 확인되는 이름 있는 재생 구간은 정렬 팝업과 확장 열기·닫기뿐이다. 미확인 모드는 새로 활성화하지 않았다.
