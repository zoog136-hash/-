# 원본 523 UI 창: 비워 둔 값의 근사·출처 기록

사용자 방침(2026-11-16 09:30): 원본 데이터에 없는 동작이나 수치는 웹 검색(리니지M 실제 화면·가이드)으로 근사치를 정해 적용하고, 그 값을 이 문서에 "TWILIGHT 근사(출처 URL)"로 모은다.

- 그림이 없는 것은 계속 비워 둔다(이미지를 만들지 않음).
- 게임에 기능 자체가 없는 것은 근사하지 않고 보고만 한다.
- 원본 테이블이나 CSB에 값이 있는 것은 근사가 아니라 원본 값을 쓴다. 이 경우 "원본"으로 적는다.

## TWILIGHT 근사(근거 약함): 정렬·필터 선택지

원본 문자열 테이블(UIStaticTextData/UITextData)에는 선택지 문구가 "정렬", "레벨 별 정렬", "등급 별 정렬"밖에 없다. 웹 검색으로도 실제 화면의 선택지를 확인하지 못했다. 검색어는 "리니지M 변신 목록 정렬 등급순", "리니지M 인벤토리 정렬 버튼 옵션", "리니지M 스킬 카드 강화 재료 정렬 자동 등록"이었다. 사용자 지시(2026-11-16 "근사치로 다 넣어")에 따라, 리니지M 화면에서 흔히 쓰는 등급순·이름순·수량순·진행 상태로 근사한다. 각 창의 첫 선택지는 원본 버튼에 적힌 문구 그대로다.

|---|---|---|
| 아이템 컬렉션 (ItemBook_Tab_Collection Btn_Sort) | 전체 | 전체 / 진행 중 / 미완성 / 완성. 같은 원본 버튼에 카드 컬렉션 창이 이미 쓰는 선택지 |

## 선택 보상 (Common_Reward_SelectBox)

- 수량 선택 줄: TWILIGHT 근사(근거 약함). 버튼(+1/+10/Max/직접입력/초기화)은 빼고, 제목 "선택한 보상"과 고른 보상 이름을 표시한다. TWILIGHT는 상자를 하나씩 연다.

## 미스터리 카드 합성 (MysteryCard_All)

- 도전 등급: TWILIGHT 근사(근거 약함). TWILIGHT 미스터리 카드는 한 번 뽑아 설정 확률로 영웅, 아니면 희귀를 준다. 그래서 4장 중 영웅 카드만 "선택 가능"으로 두고, 실패는 원본 안내문대로 하위 등급인 희귀 획득으로 표시한다. 희귀·전설·신화 카드는 "선택 불가"다.
- 확률 보기: 기존 아이템 사용 규칙의 표시 문구(설정 확률과 풀)를 그대로 보여 준다.

## 수호성 찾기 (SkillTree_RandomOpen)

- 카드 고르기: TWILIGHT 근사(근거 약함). 원본은 카드를 끌어 선 위에 놓는다. 여기서는 남은 카드(실패 카드 제외)를 Card_GuidBox에 한 줄 최대 8장으로 가운데 정렬해 놓고, 누르면 고른다. 줄이 넘치면 상자 안에 맞게 줄인다. 원본 슬롯의 수호석 비용은 먼저 확인창으로 묻는다(기존 화면과 같음).

## 오만의 탑 리스트 (OmanTower_All)

- 진입: TWILIGHT 근사(근거 약함). 원본은 다층 이동 주문서로 이 창을 연다. TWILIGHT에는 그 주문서가 없으므로, 순간이동 창의 "던전" 탭을 "오만의 탑" 버튼으로 바꿔 이 창을 연다.
- 층 행: 월드에 있는 오만의 탑 맵(oman_01 ~ oman_10)만 "N층"으로 보여 준다. 누르면 순간이동 창이 그 층을 선택한다. 가격·레벨 확인과 이동은 기존 순간이동 규칙이 맡는다.

## 거래소 (Trade_All, 서버 거래소)

- 필요한 추가 리소스: addon_ui39 이상(거래소 원본 UI 포함). 이보다 오래된 UI 추가 리소스에서는 기존 TWILIGHT 실측 고정 패널이 열린다.
- 원본: 검색 분류(UITradeMarketCategory·DescData_Korean 이름), 품목 분류(UITradeMarketCategoryMappingView), 거래 가능 여부(ItemClass.IsTradable), 판매 한도(ItemTradeMarketPolicyValue KR: 판매 등록 30개, 최소 총액 10, 최대 총액 9,999,999, 판매 기간 4,320분, 등록 수수료 화폐 ItemClass 26 아데나).
- 실측: 다른 판매자 매물은 `data/exchange/frozen_snapshot.json`(2026-11-12 공식 시세 사이트 대표 서버 1,506건)을 그대로 쓴다. 이 매물은 근사가 아니며 기존 frozen_exchange 규칙으로 산다.
- TWILIGHT 근사(근거 약함) · 실측 매물이 없는 거래 가능 품목: 같은 상위 분류와 같은 GradeID의 실측 개당 가격 중앙값(없으면 같은 GradeID, 그것도 없으면 전체 중앙값)으로 하루 3건(100% / 110% / 125%)을 둔다. 묶음 수량은 총액이 10 다이아 이상이 되는 10의 거듭제곱이다. 매물은 KST 05:00에 다시 채운다. 화면에 "TWILIGHT 근사"라고 표시한다.
- TWILIGHT 근사(근거 약함) · 세율: 7% (기본세율 2% + 성 세율 5%). 원본 Trade_Popup_Input·Trade_Tab_Sell 자리 표시 문구를 따랐다. 오프라인에는 성 주인이 없어 세율이 바뀌지 않는다. 검색어 "리니지M 거래소 수수료 세율 다이아 판매 정산"로는 실제 수치를 확인하지 못했다.
- TWILIGHT 근사(근거 약함) · 등록 수수료: 등록 1건당 1,000 아데나. 원본에는 화폐 종류만 있고 금액이 없다. 검색어 "리니지M 거래소 판매 등록 수수료 아데나"로도 금액을 확인하지 못했다.
- TWILIGHT 근사(근거 약함) · 구매자 시뮬레이션: 개당 가격을 최저 매물 개당가(실측, 없으면 근사가)와 비교한다. 90% 이하이면 5분, 100% 이하이면 30분, 120% 이하이면 3시간, 150% 이하이면 24시간 뒤에 팔린다. 그보다 비싸면 판매 기간(3일)이 끝날 때까지 팔리지 않고 "판매 실패"가 된다. 정산하면 총액에서 세금을 뺀 다이아를 받는다. 정산 내역은 30일 동안 남는다(원본 문구 "최근 한달").
- 연결하지 않음: 월드 거래소(온라인 전용 안내), 일괄 구매(Trade_Popup_Purchase_Batch는 523 클라이언트에 Atlas_Hud 그림이 없어 팩에서 뺌), 일괄 수정, 재등록, 체크박스, 검색 조건 필터, 클래스 필터, 정렬, 즐겨찾기, 툴팁, 컬렉션·제작 이동.
