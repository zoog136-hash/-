# 아덴 지리 구조와 오만 1층 — 첫 구현 단위

기준: PR #84 `ba95f3797f42103c72211f87b242c795eddecb1d`. 기존 작업 브랜치에서 이어서 작성했다. 셰이더·아틀라스·캐릭터 크기 조정은 이 단위의 변경 사항이 아니다.

## 실제 변경

- 아덴: 12,288×8,192의 가상 7구역을 48,000×25,120의 대륙으로 교체했다. 공개 지도의 상대적 마을 위치 11곳, 해안선, 세 강줄기, 숲·산악·사막·늪지 구획과 11개 주요 이동 경로를 좌표 데이터로 작성했다. 기존 소품과 돌집 PNG를 재사용하며 해안 밖 소품은 육지에 배치했다.
- 오만 1층: 동일한 9개 방/직각 통로 격자를 폐기했다. 2018년 공개 전체 지도에서 확인한 외곽, 남서쪽 진입부, 두 작은 구멍을 독립적인 9,600×4,800 지도에 반영했다. 바닥 다각형과 외곽 충돌 벽이 실제 이동·렌더링·미니맵에 사용된다.
- 플레이어의 길찾기·물리 충돌, 지도 범위, 귀환과 층 이동을 연결했다. 변경된 레이아웃 버전은 3이며 구버전 저장 좌표는 기존 마이그레이션을 거친다.
- 몬스터와 보스는 이동 가능한 다각형 내부에서 생성된다. 안전지대·벽·지도 밖을 제외한다. 보스의 저장 위치 복원과 이동도 순찰 다각형을 검사한다.
- 25개 실제 맵과 27개 기존 보스 바인딩을 자동 추출한 `data/maps/world_reference_catalog.json`에 기록했다. 이름·지역 근거와 좌표·리젠 검증 수준을 분리했다.

## 근거와 정확도

- [2019년 아덴 전체 지도 공개](https://games.app-liv.jp/archives/397568): 실제 이미지를 확보하고 상대 배치와 지형을 관찰했다. 절대 축척, 최신 한국 서버의 확장 지역, 세부 충돌과 도시 건물 배치 자료는 아니다.
- [2018년 오만 1~6층 지도 공략](https://www.gamechosun.co.kr/webzine/article/view.php?no=145842): 오만 1층 전체 윤곽을 확인했다. 원본 이미지를 게임 텍스처로 복사하지 않았다. 현재 버전과의 차이와 작은 장애물 전체는 미검증이다.
- [NC 2025년 6월 18일 업데이트](https://lounge.plaync.com/feed/35343?country=KR&locale=ko-KR): 오만 1~10층, 신념 1~4층 목록 근거다. 내부 좌표와 지도 크기를 제공하지 않는다.
- [공식 일본 지배의 탑 가이드](https://lineagem-jp.com/guides/lm/guides/dungeon_TowerofDomination): 입구와 정상, 약화 버전의 입장 구조를 확인했다. PC L1J의 1~100층을 리니지M의 층 목록으로 대체하지 않았다. 최신 한국판 전체 구성은 추가 확인 대상이다.
- [리니지M 오만 1~3층 공략](https://lineagem.inven.co.kr/dataninfo/guide/?idx=185439): 제니스 퀸의 보스명과 소속 층 근거다. 오래된 시간표는 현재 리젠 규칙으로 사용하지 않았다.

지도 이미지를 직접 확인한 뒤 별도 벡터 좌표를 작성했다. 공개 그림 픽셀과 로컬 월드 좌표 사이의 변환은 명시적이지만 **절대 축척은 잠정값**이다. M 서버 맵 ID·타일 원점·절대 좌표는 미확보이며 `null`로 남긴다. 확보된 JP L1J 구형 10층의 이동 윤곽은 M 1층 공개 지도와 달랐으므로 그대로 편입하지 않았다.

**보스의 정확한 원작 리젠 구역 검증은 0개다.** 제니스 퀸은 이 구현에서 전체 이동 가능 바닥 중 안전지대를 제외한 공간에 생성된다. 아덴 보스도 기존 로컬 전투용 구역이다. 이 범위와 게임 시간 리젠은 잠정 로컬 규칙이며 원작 좌표·시간표로 보고하지 않는다.

## 실행 증거

`evidence/validation.json`은 실제 Main 씬에서 이동·충돌·입출구·저장·다각형 스폰을 검사한다. `before_metrics`와 `metrics`는 두 레이아웃의 진입부에서 연결된 이동 가능 면적을 기록한다. 단위는 로컬 월드 픽셀이며 원작 면적이나 완성률이 아니다.

장거리 검사는 실제 CharacterBody2D와 경로를 이용해 글루디오 진입부에서 기란까지, 오만 진입부에서 반대편 전장까지 이동한다. 게임 시간만 10배로 가속하며 순간이동으로 도착시키지 않는다. 이동 중 통행 가능 영역과 충돌 여유를 반복 검사한다. 실제 이동 거리와 물리 프레임 수는 같은 JSON에 기록한다.

`evidence/before`와 `evidence/after`에는 25개 전체 지도 및 두 지역의 플레이 카메라가 있다. 전체 지도 촬영은 각 지도 경계에 맞춰 줌을 조정하므로 동일한 절대 좌표 카메라 비교가 아니다. `manifest.json`은 실제 파일 크기와 SHA-256을 기록한다. 전 지역 출력 성공을 지도 재현 완료로 계산하지 않는다.

- `aden_world-before-after.jpg`, `oman_01-before-after.jpg`: 실제 전체 지도 전후.
- `before-contact-sheet.jpg`, `after-contact-sheet.jpg`: 전체 25개 지도.
- `oman-floor-sheet.jpg`, `faith-floor-sheet.jpg`, `domination-floor-sheet.jpg`: 현재 구현된 각 탑 지도. 오만 2~10층·신념 1~4층·지배 정상은 기존 임시 구조임을 유지한다.

검사 명령: `tools/test_project.py --godot <Godot 4.7.2> --render-visual-tests`, `tests/world_structure_test.gd`, `tests/world_structure_capture_test.gd`. 실제 전체 검사 결과는 동봉 로그와 요약 JSON으로 판정한다. 검사에 사용한 4×3 L1J 데이터와 작은 이미지 fixture는 자체 제작 테스트 데이터이며 원본 팩 복원이 아니다.

로컬 최종 결과: Godot 4.7.2의 108개 검사 중 105개 통과, 실패 0개, 원본 팩이 필요한 3개 건너뜀. 전체 실행의 1,200초 제한 이후 남은 검사 4개를 개별 완료했고, 옛 지도 좌표를 고정한 검사 3개를 수정·재검사했다. 각 최종 로그와 파일 해시는 `project-validation-summary.json`에 명시한다. 이전 실패 로그와 제한 시간 로그는 로컬에 보존했다. 원격 CI에는 전체 예산을 1,800초로 조정했다.

현재 지도 검사는 실제 장거리 이동을 포함해 817개 조건 통과, 24개 탑/특수 지역 게임 회귀는 5,666개 조건 통과, 전체 25개 지역의 실제 지형 출력은 414개 조건 통과다. 318종/25맵/27개 보스 바인딩의 기존 몬스터 검사는 9,323개 조건을 통과했다. 원본 그래픽 복원·원작 좌표 검증으로 환산하지 않는다.

기존 아덴 돌집·광장·강·물리 검사 5개는 보존된 레이아웃 1 fixture를 대상으로 호환성을 검사한다. 새 대륙의 검증은 `world_structure_test` 및 25맵 회귀 검사다. 구형 fixture 통과를 새 지도의 원작 충실도 검증으로 집계하지 않는다.

## 미완료와 재개

아덴의 절대 축척·서버 좌표·세밀한 절벽·도시 밀도·지형 충돌 정밀화, 오만 2~10층과 신념 1~4층의 실제 지도, 지배 입구/정상의 전체 윤곽과 한국판 구성, 모든 원작 보스 리젠 좌표·시간은 남았다. 기존 탑을 연결한 연속 `next` 경로는 TWILIGHT 임시 진행 구조이며 원작 연결로 확정하지 않는다.

다음 단위는 같은 공략에서 확보 가능한 오만 2층 전체 지도를 실제로 대조해 별도 윤곽·이동 구역을 작성하고, 확인되지 않은 구형 격자를 교체하는 것이다. 아덴은 도로/수역 교차부와 큰 절벽의 이동 경계를 먼저 정밀화한다. 새 소품 제작을 우선하지 않는다. 최신 원격 HEAD와 미커밋 변경부터 확인하며 이 단위의 조사·제작을 처음부터 반복하지 않는다.
