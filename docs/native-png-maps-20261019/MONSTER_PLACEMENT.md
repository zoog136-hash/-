# PR #128 후속 — 실제 PNG 맵 몬스터 배치

대상: 병합된 #128의 네 원본 PNG 기반 여섯 플레이 필드. 기존 보스·몬스터 및 원작 지도 파일은 변경하지 않는다. 이 PR은 몬스터 출현을 연결하는 구현 PR이며 리니지M 원본 서버 좌표를 재현했다고 주장하지 않는다.

## 배치 내역

| PNG 필드 | 일반 몬스터 최대 슬롯 | 기존 보스 | 로스터 근거 |
|---|---:|---|---|
| albino_01 | 28 | 알비노 유니콘 | 기존 albino_01 7구역 |
| albino_02 | 28 | 알비노 피닉스 | 기존 albino_02 7구역 |
| albino_03 | 21 | 알비노 데몬 | 기존 albino_03 7구역 |
| escaros_world | 160 | 웨링, 듀페리온, 욥니르, 살라흐, 그라디움 | 기존 escaros_01~05 각 4구역·보스 |
| yahee_temple | 20 | 추가하지 않음 | 기존 등록 종의 임시 PvE 로스터 |
| balrog_temple | 32 | 추가하지 않음 | 기존 등록 종의 임시 PvE 로스터 |

- 총 일반 최대 289 슬롯 / 기존 보스 8종 / 56개 스폰 구역이다. 슬롯 수는 실제 화면 동시 출현 보장 수가 아니다.
- 기존 로스터·보스 이름과 전투 AI, 능력치, 장비, 드롭, 원래 맵·몬스터·NPC·저장 데이터는 유지한다. 신전 로스터는 공식 출현 종 고증이 아닌 임시 플레이용이며 새 보스·임의 드롭을 만들지 않는다.
- data/monsters/native_png_spawn_layout.json: 스폰 구역과 근거 파일. 이전 #128의 native_png_plan.json SHA-256에 결속하여 다른 지도 판본에 적용되지 않게 한다.
- scripts/monsters/native_png_spawns.gd: 기존 world_spawn_profiles.json 로스터를 새 지도의 검수된 보행 다각형 및 지역별 네임스페이스에 맵핑한다. 원래 서버 위치로 검증되지 않은 좌표를 사실처럼 표기하지 않는다.
- 진입점 반경 320픽셀, 포털 반경 180픽셀을 일반·보스 출현 후보에서 제외하고, 원본 PNG 알파가 차단한 이동 격자·비연결 격자·장애물 인접 셀은 추가로 삭제한다.
- NativePngField의 전용 스폰을 켜는 경우만 동작한다. 기존 일반 모드의 알비노·에스카로스 레거시 필드는 이전 스폰을 그대로 사용하고 다른 지역도 바꾸지 않는다.
- PNG 표시 미니맵은 새 다각형 기반 보스 구역을 표현할 수 있다.

## 검증 범위

- native_png_monster_spawns_test.gd: 기존 로스터와 등록 몬스터 이름, 출현 상한·보스 스키마·고유 구역, 해시 잠금, 지형 후보 스폰 가능성, 신전 신규 보스 금지 검증.
- native_png_runtime_test.gd / native_png_normal_travel_test.gd: 실제 비공개 팩 연결 시 스폰 후보와 이동·저장, 기존 필드 보존 검사.
- 공개 CI에는 원본 PNG가 없으므로 정적·코드 검증까지만 가능하다. 비공개 개인팩을 이용한 실제 Godot/OpenGL/Android 플레이, 모든 벽·물·절벽 및 보스 접근성은 별도 실기 검증이 필요하다.
- 미검증 상태로 main 자동 병합하지 않는다.

원본 게임 서버 위치·정확한 리젠·신전 몬스터 구성을 고증하려면 적법한 원본 자료에서 지역별 출현 리스트·좌표를 추가 확보해 수정해야 한다.
