# 터치·드래그·대상 선택·AUTO 수정 (2026-10-14)

기준: main `6fd15c82280a3f3dd136abe749ce1b53b31f8261`.
작업 브랜치: `feature/input-eight-fixes-20261014`. PR #100/#108의 작업은 변경하지 않는다.

## 조작

1. 가방의 장비를 한 번 누르면 해당 물리 ID의 상세창을 바로 연다.
2. 같은 칸을 360ms 안에 두 번 누르면 장비 장착 또는 소모품 1회 사용을 기존 게임 서비스에 요청한다. 다른 아이템, 스크롤, 드래그, 취소, 포커스 상실은 연속 터치 판정을 끊는다.
3. NPC 텔레포트 목록과 월드맵 지역 목록 모두 네이티브 손가락 터치를 지원한다. 놓을 때 선택하며, 스크롤/취소/목록 내용 변경은 선택하지 않는다. 이동 버튼도 네이티브 터치로 동작한다. 기존 레벨·비용·통행 검사는 유지한다.
4. 가방에서 HUD가 아닌 바닥으로 끌어 놓으면 캐릭터 주변의 통행 가능한 바닥에 **1개**를 내려놓는다. 세로로 가방 안에서 끌면 스크롤이며 바깥으로 끌면 드래그로 전환한다. 잠금/장착 중 장비는 거절하고, 생성 실패 때는 가방을 차감하지 않는다. 장비 ID·강화·속성·축복·고정된 원본 아이템 레코드를 바닥 저장과 재습득에 보존한다. 직접 버린 아이템은 AUTO가 다시 줍지 않지만 수동 습득은 가능하다. 기존 바닥 아이템 유효시간은 유지한다.
5. 몬스터/NPC 위에서 드래그하면 지나간 대상을 순서대로 추가한다. 빈 바닥에서 드래그하면 사각형 안의 대상을 선택한다. 사각형 내 동시 선택은 시작점과 가까운 순서다. 드래그는 이동/대화로 중복 실행하지 않는다.
6. 왼쪽 목록은 선택 순서를 유지한다. 항목을 누르면 그 대상만 첫째로 이동하고 나머지 상대 순서는 유지한다. 사망·삭제·맵 변경·몬스터 풀 재사용 시 오래된 선택을 정리한다. 첫째 NPC는 공격 대상이 아니므로 AUTO를 끄지 않고 전투를 대기한다. 해제 버튼으로 목록을 비울 수 있다.
7. 바닥 이동·조이스틱·수동 습득·귀환/텔레포트는 AUTO 설정을 끄지 않는다. 수동 이동 경로를 우선하고 도착하면 자동 사냥을 재개한다. 탄약 부족은 공격 대기 상태이며 AUTO 설정은 유지한다. AUTO 버튼/T 키가 명시적 켜기·끄기를 담당한다.
8. 상단 중앙 대상 이름/레벨/HP 패널을 생성하지 않고 레거시 패널도 제거한다. 전투 데이터 및 맵 이름 표시는 유지한다.
