# 523 세공·제련·연금·장비 세트·발동 교체

기준 main은 `c043715af47a8b3a8a14e49882488c5f1020484e`다. 기존 통합 작업 및 PR239와 별도인 하나의 feature 브랜치에서 구현한다. PR239의 제작·기본 강화·축복 부여와 PR261의 주문 계열 전환을 이 다섯 기능으로 집계하지 않는다. 다른 PR을 병합하거나 기존 원본·사용자 세이브를 교체하지 않는다.

메뉴의 **세공·제련·연금**에서 원본 ID가 확인된 소유 장비와 재료를 선택하고, 비용 미리보기와 확인 체크를 거쳐 실행한다. 선택 변경·취소에는 소모가 없다. 물리 ID별 옵션과 기존 사용자 옵션을 보존하며, 저장이 성공한 뒤에만 재료·아데나·결과·난수를 반영한다.

## 기존 공통 ZIP 재사용

원본은 이미 보관된 `lineagem_patch523_all_content_validated_and_508_520_deltas.zip`을 재사용한다. **25,031,173B**, SHA256 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`. 새 원본 업로드는 필요하지 않다. 공개 저장소에는 변환기·설정·테스트와 이 문서만 추가하며, 원문 표나 실행 캐시는 포함하지 않는다.

Python 3 표준 라이브러리로 기존 ZIP에서 개인 실행 캐시를 생성한다. ZIP SHA·CRC와 사용한 원문 바이트를 검사하며, 압축 내부 경로를 임의 추출하지 않는다.

```sh
python3 tools/equipment/build_five_systems.py \
  --source-zip /private/lineagem_patch523_all_content_validated_and_508_520_deltas.zip \
  --catalog data/catalog_v19.json \
  --output /private/equipment523-rules.json
```

생성한 JSON 경로와 출력 SHA256을 게임 설치 화면에 입력한다. 설치는 SHA 및 523 스키마를 검사한 뒤 `user://equipment523/<캐시SHA>/rules.json`에 복사하고 `active.json`을 원자 교체한다. 다음 프로세스는 활성 기록으로 같은 캐시를 읽는다. 원본 ZIP을 게임이 직접 실행하는 것은 아니며, Python 변환 → 캐시 설치 → 실제 게임 로드를 구분한다. UI는 자동 다운로드하지 않는다.

검수용 `--equipment523-rules=/absolute/cache.json --equipment523-sha256=<SHA>`는 명시된 파일을 읽는 경로다. 영구 설치를 증명하지 않으므로 설치 UI와 새 프로세스 검사는 따로 수행한다. 팩이 없거나 손상되면 새 거래를 거부하고 기존 가공 저장은 보존한다.

## 명시된 로컬 정책

[설정](../data/equipment523/policy.json)에 미확정 해석을 분리한다. 원문 확률·수량·대상 조인은 설정으로 바꾸지 않는다.

- 추가 실행 아데나, 축복 세공·제련의 재료1개 해석, Prob1 선택, 정령 BlessCode0 선택자, 발동의0단계/축복0 선택자와 한 슬롯 변경, 세트 임계 효과 누적은 명시된 TWILIGHT 정책이다.
- 연금 평가를 각 재료의 BasePrice+해당 강화/속성/축복 가격으로 합산하고 구간 양끝을 포함한다. 원작 서버 평가식 복원이 아니다. Base10만/Law20만은 원문 그룹 고정값이며 점술2만은 더하지 않는다. [Law20만 공식 안내](https://lineagem.plaync.com/board/update/view?articleId=637a8038203a0e1cd67507ec)는 버전이 다른 보조 근거다.
- 기존 단독 실행 게임의 PvP 수치→PvE 정책을 재사용한다. 원문 원소 정수 피해를 기존 퍼센트 필드에 넣지 않는다. 원소 치명 배율2배, DTH1당 추가 피해1, 기존30초 회복 간격은 로컬 소비 공식이다. LFE는 기존 스킬의 lfe_scale 경로에 가산한다.
- 기간 값은 확인된 날짜형 값 또는 일정 참조를 구분하고, 해석할 수 없는 만료 재료는 소모하지 않는다.

[속성 세공 공식 안내](https://lineagem.plaync.com/board/update/view?articleId=63179fb83c109974e5abc088), [축복 세공 명칭·대상 변경](https://lineagem.plaync.com/board/update/view?articleId=6553cab871f8ad2a4d4f4b91), [발동 교체 안내](https://lineagem.plaync.com/board/update/view?articleId=5fbc10f6865b600001e06e3b)는 원문과 대조한 검색 근거이며 최신523 전체 서버 실행의 증명은 아니다.

## 저장·공급·검증 경계

`item_instances[물리ID].equipment523`에 원문 선택 근거를 저장하고, 소비 때 현재 원문 풀·슬롯·대상·강화·축복·기간을 재검증한다. 다른 물리 ID나 풀로 옮긴 상태는 적용하지 않는다. 알 수 없는 기존 상태는 삭제하지 않는다. 기존 이름 스택은 정확한 카탈로그 ID/이름의 단일 바인딩과 물리 스택을 뺀 잔량만 호환 소비한다. 원본 보상 기록의 물리/record 수량을 함께 보존한다.

공급은 기존 상점·드랍·제작을 복제하지 않는다. 이 PR의 테스트 소유 주입은 정상 획득 증거가 아니다. 미병합 PR238/239의 전체 카탈로그·공급 및 미등록 원본 장비 등록은 별도 의존이다. 기존 제작은 새 옵션이 있는 장비를 무옵션 재료로 조용히 소비하지 못하도록 보호한다.

필수 리소스 검사는723시트·41,442프레임의 기존 추적/SHA와125개 스킬 SVG 및 실패 거부 검사를 유지한다. 이는 비공개 원본 아트 전체 납품이나 원작 동등성 증명이 아니다. 전체 수동 CI·시각/게임플레이 전수 검사는 실행하지 않는다. 실제 Main·개체 거래·새 프로세스와 검증 범위의 최종 결과는 PR 설명에 정확한 커밋과 함께 기록한다.
