# 성물 소환 스킬 레벨 증가분 연결

기준 main은 `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`, 작업 PR은 [#248](https://github.com/zoog136-hash/-/pull/248)이다. 기존 성물 소환 화면에서 원본 규칙을 설치하고, 보유·장착·원본 조건에 맞는 등급별 스킬 레벨 증가를 기존 전투와 스킬 상세에 연결한다. **현재 등록 스킬 119개의 정확한 원본 정체성을 검증했고, 확인된 직접 수치 증가분은 24개 스킬에, 원본 성공률 차이는 별도 게임 적용 설정으로 5개 스킬에 연결한다. 완전한 원작 전투 수식이나 미확인 효과 전체를 구현했다는 뜻은 아니다.**

## 원본과 정체성

- 정식 Library 자료: `libfile_f3e9e5b322cc8191ae441565bbd24c27`, `lineagem_patch523_all_content_validated_and_508_520_deltas.zip`.
- 실제 원문: 25,031,173 bytes, SHA-256 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`. 전체 ZIP CRC 통과. 원문·플레이어 세이브를 수정하지 않는다.
- `BuffCardTranscendence`: 성물 59개의 그룹 매핑. 현재 main의 정식 카탈로그와 정확히 대조되는 58개와 별도 등록이 필요한 세계수의 꽃잎 `25162` 1개다.
- `BuffCardTranscendenceBonus`: 7그룹·13행. 모두 `SpellLevelUp`, `Value`, `Grade`, `+1`. 대상 원본 등급 ID는 `1/4/5/32`. 영웅 성물은 일반, 전설은 일반·영웅, 신화는 일반·영웅·전설, 유일은 일반·영웅·전설·신화 스킬을 가리킨다. 미사용 그룹 `58/68/78`을 다른 카드에 전용하지 않는다.
- **원본 스킬 등급은 `BuffCardDeck.ID=41, Name=Spell`의 `BuffCard.SpellClassID → GradeID`로 확인한다.** 기존 게임의 한글 등급이나 이름만으로 추정하지 않는다.
- 현재 스킬 119개의 `SpellClassID`와 원문 행 SHA는 일반 스킬 PR [#245](https://github.com/zoog136-hash/-/pull/245)의 검토된 바인딩 커밋 `e1c8c9de73b92e91686d9474f162881c4c19bd90`과 일치한다. 작은 `relic_spell_bindings523.json`에는 ID·해시·버프 재계산 여부만 저장한다. 원문 효과값·ZIP을 공개 Git에 추가하지 않는다.
- 호스트 ID·이름·직업·origin·activation 해시와 원문 행 SHA, 스킬 카드 ID·등급을 모두 대조한다. 화면과 퀵슬롯의 완전히 같은 복사본은 정식 카탈로그를 다시 조회하여 계산한다. 같은 ID에 값이 달라진 레코드는 원본 효과를 자동 부여하지 않는다.

이 표에는 초월 시도·비용·성공률이 없다. 무료/100% 초월 버튼, 새 승급 진행도, 다른 카드로의 확대를 만들지 않는다. 기존 각성 비용과 사용자가 정한 게임 비용은 보존한다.

## 전투에서 적용하는 값

`SpellBonus`, 직접 연결된 `BuffBonus`, `Bonus`, `BonusType`, `Unit`, `UIUnit`을 실제 ZIP에서 읽는다. 원본 `MinSpellLevel`과 캐릭터 레벨 조건은 해당 단계의 행을 선택하는 기준이며, 여러 단계의 값을 합산하지 않는다. 클래스·적용 대상 조건이 붙은 값을 일반 능력치로 바꾸지 않는다. 동일 우선순위에 다른 행이 있으면 모호함으로 처리한다.

기존 게임의 기본 수치에 **원본 스킬 레벨 0과 1의 확인된 차이**를 더한다. 전체 피해·명중 공식을 원작처럼 재현하거나 임의의 비율을 곱하지 않는다. 예를 들면 현재 기본 피해가 80인 아이스 스파이크는 원본 `SpellDamageBase` 40→45의 차이 +5를 반영해 85가 된다. 일반 스킬 PR의 비용·회복 어댑터가 먼저 기본값을 제공해도 같은 레벨 차이는 한 번만 적용된다.

연결된 경로는 다음과 같다.

- 기본 스킬 피해: 아이스 스파이크 +5, 헬 사이드 +6. 기존 유료 시전과 모션 마커로 전달되는 공격 스냅샷 및 실제 피해 계산에서 소비한다.
- MP 회복: 블러드 투 소울·마나 체인지 +1. 기존 HP·재료 비용과 MP 상한을 유지한다.
- 능력치: HP/MP, 근거리 피해·명중·치명타, ER, CON, 방어(AC 감소), MR, 공격·이동 속도, 소지 무게. `Percentage`의 분모 10000, `Weight`의 분모 100 등을 원본 `UIUnit`으로 변환한다. AC 개선은 현재 게임의 양수 방어로 연결한다.
- 몬스터 피해 감소: 원본 `PVEDamageReduction` 증가분을 별도 `pveDamageReduction`으로 보존하여 몬스터 공격 소비 경로에서만 더한다. PvP 감소를 PvE에 합치지 않는다.
- 앱솔루트 배리어: 직접 이동 속도 증가분 +0.05와 지속시간 +2초. 지속시간 증가는 다음 시전에 반영하며 이미 걸린 버프의 시간을 늘리거나 초기화하지 않는다.

기존 `learned[id]=1`은 소유 상태다. 큰 저장 값이 있어도 원본 스킬 레벨로 해석하지 않는다. 원본 기본 단계는 0이며 성물의 확인된 +1만 반영한다. 강화 관계가 있는 스킬은 최종 적용된 스킬의 정확한 ID·등급을 사용한다. 실행 보류·다른 직업·미습득·조건 불충족 스킬을 이 기능으로 활성화하지 않는다.

소환 변경, 해제, 보유 상태·서버 문맥·원본 규칙 교체, 직업·캐릭터 레벨·무기·학교·습득 변경 때 캐시를 무효화한다. 이미 걸린 해당 버프의 능력치도 다시 계산한다. 시간·쿨다운·비용을 다시 적용하거나 재계산으로 치유하지 않는다. 최대 HP/MP가 줄면 현재 값을 상한으로 제한한다. **별도 원본 ZIP을 사용할 수 없는 경우에도 공개 바인딩의 ID/해시 표식으로 해당 버프를 기본값으로 되돌린다.** 저장된 파생 보너스가 원본 팩 없이 남는 것을 방지한다.

## 화면과 설치

게임 메뉴 → 성물 → 선택 상세 → **원본 규칙 자료 불러오기**에서 정확한 최신523 ZIP을 선택한다. 검증 후 `user://source_rules/relic-patch523.zip`에 원자적으로 설치한다. 손상·다른 버전·쓰기 실패는 기존 규칙을 보존한다. 미보유 상태에서도 원본 매핑은 조회할 수 있고, 적용에는 영구 보유와 현재 소환의 정식 정체성 일치가 필요하다.

성물 패널은 등급별 +1과 현재 적용 상태를 표시한다. 기존 메뉴 → 스킬 → 선택 상세의 **사용 정보 / 습득·출처** 양쪽에는 원본 스킬 레벨 0→1과 실제 반영 증가분을 표시한다. 미확인 효과는 해당 스킬에 따로 표시한다. 공통 HUD 게시기나 다른 기능 PR의 화면을 다시 작성하지 않는다.

서버 조건은 최신523 행을 공급한 기존 원문 조건 평가기로 검사한다. 지도·언어를 서버로 추정하지 않는다. 이벤트 카드 1개의 날짜 조건은 아직 미해석이며 컬렉션의 별도 기간 해제 정책을 전용하지 않는다.

## 성공 확률의 조사와 게임 적용 설정

후속 사용자 지시에 따라 확률 관련 보류 항목을 다시 조사했다. 원문에는 엑스칼리버 70→73%, 블랙 핸드·다크 핸드·데스 핸드 45→48%, 파워 그립 50→51%의 `SpellHitProbabilityBase`가 있다. [NC 공식 블랙 핸드 안내](https://about.ncsoft.com/news/article/lineagem-update-20210127)는 공포 효과를 설명하고, [공식 스킬카드 확률 안내](https://probability.plaync.com/lineagem/view?probCategoryId=6656df8e96b3cf5ad823b780)는 카드 합성을 다룬다. 조사한 공개 자료에서 저항·보스까지 포함한 전체 상태 성공식은 확인하지 못했다. 합성 확률을 전투 확률로 전용하지 않는다.

`data/skills/relic_spell_effect_policy.json`의 `status_probability_projection`은 **CUSTOM_BALANCE 게임 적용 설정**이다. 위 5개 정확한 원본 ID와 기존 상태 유형만 허용하고, 원본의 레벨 차이 +3%p/+1%p를 현재 `status_chance`에 더한다. 기존 게임의 기본 성공률·저항·보스 계수·실패 처리와 사용자 지정 비용을 보존한다. 숫자 증가분은 원문이 우선이며 자체 확률을 새로 만들지 않았다. 원작 전체 공식이라고 주장하지 않는다. 적용 여부와 0~1 범위를 이 설정에서 바꿀 수 있으며 변경은 다음 실행에서 읽는다.

사용 정보·출처 화면에도 `상태 성공률 +3.00%p · 게임 적용 설정(원본 증가분)`처럼 구분한다. 설정을 끄면 원래 성공률로 돌아간다. 실제 상태 판정에서 같은 난수와 대상에 기존 실패/보너스 적용 후 성공이 갈리는 경계를 검증한다. 비용·확률 승인을 연쇄 회복 정의나 PvP 기능 활성화의 승인으로 확대하지 않는다.

## 남은 범위

119개 바인딩 중 8개 스킬에 아직 연결할 수 없는 효과가 있으며, 일부는 적용 가능한 효과와 함께 미확인 효과를 가질 수 있다. 상세 화면의 대기 목록에 구체적 원본 타입을 표시한다.

- `InvokeOption` 및 적용 대상·캐릭터 클래스 조건: 조건부 발동을 일반 능력치로 바꾸지 않는다.
- `PVPDamageReduction`: 현재 단독 게임에 검증된 PvP 소비 경로가 없다.
- 드래곤 포스·플라즈마 다이브·라이프 스트림 등의 자식 주문 회복: 원문 자식 주문의 레벨 상속과 `RestorationID` 소비를 확정할 정보가 부족하다. 이는 확률·비용 숫자 공백과 별도의 실행 의미 문제다. 현재523 자료에는 `Restoration` 테이블이 없다. 임의의 회복량을 만들지 않는다.

현재 기본 카탈로그에 없는 원본 스킬이나 실행 보류된 공식 참조 스킬 전체를 새로 지급·활성화하지 않는다. 신규 성물 25162의 등록은 별도 카드 PR의 범위다.

PR #231의 성물 화면/HUD/World 공통 패치3개와 PR #245의 스킬 카탈로그/시전/두 UI 공통 패치4개에 `git apply --check`를 수행한다. 실제 타 PR 병합이나 조합 런타임 통과를 주장하지 않는다. 원본 규칙 증가분을 비용 어댑터 다음에 계산하도록 경로를 분리했다.

main·다른 PR을 병합하지 않는다. 커밋에 `[skip ci]`를 사용하며 수동 CI 실행·재실행·취소, 워크플로·보호 규칙 변경을 하지 않는다. 원격 필수 CI 미실행은 통과가 아니다.
