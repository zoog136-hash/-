# 장비 컬렉션 — 실제 게임 통합

기준 main: `5a5c4ff54565e26c58a145dabe749e8c41fc7a24`.
이전 기능 브랜치 `9a8e0807a9cc28979b72d9d490ecf9227b73b6bc`의 재개 기록은 보존한다.

## 현재 게임 연결

- 실제 `Main.tscn → scripts/world.gd`와 기존 `renewal_hud.gd`에 연결한다. 독립 데모 project.godot/인벤토리로 대체하지 않는다.
- 메뉴 → **장비 컬렉션**, 아이템 도감 → **장비 컬렉션**. 변신·마법인형·성물 카드 컬렉션 버튼은 이 장비 서비스와 혼동하지 않는다.
- 원문 표기 각인만 제거해 등록 비교한다. 원본 장비명·sourceId·물리 ID·강화·축복·속성·이미지·기존 세이브는 유지한다.
- 요구 강화는 정확히 일치해야 한다. 높은 강화로 임의 대체하지 않는다. 사용자 확인 후 선택한 ID 한 개만 소모한다. 장착/잠금/원본 ID/실물 수량 불일치는 차단한다.
- 기존 전체 저장 파일에 인벤토리와 등록 영수증을 함께 원자적 기록한다. 저장 성공 전 메모리의 장비·진행도는 바꾸지 않는다. 재요청/재접속으로 중복 소비·보너스가 생기지 않는다.
- 구 세이브 첫 이전에 `.pre-equipment-collections`를 보존한다. 손상·미지원 버전·외부 파일 변경은 조용히 초기화/덮어쓰기하지 않는다. 아직 알려지지 않은 확장 필드도 유지한다.
- 소비된 숫자 장비 ID를 구 세이브 불러오기에서 재발급하지 않는다. 컬렉션 효과는 영수증에서 다시 계산하며, 모든 전투 틱마다 447개를 재검색하지 않는다.

## 데이터 범위와 보류

원본 제공 데이터 447개/1,659슬롯/432개 정규화 이름을 그대로 보존했다. 이전 브라우저 구현의 `data_ready=390`은 실게임 활성 수가 아니다.

정적 실제 카탈로그 대조: **339개 적용 가능, 108개 보류**. 57개는 원자료 검토, 19개는 요구 장비 원본 ID 미매칭, 32개는 아직 연결하지 않은 효과 포함이다. 정규화 장비명은 408/432개가 정확히 매칭된다. 사유는 UI와 `RUNTIME_BINDING_AUDIT_20261020.json`에 남긴다.

일부 효과만 빼고 재료를 소비하지 않는다. PvP 효과를 임의 PvE로 바꾸지 않고, 대미지 리덕션 무시/확률 등 미검증 수식을 단순 대미지로 대체하지 않는다. 조사표의 이름 오기를 비슷한 장비로 추측하지 않는다.

이 데이터의 영구 지속은 TWILIGHT의 적용 정책이다. 원작 모든 항목이 현재 영구/획득 가능하다고 전수 확인한 뜻은 아니다. 실게임 카탈로그 ID 존재와 실제 사냥·제작을 통한 획득 가능성은 별도다.
