## 조정 가능한 TWILIGHT 실행 정책

`data/titles/local_policy523.json`에 원본과 분리했다. UI에도 자체 정책으로 표시한다.

- 기부 원문 Probability1500000 등의 실행 분모는10,000,000으로 가정한다.
  일반 심사는 별도10%다. 두 값은 원본 실행 확률로 확정하지 않는다.
- 모든 후보 중1개를 명시 선택한다. QuestAmount3은 그대로 보존하고3개 모두
  완료로 해석하지 않는다. 일일 경계는 UTC05시, 실패한 일반 심사는 자격을 소비한다.
- 메인 효과는 해당 메인의 첫 서브 달성 시 적용한다. 단일 캐릭터 세이브이며
  서버/계정 공유를 흉내 내지 않는다. 직접 플레이어 피해·반사만 막타로 인정한다.
- PvP 전용 수치는 명시적 NPC 전투 적용 설정을 사용한다. 무기 막기는 성공한
  물리 타격 전체의50%를 남긴다. 원본 무기 성분별 공식과 동일하지 않다.
- 결정타는 직접 성공 타격에서1회 추첨하며 기본2배에 원본 증폭5%를 더한다.
  기본 배율·처리 성분은 자체값이다. 공식 패치에서 무기 막기의 정성적 효과와
  후작 결정타/증폭 수치는 확인했지만 정확한 실행 공식은 복구하지 못했다.
- 가루 원본 드롭 표에는 확률·수량이 없어 자체10%/1개를 사용한다.

## 거래·저장·검증 경계

확인 화면은 읽기만 한다. 최종 확인에서 현재 비용·소지 키·잠금·단계·revision을
다시 검사하고, 지속 RNG의 다음 상태·재료 차감·작위/결과를 기존 원자 저장기에
같이 쓴 뒤 메모리를 반영한다. 저장 실패 시 RNG/재료/진행과 이전 파일을 보존한다.
시계 역행, 만료, 중복 확인·사망 이벤트, 재사용되는 actor life와 새 프로세스를 구분한다.
손상된 작위 상태나 필요한 원본 누락은 기존 세이브의 덮어쓰기를 차단한다.

전수 규칙 검사와 실제 Main 검사는 별도다. `tests/title523_test.gd`는 원본25개
전이·128개 목표·178개 공급 행과 예외를 검사한다. `tests/title523_main_test.gd`는
실제 메뉴·확인/취소·writer 실패·소비·배지·전투 소비자·바닥 습득과 재접속을 검사한다.
검사는 별도 XDG 프로필만 사용한다. 소유량·원본 actor·완료 직전 수량·성공 RNG는
격리 fixture임을 명시하며, 실제 수천 번의 사냥이나 자연 공급 완료로 집계하지 않는다.

현재 main의 일반 지도에서 원본 작위 대상33종·가루 공급126종(178행) 전체의 배치를

따라서 자연 획득→25단계 전체 사냥 진행 완료를 주장하지 않는다. 정확한 원본 ID와
원행을 주는 기존 지도/몬스터 공급자가 연결되어야 한다. 혈맹·공성·일반 퀘스트
확장·투기장·지구라트·펫·M 엔진/APK를 도입하지 않았다.

실행 로그·화면·최종 코드 해시는 현재 환경의 `/workspace/title523-logs/`에 보존한다.

## 공급자 연결 계약과 미완 경로

현재 main 기준 직렬화 데이터의 `source_m_npc_id` 등록은0개였으며 이 검사는 동적

178개 가루 드롭의 자연 플레이는 막힌다. 좌표·가짜 보유·무료 지급으로 이를 통과시키지 않는다.

소비자는 실제 `_deal_successful_player_hit`→사망 이벤트에서 직접 플레이어의 타격과

가루는 같은 원행 계약의 `_roll_drop`→바닥 드롭→가시성·거리 검사→습득 경로를 쓴다.

정확한 class117544·patch523·일반 축복1·비테스트 StackableItem 기록과 실제 비용·소유권
거래를 보장해야 한다. 동명 구형 아이템·보유량만으로 소비 자격을 만들지 않는다.
