## 확인하고 수정한 코드 문제

1. 기존 소모품 구매/매입 가격 역전. 강력 HP 물약은 구매 180 / 매입 200, 축복받은 HP 물약은 구매 450 / 매입 800으로 같은 상품을 사고 팔 때 차익이 생겼다. 신규 재고만 가격 하한을 적용하던 #141과 달리 기존 물약에도 적용되는 매입 측 상한을 추가했다. 일반 HP 물약은 구매 50 / 매입 40 그대로이며 강력/축복받은 물약의 매입가는 각각 180/450이 된다. 기존 구매 가격 및 상품 구성은 변경하지 않는다.
2. 매입 quote에는 지갑 상한 검사가 있으나 apply에는 없었다. quote 이후 wallet이 바뀌면 허용 상한을 넘어 지급하면서 아이템을 제거할 수 있었다. 기존 상한 9000000000000000000을 공통 상수로 유지하고 실제 apply에서도 장비/수량 변경 전에 다시 검사한다. 정확한 상한은 허용하고 초과 거래는 어떤 아이템도 변경하지 않는다.
