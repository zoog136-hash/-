  바닥을 새로 그리거나 캐릭터를 축소하지 않는다.

  물리 슬라이딩에 잘못된 셀 중심 제약이 적용되지 않게 한다.
- 지배 검수 시작점·안내 NPC·포털 5개를 PNG의 중앙 바닥과 원본 연결 경로에서 확인한

  이동은 검수 세션의 메모리 데이터에만 적용한다. 일반 저장을 쓰지 않는다.

## 정합 판정과 남은 작업

아덴 기란의 서로 다른 정원 6개는 아직 후보 기준점이다. 최대 오차 약 25.76 월드 px로
4px 발 기준을 만족하지 않는다. 전역 아핀이나 다른 마을로 확정·외삽하지 않는다.
오만 1~10층의 48×24 원본 좌표/PNG 캔버스 대응은 유지하지만 모든 벽의 시각 정합을
확정한 것은 아니다. 1·5·6·7·8층은 검수된 전경 마스크가 아직 없다.

지배는 사용자가 지정한 **오만 정상 원본 111.png**를 쓴다. 게임 ID는 `domination_summit`이다.
원본 111 격자와 PNG 전역 대응의 경계 진단 오차는 중앙값 144.76 / 90백분위 358.73 PNG px이며
확정 고유 기준점은 0개다. 수정 기둥 아래 원본 셀이 열려 있는 판본 불일치는 수동 샘플 도형으로만
추가 차단하고 전체 판정을 `REVIEW_REQUIRED`로 유지한다. PNG의 흰 뷰어 빈칸 마스크는 기존 v2를
재사용하며 일부 숫자 윤곽이 남았다. 이것을 지형/충돌 데이터로 사용하지 않는다.

필요한 추가 자료는 111 및 오만 각 층과 동일 판본의 오브젝트/통행 속성, 확정 지형 기준점,
전경 원본 또는 수동 검수 마스크, 아덴 지역별 정확한 문·벽·도로 대응이다.
물·건물·소품의 원본 독립 레이어가 있는 것처럼 표시하지 않는다.
