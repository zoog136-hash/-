# 인벤토리 아이템: 리니지M 인벤 이미지 연결

## 범위와 실제 결과

2026-10-14 기준 main `f5138e59376675fda51a501fee2be54739e04aa9`에서 시작한 인벤토리 전용 수정이다. 바닥 그림, 게임 플레이 DB, 이름, 능력치, 등급, 강화, 저장 데이터는 변경하지 않는다.

실행 시 아이템 2,576행 중 기존 원본 연결 2,129행을 유지하고 444행에 인벤 이미지를 추가 연결했다. 444행은 정확한 이름 일치 20행과 자체/변형 아이템의 명시적 외형 대응 424행으로 구분된다. 외형 대응을 원본 아이템 신원 일치나 424개의 새로운 개별 원화로 계산하지 않는다.

이번 연결에 사용하는 이미지 경로는 365개이며, 기존 이미지 326개를 재사용하고 새 PNG 39개를 확보했다. 새 파일을 포함한 모든 이미지 바이트는 로컬 자산으로 읽으며 게임 실행 중 인터넷 연결이 필요하지 않다. 인벤토리의 공용 심볼 항목은 417행에서 3행으로 줄었다. 기존 원본 검수 대기 25행 및 자체 UI 그림 5행도 인벤 이미지로 연결했다.

## 미해결 3개

- 정제된 목재
- 약초
- 드래곤의 용옥

인벤 아이템 DB에서 맞는 원본 그림을 확인하지 못했다. 이 3개는 엉뚱한 그림을 원본으로 등록하지 않고 기존 대체 심볼을 유지한다. 따라서 전체 연결 완료라고 보고하지 않는다. 새 원본이 확보되면 `tools/inven_inventory/policy.json`의 미해결 목록과 테스트의 명시적 예외를 함께 갱신해야 한다.

## 연결 방식

`data/inven_inventory_icons.json`에는 대상 이름·종류·슬롯, 이미지 경로·크기·SHA-256, 인벤 원본 ID·이름·상세 페이지·이미지 URL, 이름 일치/외형 대응 구분이 들어 있다.

`ItemVisualResolver.describe()`는 인벤토리이고 기존 sourceId가 없으며 기존 도감 이름이 아닌 경우에만 새 연결표를 조회한다. 실제 sourceId, 동명 도감 변형, 다른 종류/슬롯, 불완전한 아이템 정체성은 외형 대응으로 덮어쓰지 않는다. 원본 sourceId를 게임 아이템 sourceId에 복사하지 않는다.

`ground=true`는 기존 `_describe_original()` 경로를 그대로 사용한다. 기존 심볼을 쓰던 바닥 항목도 이번 인벤토리 변경으로 몰래 교체하지 않는다.

## 검증 근거

GitHub Actions 실행 `38574499201`에서 Godot 4.7.2로 아래 단계를 실제 실행했다. 코드/자산 검증은 모두 통과했으나 실행 마지막 Git 저장 단계에서 무시 대상 `.gd.uid`를 추가하려다 실패했다. 수정된 보존 단계는 아래 검증을 다시 꾸며내지 않고 동일한 검증 자산 ZIP의 SHA-256을 확인하여 정확히 같은 자산을 커밋한다.

- 에디터 import: 통과.
- 전체 이미지/원본 픽셀/바닥 불변/게임 DB 불변 검사: 28,077개 통과.
- 기존 아이템 시각 검사: 6,445개 통과.
- 아이템 그림 smoke 검사: 31개 통과.
- 아이템 인스턴스/장착 검사: 19개 통과.
- 창고/저장 이전 검사: 23개 통과.
- 실제 포인터 UI 상호작용: 84개 통과. 이름 약 5초 표시, 상세정보, 바닥 드롭 정체성 저장, 텔레포트, 다중 대상 및 자동전투 회귀를 포함한다.
- 실제 게임 인벤토리 및 훈련용 활 상세 창: 1280×720, 960×540 캡처 생성 완료.

검증 요약은 `docs/verification/inven_inventory_20261014.json` 및 `inven_inventory_suites_20261014.json`에 보존한다. 캡처는 별도의 가상 3D 장면이 아니라 실제 Main 장면의 인벤토리 UI이다. 전체 2,576행의 개별 화면을 하나씩 육안 확인한 것은 아니며, Android 실기기 검증도 수행하지 않았다.

## 유지보수

오프라인 원본 파일 검증:

```sh
python3 tools/inven_inventory/build.py
```

명시적으로 출처를 갱신할 때만 실행:

```sh
python3 tools/inven_inventory/build.py --acquire
```

실제 Godot 검증 및 캡처:

```sh
python3 tools/inven_inventory/verify.py --godot /path/to/godot --output /tmp/inventory-inven
```

검증 도구는 Python Pillow 및 UI 캡처용 Xvfb를 사용한다. 일반 게임 실행에는 필요 없다.

## 출처와 권리

공개 리니지M 인벤 아이템 상세 페이지의 ID·이름·이미지 대응을 확인했으며, 기존 검증 이미지 또는 원본 PNG 바이트를 사용한다. 원본 워터마크와 픽셀을 수정하지 않는다. 출처 확인과 공개 열람 가능 여부는 별도의 배포/상업 이용 허락을 뜻하지 않는다. 외부 공개·배포 시 해당 이미지의 이용 권한을 별도 확인해야 한다.
