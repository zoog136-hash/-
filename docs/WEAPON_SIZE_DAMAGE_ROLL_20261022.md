# 무기 소형/대형 데미지 독립 추첨 (2026-10-22)

## 전투 공식

- 근거리·원거리 스탯 = 캐릭터의 기본 공격력 + 무기가 아닌 장착 효과의 공격력 + 강화 고정 데미지 + 능력치/스킬/컬렉션/소모품/장비의 해당 공격형 고정 보너스.
- **무기의 `atk`는 제외**한다. 레거시 무기 `atk`에는 소형 무기 기본값과 추가 데미지가 합산된 아이템이 있어 스탯 또는 실타격에 그대로 더하면 중복된다.
- 무기 고유의 고정 추가 데미지 (`additionalDamage`, `meleeDamage`, `rangedDamage` 또는 설명의 "추가 대미지")는 기존 옵션 어댑터에서 유형별 공격력에 **한 번만** 더한다. 무기 강화 고정 증가분도 현행대로 유지한다.
- 명중한 **일반 근거리·원거리 공격** = 해당 스탯 + 대상 크기별 무기 데미지 `rng.randi_range(1, 최대값)`; 이전 고정 `대형−소형` 보정과 일반타 무관한 `-6..+9` 분산은 적용하지 않는다.
- 물리 계열 **직업 스킬**은 각 명중타에 크기별 무기 추첨을 추가한다. 주문/마법 공격에는 무기 물리 추첨을 추가하지 않는다. 이후 크리티컬·속성·기존 후처리/저항은 그대로이다.
- 무기 미장착 또는 최대 0은 추첨 보너스 0. 무기 레코드는 변경하지 않으며 드랍·저장도 그대로이다.

## 데이터 우선순위

1. 무기 `small_damage`/`large_damage` 명시값.
2. 이름 있는 `작은 대상 대미지`/`큰 대상 대미지` 옵션.
3. Inven `stat: "10/20"` / 기존 `desc: "10/20 · ..."`.
4. 사이즈 정보가 없는 레거시·지역 확장 무기만 `atk`를 동일 소형/대형 최대값으로 사용 (수치가 없는 무기는 0).

예: 무기 `10/20`은 소형 +1~10, 대형 +1~20을 **각 명중 때** 균등 추첨한다. `+3 추가 대미지`는 공격력 표시와 실타격에 고정 +3이며 무기 기본 10/20은 근·원거리 스탯 표시에서 제외한다.

## 화면·검증

상태 스냅샷에 `weapon_small_damage`, `weapon_large_damage`를 분리하고 기존 자세한 상태창, 캐릭터창, 레거시 상세창에서 최대값 또는 1~최대값으로 표시한다. 기존 근거리/원거리 대미지 값은 같은 계산 함수를 사용해 자동으로 정정된다. 증빙 검사는 `tests/weapon_size_damage_test.gd` 및 `tests/item_options_runtime_smoke_test.gd`; 워크플로 `Twilight Item Options Runtime`가 강제 실행한다. 전체 GitHub CI 성공 전에는 병합하지 않는다.
