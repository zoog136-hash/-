# TWILIGHT 지도 런타임 수정 — 2026-10-23

## 이번 변경의 실제 범위

- **오만 1~10층:** 현행 `external_map_packs/oman_v2` 는 충돌/지형 그리드 기반 리메이크다. 일반 화면에 각 층의 원본 PNG를 렌더링한다고 주장하면 안 된다. 현 저장소에는 1~10층에 대응하는 인가된 완성 원본 PNG 패키지가 없으며, 원본과 좌표를 1:1 검증할 수 없어 해당 지도 아트는 이번 변경에 포함하지 않는다.
- **지배의 탑 `111.png`:** `--png-review` 검토 코드만 존재하며, 정상 플레이에 활성화할 만한 정합도와 원본 PNG 데이터가 저장소에 없다. 문서 `docs/png-refinement-20261018/README.md` 에 따르면 독립된 검증 기준점이 확보되지 않았다. 검증되지 않은 지도를 일반 게임에 강제 사용하지 않는다.
- **아덴월드:** 원본 PNG 픽셀 대 게임 오브젝트 비율을 수정하고자 아덴 전용 2.0 배 월드 아트 변환을 적용한다. 렌더러 PNG 청크 위치/크기, 맵 바운드, 실제 출입구, 충돌, 몬스터 서식지, 이동 가능 폴리곤, 경로 표본을 같은 변환으로 보정한다. 원본 PNG 파일 및 SHA/플랜은 건드리지 않는다.
- **에스카로스:** 기존 연속 대형 PNG를 유지하면서 첫 진입의 다중 동기 디코딩을 줄이고, 디코딩 후 텍스처 예산 초과로 폐기될 청크의 반복 디코딩을 방지한다. 입장 시 멀리 있는 일반 몬스터는 생성하지 않고 이동해 근접하면 기존 슬롯에서 생성한다. 보스/드랍/리스폰 정의와 슬롯 수는 유지한다.
- **알비노 3·4구역:** 일반/PNG 지도 선택에서 둘 다 제거하고, 이름이나 이전 저장 파일로 접근하면 2구역으로 이동한다. 2구역 다음 이동은 신념의 탑 1층으로 바로 연결한다. 이전 사용자 저장은 SHA 기반 바이트 백업 후 위치를 안전하게 이전한다. 옛 JSON/원본 이미지의 해시 연동 자료는 백업/이전 호환을 위해 보존하되 일반 게임에서는 접근되지 않는다.

## 배포 전 확인 항목

1. 기존 아덴월드 캐릭터 저장 파일 백업 및 자동 안전 귀환, 몬스터/아이템/수집 기록 유지.
2. 아덴월드의 도로·건축물 크기를 다른 맵과 동일 캐릭터로 비교, 출입구/몬스터/충돌의 실좌표 정합 확인.
3. 에스카로스 입장 및 이동 프레임타임, 디코드 수와 GPU 텍스처 예산, 멀리 있는 몬스터의 물리·시각 동작 확인.
4. 일반/PNG 두 실행 모드에서 알비노 3·4구역 접근 불가, 1→2→신념 이동 및 3·4 옛 저장 이어하기 확인.
5. 추후 인가된 오만 각 층의 PNG 및 지배 111.png와 좌표 기준점이 확보된 뒤 별도 원본 정합 PR 제작.

**검증 한계:** 이 문서와 코드 변경은 실제 Godot 렌더링/FPS 측정을 대체하지 않는다. 해당 런타임 테스트가 완료되기 전 품질·프레임 개선량을 확정 수치로 기재하지 않는다.
