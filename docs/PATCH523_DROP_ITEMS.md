# Patch523 드롭·아이템 연결

원본의 드롭 대상과 아이템 정의를 연결한다. 몬스터 드롭 확률·수량은 기존 TWILIGHT 규칙이며, 기존 양수 확률과 사용자 지정 규칙을 이 확장에서 변경하지 않는다. 퀘스트·테스트 조건을 무조건 지급으로 바꾸지 않는다.

## 적용 범위

- 드롭 46,854행, NPC 4,848종, 드롭 아이템 ID 2,379개. 중복 행은 추가 추첨권이나 수량으로 계산하지 않는다. 축복·퀘스트 조건은 별개로 보존한다.
- 아이템 정의 2,568개: 드롭 ID 2,379개와 실행 가능한 상자의 보상 의존성 189개. 상자 보상이 몬스터 드롭 목록을 늘리지 않는다.
- 원본 지정 카드 174개 정의를 기존 등록 카드의 전체 원본 행과 대조한다. 현재 테스트·서버 조건 없이 사용할 수 있는 111종을 실제 카드 보유·중복 카드·공개 UI·저장에 연결한다. 무작위 카드팩 확률과 합성 규칙은 유지한다.
- 지속 버프 5종, MP 회복 1종, 확정 상자 9종, 원본 확률 상자 64종, 혼합 상자 2종을 연결한다. 직업별 보상 관계, 수량, 축복, 초기 강화 단계를 보존한다. 불완전한 확률 합을 정규화하거나 균등 확률로 채우지 않는다.
- 원본 드롭 무기의 발동 37개와 상자 보상 무기의 같은 발동 8개를 연결한다. 크로우 9개는 무기 기본 대미지의 최댓값을 사용하며 캐릭터 치명타와 분리한다. 이도류 16개와 총 출혈 20개는 아래 보완 규칙을 명시한다.
- 원본 장착 부위 293을 `domination_stone` 전용 슬롯으로 연결한다. 지배석의 MR +2와 경험치 +1%를 적용하고 장비창 3쪽에서 표시한다. 기존 축복·저주 스택 키는 별개로 보존한다. 이 부위에 강화 시도 규칙을 새로 붙이지 않는다. 탑 이동·퀘스트·세트 활성화는 별도 미연결 기능이다.
- 확인된 원본 양손 무기·양손 무기와 함께 착용 가능한 보조 장비 플래그를 적용한다. 일반·원본 장비의 기존 물리 개체와 세이브를 유지한다.

## 원본과 TWILIGHT 보완 규칙

원본 정의와 공개 근거가 보완 규칙보다 우선한다. 원본은 팩 내부에 그대로 남긴다.

| 보완 규칙 | 기본값 | 게임 설정 |
| --- | --- | --- |
| 이도류 배율 적용 범위 | 무기 기본·추가·강화 대미지. 원본 발동 확률·배율은 변경하지 않음 | 기본만 적용하거나 발동 끄기 가능 |
| 총 출혈 틱 간격 | 기존 게임의 0.75초. 원본의 3초·10D1·발동 확률 유지 | 0.1~3초 |
| 출혈 `MaxHPPercent=50` 해석 | 누적 출혈 피해를 대상 최대 HP의 50%로 제한하는 추정 규칙 | 상한 제거 또는 발동 끄기 가능 |
| 확률 상자 선택 횟수 | 원본 확률표로 1회 선택. 확정 보상은 1회 지급 | 1~10회 또는 상자 선택 규칙 끄기 가능 |

원본은 출혈 틱 간격과 `MaxHPPercent`의 의미를 설명하지 않는다. 이 연결은 별도 추가 저항 추첨을 만들지 않으며, 원본 특수 저항 선언도 원본 행으로 보존한다. 출혈은 기존 몬스터 전투 상태와 같은 세션 수명을 사용한다. 설정은 저장·재진입에서 유지한다.

근거: [NC 무기 가이드](https://lineagem.plaync.com/guidebook/view?title=%EB%AC%B4%EA%B8%B0+%EC%95%84%EC%9D%B4%ED%85%9C), [무기 대미지를 직접 측정한 공개 실험](https://www.inven.co.kr/board/lineagem/5056/8440), [NC 총사 가이드](https://lineagem.plaync.com/guidebook/view?title=%EC%B4%9D%EC%82%AC+%EB%A7%88%EB%B2%95). 공개 자료에서 확인되지 않은 부분을 원본 공식으로 표시하지 않는다.

## 설치·저장

설정의 **523 드랍 자료 ZIP 설치**에서 적용팩을 선택한다. 원본 보존 ZIP은 설치팩이 아니다. 설치 시 ZIP 경로·크기·파일 목록·SHA를 확인하고 새 버전 폴더에 기록한 뒤 현재 게임의 카탈로그를 갱신한다.

실제 소비 경로는 `user://lineagem_patch523_drops/<payload SHA256>/monster_drops.bin`이다. 개발 실행에서는 검증한 BIN의 폴더를 `--patch523-drop-root=<폴더>`로 지정할 수 있다. Drive 백업은 게임에 자동 적용되지 않는다.

카드 지급, 상자 지급, 원본 HP/MP 물약, 원본 버프는 자원 변경과 저장을 함께 처리한다. 저장 실패 시 아이템·재화·카드·버프·난수 상태를 게시하지 않는다. 카드 공개 연출은 저장 성공 뒤에 시작한다. 설정 저장 실패도 이전 값을 유지한다. 이름만 비슷한 원본 강화 주문서는 기존 일반 강화 UI로 보내지 않는다.

## 검증과 남은 범위

합성 원본을 사용하는 Python 회귀 검사와 실제 Main을 사용하는 선택 실행 검사 `tests/patch523_item_use_test.gd`를 제공한다. 개인 세이브 대신 격리된 XDG 프로필과 검증한 맵 팩을 사용한다. 전체 CI나 수동 원격 CI를 재실행하지 않는다.

미연결 원본 효과는 아이템을 보존하고 UI에서 표시한다. 스킬 카드의 원본 주문 ID를 현재 플레이어 스킬 API로 연결하는 작업, 발동 옵션 교체의 선택 상태·재료 처리, 일부 선택 보상·수명·영토·무제한 사용 규칙은 남아 있다. 원본 NPC 픽셀과 전체 출현 조건의 완료를 이 팩의 ID 연결 완료로 대신하지 않는다. Android 실기기 검증은 별도이며, 이 기록은 데스크톱 실제 게임 실행 검증이다.
