# Patch523 드롭·아이템 연결

원본의 드롭 대상과 아이템 정의를 연결한다. 몬스터 드롭 확률·수량은 기존 TWILIGHT 규칙이며, 기존 양수 확률과 사용자 지정 규칙을 이 확장에서 변경하지 않는다. 퀘스트·테스트 조건을 무조건 지급으로 바꾸지 않는다.

## 적용 범위

- 드롭 46,854행, NPC 4,848종, 드롭 아이템 ID 2,379개. 중복 행은 추가 추첨권이나 수량으로 계산하지 않는다. 축복·퀘스트 조건은 별개로 보존한다.
- 아이템 정의 2,624개: 드롭 ID 2,379개와 실행 가능한 상자의 보상 의존성 245개. 상자 보상이 몬스터 드롭 목록을 늘리지 않는다.
- 원본 지정 카드 187개 정의를 기존 등록 카드의 전체 원본 행과 대조한다. 현재 테스트·서버 조건 없이 사용할 수 있는 122종을 실제 카드 보유·중복 카드·공개 UI·저장에 연결한다. 무작위 카드팩 확률과 합성 규칙은 유지한다.
- 지속 버프 5종, MP 회복 1종, 확정 상자 9종, 원본 확률 상자 64종, 혼합 상자 2종을 연결한다. 직업별 보상 관계, 수량, 축복, 초기 강화 단계를 보존한다. 불완전한 확률 합을 정규화하거나 균등 확률로 채우지 않는다.
- 원본 선택 상자 22종 중 만료 조건 없는 21종은 선택 UI → 정확한 원본 엔티티 → 인벤토리 수령으로 연결한다. 열기·취소는 소비하지 않고 확인 시 1개만 지급한다. 원본 `SelectMaxCount=1`, 보상 ID·수량·축복·직업 조건은 그대로 쓴다. `174433`은 원본 만료 조건으로 소비하지 않는다.
- 선택 장비 3종 상자의 출력에는 초기 강화 필드가 없다. `353364`·`369472`·`369482`의 실제 원본명과 공식 자료를 검색했지만 출력 초기 강화값을 확인하지 못했다. 팩의 `enchant:null`은 그대로 두고 기존 게임의 기본 +0을 표시된 자체 설정으로 적용한다. 설정을 끄면 장비 선택 시 상자를 보존한다. 물리 장비의 출처에 원본 null과 자체 +0을 구분해 저장한다.
- 스킬서 350개에 카드 → SpellClassID → 정렬된 원본 전체 행 SHA256·일반 학습 조건을 연결한다. 22개는 원본 미지원 직업128로 차단하고, 328개는 별도 원본 주문 엔진 바인딩을 요구한다. PR245 `c8f909a`의 검토된 바인딩과 ID·SHA가 동시에 일치하는 책은 312개(주문291종)다. 현재 PR238에는 그 엔진을 복제·병합하지 않는다. PR245 어댑터가 없거나 정의가 다르면 책을 소비하지 않는다. 원본 마스터리·변신·선행 카드 등 미지원 조건도 보존한다.
- 원본 드롭 무기의 발동 37개와 상자 보상 무기의 같은 발동 8개를 연결한다. 크로우 9개는 무기 기본 대미지의 최댓값을 사용하며 캐릭터 치명타와 분리한다. 이도류 16개와 총 출혈 20개는 아래 보완 규칙을 명시한다.
- 원본 장착 부위 293을 `domination_stone` 전용 슬롯으로 연결한다. 지배석의 MR +2와 경험치 +1%를 적용하고 장비창 3쪽에서 표시한다. 기존 축복·저주 스택 키는 별개로 보존한다. 이 부위에 강화 시도 규칙을 새로 붙이지 않는다. 탑 이동·퀘스트·세트 활성화는 별도 미연결 기능이다.
- 확인된 원본 양손 무기·양손 무기와 함께 착용 가능한 보조 장비 플래그를 적용한다. 일반·원본 장비의 기존 물리 개체와 세이브를 유지한다.

## 원본과 TWILIGHT 보완 규칙

원본 정의와 공개 근거가 보완 규칙보다 우선한다. 원본은 팩 내부에 그대로 남긴다.

| 보완 규칙 | 기본값 | 게임 설정 |
| --- | --- | --- |
| 이도류 배율 적용 범위 | 무기 기본·추가·강화 대미지. 원본 발동 확률·배율은 변경하지 않음 | 기본만 적용하거나 발동 끄기 가능 |
| 총 출혈 틱 간격 | 기존 게임의 0.75초. 원본의 3초·10D1·발동 확률 유지 | 0.1~3초 |
| 출혈 `MaxHPPercent=50` 해석 | 누적 출혈 피해를 대상 최대 HP의 50%로 제한하는 추정 규칙 | 상한 제거 또는 발동 끄기 가능 |
| 선택 장비 초기 강화 | 원본에는 필드 없음. 기존 TWILIGHT 기본 +0 | +0 자체 규칙 끄기 가능 · 끄면 상자 보존 |
| 확률 상자 선택 횟수 | 원본 확률표로 1회 선택. 확정 보상은 1회 지급 | 1~10회 또는 상자 선택 규칙 끄기 가능 |

원본은 출혈 틱 간격과 `MaxHPPercent`의 의미를 설명하지 않는다. 이 연결은 별도 추가 저항 추첨을 만들지 않으며, 원본 특수 저항 선언도 원본 행으로 보존한다. 출혈은 기존 몬스터 전투 상태와 같은 세션 수명을 사용한다. 설정은 저장·재진입에서 유지한다.

근거: [NC 무기 가이드](https://lineagem.plaync.com/guidebook/view?title=%EB%AC%B4%EA%B8%B0+%EC%95%84%EC%9D%B4%ED%85%9C), [무기 대미지를 직접 측정한 공개 실험](https://www.inven.co.kr/board/lineagem/5056/8440), [NC 총사 가이드](https://lineagem.plaync.com/guidebook/view?title=%EC%B4%9D%EC%82%AC+%EB%A7%88%EB%B2%95). 공개 자료에서 확인되지 않은 부분을 원본 공식으로 표시하지 않는다.

## 설치·저장

설정의 **523 드랍 자료 ZIP 설치**에서 적용팩을 선택한다. 원본 보존 ZIP은 설치팩이 아니다. 설치 시 ZIP 경로·크기·파일 목록·SHA를 확인하고 새 버전 폴더에 기록한 뒤 현재 게임의 카탈로그를 갱신한다.

실제 소비 경로는 `user://lineagem_patch523_drops/<payload SHA256>/monster_drops.bin`이다. 개발 실행에서는 검증한 BIN의 폴더를 `--patch523-drop-root=<폴더>`로 지정할 수 있다. Drive 백업은 게임에 자동 적용되지 않는다.

카드 지급, 상자 지급, 원본 HP/MP 물약, 원본 버프·선택 보상·연결된 스킬서 학습은 자원 변경과 저장을 함께 처리한다. 저장 실패 시 아이템·재화·카드·버프·난수 상태를 게시하지 않는다. 카드 공개 연출은 저장 성공 뒤에 시작한다. 설정 저장 실패도 이전 값을 유지한다. 이름만 비슷한 원본 강화 주문서는 기존 일반 강화 UI로 보내지 않는다.

원본과 phase2·phase3 적용팩은 비공유 프로젝트 Drive에 보존한다. 최신 phase4는 기존 Library 항목의 버전3에 보존됐고 로컬 생성·설치까지 검증했다. phase4의 Drive 전송은 승인 대기 상태로 실행되지 않았으며, Drive에 실제 보관된 최신 파일은 phase3이다. 원본·실행 데이터는 공개 Git에 넣지 않는다. 이전 BIN SHA `bec901d2…`·`1d0756f1…`와 최초 멤버십 BIN `4455cbbd…`의 설치·읽기 호환성을 유지한다.

## 검증과 남은 범위

합성 원본을 사용하는 Python 회귀 검사와 실제 Main을 사용하는 선택 실행 검사 `tests/patch523_item_use_test.gd`를 제공한다. 개인 세이브 대신 격리된 XDG 프로필과 검증한 맵 팩을 사용한다. 전체 CI나 수동 원격 CI를 재실행하지 않는다.

이번 확장의 로컬 검사: Python61개, 실제 Main/OpenGL 선택·학습 계약446개(선택 상자21종·명시적 옵션98개·새 보상 카드11종), 기존 아이템 사용 회귀1,784개(지정 카드122종·상자75종·저장 실패19회)가 통과했다. 선택 UI·자체 설정20개 검사는 실제 OpenGL 화면과 저장 실패·재진입까지 통과했다. 이전 두 버전의 재설치·최신 유지·축복 스택·장착·재진입25개도 통과했다. 모든 학습 성공 검사는 PR245 엔진이 설치된 것으로 오해하지 않도록 계약 fixture라고 표시한다.

미연결 원본 효과는 아이템을 보존하고 UI에서 표시한다. 스킬서 실제 전투 엔진 통합은 PR245에 의존한다. PR238은 ID·원본 행 SHA가 검증된 어댑터를 소비하는 원자적 학습·책 소비·출처 저장을 제공한다. PR245 미설치 보존은 실제 Main에서, 긍정 학습 거래는 실제 Main의 계약 fixture에서 검증하며 이를 PR245 전체 엔진 통합 검증으로 표시하지 않는다. PR245 바인딩에 없는 16개 책, 원본 스펠 그룹 마스터리 조건, 발동 옵션 교체의 선택 상태·재료 처리, 일부 수명·영토·무제한 사용 규칙은 남아 있다. 예를 들어 HP 아이템126702는 ValidLand44611/44621/44631/44641/44651과 Buff54792의 동시 효과가 있어 HP값만 적용하지 않는다. 만료 HP150973/164453/173003과 선택상자174433도 기존 자원을 보존한다. 원본 NPC 픽셀과 전체 출현 조건의 완료를 이 팩의 ID 연결 완료로 대신하지 않는다. Android 실기기 검증은 별도이며, 이 기록은 데스크톱 실제 게임 실행 검증이다.
