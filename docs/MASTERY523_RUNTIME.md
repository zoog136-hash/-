# 523 무기 숙련 실행 연결 — Draft

기준 main `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`에서 독립 브랜치로 작업했다. 작업 시작 시 열린 PR을 대조했으며 다른 PR을 병합하지 않았다. 코드는 Git, 원본 행은 별도 Library 팩으로 보관한다.

## 실제 게임에서 가능한 작업

메뉴 → **무기 숙련**에서 무기를 선택한다. 원본 누적점수/표 기준 레벨, 보유·적용 옵션, 색상 잠금, 재화 보유량과 비용을 표시한다. 장착 무기에 해당하고 레벨을 만족하는 옵션만 적용하며, 교체로 레벨보다 높은 옵션을 소유하게 되어도 삭제하지 않는다.

1. **숙련치 구매**: 기존 도감의 ItemClass/도감 ID117544·이름이 모두 일치하는 상급 축복의 가루400개를 실제 인벤토리에서 차감하고 선택한 무기에250,000점을 지급한다. 원본 Count1~5의 비용행을 사용한다. 잠긴 재료·불명확한 물리 개체 소유권은 거부한다. Daily라는 원본 주기는 확인됐지만 정확한 초기화 시각이 없으므로 이 저장의 첫 주기5회만 실행하고 이후 자동 초기화를 보류한다.
2. **고정 옵션 색상 재설정**: 보유 값이 모두 Probability1,000,000인 고정값이고 잠금이 없을 때 실행한다. 원본 아데나1,000,000을 실제 차감하고 보유한 네 색상을 원본 Grade 확률로 각각 재결정한다. 값은100% 결과 그대로 유지해 네 색상과 Slot1/2의 값 결합을 추정하지 않는다. 현재 레벨보다 높은 보유 옵션도 같은 조건에서 변경할 수 있다. 난수 상태는 성공한 저장에만 반영한다.
3. **로컬 숙련 교체**: 현재 직업의 원본 허용 목표와1~N레벨 prefix를 선택하고 비용을 확인한다. 원시 누적 정수점수는 정확히 합산하며, 옵션 그룹/목표 무기에서 BonusID·BonusType을 새로 조회한다. 선택 범위 색상·수치를 유지하고 잠금은 초기화한다. 출발 점수·옵션을 비우며 목표의 기존 옵션은 선택 범위로 대체한다. 실제 다이아 기본800 + 독립 숙련 교체 레벨 비용을 차감한다. 첫 교체 전에 이전 세이브의 SHA가 같은 독립 백업을 보존한다. 온라인 서버 이전을 흉내 내거나 무기 레벨을 그대로 복사하지 않는다.

모든 실행은 기존 HUD 확인창 → 자원/상태 재검사 → 기존 Main 원자 저장 → 성공 후 화면·인벤토리·능력치 갱신 순서다. 취소·중복/오래된 확인·쓰기 전 실패 시 재화·원래 숙련·난수·원본 파일을 보존한다. 파일을 쓴 뒤 후속 처리에서 오류가 나면 실제 대상 payload와 대조해 이미 저장된 결과를 반영하고, 다시 불러오기 전까지 재시도를 차단한다. 이미 차감된 거래를 미실행으로 간주해 되풀이하지 않는다. 같은 캐릭터의 클래스 변경에서도 동일 숙련 네임스페이스를 사용한다.

## 원본 연결 근거

- 15무기/120성장행/540옵션행/36전환그룹. ActualType12→BaseType2이며 매핑에 없는 무기를 임의로 묶지 않는다.
- Currency1682 → CurrencyUnitClass1902(Unit4, Class117544) → ItemClass117544. 현재 Inven 도감의 동일 ID와 명칭을 함께 검증하는 명시적 단일 bridge다. 다른 웹 ID를 원본 ItemClassID로 일반화하지 않는다.
- Constant53172(MasteryPointPurchaseResetScheduleType=1) → ContentsResetScheduleType1(Daily). DailyMidnight24와 구분하며 다른 시스템의05시를 전용하지 않는다.
- MarketPurchase95441 → Payment104111(Unit201, Currency4,800) 및 Product133971(Unit281, AdditionalService101,1). **Purchase.AdditionalCurrencyID=4**가 독립 서비스의 추가 재화도 다이아임을 명시한다. 따라서 MasteryChangeLevelCost100/300/600/1200/2400…을 이 상품에 연결한다. 클래스체인지 전용1/3/6/12/24…표와 혼합하지 않는다. 할인false와 원본2016~2099 기간을 보존하며 시간대 경계가 불명확한 시작/종료 연도는 보류한다.
- 원문 도움말은 네 슬롯의 값·색을 각각 정해진 확률로 결정하고 잠기지 않은 모든 슬롯을 재결정한다고 설명한다. 이 자료를 private pack에 보존한다. 이 구현의 실행 가능 재설정은 값이100%로 고정되어 값 대응에 추정이 필요 없는 경우로 한정한다.
- 공격 속도와 치명타의 원본 percentage 단위를 기존 게임의 같은 단위 소비자에 연결한다. 피해·명중·HP/MP·MR도 기존 소비자를 쓴다. PvP를 PvE로 전환하거나 미확정 리덕션/매칭 중첩식을 만들지 않는다.

## 보존 및 정확한 남은 차단

- 점수는 signed64 범위의 정수 문자열이다. 정수 합산·overflow 거부만 하며 미확정 서버 스케일/상한/반올림을 만들지 않는다. 확인된 원시점수 지급 API도 유지한다.
- 자동 일반 명중당 점수 환산, 최초 옵션 획득의 네 값 배치 및 변동값/잠금 재추첨의 네 슬롯↔Slot1/2 결합은 미완료다. 따라서 해당 재설정·획득 경로는 계속 거부한다.
- 구매 Daily 초기화 시각은 미확정이라5회 이후 재구매만 보류한다. 시계를 바꾸거나 재접속해도 새 구매 주기를 만들지 않는다. 기존 영수증과 구매 수량의 불일치를 거부한다.
- 독립 서비스의 MarketPurchaseRestriction12/Duration1 해석이 미완료이므로 이 저장의 첫 로컬 교체만 실행한다. 반복 구매를 임의로 허용하지 않는다. 월드 던전/pending server-selection으로 명시된 상태나 진행 중인 카드 확인은 차단한다. 실제 온라인 판매·계정 서비스의 동등성을 주장하지 않는다.
- 옵션 미선택 시 목표에 기존 옵션/색상/잠금이 있는 경로는 처리 근거가 부족해 해당 경로만 거부한다. 옵션을 포함한 prefix 교체와 빈 목표의 점수 전용 교체는 실행할 수 있다.
- 색상 매칭은 목표 Step+Grade로 조회하지만 실제 여러 단계의 중첩·적용 순서는 미확정이라 전투 효과는 아직 적용하지 않는다.
- 서버이전은 별도의 높은 상태 선택/동률 출발 우선 계획만 제공한다. 점수 합산이나 로컬 단독 저장으로 두 서버 이전을 실행하지 않는다.
- 팩이 없으면 숙련을 비활성화하고 저장의 원래 네임스페이스를 그대로 보존한다. 구형 데이터 전용 팩도 조회·기존 상태 보존은 가능하며 실행 자료가 필요한 버튼만 새 팩을 요구한다. 손상된 숙련을 로드하면 덮어쓰기를 차단한다.
- Android·원작 UI/서버 동등성·전체 사냥 흐름은 미검증이다. 이 PR은 숙련 전체 복원 완료가 아니다.

## 별도 팩과 재현

Library 정식 materialize 후 실제 바이트·SHA·전체 ZIP CRC를 확인했다. 원본 접근을 우회하거나 공개 diff에 원본 행/픽셀/팩을 넣지 않았다.

| 입력 | 바이트 | SHA256 |
| --- | ---: | --- |
| 누적523 content | 25,031,173 | `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832` |
| 전환 심층 자료 | 122,889 | `bf2cf2a42dc7e9fdae9dcacd5b3fc45a1d8162c8b66a358f3a1fb2232b89be04` |
| 실행 자료 포함 숙련 팩 | 235,676 | `671fd9b307182e0ed8b8789124ea5710aa766d3de20c74df381455abf2bd9d6b` |

새 팩은 기존 Library 파일의 version1로 보관했다. 제작기는 원본 ZIP SHA/CRC, 표/선택 서비스 행의 유일성, 임계치,36×15 대응 및 확률 합계, 상품·결제·추가 재화·재료 연결을 검증한다. 공개 리소스 장부는 승격하지 않는다.

```sh
python3 tools/mastery/build_mastery523_pack.py /private/content523.zip /private/mastery523.operations.private.json
godot --path . -- --mastery523-pack=/private/mastery523.operations.private.json --mastery523-sha=671fd9b307182e0ed8b8789124ea5710aa766d3de20c74df381455abf2bd9d6b
```

`tests/mastery523_test.gd`는 원본/합성 경계를 검사한다. `mastery523_main_test.gd`는 기존 Main 저장·UI 보존 경로, `mastery523_operations_test.gd`는 실제 원본 팩과 Main의 구매/재설정/교체·확인/취소·정확한 재화 차감·실패 원복·난수·백업·재접속을 검사한다. `TWILIGHT_MASTERY_CAPTURE_DIR`을 지정하면 같은 거래 테스트에서 실제 OpenGL 캡처를 남긴다. 합성 fixture나 수동으로 준비한 소유 옵션 테스트 상태를 실제 게임의 무료 지급으로 계산하지 않는다.

세부 로컬 결과와 로그SHA는 `mastery523_verification.json`에 보존한다. 필수 리소스723시트/41,442프레임 SHA 검사는 통과했다. 역사적 --source-dir은 이전 a1.zip 부재로 실패하며 이번523 ZIP 검사와 구분한다. 커밋은 [skip ci]이며 수동 CI 실행/재실행은 하지 않는다.
