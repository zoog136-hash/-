## 연결한 소비 범위

기존 이름 기반 소지 키와 공급자의 `귀환 주문서 (각인) · 원본#239`를 별개로 유지한다. 공급 스택은 등록된 카탈로그의 `source=lineagem_patch523`, `source_snapshot=patch523`, `sourceId=m523:item:239`, 원본 ID, 정식 이름, 등급, 소비 가능 여부와 **명시적 Bless1**을 모두 확인한다. 접미사만 보고 ID를 만들거나 다른 축복 스택을 같은 아이템으로 합치지 않는다. 카탈로그가 재접속 전에 원래 공급자에 의해 등록돼야 한다.

퀵슬롯 저장에는 원래 공급 키를 보존하고 HUD와 실행 시에만 126424로 투영한다. 타깃도 실제 소지한 정확한 키 하나를 선택한다. 일반 아이템·원본 아이템 수량을 합산하지 않으며, 미보유 시 일반239를 대신 소비하지 않는다. 아이템 사용 입구의 좁은 어댑터를 통해 향후 공급자의 일반 미지원 아이템 핸들러보다 먼저 이 검증을 수행한다. 다른 PR의 코드를 가져오지 않았다.

282783/295514의 원본 InfiniteAmount는 그대로 유지한다. 네 원본 ID 이외의 주문서나 미확인 축복 상태는 이 어댑터의 대상이 아니다. 기본239의 귀환 효과는 기존 TWILIGHT 아덴 귀환 경로를 재사용하며 원본 M의 ConsumeTerritoryClassID 평가나 원본 M 귀환 좌표의 구현이라고 주장하지 않는다. 전용126424는 앞서 검증한 `source_70` 대응 시작 지점과 지역 귀환의 저장 실패 원복을 사용한다.

## 검증과 미완성

`regional_return_supply_world_fixture.gd`는 검증한 비공개 BIN에서 정확한239 메타데이터를 읽어 **테스트 카탈로그만** 등록한다. 실제 Main의 바닥 아이템 → 기존850ms/거리/시야 검사 → 습득 → 퀵슬롯 등록 → 기본 소비 → 지역 투영 → 전용 소비 → 저장/읽기 → 새 프로세스 재접속을 검사한다. 별도의239 소지 키와 수량이 보존되는지도 확인한다. NPC 처치나 판매 실행을 이 fixture로 대신 완료했다고 주장하지 않는다. 전용126424의 테스트 소지는 명시적인 격리 fixture다.

이 PR에는 공급 PR의 런타임·팩 설치기가 없다. 따라서 **일반 플레이의 전용 주문서 획득 → 전환 → 소비 전체 연결은 미완성**이다. 알려진 후속 연결점은 PR247의 Merchant514/구매행16884를 정확한126424 키로 바인딩하고 소비 가능한 정의에 등록하는 것이다. PR247의 비공개 `_bindings`를 외부에서 고치거나 출처를 `inven`으로 위장하지 않았다. 가격·드롭률·무료 지급·새 판매자를 만들지 않았다.

무한 두 종류도 원본 전체에 공급 근거가 전혀 없다는 뜻은 아니다. Reward282033 → 282783은 Quest83343, Reward311114 → 295514는 Quest85194에 연결된다. 이번에 대조한 드롭·NPC·탐험 공급자가 아니며 일반퀘스트는 제외 범위여서 활성화하지 않았다.

## 지도 차단 범위 정정

Land44544/44614/47722의 원본 행과 AssetPath13202/13209/13379는 존재한다. Land44544에는 Locations42994(마을),43014(재시작),43034/43044 입력이 있다. Land47722에는 Portal19352/19362/19372와 목적 Territory195932/195942/195952 입력도 있다. 따라서 연구소 두 곳을 일괄적으로 “Land·목적지 원본 없음”이라 부르지 않는다. 두 연구소의 독립 Locations 귀환 지점은 해당 표에서 확인하지 못했다.

현재 차단은 이 브랜치에서 M 지형/좌표 변환, 연구소 실행 진입과 검증된 귀환 위치가 연결되지 않았다는 범위다. PR232가 진행하는 아덴 원문676청크 복원과 구분하며 이 PR에서 새 지도를 만들지 않는다. 기존 PC `source_70` 한 곳의 이름 기반 대응을 원본 M 지리로 승격하지 않는다.

재현은 `REGIONAL_RETURN523.md`의 격리 XDG/맵 팩 환경에 `TWILIGHT_REGIONAL_SUPPLY_BIN=/absolute/verified/monster_drops.bin`을 더하고 `tests/regional_return_supply_test.gd`를 실행한 뒤, **동일 프로필의 별도 프로세스**에서 `tests/regional_return_supply_restart_test.gd`를 실행한다. 테스트는 지정한 phase3 SHA가 다르면 실행하지 않는다. 결과와 증거 해시는 `validation.json`에 기록한다.
