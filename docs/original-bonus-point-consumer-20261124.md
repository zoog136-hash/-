# 깨달은자의 눈: 정확한 523 실물 소비
원본 ItemClass **146402**(비테스트, 레벨 89+, BonusStatRecharger) → ItemBonus 228432 → Bonus 726502 이다. 이 행은 소지 효과가 아니며 BonusSubStatAmount / Value +1, 적용 종류·대상 0이다. 원본 한글 설명도 보너스 스탯 +1이다. 같은 이름으로 권한을 부여하지 않는다.

TWILIGHT에서는 원본 지급자로부터 받은 물리 영수증 1개 감소와 미분배 능력치 +1을 한 저장에 넣는다. 일반 엘릭서 횟수, STR과 같은 개별 능력치, 다른 장비나 재화는 증가시키지 않는다. 미분배 능력치를 기존 캐릭터 능력치 소비자가 분배하는 것은 TWILIGHT의 대응 구현이며, 원본 서버 내부 절차를 확인했다는 의미가 아니다. 퀘스트 성장 거래 없이 임의로 스탯을 저장하는 요청은 계속 거부한다.

숫자가 있는 모든 행을 일괄 사용 가능으로 만들지 않았다. 한계를 이겨낸 자의 심장 **146412**는 상한만 +1, 이그드라실의 열매 **147152**는 상한과 보너스 포인트 둘 다 +1이다. 기존 일반 능력치 배분기에 영구 상한 규칙이 없어서 두 아이템은 소비하지 않는다. 일반 엘릭서의 별도 상한을 이 둘에 차용하지 않았다. 이름만 남은 저장, 실제 상점 판매 여부, 별도 퀘스트 보관함에 대한 기능 완료도 주장하지 않는다.

검증 경로: 원본 archive → Main의 원본 공급자 지급(개발 도감 지급 경로) → 실물 선택 → 인벤토리 HUD → 실패 시 보존/성공 시 공동 저장 → 재읽기 → 기존 능력치 입력. 테스트와 증거에 원본 파일/이미지는 넣지 않았다.
