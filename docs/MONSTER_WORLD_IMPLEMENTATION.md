재개 시 PR #46·#48은 최신 main `ee47dfd`에 병합되어 있었습니다. 이 main을 기존 PR #43 브랜치로 통합할 때 텍스트 충돌은 없었습니다. 도감 2,852건, source-ID별 아이템·이미지, 등급 근거, HP 흡수 1 및 아이콘 렌더러를 유지합니다. 다른 미병합 기능 브랜치는 섞지 않았습니다. 최종 main `5596a64`에는 PR #49의 도감 가시성·창 드래그 보완도 포함되며 동일 브랜치로 통합했습니다. 도감·원본 아이콘 관련 파일과 창 드래그·UI 검사는 main과 동일하고, renewal_hud에는 HP/MP 전용 갱신 8줄만 추가됐습니다. 최신 main을 feature가 포함하며 PR #43은 병합 충돌이 없습니다.

## PR #43 재개 — 피격 HUD 비용

중단 HEAD `7bf4a0b`에 있던 0.25초 갱신 합치기를 확인한 뒤, 최신 main 통합 코드에서 32/96/192마리 실제 AI·자동사냥·양방향 피해를 새로 실행했습니다. 이후 HP만 변하는 갱신에서 장비 개체 동기화, 전체 능력치 계산, 숨겨진 인벤토리·아이콘 재구성을 제거했습니다. 화면 HP/MP와 열린 캐릭터 창 수치는 즉시 갱신합니다. 표시 상한만 최근 전체 갱신에서 재사용하며 실제 명중·피해·저항 공식은 계속 현재 상태를 읽습니다.

장비·스탯·버프 변경, 피격 패시브의 능력치 발동·만료, 사망·부활, 불러오기는 전체 갱신을 수행합니다. HP 흡수 1과 독/출혈은 HP 갱신만 수행합니다. 전체 갱신에서 중복 장비 ID 동기화도 한 번으로 줄였습니다.

변경 전 비교 기준은 `1b53a3ea56ef61bd69af5d2b1649ac325b52ca33`입니다. 중단 코드와 최신 main의 PR #46·#48을 결합한 tree이며, 이후 HUD 변경을 포함하지 않습니다. 같은 엔진/러너에서 같은 192회 근접·원거리·마법 입력을 32프레임에 나누어 실행합니다. [비교 코드](../tests/benchmark_combat_hud.gd), [새 기능 검사](../tests/combat_hud_test.gd), [최신 실제 CI 결과](monster-world-evidence/VALIDATION.md)를 함께 확인하세요. 측정 카운터는 테스트용 하위 스크립트에만 존재합니다.

최종 코드 `98c9e5f693df280f1543a6c21133095eed9a4812`에서 새 전체 회귀 **53/53**, HUD **1,200항목**, 몬스터 월드 **9,323항목**, 공격 프로필 **48항목**이 통과했습니다. 같은 CI 러너의 변경 전후 비교에서 실제 남은 HP 16,078과 표시 상한 20,000은 같았으며 전체 HUD 2→0회·장비 동기화 4→0회·능력치 스냅샷 2→0회였습니다. 일반/캐릭터 창 개방 시 월드 갱신 함수 p95는 40.532/39.588ms에서 0.066/0.082ms로 줄었습니다. 이는 전체 GPU 프레임 시간이 아닌 제어한 피격·HUD 경로 측정입니다. 새 CI 12회 실행은 모두 성공했고 실제 OpenGL 106장과 32/96/192마리 양방향 전투·저장·도감 회귀 증거는 [최종 실행 목록](monster-world-evidence/CI_RUNS.md)에 있습니다.

군집 로그 검토 후 피격 패시브의 능력치 변경에서 전체 HUD 재구성이 물리 신호 안에서 동기 실행되는 경로도 분리했습니다. HP/MP 상한은 즉시 게시하고, 전체 능력치 창 갱신만 UI 처리 단계에 합칩니다. 같은 프레임의 여러 발동은 한 번만 재구성합니다. 장비·버프·로드 등의 명시적인 전체 갱신은 대기 요청을 해제하며, 실제 전투 능력치는 계속 현재 버프를 읽습니다. 새 HUD 검사는 이 경계 2개 항목을 추가해 총 1,200항목입니다. 이 보완 및 풀 정리 수정 뒤 전체 회귀와 실제 OpenGL을 다시 실행해 통과했습니다.

보완 커밋의 실제 OpenGL 폭젠 검사에서 삭제 예약 시체가 풀로 들어가는 기존 정리 경계 오류가 발생했습니다. 그 실행은 실패로 기록합니다. `recycle`은 삭제 예약 노드를 거부하고 중복 반환을 멱등 처리하며, 스폰은 해제·삭제 예약 풀 항목을 건너뛰고 새 개체를 준비합니다. 실제 시체 정리/풀 경계를 재현하는 몬스터 월드 검사 3개를 추가했습니다. 실패 실행 `37916677807`과 최종 성공 실행 `37918099919`를 [CI 문서](monster-world-evidence/CI_RUNS.md)에서 구별합니다. 코드 이후에는 증거·문서만 커밋하며 게임 코드를 변경하지 않았습니다.
