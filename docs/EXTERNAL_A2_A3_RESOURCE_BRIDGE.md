# TWILIGHT: A2/A3 외부 리소스 연동 (1차 구현)

## 실제로 수행한 작업

- 사용자 제공 `a2(1).zip`의 `appcenter/img/item/*.png`, `appcenter/img/monster/ms*.png`와 `a3.zip`의 `db/l1remaster.sql`에서 아이템 `iconId`/NPC `spriteId`, 한국어 `desc_kr`를 교차 대조한다.
- DB 테이블 전체를 게임에 덮어쓰지 **않는다**. 정확한 한국어 이름에 **하나의 이미지 ID만** 연결되는 항목을 식별한다. 충돌하는 이름은 제외한다.
- 생성된 선택형 압축파일을 Godot 프로젝트 루트에 풀면 `data/external_l1j/a2_bridge_v1.json`과 `assets/external_l1j/{items,monsters}/*.png`가 생긴다.
- 인벤토리/도감/상점 이미지(UI 공통 경로), 기존 인벤토리 상세 및 바닥 드랍, 필드 몬스터 렌더러에 연결된다. 기존 수동 검증된 L1J 리소스가 있을 경우 그것을 최우선한다.
- 원본 몬스터 초상화(82×123)의 검은 주변 배경은 출력 팩에서만 투명하게 처리한다. **정지 이미지**이고 공격/달리기 프레임 복원이 아니다.
- 파일이 없을 때는 기존 TWILIGHT 화면과 DB/저장 기능으로 안전하게 돌아간다.

## 입력·생성 방법

입력: `a2(1).zip`, `a3.zip`. 프로젝트 외부 빌더: `build_external_a2_pack.py --a2 'a2(1).zip' --a3 a3.zip --output twilight_external_a2_pack.zip`.

위 ZIP을 **Godot 프로젝트의 루트**에 압축 해제한 뒤 Godot 에디터에서 임포트, 재실행한다. GitHub에는 이번 1차 PR에서 런타임 연결 코드만 올리고, 외부 이미지·제3자 SQL·클라이언트 실행 파일은 올리지 않는다. 원본 저작물의 재배포/상업 사용은 별도 권리 확인이 필요하다.

## 사용 범위/한계

- 생성 당시 A3 아이템 DB 한국어 이름 기준 5,464개, 몬스터 이름 792개와 총 3,638개 고유 PNG 경로를 팩에 포함한다. **TWILIGHT 실제 몬스터/아이템 이름과 정확히 일치하여 화면에 나타나는 수는 별도로 실행 측정해야 한다.**
- 동일 이름에 다른 원본 이미지 ID가 매핑된 아이템 39종, 몬스터 137종은 자동 적용을 차단한다. 한국어 이름이 불일치하는 항목은 기존 이미지를 유지한다.
- PR #59 스킬은 별도 작업이다. 이 PR은 좌표계/서버/확률/스킬/저장을 수정하지 않는다.
- `a1.zip`은 UI·인게임 외형 비교용 캡처 자료이며 배포 가능한 UI 스킨으로 오인하지 않는다.
- `a3.zip`의 맵 바이너리는 충돌/좌표와 지형 **텍스처**가 별개다. 이 PR로 맵 지형 외형이 자동 교체되었다고 주장하지 않는다.
- 현재 검증: 로컬 ZIP 생성·파일 이미지 디코드·일부 배경 투명화 확인. **최신 Godot 4.7.2 실행/PC Android 터치 실기기 검증은 미수행**.

## 다음 단계

2. 리니지풍 UI의 패널/버튼/터치와 캐릭터 4/8방향 동작을 실제 렌더 영상으로 수정한다.
3. A3 지형/충돌 그리드와 제공한 원본 맵 텍스처를 각각 확인하여 출처 검증된 외형을 붙인다.
4. 일치하지 않는 도감 ID/아이콘과 장비 바닥 이미지에 대한 수동 검증을 늘린다.
