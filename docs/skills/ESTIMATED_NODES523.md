# 누적523의 8개 구성 참조: TWILIGHT 추정 실행

사용자 지시 “8종 조사해보고 추정치로 완료시켜”에 따라8종의 로컬 게임 실행을 구현한다. 원본 비용·학습 ID와 추정 효과를 구분한다. 이것은 원본 노드 인터프리터나 서버 전투 수식 복원이 아니다.

## 재조사 결과와 이전 보고 정정

대상은 `SpellCompositionNode`21·31·613·804·942·1072·1132·1142다. 전체 SpellClass의 서로 다른 구성 값85개 중 SpellNode.ID와 값이 같은 것은16개뿐이고, SpellNode의 부모0인 행은146개다. 따라서 이 열을 SpellNode.ID의 외래키라고 간주할 근거가 부족하다. 이전 보고의 “노드8종이 누락”은 **단순 ID 조인에서8개가 일치하지 않는다는 관찰**이며, 원본 노드8개가 실제로 삭제·누락됐다고 확정할 수 없다. 조사 도구도 `direct_id_join_unresolved`로 정정했다.

SpellNode의 부모 참조는 닫혀 있지만 구성 값→실행 루트 대응과 노드·조건 유형의 의미는 제공된 표에서 확인되지 않았다. 숫자가 비슷한 다른 노드를 붙이거나, 이름에 `[미사용]`이 붙은 하위 주문을 활성 주문으로 승격하지 않았다. 아래 규칙은 정확한 기존 스킬 ID + 원본 SpellClass.ID + 구성 값이 모두 맞는8개에만 적용한다.

아수라는 원본 대상이 PCEnemyNCompanyButEnemyClan이므로 자기 강화 분기만 로컬 추정한다. PC 대상 홀드를 몬스터에게 주지 않는다. 다른7종도 미지원 공성·파티/적대 관계·원본 강화 분기 전체를 복원했다고 주장하지 않는다.

기존3개 스킬북 가격·저장 ID는 그대로다. 새로 실행하는 카운터 디텍션의 책은10만, 엘리멘탈 스턴·미스틱은40만, 아수라·브레스 스턴은100만 아데나로 추정한다. 새5종의 습득 레벨은 원본의 해당 직업 일반 학습 행을 사용한다. 새 기능을 자동 습득시키지 않는다. 드랍 확률·각성 비용도 변경하지 않는다.

역할 대조에는 공식 [다크엘프 가이드](https://lineagem.plaync.com/guidebook/view?title=다크엘프+마법), [마법사 가이드](https://lineagem.plaync.com/guidebook/view?title=마법사+마법), [요정 가이드](https://lineagem.plaync.com/guidebook/view?title=요정+마법), [뇌신 가이드](https://lineagem.plaync.com/guidebook/view?title=뇌신+마법), [투사 가이드](https://lineagem.plaync.com/guidebook/view?title=투사+마법)를 사용했다. 공식 설명은 회복/회피·탐지·스턴·보호·각성 역할의 근거이며 위 추정 계수의 출처가 아니다. 공개 가이드와 누적523의 운용 분류가 다르면 원문 정체성과 원문 패시브 분류를 우선한다.

## 게임과 UI 연결

`data/skills/estimated_nodes523.json`에8종의 추정값과 범위를 모았다. 기존441 프로필의 외부팩 버전1을 그대로 사용한다. 팩이 없거나 원본 ID·구성 값이 다르면 참고 항목을 활성화하지 않는다. 별도 옵션을 추가로 켤 필요는 없고, 기존 원본팩을 설치한 시작 경로에서 적용된다.

기존 **스킬 화면 → 구입 → 습득 → 사용/퀵슬롯/AUTO**를 사용한다. 선택 카드 머리글에 **TWILIGHT 추정**을 표시하여 스크롤 없이 구분할 수 있다. 상세에는 실제 비용과 효과값을 표시한다. 패시브는 습득 후 실제 피해 계산에 적용하고 직접 사용·퀵슬롯 버튼은 막는다. 탐지 AUTO는 은신 대상이 있을 때만 동작한다.

은신 몬스터의 명시적인 로컬 상태와 재은신 제한을 추가했다. 이 상태는 클릭/선택·일반 타겟 탐색·스킬 대상 필터에 연결되고 풀 재사용 시 초기화된다. 일반 몬스터에 임의로 은신을 부여하거나 아직 해석되지 않은 원본 NPC 은신 보너스 전체를 연결한 것은 아니다.

대시는 비용 전에 전체 경로의 통행·발판 여유·시야를 검사한다. 명시적으로 선택한 대상이 멀거나 은신하면 다른 대상이나 무대상 대시로 바꾸지 않는다. 보호막은 한 타격당 중복 발동하지 않으며 소진/만료 시 표시도 제거한다. 패시브 경감은 보호막 표시를 통해 두 번 더하지 않는다.

## 검증과 범위

Godot4.7.2에서 규칙/설치 범위/대시 충돌42검사, 실제 OpenGL의8종 UI/시전87검사, 실제 Main/current source map/세이브32검사가 통과했다. 기존 원본 스킬의 headless52검사와 정적 스킬 인덱스/장비 캐시 검사(반복 조회40회)도 통과했다. 최종 화면3장(960×540 1장,1280×720 2장)을 직접 열어 첫줄 추정 표시, 원본 MP/재료, 실제2~4초 상태 지속 표시를 확인했다. 최종 실행에 스크립트·리소스 오류는 없고 llvmpipe V-Sync 경고만 있다.723시트/41,442프레임 무결성도 통과했다.
