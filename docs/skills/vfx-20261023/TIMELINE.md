# 재생 시간 명세

아래는 TWILIGHT 자체 제작 시간이다. 원작 측정 ms/프레임은 전 스킬 UNVERIFIED/null이다. 스킬별 픽셀·프레임·클립 시간·계승은 `data/skills/authored_vfx.json`에 있다. 원작 영상의 FPS나 스킬 사용 속도로 이 수치를 제시하지 않는다.

| 이벤트 | 앵커 | 자체 클립 프레임 | 프레임별 ms | 동작 |
|---|---|---:|---|---|
| prepare | 기존 cast 진입 직전, 같은 tick | 별도 2셀은 독립 검토용 | 30,35 | 런타임은 준비 이벤트만 알리고 전투 시전을 지연하지 않음 |
| cast | 기존 시전 승인/비용 지불 지점 | 4 | 40,45,55,70 | 본체 210ms, 지면은 별도 430ms까지 |
| release | 실제 모션 마커, 각 지연 flight의 활성 시점 | 2 | 25,40 | 65ms, 발사점은 기존 변신/무기 profile 사용 |
| travel | 기존 flight 활성~도착/취소 | 4 반복 | 40,35,45,40 | 실제 좌표를 관찰, 속도/피해를 제어하지 않음 |
| impact | 실제 성공 판정 | 12 | 25,25,35,40,45,50,55,60,65,70,75,80 | 625ms, 화살/포우의 실제 타격당 1회 |
| aftermath | impact 표시 종료 | 8 | 45,50,55,60,65,70,80,95 | 520ms, 낮은 상세에서는 생략; 긴 delta의 초과 시간을 소비 |
| end | 표시 수명 또는 버프 종료 | 선택 4 | 45,60,75,100 | 공격의 end는 정리 이벤트, 버프의 end는 280ms 소멸 클립 |
| persistent | 실제 버프 유지 | 4 반복 | 140,170,150,180 | 실제 버프 remaining/대상을 따라 종료 |
| status | 실제 상태 성공 | 4 반복 | 75,85,85,95 | 상태 타이머/사망/life ID가 종료를 결정 |
| resist | 실제 실패/저항 | 4 | 45,55,65,85 | 250ms, 명중 섬광을 생성하지 않음 |

발사/타격의 절대 시각은 여기에 임의 상수로 고정하지 않는다. 기존 `motion.profile.marker_for(style)`와 flight 콜백이 기준이다. 이동 거리는 대상의 실제 hit position까지이며 각 flight가 원래 사용하던 1050px/s와 80ms 연타 지연을 유지한다. 회피·저항에는 추가 성공 타격을 만들지 않는다. 치명타 정보는 전달하되 확인되지 않은 원작 전용 형태는 추가하지 않는다.

본체·지면·가산광은 같은 캐시 아틀라스를 공유하지만 수명은 별도다. 지면은 실제 맵 바닥(-20) 위, 캐릭터(0) 아래인 전역 z=-1에 둔다. 본체는 기존 스킬 레이어(12), 가산광은 그 위에 표시한다. 런타임이 끝난 클립은 마지막 프레임을 붙잡지 않고 숨긴다. SPX는 설치된 자체 `SpriteFrames` 시간/빈 프레임을 그대로 사용하며 이 자체 타임라인으로 재타이밍하지 않는다.
