# VFX 2차 제작 — 원작 고증 완료 아님

기준 main은 `e0a14f07da7764598822be669d05b3c2985d13eb`이다. 기존 #151 브랜치를 보존하고 `feature/twilight-skill-vfx-r2-20261023`와 `/workspace/twilight-vfx-r2` worktree에서 최신 맵/강화 UI 변경 위에 스킬 변경만 적용했다.

1차의 얇고 흐린 도형과 공통 문양만으로는 요청한 품질을 충족하지 못했다. 2차는 실제 아틀라스와 실행 코드를 교체한 제작 중 버전이다. 기존 영상은 1차 기록으로 남기고 새 영상/검사 자료는 `revision-2/`에 둔다.

## 실제 변경

- 70개 자연 발동/액티브용 아틀라스를 다시 그렸다. 10개 강화 연결은 기본 외형을 계승하며 45개 수치/스택/증폭 패시브에는 임의 시전 효과를 만들지 않았다. 125개 레코드와 695개 조사 항목은 제작 완료 수가 아니다.
- 아틀라스는 1024×1536 RGBA, 128×128 셀 96개다. 타격은 12→20프레임, 발사체 이동은 4→8프레임, 유지/상태는 4→8프레임으로 보강했다. 기존 자체 타임라인 총 길이는 유지했다. 이 수치들은 원작 측정값이 아니다.
- 가열된 재질의 중심/가장자리, 난류 밀도, 칼날 내부의 섬유광, 미세한 방전과 파편을 직접 래스터화했다. 외부 게임 비트맵을 생성기 입력으로 쓰거나 트레이싱하지 않았다.
- 낙뢰는 중심광·주변 전류·가지 방전·지면 접점을 분리한다. 연쇄 번개의 본체는 실제 두 끝점을 잇고 충돌광은 맞은 대상에 둔다.
- 지면 분출과 미티어 충돌은 치솟는 열기와 파쇄물을 사용한다. 미티어에는 위쪽에서 실제 대상까지 내려오는 **자체 제작 시각 궤적**을 연결했다. 피해/장애물/취소는 기존 flight만 결정한다. 원작 낙하 궤적을 확인하여 재현했다는 뜻은 아니다.
- 포우 슬레이어는 기존에 검토한 PC 계열 SPX의 보라색 전류·청백색 굽은 검광·마젠타 섬광이라는 넓은 시각 언어를 참고해 독립 제작했다. PC 자료와 리니지M의 동일성은 확인되지 않았다. 비공개 팩과 명칭 바인딩은 유지했다.
- 반격의 타격과 보호 유지 표현을 나눴다. 은신/암흑 보호/암흑 손, 둔화/얼음 공격, 마나 흡수/회복, 지면 구속/화염을 구분했다. 원작 영상이 없는 세부 형상은 여전히 UNVERIFIED다.
- 회복의 규칙적인 나선과 하울의 꽃잎 같은 방사 문양을 걷어내고, 각각 비대칭 상승광/미세 입자 및 흙먼지/균열/파쇄물로 바꿨다.
- 시전 본체·지면 문양·상태 머리 표시의 기준점을 수정했다. 지면 기술은 대상의 실제 발 위치를 관찰하므로 변신별 피격점 높이가 달라도 접점을 유지한다. 잔광은 같은 기준점을 계승한다.
- 제작실은 기존 12개 대표 샘플뿐 아니라 13직업의 시각 연결 80개를 선택할 수 있다. 기존 공격 모션 마커에서 발사하며, 연타 수/80ms 간격은 런타임 데이터를 사용한다. 이 장면은 피해 시뮬레이션·스킬 해금·저장을 수행하지 않는다.

## 공개/비공개와 근거

[추가 검토 기록](evidence/reference-review-r2.json)에 기존 Drive 보관본의 공식 TRINITY 인게임 시연 4개와 이용자 뇌신 전투 클립 3개의 실제 바이트 SHA, 크기, 디코딩 메타데이터, 확인 범위를 기록했다. 2020년 공식 자료는 현행 리부트 외형의 증거가 아니다. 뇌신 클립은 속도 편집과 다른 효과의 중첩이 있어 원작 전투 시간축으로 사용하지 않는다. YouTube의 차단된 최신 공식 시연을 봤다고 기록하지 않았다.

완전한 현행 스킬의 원작 타임라인 및 동일 배율 비교 승인 수는 여전히 0이다. 스킬별 원작 시전/충돌 ms와 프레임 번호는 검증 전 null로 유지한다. 참고 영상과 비공개 SPX 원본/캡처는 공개 Git에 추가하지 않는다.

## 성능 예산과 남은 작업

기존 활성 160개/오디오 6음성은 유지한다. 각 아틀라스가 4→6MiB로 커져 캐시를 12→8장으로 줄였으며, 사용 중인 아틀라스를 보호한 상태에서도 48MiB를 넘지 않게 제한한다. 전체 앱/GPU 메모리를 의미하지 않는다. 낮은 상세 설정은 활성 64개와 본체 위주 표시를 사용한다. 시각 예산이 부족해도 피해 콜백을 생략하지 않는다.

[로컬 결과](revision-2/validation.json), [12계열 재생 영상](revision-2/representative-skills.mp4), [70개 자체 연출 전체 재생](revision-2/all-natural-effects.mp4), [에스카로스 실행 결과](revision-2/escaros-runtime.json)를 구분한다. 자동 검사 성공과 아트 품질 승인은 다르다. Linux llvmpipe는 Android 실기기 성능을 입증하지 않는다.

대표 영상은 12계열 × 2.4초 = 28.8초이며 잔광/종료까지 보여준다. 기존 캐릭터의 보조 무기/먼지 연출만 제작실 옵션으로 숨겨 스킬을 분리해서 본다. 전체 색인은 70개 × 1.2초 = 84초이며 기존 캐릭터 보조 연출을 포함하고 늦은 잔광은 잘릴 수 있다. 둘 다 1280×720/30fps 무음 Godot 캡처이며 원작 나란히 비교 영상이나 게임의 실제 FPS 측정치가 아니다.

최신 main 기준 선택 회귀 11개가 통과했다. 자체 VFX 검사는 1,565개, 실제 비공개 팩 검사는 126개다. Main에서는 기존 몬스터 161개, 통제 AUTO 명중 2회 + 실제 자동사냥 명중 19회, 발사/이동 30회, 명중 효과 21회와 실패/저항 표시 9회를 기록했다. 변신 전환 및 실제 맵 전환 후 정리도 확인했다. 900프레임/게임 시간 15초의 짧은 실행으로, 벽시계 중앙 61.446ms, p95 237.81ms, 최대 활성 효과 5개/해당 아틀라스 6MiB였다. **이 환경에서 60FPS를 달성한 결과가 아니다.** 맵/강화 UI 등 기준 main 자체가 달라졌으므로 1차 측정과 VFX 성능 개선율을 비교하지 않는다.

통제 검증의 첫 실패와 진단 로그도 보존했다. 실제 세 발이 지형 검사에서 막히며 명중 효과가 발생하지 않는 것을 확인한 뒤, 발사점~피격점 경로가 열린 기존 대상/위치를 선택하도록 검증 절차를 고쳤다. 통제 구간 뒤에는 population과 몬스터 처리 상태를 원래대로 복원했다. 게임의 충돌/사거리/피해 판정은 변경하지 않았다. 리소스 가져오기 전 실행한 첫 캡처도 성공 결과에서 제외했다.
