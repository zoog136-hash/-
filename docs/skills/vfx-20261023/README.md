## 실제 적용한 제작물

- 70개 ID용 독립 제작 PNG 아틀라스, 4,480개 셀, PNG 20,709,384바이트. 각 1024×1024 RGBA, 128×128 셀이다. 입력 비트맵 없이 곡선, 결정 면, 이동하는 밀도장, 궤적과 파편을 래스터로 제작했다. 생성기와 파일별 SHA-256은 공개 저장소에 함께 보존한다.
- `AnimatedSprite2D`와 비균등 시간의 `SpriteFrames`로 재생한다. 본체·지면·가산광의 위치, 블렌딩, 수명과 소멸을 분리했다. 타임라인 변경으로 피해 콜백을 예약하거나 지연하지 않는다.
- 실제 공격 마커가 만든 flight의 위치로 투사체를 갱신한다. 화살 머리가 판정 위치를 앞서가지 않게 기준점을 보정했다. 3연타는 기존 세 flight의 80ms 간격과 개별 명중 결과를 그대로 관찰한다. 연쇄 전기는 기존 연쇄 타격의 실제 두 끝점을 연결한다.
- 명중한 상태 기술만 충격과 상태 표시를 재생한다. 상태 표시는 실제 타이머·사망·몬스터 life ID를 따라 정리된다. 실패는 `resist`로 분기한다. 치명타 외형 차이는 원작 확인 전 추가하지 않았다.
- 시전 취소·사망·맵 전환에서 시각 상태를 정리한다. 변신과 무기별 발사점은 기존 `combat_projectile_origin()` 및 모션 마커를 사용한다. 캐릭터/변신 프레임과 속도 데이터를 수정하지 않았다.
- [독립 재생 장면](../../../scenes/SkillVFXLab.tscn), [12계열 짧은 Godot 렌더 영상](previews/authored-studies.mp4), [125개 연결 상태표](RUNTIME_125.md)를 제공한다. 영상은 1280×720/30fps/14.4초의 무음 자체 제작 초안 시연이며 원작 비교 영상이 아니다. 기존 합성 음향의 6음성/이벤트 호출은 기능 검사로 확인했으며 원작 소리·청감 일치 검증은 미완료다.

이 아틀라스는 **원작과 대조하여 승인한 최종 스킬 아트가 아니다.** 계열별 제작 함수를 사용하며, 각 스킬의 원작 고유 형상·프레임·8방향 디테일을 확정한 상태도 아니다. 특히 미티어의 현재 이동은 기존 TWILIGHT flight를 따른다. 원작의 낙하 연출을 검증하여 재현했다는 의미가 아니다. 개별 스킬의 제작 상세와 원작 비교 승인은 모두 PENDING이다.

## 125와 695의 의미

실제 main은 런타임 레코드 125개, 조사 항목 695개다. 125개 중 자체 재생 리소스가 있는 자연 발동/액티브/발동 패시브 70개, 기본 연출을 계승하는 강화 관계 10개, 독립 시각 이벤트가 없는 수치/스택/증폭 패시브 45개로 구분했다. 수치 패시브에 임의 시전·오라를 추가하지 않았다. 강화 외형 차이도 확인 전 기본 연출을 유지한다.

695개 조사 상태는 PARTIAL 125, BLOCKED 568, PVP_EXCLUDED 2다. 이 숫자는 원작 제작 완료 수가 아니다. [조사 원장](research-695.json), [런타임 원장](runtime-125.json), [리부트 조사 전용 항목](reboot-research-only.json)을 분리했다. 새 스킬 해금, 스킬 ID·학습·스킬북·직업·비용·쿨타임·피해·명중·상태 확률·자동사냥·저장 형식 변경은 없다.

[공식 우선 자료](references.json)와 [13직업 출처 색인](class-reference-index.json)에 확인 범위를 남겼다. VANGUARD, RISING STORM, ContiNew, THE GOLDEN AGE와 다른 직업의 공식 안내/영상 위치를 조사했다. 2026-10-23 이전 자료만 대상으로 했다. DB의 기존 역사 기준일을 새 리부트 정보로 덮어쓰지 않았다.

YouTube 전투 영상 요청은 프록시에서 HTTP 403으로 차단됐다. 공식 페이지가 직접 제공하는 NC MP4 5개는 실제로 내려받아 프레임을 검토했다. 투사 영상 4개는 5/6/6/4초의 움직이는 원화이고, 뇌신 영상은 31.866667초의 브랜딩 시네마틱이었다. 전투 스킬의 프레임 측정 근거로 사용하지 않았다. 원작 스킬 영상 측정 및 동일 배율 비교 승인 **0개**다. 원작의 시전·충돌 ms/프레임 필드는 null/UNVERIFIED이며 임의 수치나 일치율을 부여하지 않았다.

## SPX: 실제 파일 검사와 남은 한계

연결된 Drive의 A2002 분할 4개를 복원했다. 결합본은 150,480,291바이트, SHA-256 `d5438f74b486e42481ad34badb527794bbda10a591388c2177e580f2af8c34d7`로 기존 원장과 같으며 외부 ZIP 및 내부 patch ZIP의 CRC를 확인했다. 대상 10개 SPX는 156개 프레임 레코드, 그중 빈 레코드 10개다. 실제 디코드 메타데이터는 [검사 기록](evidence/source-pack-audit.json)에 있다. 빈 프레임을 누락 프레임으로 지우지 않았다.

포우 슬레이어/아우라키아 팩 생성기에 원본 좌표계의 (0,0), 리샘플 비율, 빈 합성 프레임 인덱스를 추가했다. 설치된 팩에 이 메타데이터가 있을 때만 source offset을 적용한다. 구형 팩에는 기존 중심 배치를 유지한다. 설치된 `SpriteFrames` 시간은 런타임에서 축약/재타이밍하지 않는다.

SPX만으로 절대 tick 시계나 리니지M 버전·방향을 확정할 수 없다. 기존 팩의 14FPS는 `UNVERIFIED_NO_ACTION_TABLE` 검토용 값이다. 이번에 원본 재생 타이밍을 복원했다고 주장하지 않는다. 원작의 정확한 부착점·합성·방향·공격 레이어 승인도 남아 있다. 아우라키아와 포우 슬레이어(임팩트)의 BLOCKED 상태는 그대로다.

이 두 BLOCKED ID의 팩 미설치 미리보기는 별도 `preview_profiles`로 유지한다. 임팩트 파생은 기본 포우 연출, 아우라키아는 공유 용 계열 연구 초안을 표시한다. 아우라키아 고유 연출 제작 완료로 집계하지 않는다. 런타임 DB·학습 목록·125개 실행 레코드에 추가하지 않았다.

재생성한 비공개 팩은 로컬 별도 경로에 있고 공개 Git에 포함하지 않았다. [팩 크기·SHA와 로컬 설치 정보](evidence/private-pack-metadata.json)를 제공한다. 원본 4개 분할 파일은 기존 Drive에서 유지된다. 재생성 팩의 새 외부 전달 상태는 **LOCAL_ONLY_NOT_DISTRIBUTED**다. 전체 6개 업로드를 요구하는 `--source-dir` 검사는 이 작업에 필요하지 않은 `a1.zip` 부재로 실패했다. [실패 기록](evidence/source-check-all-six.txt)을 유지하며 A2002 개별 SHA/CRC 검사와 혼동하지 않는다.

## 타임라인과 모바일 예산

[타임라인 명세](TIMELINE.md)는 자체 제작 시간과 원작 미측정 값을 구분한다. 준비/시전은 기존 시전 앵커, 발사는 기존 모션 마커, 이동은 기존 flight, 타격은 기존 명중·상태 판정 콜백에 연결한다. 마커·flight 속도 1050px/s·연타 간격 80ms·판정 RNG는 수정하지 않았다.

활성 효과 160개와 오디오 6음성 제한은 유지했다. 자체 아틀라스는 사용 중인 것을 pin하여 최대 12장/48MiB RGBA로 제한한다. 이 수치는 전체 프로세스/GPU 메모리가 아니다. 풀의 숨은 스프라이트는 텍스처 참조를 해제하고, 유휴/clear에서 자체·SPX 캐시를 정리한다. 낮은 상세 설정은 활성 64개와 본체 위주 표시를 사용한다. 시각 예산이 부족해도 flight의 피해 콜백은 실행된다. 새 화면 전체 플래시·카메라 흔들림·화면 텍스처 셰이더는 추가하지 않았다.

## 검증과 미완료

Godot 4.7.2 `ed1daf0bf`를 사용했다. [로컬 회귀 결과](evidence/regression-summary.json)는 기존 전투 마커, 256 flight 콜백, 오디오, 125개 도감/63개 액티브, 학습·상태·저장·창고 이전 검사와 새 VFX 검사 결과다. [실패했던 첫 실행](evidence/regression-first.json)도 보존한다. 긴 프레임 뒤 잔광이 새로 살아나던 문제를 수정했으며 실패 판정을 완화하지 않았다.

신규 VFX 검사에는 8방향 화살 머리 위치, 실제 도착 전 타격 금지, 세 flight/세 타격, 시각 예산 압박 중 256 콜백 유지, 캐시/풀 정리, 지면/본체의 독립 종료와 상태 life ID 정리를 포함한다. 실제 비공개 팩 검사는 합성 fixture와 별도로 수행했다. 기능 검사 성공은 원작 시각 승인과 다르다.

최종 자체 VFX 검사는 1,393개, 실제 비공개 팩 검사는 126개를 통과했다. 비공개 원본은 별도 실제 OpenGL 장면에서도 두 계열의 시전/타격 4위상을 렌더했다. [렌더 기록](evidence/private-source-gl.txt)과 [비공개 캡처 SHA](evidence/private-source-gl.json)만 공개하며 원본이 보이는 캡처 4장은 저장소 밖에 둔다. 이것은 리니지M 원작 비교나 최종 합성/방향 승인이 아니다.

OpenGL Compatibility/llvmpipe에서 12계열 및 8방향을 직접 캡처했다. 에스카로스의 실제 Main 부하 검사 원본/후속 결과는 `evidence/`에 구분한다. 첫 부하 측정에서는 165개 기존 몬스터가 있었으나 스킬 피해 콜백을 확인하지 못했다. 이 결과를 성공으로 계산하지 않았다. 이후 맵 이동 직후의 물리 위치가 안정된 뒤 검사하도록 캡처 절차를 보완했고, 전투 코드는 바꾸지 않았다.

최종 Main에서는 기존 몬스터 164개, 정지 AUTO 퀵슬롯 성공 타격 2회, 실제 자동사냥 성공 타격 20회, 발사/이동 각 30회, 실패/저항 8회를 확인했다. 기존 변신 전환과 실제 맵 전환 시 flight/VFX 정리도 통과했다. 900프레임/게임 시간 15초의 짧은 부하 검사다. 벽시계 중앙 55.036ms, p95 220.215ms, 최대 VFX 5개, 해당 스킬 아틀라스 4MiB였다. **이 소프트웨어 GPU 환경에서 60FPS를 달성한 결과가 아니다.** 장시간·최대 160효과·여러 직업 동시 렌더 또는 Android 성능 검증으로 확대하지 않는다. [실제 측정](evidence/escaros-runtime.json).
