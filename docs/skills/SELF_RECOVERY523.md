# 누적523 추가 자기 회복·해제·보호 경로

이미 완료한8종 추정 구현은 그대로 유지한다. 이 문서는 이후 확인한 **기존 스킬7종의 자기 대상 경로**와 설정 UI를 기록한다. 전체 스킬 구현 완료라는 뜻은 아니다.

## 원본 우선 적용

확인된 계수/단위/비용과 시전 허용 플래그가 추정값보다 우선이다. 최종 회복 반올림·피해 계산 순서는 TWILIGHT 정책이다. 네 복합 회복은 기본 단계만 사용하며 미확정 상위 강화 효과를 합산하지 않는다. 현재 호스트에 없는 감전/계약/파티 상태는 복원했다고 주장하지 않는다. 라이프 스트림의 파티원 회복을 자신에게 중복 적용하지 않는다. 플라즈마의 미사용 후속 버프70061을 활성화하지 않는다.

역할은 공식 [기사](https://lineagem.plaync.com/guidebook/view?title=기사+마법), [투사](https://lineagem.plaync.com/guidebook/view?title=투사+마법), [뇌신](https://lineagem.plaync.com/guidebook/view?title=뇌신+마법), [마검사](https://lineagem.plaync.com/guidebook/view?title=마검사+마법), [마법사](https://lineagem.plaync.com/guidebook/view?title=마법사+마법) 설명과 대조했다. 기존 인계 `TWILIGHT_source_implementation_guide_20261103.zip`도 정식 Drive 다운로드(1,519,343 bytes, SHA256 `99149dafd92d629f4cd5f55d7d6eb74d4da46081d49f0276ffbe589b0ef5e135`)/CRC 검사 후 전투·대표 스킬 연결 보고서를 읽었다. 이 보고서는 base508 문맥으로만 사용하고 최신523의 수치를 덮어쓰지 않았다. 수식과 타입 조건을 버리면 안 된다는 경계도 유지한다.

## 설정과 저장

기존 **설정 → 복합 회복 스킬**에서7종을 선택한다. 회복 비율·피해 감소·비용·원문 지속은 편집하지 않는다. 다음 자체 정책만 편집할 수 있다.

- 재사용: 클리어25초, 나머지2초가 기존 TWILIGHT 기본값이다. 원문 CastDelay의 단위를 확정해 환산한 값이 아니다.
- 정의가 없는 회복량: 플라즈마120, 라이프 스트림180.
- 라이프 스트림 보호막 상한: 최대HP1~100%, 기본100%.
- 풀 힐: 같은 원본 주사위 계수로 굴림/평균값 선택. 기본은 굴림이다.

설정은 `user://twilight_skill_rules523.cfg`에 임시 파일 후 원자적 교체로 저장한다. 미지정 값은 기본값, 숫자는 범위 제한, NaN/무관한 필드는 거부한다. 다른 섹션을 유지하며 손상 파일은 덮어쓰지 않는다. 원본 데이터와 진행 세이브·습득/장비/재화에는 쓰지 않는다. 설정 변경은 다음 시전에 적용하고 이미 걸린 버프/대기 중 행동을 소급 변경하지 않는다.

스킬 화면의 카드에는 **원본 + TWILIGHT 설정**을 표시한다. 구입·습득·사용·기존 자동/퀵슬롯 흐름을 유지한다. 시전 불가 상태 검사에서도 최종 resolve 결과를 사용하여 명시된 탈출 플래그가 실제로 동작한다. 비용은 부모에서 한 번만 지불하며 하위 주문을 다시 유료 시전하지 않는다. 플라즈마의 줍기 제한은 바닥 아이템을 삭제/지급하기 전에 검사한다. 제한 종료 후 한 번만 줍고 반복 요청은 중복 지급하지 않는다.

## 적용팩과 설치 경로

**최신 적용팩 v2**는 JSON `player_skills523_apply_v2.json`:4,345,285 bytes, SHA256 `3f9656d03a7a3ac040e8e16ebfcc13ac09bfe93079cac55f067673155e1713d6`이다. 포맷 schema1은 유지하고441 프로필·20개 표 검증 정보·15개 하위 주문·단위/타입 메타데이터를 포함한다. 원본과 팩은 공개 Git에 넣지 않는다. 승인된 비공유 Drive의 프로젝트 리소스 저장소에서 실제 적용팩 폴더와 원본 보존 폴더를 구분했다. 확정 비공개 링크/ID는 별도 인계에 기록한다.

이미 보존된 원본 ZIP은25,031,173 bytes, SHA256 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`다. 기존 Drive 보존 사본을 새 소비 폴더에 정식 다운로드하여 해시와 전체 ZIP CRC를 확인했고 중복 업로드하지 않았다. 이는 원본 백업이며 게임 설치용 JSON과 다르다.

기존 개인 Library/Space 버전1의4,141,471-byte 팩은 이전8종 단계의 보존본이다. 새7경로에는 위 최신 적용팩이 필요하다. 기존8종 정의를 새로 만들거나 재업로드하지 않았다.

Drive 보관만으로 게임에 자동 적용되지는 않는다. 이번 검증에서는 정식 Drive 다운로드 → `/workspace/skills523-drive-consumer/apply/player_skills523_apply_v2.json` → SHA/JSON 스키마 확인 → 실제 Main의 인수 로드/시전으로 검증했다. 원본 보존 사본은 같은 소비 폴더의 `backup/`에 분리했다. 파일이 JSON이므로 적용팩 ZIP CRC는 해당 없고 원본 ZIP CRC를 별도로 검사한다.

```sh
godot --path /path/to/TWILIGHT -- \
  --player-skills523-pack=/private/apply/player_skills523_apply_v2.json \
  --player-skills523-sha256=3f9656d03a7a3ac040e8e16ebfcc13ac09bfe93079cac55f067673155e1713d6
```

코드는 같은 PR245 브랜치이며 main/다른 PR을 병합하지 않는다. 이 스킬 데이터팩을 전체 게임 실행 리소스 납품으로 집계하지 않는다. 리니지M 엔진/APK/XAPK를 탐색·전송·분석하지 않았다. 새 보고서·감사자료·화면을 Drive에 업로드하지 않았다.

## 검증 및 남은 경로

Godot4.7.2에서 새 Drive 소비 파일을 사용하는 실제 Main/current source map/OpenGL 검사81개가 통과했다. 설정 UI 조작/별도 재로딩/진행 파일 불변,7종의 구입·습득·실제 회복·정화·피해 경감, 부모 비용/자기 비용 조건, 보호막 대체/소진·만료, 줍기 제한/중복 방지, 원문 보존과 실패한 하위 구성 교체의 원자성을 포함한다. 원본 컴파일러6검사, 기존 정책42검사, 실제 Main/세이브32검사도 통과했다. 완료한8종의 별도 UI 검사를 다시 만들거나 반복하지 않았다.

의도적으로 손상된 설정을 넣는 독립 검사 `player_skills523_recovery_negative.gd`는 ConfigFile의 **예상 parse 오류1회**와 함께 덮어쓰기 거부/바이트 보존/NaN 거부를 확인했다. 이 예상 오류 로그를 정상 UI 로그와 섞거나 모든 오류를 무시하는 필터를 만들지 않았다. 정상 Main/UI 로그에는 스크립트·리소스 오류가 없고 소프트웨어 OpenGL의 V-Sync 경고만 있다.

최종 실행 로그: `/workspace/skills523-core-results/player_skills523_recovery_live-complete.txt`. 설정 화면을 다시 표시한13검사도 통과했고 실제1280×720 설정 화면에서 추정 회복량/재사용 편집과 원본 구분을 확인했다. 진단용 전체 기본 계약 목록은 `tests/player_skills523_inventory.gd`로 다시 생성할 수 있다. 최신 분류는 `host_contract_available`137, `source_blocked`15, `reference_blocked`327이다. 실행 계약이 있다는 분류이며137개 전부의 실플레이 완료 수가 아니다. 원본 미연결38개와 기존 참고/실행 보류 항목은 삭제·자동 지급하지 않는다.

기존 스킬의 남은15개는 라이트·브레이브 멘탈·타운트·어드밴스 스피릿·블러드 러스트(원본 패시브/기존 액티브 불일치), 트리플 애로우·포우 슬레이어(반복 공격/범위), 래피드 샷(공격·상태 실행), 슬로우·블랙 핸드·다크 핸드·파워 그립·사이드 그랩·데스 핸드(PC 대상), 스태틱 필드(자기 대상 영역 실행)다. 이들은 시전/상태/대상 실행과 검증 작업이 남아 있으며 추정 허용만으로 완료된 것이 아니다. 참고 전용327개, 미확정 노드·후속 조건·전역 사거리/시간·전체 강화 분기, Windows/Android 실기기 및 전체 몬스터 AI 검증도 별도 미완이다.

CI 수동 실행·재실행은 하지 않고 `[skip ci]`를 사용한다. 로컬 성공을 원격 CI 통과나 main 적용 완료로 보고하지 않는다.
