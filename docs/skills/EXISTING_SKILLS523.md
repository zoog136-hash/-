## UI·설정·저장

기존 스킬 화면에서 구입·습득·패시브 적용·ON/OFF·일반 공격·퀵슬롯으로 이어진다. 카드는 `원본 실행 + TWILIGHT 설정`을 표시한다. 반복 발사 카드는 무료 ON/OFF와 **발사당 MP/HP·재료·타수·호스트 간격**을 분리해 표시한다. ON/OFF 퀵슬롯은 수동 전환이며 AUTO가 반복 반전하지 않는다. 변환 패시브의 필터/버튼도 최종 resolve 결과를 사용한다.

설정 → **기존 스킬 전환**은9종을 선택해 정의가 없는 호스트값을 편집한다. 확정된30%/2배·20%·25%·원본 비용/3연사에는 편집 항목이 없다. 기존 회복7경로와 같은 `user://twilight_skill_rules523.cfg`의 별도 스킬 섹션을 사용하고 다른 섹션/진행 파일을 보존한다. 원자적 저장과 손상 설정·NaN 거부를 공유하며 다음 실행부터 반영한다.

ON/OFF는 기존 `original_combat_state.source523_toggles`로 저장한다. 제안 스냅샷으로 기존 실제 저장 API를 호출하고 성공한 뒤 상태·오라를 게시한다. 실패하면 기존 파일과 동작을 유지한다. 다른 직업/미습득 토글과 미설치 팩은 실행하지 않으며 미래 토글의 bool 값은 보존한다. 패시브의 원래 ID·이름·직업·origin·activation은 정체성 행에서 변경하지 않고 실행 사본만 전환한다. UI/퀵슬롯의 정확한 깊은 복사본은 정식 카탈로그의 결과 캐시를 공유한다. 변경된 사본은 캐시를 덮어쓰지 않는다.
