원작 가디언의 형태별 능력·소환수 독립 HP·명중률·공격/보호막 수치·명령 UI·맵 동행 규칙·2025년 직전 변경 이력·영상 타격 프레임은 미확인입니다. 소환 NPC, HP 조건 전환, SP 보호막이라는 확인된 구조를 구현하고, 나머지 실행 수치는 `balance.json`에 CUSTOM_BALANCE로 분리했습니다. 명령 기능과 안전한 지도 전환 종료는 TWILIGHT 실행 규칙이며 원작 확인으로 표시하지 않습니다.

## 실제 실행

- 독립 Node2D 가디언이 길 찾기와 충돌 검사를 사용하여 보호/공격/따라오기/대기 명령을 실행합니다. 해제로 소환을 종료합니다.
- 소환수 공격은 자체 준비·타격·회복 시간을 사용합니다. 실제 타격 프레임에서 NPC의 생존·life_id·지도 세대·거리·시야·명중을 검사합니다. 빗나감에는 명중 폭발이 생기지 않습니다.
- 주인 무기의 추가타·흡혈·반격을 가디언 공격에 재귀 적용하지 않습니다. 일반 NPC 사망 경로를 사용합니다.
- 낮은 HP 또는 HP 조건을 넘는 피격에서 소환수를 한 번 종료하고 SP 보호막으로 전환합니다. 해당 타격부터 공통 보호막 흡수 경로를 사용합니다.
- SP는 INT·장비·강화·도감·아이템 버프·스킬 수치를 합산하며 기존 마법 피해 가산과 별도로 관리합니다. 아이템 인스턴스/강화/각인/축복은 변경하지 않습니다.
- 소환 중과 보호막 중에는 재소환/자동 재등록 시전을 막습니다. MP·쿨타임은 정상 시전 한 번만 소모합니다.
- JSON 저장은 ID·남은 시간·비전투 명령만 복원합니다. 대상 참조·진행 중 타격은 재생하지 않으며 MP를 다시 소모하지 않습니다. 보호막 저장은 소환수를 부활시키지 않고 오라와 남은 용량을 복원합니다.
- 사망·직업 변경·지도 세대 변경·만료·해제에서 소환수/대상 참조/진행 타격/지속 이펙트를 정리합니다.
