## 저장 호환성

- `game_db_v17.json` 및 기존 257개 레코드는 수정하지 않습니다. 216개 자체 스킬과 과거 이름 후보 41개는 레거시 DB에 남습니다.

- 첫 이전 전에 원본 저장을 `.pre-original-skills`로 복사합니다. 복사 실패 시 이전을 중단합니다. 새 저장은 임시 파일 작성/flush 후 rename으로 교체합니다.
- 기존 퀵슬롯은 직업·등급이 일치하는 액티브만 이전합니다. 자체 스킬, 잘못된 직업, 패시브, 개편 후 등급이 모호한 이름은 원래 내용과 자동사용 설정을 아카이브합니다.
- 장비 인스턴스 ID, 강화·각인·축복, 아이템·변신·인형·성물 레코드는 재생성하거나 삭제하지 않습니다.
- 직업·맵·저장 불러오기 시 대기 공격 세대를 취소해 이전 대상에 지연 타격하지 않습니다. 유지 가능한 버프는 타이머와 오라를 다시 연결합니다.
