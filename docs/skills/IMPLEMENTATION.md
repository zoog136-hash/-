# 원작 스킬 이행 구조와 재개 절차

이 변경은 2025-06-17 기준 복원 작업의 검증 중인 단계입니다. 122개 실행 연결을 전체 원작 목록 또는 원작 전 효과의 완성으로 해석하지 않습니다. 모든 실행 레코드는 PARTIAL이며, 현재 페이지의 486개 상세 ID는 날짜 미확인 후보입니다.

## 데이터와 실행 경로

| 파일 | 책임 |
|---|---|
| `data/skills/master.json` | 내부 안정 ID, 직업별 허용, 등급, 액티브/패시브, 필수 조사 필드와 검증 상태 |
| `research_inventory.json` | 695개 직업·이름 배정의 역사적 관측, 현재 후보, PARTIAL/BLOCKED/PVP_EXCLUDED |
| `curation.json`, `source_seed.json`, `sources.json` | 수작업으로 검토한 효과, 출처 URL·게시/적용/수정 날짜·해시 |
| `balance.json` | 확인된 수치와 CUSTOM_BALANCE 수치, 반격 확률, 장비 발동 기본값 |
| `relations.json` | 확인된 강화·효과 계승 패치와 UNKNOWN 선행 조건 |
| `status_rules.json` | 상태 저항·면역·보스 보정·중첩 규칙 |
| `equipment_links.json` | 기존 장비/변신/인형/성물 발동 설명의 연결 또는 BLOCKED 사유 |
| `vfx.json`, `assets/skills/` | ID별 독립 SVG, 합성 WAV, 효과 계열·위상·타임라인·참고 확인 상태 |
| `research_inputs/` | 재생성 입력과 현재 상세 후보. 원작 이미지·애니메이션·음원 파일을 포함하지 않음 |

`world.gd`는 원작 ID의 수동·자동 시전을 `skill_service.gd`로 넘깁니다. `skill_catalog.gd`는 학습/직업/속성/무기 조건과 상위 패치를 처리합니다. 서비스가 비용과 쿨타임을 한 번 지불한 뒤 기존 플레이어 모션의 공격 이벤트에서 투사체를 발사합니다. 투사체가 실제 대상에 도착하면 독립 명중 판정·피해·상태·명중 효과가 실행됩니다. 상태 효과는 `status_service.gd`를 거쳐 몬스터 AI의 기존 상태 타이머에 적용됩니다.

반격은 독립 확률과 피해 배율을 사용하고, 상위 효과는 하위 값을 대체합니다. 반사/추가타의 재진입 깊이로 연쇄 발동을 차단합니다. 표시 예산은 피해 판정에 영향을 주지 않으며, CanvasItem 효과 풀은 160개, 합성 오디오는 6음성으로 제한합니다. 고유 프리셋은 자체 연출을 뜻하며 원작 영상과의 일치 검증을 뜻하지 않습니다.

## 저장 호환성

- `game_db_v17.json` 및 기존 257개 레코드는 수정하지 않습니다. 216개 자체 스킬과 과거 이름 후보 41개는 레거시 DB에 남습니다.
- 원작 스킬은 `original_skill_state`에 학습 ID·레거시 참조·직업별 슬롯·요정 계열을 저장합니다. 알 수 없는 향후 ID도 왕복 보존하고 활성화하지 않습니다.
- 첫 이전 전에 원본 저장을 `.pre-original-skills`로 복사합니다. 복사 실패 시 이전을 중단합니다. 새 저장은 임시 파일 작성/flush 후 rename으로 교체합니다.
- 기존 퀵슬롯은 직업·등급이 일치하는 액티브만 이전합니다. 자체 스킬, 잘못된 직업, 패시브, 개편 후 등급이 모호한 이름은 원래 내용과 자동사용 설정을 아카이브합니다.
- 장비 인스턴스 ID, 강화·각인·축복, 아이템·변신·인형·성물 레코드는 재생성하거나 삭제하지 않습니다.
- 직업·맵·저장 불러오기 시 대기 공격 세대를 취소해 이전 대상에 지연 타격하지 않습니다. 유지 가능한 버프는 타이머와 오라를 다시 연결합니다.

기존 독립 게임 규칙의 회귀를 위한 세 테스트는 `legacy_skill_fixture.gd`를 명시적으로 설치합니다. 이 테스트 어댑터는 정상 게임의 활성 도감에 레거시 스킬을 복구하지 않습니다. 원작 실행 검사는 별도 `original_skill_*` 테스트가 맡습니다.

## 재생성과 검증

```sh
python3 tools/build_original_skills.py
python3 tools/report_original_skills.py
python3 tools/validate_original_skills.py --report docs/skills/data-validation.json
python3 tools/test_project.py --godot /path/to/Godot_v4.7.2-stable_linux.x86_64 --logs test-results
```

`research_original_skills.py --cache /separate/reference/cache`는 현재 공개 DB를 갱신합니다. 현재 설명을 과거 수치로 승격하지 않습니다. 재생성 도구의 기본 입력은 저장된 조사 스냅샷입니다. 날짜별 원문 HTML은 재배포하지 않고 출처와 확인 메타데이터를 남깁니다.

## 다음 구현 게이트

1. BLOCKED 항목별로 2025-06-17 직전 공식 패치·도감·날짜가 있는 플레이 영상에서 존재/등급/대상/효과를 확인합니다. 2025-06-18 뇌신 리부트 이후 정보는 별도 경계 자료로만 사용합니다.
2. 과거에 존재했다는 관측과 기준일에도 유지되었다는 검증을 구분합니다. 현재 122개도 `historical_continuity=UNKNOWN`이며 전후 개편 검증이 필요합니다.
3. 선행 없음의 VERIFIED 근거가 없으면 UNKNOWN을 유지합니다. 상위 명칭만 보고 선행 관계를 생성하지 않습니다.
4. 그랜드 마스터: 카운터·리포스트·카운터 리벤지·타이탄·콤보·돌진·소환·마법 복사·버프 제거는 전용 이벤트/대상 처리가 확인될 때 추가합니다. 현재 연결된 효과의 미흡한 부분도 PARTIAL로 유지합니다.
5. 영상 URL/업로드 날짜/타임스탬프/판정 프레임을 VFX 조사 필드에 기록한 뒤 색·형태·모션·지속·타격 이벤트를 대조합니다. 현재 이 비교는 UNKNOWN입니다.
6. Windows 실제 렌더·Android 실기기·장시간 자동사냥·효과 과밀 성능을 별도 확인합니다.

제공된 PC 리니지 소스 ZIP 8개는 구조 참고로만 검토했습니다. 파일 해시와 확인한 스킬 관련 경로는 `external-source-inventory.json`에 남겼습니다. PC의 스킬 ID/확률/효과와 에셋을 리니지M 원작 근거로 사용하거나 그대로 이식하지 않았습니다.
