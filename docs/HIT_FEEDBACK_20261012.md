## 실제로 확인한 참고 자료와 한계

아래 **실제 플레이 정지 캡처**의 픽셀을 확인했다. 영상 전체 재생이나 프레임별 시간 측정을 완료했다고 주장하지 않는다. 광원의 형태·배치·색 대비를 참고하며 시간값은 TWILIGHT 자체 조정값이다.

- https://www.inven.co.kr/board/lineagem/5019/597292 — 사냥 화면. 대상 주변의 밝은 중심광과 가로 방향 금색 섬광.
- https://www.inven.co.kr/board/lineagem/5409/19573 — 사냥 화면. 금색 Critical 표시와 전투 효과의 밝기 대비.
- https://www.inven.co.kr/board/lineagem/5019/466756 — 이용자 직접 캡처. 밝은 접촉 지점·자주/청색 계열 효과와 텍스트의 상대 배치.
- https://lineagem.plaync.com/board/free/view?articleId=651404742787ce160312870e — 공식 커뮤니티 이용자 캡처. 설원 전투의 밝은 근접 궤적.

크리티컬, 스킬 발동, 속성 공격이 함께 보일 수 있는 정지 화면이므로 모든 광원을 일반 치명타라고 단정하지 않는다. 특정 스킬의 고유 효과, 실제 타격 지속시간·판정·사운드·카메라 흔들림은 이 자료만으로 확정하지 않는다.

## 이번 코드

- `impact_visuals.gd`: 직접 작성한 곡면 검기·방향성 관통광·중량 충격파·원거리 접촉광·마법 링/불꽃. 48×48 빛 번짐 텍스처를 시작 시 한 번 생성하고 재사용한다. 원본 게임 스프라이트·폰트·소리 복제 없음.
- `combat_vfx.gd`: 원래 `impact()`/`number()` 호출과 160슬롯 풀을 유지. 작은 선 중심 효과 대신 빠른 백색 코어와 잔광을 합성한다. 치명타는 기존 boolean으로만 구분하고 가로 금색 섬광·기울인 Critical·숫자 팝을 추가한다. 연타 숫자는 모두 표시하고 같은 위치의 110ms 내 중복 제목만 억제한다.
- `player_action_fx.gd`: 기존 `visual_progress`와 `attack_hit_ratio`를 읽어 검기/발사광의 피크를 타격 마커에 맞춘다. 원거리의 실제 투사체를 새로 발사하지 않는다.
- 선명한 기하 효과는 동시에 최대 32개. 초과분은 작은 접촉 표시로 낮추고, 시야 밖은 그리지 않는다. 숫자는 이 예산과 별개다. 전투 RNG·데미지·명중·치명타 확률·AI·공격속도·이동·드랍·세이브·카메라·Engine.time_scale을 변경하지 않는다. 기존 시각 전용 28ms 크리티컬 정지를 유지한다.
- `impact_intensity`는 개발용 0~1 속성(기본 0.85). 게임 설정 UI에 새 옵션을 추가한 것은 아니다. 전체 화면 섬광이나 카메라 흔들림은 추가하지 않는다.

일반/치명타 접촉 수명은 기존 220/300ms 유지. 코어 65ms·숫자 35ms 확대 후 120ms 안에 복귀는 **자체 조정값**이며 원작 측정치가 아니다. 독/출혈은 약한 지속 피해 효과를 유지한다.

## 검증과 전달 구분

현재 대화 컨테이너에는 Godot가 없고 외부 DNS가 실패하여 로컬 엔진 실행/전체 clone 검사를 수행할 수 없었다. GitHub의 최신 파일을 직접 읽고 별도 브랜치에 적용하며 실행 검증은 GitHub Actions에서 한다. 이 문서의 테스트 목록은 실행 계획이며, 실제 성공은 해당 커밋 Actions 결과로 별도 확인해야 한다.

- `tests/hit_feedback_test.gd`: 유형 분리, 피크·복귀, 중복 제목, MISS/회복 표시, 게임 RNG 보존, 3,000회 풀 수명 검사.
- `tests/hit_feedback_render_test.gd`: 실제 OpenGL에서 0/40/120/240ms 효과 표와 160효과 부하 표, 상세 렌더 32개 상한. 표는 격리된 렌더 테스트이며 플레이 영상이 아니다.
- 기존 `combat_vfx_test.gd`, `actor_motion_test.gd`, `combat_timing_test.gd`, `volley_motion_test.gd` 및 전체 프로젝트 회귀를 재사용한다.
- 기존 `capture_combat.gd`는 별도 실제 게임 화면 검증이다. Windows/Android 실기기 FPS, 장시간 플레이, 원작과 동일한 체감, 오디오 개선은 아직 보장하지 않는다.
