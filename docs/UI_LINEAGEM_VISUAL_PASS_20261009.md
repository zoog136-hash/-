## 실제 변경 범위 (1차)

1. `renewal_theme.gd` — 공통 색상/패널/탭/아이템 슬롯/목록/스크롤·구분선 테마. 도감·상점·지도·강화·스킬 등 공통 창에 전파.
2. `renewal_window.gd` — 금색 상단 라인, 문양, 탭 강조, 드래그 가능한 헤더, 공간 부족 시 컴팩트 메뉴로 콘텐츠 영역 확대. 기존 Navigation/TitleDrag/Close 노드명 유지.
3. `renewal_ornament.gd` — 기존 위치/크기 누락으로 보이기 어려웠던 벡터 프레임을 전체 창에 표시, 이벤트 투과 설정 및 경량 그리기.
4. `renewal_hud.gd` — 하단 슬롯/상단 단축 아이콘/퀘스트 추적기의 배치·외관과 게임 내 AUTO·공격 버튼 강조. 버튼 이름, 시그널, 실제 HP/MP·피해 계산, 월드 인벤토리·도감 데이터 경로는 유지.
5. `lineagem_ui_visual_smoke_test.gd` — 새 테마, 공통 창의 드래그·길찾기 노드, 선택 탭·닫기 버튼 검증.

- 인벤토리/장비창: 원본 소스ID별 이미지·강화 수치·등급 색상, 상세 패널.
