확인된 동작: 무기/방어구 축복 시도, 실패 시 **주문서만 소모**·장비와 강화 단계 유지,
성공 시 **추가 옵션**, 이미 축복받은 장비는 일반 축복 부여 재시도 불가.
기본 축복은 **축복받은 무기/갑옷 강화 주문서의 인챈트**와 완전히 별개의 시스템이다.

### 기본 축복 옵션 (구형 장비 등급 기준)

| 등급 | 무기 | 방어구 |
| --- | --- | --- |
| 일반 | 최대 HP +50 | MR -1 |
| 고급 | 무게 보너스 +200 | 최대 HP +30 |
| 희귀 | 무기 명중 +1 | 무게 보너스 +100 |
| 영웅 | 추가 대미지 +1 | AC -1 |
| 전설 | 추가 대미지 +1 | AC -1 |
| 신화 | 추가 대미지 +3 | AC -3 |
| 유일 | 추가 대미지 +5 (**TWILIGHT 자체 확장**) | AC -5 (**TWILIGHT 자체 확장**) |

하위 등급의 옵션이 누적되지 않으며, 해당 **등급의 한 가지 옵션**만 적용한다.
무기 축복 대미지는 기본 근거리/원거리 공격에, 명중은 무기 명중 판정에 적용한다.

### 확률

공식 확률 공개 웹 화면에서 세부 숫자 표를 직접 확인할 수 없어 **확률을 원작 수치라고 표기하지 않는다**.
현재 `scripts/equipment_blessing.gd`의 `SUCCESS_CHANCES`는 로컬 RPG용 조절 가능한 **TWILIGHT 임시 밸런스**다.

- 일반 60%, 고급 45%, 희귀 25%, 영웅 12%, 전설 6%, 신화 2%, 유일 1%.
- UI도 “임시”라고 명확히 보여준다.
- NC 자료의 정확한 신규 서버/월드/아이템별 수치를 검증한 뒤 확률 데이터만 교체한다.

## TWILIGHT 구현 범위

1. 소모품 `축복 부여 주문서` 및 `축복 부여 주문서 (각인)` 사용.
2. 사용 시 **미축복 무기/방어구 물리 인스턴스 ID**별 선택창. 성공 시 적용 옵션과 임시 확률 표시.
3. 개체별 `item_instances[ID].bless_state = "blessed"` 기록. 동일한 이름의 다른 복제본에 적용되지 않는다.
4. 성공/실패 모두 주문서 하나 소모. 실패·이미 축복·잘못된 대상에는 장비/강화/속성 변화를 주지 않는다.
5. 장착 중인 실제 개체에서만 대미지·명중·AC·MR·HP·무게 수치에 반영. 장착 해제 시 효과도 사라진다.
6. 인벤토리와 선택 상세에 '축복받은' 명칭, 금색 ✦ 아이콘, 추가 축복 옵션을 표시.
7. 기존 JSON 세이브의 `item_instances` 저장 경로를 그대로 사용; 구버전 저장도 별도 변환이 필요 없다.
8. 테스트 편의용 새 캐릭터 초기 인벤에 각인 주문서 5장을 지급한다. **기존 저장은 자동으로 5장 지급되지 않는다.**
9. `tests/equipment_blessing_smoke_test.gd`: 성공/실패, 비파괴, ID 분리, 중복 방지, 장착 스탯, 저장/불러오기.

## 별도 후속 기능

- 전설/신화 축복 무기 **2차 축복 강화**, 현재 시즌 공식 확률 반영.
- 축복의 가루 100개 + 봉인된 주문서 1개 + 아데나 50,000 제작 메뉴.
- 성배 축복 / 은총 / 절대 은총 별도 기능.
- 플레이테스트 주문서 무상 지급은 정식 밸런스 출시 전에 제거하거나 개발자 모드에 격리한다.
