# 예전 세이브의 퀘스트 소품과 실제 원본 가방

> 중간 검증 기록. 이후 사용자의 퀘스트 전용 제외 요청으로 이 아이콘/안내는 활성 가방에서 제거되었고, 원본 파일과 이전 보유 기록은 그대로다.

사진의 `[퀘스트] 죽은 모험가의 일지`는 ItemClass 1214(TestItem=true),
Icon 345 → AssetView 916 → `icon/Item/gereng_letter.png`입니다.
Quest 271 → Reward 862 및 Goal 166(ItemUse), 한국어 목표 8069가
연결됩니다. 원본 ItemBonus는 버프 참조 34와 300초이며 단순 읽기
팝업으로 대체할 수 없습니다. 활성 퀘스트 사용 정책이 적용되지 않은
구 소지는 안내를 제공할 뿐, 기존 세이브를 수정하거나 신규 지급하지 않습니다.

카탈로그 등록에서는 제외된 상태 그대로, 고유 이름을 원본에서 확인한
소품 5개(1214, 1991, 2001, 2011, 122562)에 자기 자신 원본 아이콘만
허용합니다. 명시적 번호가 다르면 연결하지 않습니다. 4개의 기록/메모는
같은 원본 편지 아이콘이며, 맹세의 잔은 별도의 원본 병 아이콘입니다.
아이콘을 확인하지 못한 슬롯은 같은 Common_Slot의 중앙 글자로 실제
아이템 이름을 표시하고, 선택한 동안에는 실제 행동 문구가 우선합니다.
새 이미지, 대체 그림, 퀘스트 보상은 만들지 않습니다.

핀한 UI44·523 원본 PNG로 실행한 Main 21/21: 이름만 남은 보유품을
저장하고 다시 읽기, 물리 퀘스트 영수증 유형 두 번째 슬롯에 같은 PNG
(64×64), 미확인 아이콘 대신 원본 슬롯의 이름 글자, 안내 후 수량과
저장 파일 보존, 일반 지급 거부. 이 시험은 모형 저장이며 사용자 기기
데이터에 쓰지 않았습니다. 개인 기기 전체 아이콘 표시는 별도입니다.
