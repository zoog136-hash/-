# 맵 전용 작업 통합 상태

UI / 맵 / 나머지 통합의 세 작업 단위를 유지하라는 사용자 지시에 따라,
기존 PR222와 기존 맵 작업공간을 맵 담당으로 사용한다. 새 PR이나 작업공간을
추가하지 않는다. 다른 두 작업 단위의 PR 정리는 상위 통합 담당 범위다.

## 이관과 보존

- PR222 원래 HEAD: `5de681308591a566115c266a69d01585c0f47d28`.
- 기존 base: PR217의 `feature/original-spr-runtime-20261101`,
  `c2e4dbd539431cde52cd7b636b5a74da7c004435`.
- 대조한 main: `00b84cfe19c05e01d30208384bf7fbcc4ae6bbf2`.
- 기존 base는 main의 조상이다. 기존 변경44파일 중35파일은 main에 없고,
  9파일은 다르며, 동일한 파일은0개다. 이를 버리거나 중복 완료로 처리하지 않는다.
- 같은 맵 브랜치에서 main을 충돌 없이 병합했다. main 대비 원래44파일의
  변경은 그대로 유지하며, main의523 world-links 연결도 보존한다.
- 원래 PR222 HEAD는 로컬 `backup/pr222-before-map-consolidation-20261105`에도
  보존한다. 이전 맵 HEAD `786b9aac66fbc5582c090e2c902e5e2f6a9e74b6`와
  그 브랜치·검증 기록·정상 보유 원본·팩·세이브도 유지한다.
- main/다른 기능 브랜치에 쓰지 않는다. 원본 자산·팩·세이브·캡처를 공개 Git에
  추가하지 않고, 전체/수동 CI나 중복 리소스팩 업로드를 실행하지 않는다.

이 PR의 기존 기능은 base508 복원 도구와 명시적 source-edge 검토 경로다.
기본 게임을 이 검토 모드로 전환하지 않으며, 현행523 지형 또는 원작 통행 의미로
재분류하지 않는다. 과거33/34 맵의 원본 입장 컴포넌트 검토 결과는 과거 실행
범위다. 이 작업공간에서 새로 그 전체 검사를 실행한 결과가 아니다.

## 현재 검증과 차단

- 통합 트리의 Python codec/geometry 회귀23개 통과.
- Godot4.7.2에서 `base508_game_mode`, `base508_pack`,
  `base508_source_navigation`, `base508_source_edge_field`,
  `base508_portal_contract` 다섯 스크립트의 개별 문법 검사 통과.
- 추적 자산723 atlas /41,442frame /233,420,026byte 무결성 통과.
- 최초 unittest 자동 탐색은 private 입력 인자가 필요한 수동
  `test_base508_streaming.py`를 잘못 수집했다. 올바른 다섯 unittest 모듈을
  명시한23개 결과가 위 통과 기록이며, 그 수동 원본 검사를 통과했다고 하지 않는다.
- 전체 에디터 임포트는 저장공간 부족으로 생성 캐시/MD5 오류가 발생했다.
  종료코드0만으로 통과 처리하지 않았다. 원본 대신 재생성 가능한 캐시만 정리했다.
- 같은 실행에서 main과 바이트가 동일한 `scripts/skills/skill_service.gd:434`의
  `var amount := ...` 타입 추론 파싱 오류가 발생했다. 파일 SHA256은
  `7542f73e95b0aa8361147fac564e26b1ed5a54d11a16dcdc9e6ae0209debc0e3`다.
  맵 이외 통합 담당이 수정해야 하며 여기서는 변경하지 않는다.
  따라서 이 트리의 실제 Main/세이브 게이트 통과 또는 게임 완성을 주장하지 않는다.

main 파싱 오류 해결 후 Main/세이브/필수 리소스 경로를 집중 확인해야 한다.
기존 base508 검토용 private 팩/표가 없는 실행에서 가짜 팩을 만들거나 현행523
입력을 base508로 바꾸어 원본 실게임 검사로 세지 않는다.

## 현행523 원본 연결 잔여

보유989 SP2(75,664,378byte)의 독립 로딩·추정 디코딩은 이미 별도 소비자에 있다.
main 디코더 SHA256
`ab105e0c54e5c45658513631443f3a356e6e14d849d97daccffc6ad25df49cbe`는
기존36,246항목 /17,115프레임 전체 렌더 검사와 동일하다. 이번에 다시 검사하거나
새 디코더·미사용 가드·임의 UI/그림을 추가하지 않는다. M 원작 픽셀/알파/합성
동등성 또는 실제 지도 배치의 증명은 아니다.

아직 필요한 연결은 다음과 같다.

`원문 정적 배치 레코드 → SPR 선언/별칭/액션/틱/속성 → SP2 파일/저장그룹/프레임
→ 원문 앵커/레이어 → 지도 그리기`

현재 지도 렌더러 `_read_chunk → _append → _build_frame`은 TI2 참조를 소비한다.
기존 단일 SP2 미리보기나 플레이어 상대 샘플을 원본 지도 배치로 계산하지 않는다.
필요한 전역 인계 ZIP은 현재 환경 수신0byte이며, 공식 수신 준비 전 HTTP401이
발생했다. 인증 복구 증거가 없어 반복·우회하지 않는다. 원래30 SPR 선언과 전역
배치 계보를 읽기 전 좌표·방향·기본 프레임·통로를 만들어 연결하지 않는다.
