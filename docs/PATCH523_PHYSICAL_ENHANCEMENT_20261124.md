# 523 물리 주문서 강화 경로와 원본 누락 목록

이 변경은 강화창 진입을 위해 물리 보유 주문서 묶음 전체를 일반 이름 스택으로
넘기던 경로를 건너뛴다. 보유 물리 ID를 지정했다면 그 ID를 계속 사용한다.
강화 실행 때에만 원본 ItemClass·축복 상태와 현재 소유 증명을 대조하고, 검증된
수량을 기존 물리 소비 장부의 원자 저장에 포함한다. 수량이나 소유 증명이
바뀌거나 잠겼으면 소모 전에 거부한다. 장비·주문서·비용·난수는 저장 결과가
정상일 때만 확정된다. 별도 인장 강화, 기존 일반 스택, 기존 확률·소비 정책은
바꾸지 않는다. 원본으로 표시된 장비나 물리 주문서를 원본 규칙 없이 일반
TWILIGHT 확률로 처리하지 않는다. 축복/저주 물리 묶음은 정확한 suffix와
축복 상태가 일치할 때만 기본 ItemClass로 연결한다.

원본 근거: 고정된 523 정의 ZIP, SHA-256
`d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`.
`ItemClass`, `DescData_Korean`, `ItemBonus`(2032/2022/8352)에서
장비·주문서 그룹을 읽고 실사용 비테스트·지역 제한 없는 원본 ID를 대조했다.
1,959 장비 ID, 204 주문서 ID의 **정의 관계 범위**이며 전체 인벤터리를
실기동한 숫자는 아니다.

쓰지 않았다. 속성 강화/제련/세공·전체 강화 옵션·아이콘은 이 변경 범위 밖이다.

전체 비테스트 분모 30,398개에서 27,440개는 강화 대상·주문서 선언 범위 밖,

2,146개 중 1,198개는 별도 원본 조건이 있다. 위 17개는 정확한 실행 입력이
없다. 후보 등급은 원본 정적 관계의 판정이며 실제 게임 전수 통과가 아니다.
