# TWILIGHT 전체 상세 도감 적용 — 2026-10-09

## 범위와 실제 검증
인벤 출처 `data/catalog_v19.json`의 데이터 전부를 유지하며 실제 게임 도감에 노출한다.

| 도감 | 등록 수 | 원본 옵션 문장 수 |
|---|---:|---:|
| 아이템 | 2,129 | 6,816 |
| 변신 | 413 | 1,799 |
| 마법인형 | 166 | 887 |
| 성물 | 144 | 745 |
| **총계** | **2,852** | **10,247** |

카드/장비 `sourceOptions`는 원본으로 보존하고 각 레코드의 `sourceUrl`, `sourceId`, 이미지도 유지. 상세 도감과 실제 플레이용 임시 아이템 DB는 별개이므로 원본 개수와 런타임 병합 아이템 수가 다른 것은 정상이다.

## UI 변경
- 예전에는 한 항목의 옵션을 `sourceOptions.slice(0,16)`까지만 보여줬다. 현재는 원본 옵션 전부를 스크롤로 확인.
- 이름/등급/유형뿐 아니라 설명으로도 검색 가능.
- 원본 전체 옵션 수, 일반 수치형 식별 수, 개별 효과 검증 필요 수를 제공.
- 이전에 사용자가 삭제하라고 지정한 손상/비손상·저주 옵션은 게임 표시에서 제외. 원본 JSON은 변경하지 않아 확인 가능.
- PvP 옵션의 표기는 PvE로 통일.

## 일반 수치형 옵션 연결
`scripts/detailed_catalog_options.gd`는 도감 문구의 쉼표/붙임표/공백 차이를 정규화하고 숫자를 파싱한다. 입력에는 STR/DEX/CON/INT/WIS/CHA, HP·MP, 이동/공격속도, AC/MR/SP, 명중, 근·원거리/마법 대미지·치명타, 물약 회복량/률, 경험치, 무게, 스턴/공포 등 내성과 적중, PvP→PvE 감쇄/추가 피해, 데미지 리덕션 무시, 주기 HP·MP, HP흡수 등이 포함된다.

파싱된 옵션은 `world.gd`의 기존 장비·변신·인형·성물 능력치 계산 경로에 연결한다. 기존 원본의 구조화 수치(`atk`, `def`, `hpFlat`, `hpPct`, `xp`, `speed`, `attackSpeed` 등)가 존재하면 중복 합산하지 않는다. 이전 세이브로 불러온 레코드는 필요할 때 다시 정규화한다.

**중요: 원본 옵션 10,247개가 모두 전투에서 발동한다는 뜻은 아니다.** 고유 발동, 특정 직업/무기/대상 한정, 스킬 레벨, 면역, 특수 확률 등의 문구는 원본에 모두 남기되 실제 효과는 별도 검증이 필요한 상태로 표기한다. 수치 파서는 확정할 수 있는 일반옵션만 연결하며, 모르는 효과를 임의로 구현하지 않는다.
