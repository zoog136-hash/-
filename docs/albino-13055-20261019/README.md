## 코덱스/개인 환경 재생성

원본 파일/파생 PNG는 공개 Git 저장소에 넣지 않는다. 원본을 사유 리소스 폴더에 배치한 후:

```bash
python3 tools/map_restore/build_albino_13055_visual_pack.py \
  --source /private/maps/13055.png \
  --output /private/twilight/albino_13055
```

출력: `albino_01_13055_visual.png` ~ `albino_04_13055_visual.png`, 검토용 미리보기 및 manifest.

실행 시 SHA-256, 해상도, 파일 크기를 검증하며, 출력 디렉터리는 저장소 밖이어야 한다. 원본을 덮어쓰지 않으며 기존 산출물도 덮어쓰지 않는다.
