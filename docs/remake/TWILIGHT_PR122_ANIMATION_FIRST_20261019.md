# PR122 — 애니메이션 제작 우선 복귀 (2026-10-19)

사용자 지시: “애니메이션 작업 먼저”, “신화 이상변신들은 아주 상세하게 보완”. 기존54프로필 색상/모션 공유 연결은 고유 애니메이션 전체 완료가 아니다. 조기 전체CI33개는 이 세션의 정확한HEAD 실행만 취소 요청했다. 완료/실패 이력과 원화/커밋은 보존한다.

유일·신화31종의 상세 애니메이션은 아직 완료되지 않았다. 새 상세 완료0/31이며 기존 승인405/498 이력과는 다른 품질 작업이다. 기존 공유 프로필은 상세 완성으로 집계하지 않는다. 전용 원형·장비·8방향·보행6/전용run6·공격·피격·사망을 제작한다. 새로운 원화와 기존 프레임 부족14의 보행/달리기 보완을 우선하며, 전체CI는 지금 다시 실행하지 않는다.

현재 해방된 할파스393·지배자 기르타스267의 동쪽 보행6+전용run6 원화2장을 제작·보존했다. 기르타스는512소스캔버스에서 서로 다른12자세 기하PASS이나 독립 시각/전방향/런타임승인은 미완료다. 할파스는 원화의 배경광/영역 분리 문제로HOLD이며 원본을 보존하고 새 버전으로 수정한다. 두 생성본 모두 여분의 배경광 제거 및 고정 지지 교대 보완을 진행한다. 제작용 프로필에 아직 설치하지 않았다.

[31종 큐·원화·정확한 생성 요청·SHA·CI취소 기록](evidence/pr122-mythic-detailed/batch01). 새 PR/병합/rebase/강제푸시는 하지 않는다. 소스 단계 커밋은사용자가 지시한 제작 우선에 맞춰skip ci로 저장하며, 개별 완성 소스의 최소 재생 확인은 별도다.
