## 범위와 현재 상태

영웅급 **109종 = 기존 승인 이력 84종 + 미승인 25종**이다. 승인 84종 안의 기존 프레임 보완 11종은 별도 제작 대상에 넣지 않았다. 과거 `approval_preserved` 플래그가 아니라 현재 `VERIFIED_COMPLETED`/`FRAME_INSUFFICIENT` 상태를 사용한다. 따라서 이번 저장으로 승인 이력 405/498을 바꾸지 않는다.
