## 1. 확인된 원인 후보 및 우선 가설

- 현재 `scripts/animation/actor_motion.gd`는 상태가 `run`인데 해당 SpriteFrames에 달리기 전용 트랙이 없으면 `walk`를 폴백한다. 기존 `gait` 시계/프레임 선택과 몸통 상하 보정도 확인할 것.
- 아래 14종은 **이 PR 브랜치의 실제 SpriteFrames.tres에서 방향별 walk 프레임 2~4장을 확인**한 개체다. 8방향 모두 해당 수로 구성되었고, 현재 별도 `run_0..7` 트랙은 없다.
- 사용자가 관찰한 발의 출현/소멸 현상은 프레임 수 부족 외에도 잘못된 아틀라스 잘라내기, alpha, 다리 관절/접지 누락, 프레임 순서, 셀별 앵커·마진 흔들림에서 발생할 수 있다. **원인 확정 전 일괄 FPS 상승·루트 바운스 증폭·프레임 복제로 해결했다고 주장하지 않는다.**

## 3. 제작/수정 명령 (Codex / 담당 작업자)

1. **선행 감사**: `AGENTS.md`, `TWILIGHT_PROJECT_RULES.md`, `docs/RESOURCE_INTEGRITY_POLICY.md`를 읽고 **최신 main**과 PR #122 head SHA를 재확인한다. 작업 환경에서 `python3 tools/check_resource_integrity.py --root .` 사전 검사. 업로드·비공개 원본이 없으면 있는 척하지 말고 HOLD/미전달로 기록. PR #100은 이미 main 병합 완료되었으므로, 현재 PR #122가 여전히 옛 feature 브랜치를 base로 사용하는 점을 먼저 기록하고 병합 기반을 임의 변경하지 않는다.
2. **원인 분리 검사**: 14종 × 8방향에서 walk 1주기를 연속 재생하고 `SpriteFrames.tres`의 프레임 텍스처/AtlasTexture region·margin·원본 크기·알파·발 접지 픽셀·골반/몸통의 위치·관절/프레임 순서를 확인한다. 실제 Main 이동, 자동 이동, 대각 이동, 속도 효과 적용에서 `run` 폴백과 `gait` 동기화를 수치·캡처로 대조한다. 진단 시 원본 PNG는 SHA 보존하고 덮어쓰지 않는다.
3. **품질 목표**: 부족한 대상의 **8방향 각각 걷기와 달리기를 구분하여**, 방향/모션별 최소 6개(가능하면 8개)의 **서로 다른 유효한 전신 관절 자세**로 구성한다. 생성/복제/보간만으로 숫자를 맞추지 않는다. 실제 지지발 접지→체중 이동→반대발 이동→반대발 착지의 연속 보행을 표현한다. 몸통·팔·다리·머리(동물형은 몸통·다리, 특수형은 해당 지지부위)가 자연스럽게 연결되고, 발/다리/무기/외형이 튀거나 사라지거나 분리되지 않게 한다. 인간형, 갑각·거북·펭귄, 특수형 등 형태마다 보행 방식을 구별한다. 비행/부유형은 지면 접촉을 가짜로 강요하지 않는다.
4. **재생 로직**: 새 `run_0..7`을 넣는 경우 `run`과 `walk`의 전용 트랙 선택 및 각 재생 주기/월드 이동 속도 비율을 확인한다. 씬 루트 전체 바운스/부자연스러운 scale 신축으로 발소실을 감추지 않는다. atlas anchor/피벗은 각 시점 동일 지면 접지점 기준으로 보정한다. 필요하다면 로직을 **해당 14종에 영향이 한정되도록** 수정하고 기존 8방향 정상 127종·기본형에 대한 회귀를 입증한다.
5. **기존 동작 완전 보존**: `idle`, `attack`, `cast`, `special`, `hit`, `death`, 변신 외형 식별, 무기·스킬/효과, 공격 타격 마커·명중·피해·모션 속도 보정, 실제 이동 속도, 저장, 자동사냥, AI, 맵·경로·충돌, HUD와 기존 기본형은 함부로 변경하지 않는다. **기존 정상 공격 프레임은 그대로 보존(가능하면 프레임별 SHA 비교)**. 정상 완료 392종 및 현재 PR #122의 4건 진행과 WIP 아트를 지우거나 덮어쓰지 않는다.
6. **작업 방식**: 먼저 대표 인간형 1종(신화-사신 남, 2프레임)과 비인간형 1종(도구리/크라켄 중 원본 접근·검증 가능한 대상)의 연속 걷기/달리기를 확인한다. 두 계열의 실게임 8방향 검증이 성공하면 나머지 대상별 소규모 커밋으로 확장한다. 생성에 필요한 권리·원본이 없거나 실제 분리 관절 포즈를 만들 수 없다면 가짜 완성 대신 HOLD, 원인과 필요한 원본을 명시한다. 캐릭터를 새 디자인으로 바꾸거나 3D로 제작하지 않는다.
7. **완료 검증**: 각 14종 × 8방향 × walk/run에서 프레임 수·실제 **고유 자세**·프레임 순서·발 접지·alpha/크롭/장비 유지, 0.75x/1x/1.5x 속도와 방향 전환, 공격 전환/복귀, 자동 이동을 확인한다. Godot 4.7.2 **실제 Main**의 정상 카메라/지도에서 연속 시간 재생 OpenGL 캡처(정면/후면/측면/대각 포함)와 비교용 프레임 스트립/영상 또는 GIF, 실패 로그, 검사 코드, 정확한 CI 링크/SHA를 PR #122에 보존한다. 격리 샘플·정적 시트·헤드리스 PASS만으로 실기 시각 검증 PASS를 주장하지 않는다.
