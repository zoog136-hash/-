# 사용자 요청 중단 보존

작성물6205개(7,690,725,267바이트), PNG4606개를 바이트·SHA-256 그대로 보존했다. 압축본4,751,840,049바이트를28MiB 이하162개 조각으로 나눴다. 전체 멤버 SHA와 zstd 체크섬을 복원 스트림에서 검증했다.

`preservation-manifest.json`과`SHA256SUMS`를 먼저 확인한다. `all-current-work.tar.zst.part001`부터 숫자순으로 이어 붙이고 전체 SHA-256 `603b43965554cfdeec136d4a1b9332ea4408d74966af4b83a4b366dc0f6a0a65`를 확인한 뒤 zstd/tar로 격리 디렉터리에 복원한다.

후보 팩과 실패 로그는 승인본이 아니다. 신규 승인0, 전체 로컬 회귀 중단, 현재 HEAD 전체 CI 미확인, 비공개 원본 백업 NOT_DELIVERED, 이전 사신 UNRECOVERED를 유지한다. 이 묶음은 이번 세션의 생성 원화·게임 캡처·코드·보고서이며 제3자 원본 비공개 백업을 포함하지 않는다.

대용량 보존은 GitHub 단일 push pack 제한을 넘기지 않도록 저장 전용 커밋으로 나눈다. 각 저장 메시지의 `[skip ci]`는 사용자 중단 요청을 지키기 위한 것이며 검증 성공을 뜻하지 않는다.
