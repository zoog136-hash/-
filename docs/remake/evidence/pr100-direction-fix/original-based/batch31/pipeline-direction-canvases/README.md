# Optional direction canvas review package

Frozen review evidence for the additive mixed_sources_v1 whole-sheet canvas_sizes_by_direction field. This is a source-code/review package, not installed animation assets or a production import. No art, source pixels, profiles, import settings, maps, completion counts, or Main evidence are modified by this package. It does not certify animation semantics, gameplay, Android runtime, or delivery of original resource packs.

The new map is accepted only on whole-sheet entries in mixed_sources_v1. Exact selected-direction keys, integer canvases 64..2048, the declared maximum analysis canvas, actual per-direction canvas/foot/anchor bounds, whole-PNG use, global role/slot/pose uniqueness, source identity, and mandatory 104/112 slots remain enforced. Per-phase overrides and per-pose-file maps are rejected. Legacy analyze, import_sheet, spriteframes, pose-files preparation and transaction installation functions remain unchanged; the existing optional 29-test source is byte-identical to its baseline. The independent mixed auditor validates actual resources, including uniform mixed inputs. The existing legacy parser is unchanged.

The initial independent adversarial review found three classes of blocking issues: missing or doubled runtime normalization metadata could pass; stripping direction metadata could hide real variable AtlasTexture canvases; fractional actual Rect2 coordinates could be truncated by the legacy reader. Fixes require exactly one resource-section Vector2(256,256) assignment, verify actual declared canvas and foot for every mixed frame even with no map, and independently reject noninteger actual Rect2 coordinates. Mixed-only provenance cannot be mislabeled to bypass the helper. The actual-canvas gate executes before virtual Image.new allocation; its regression test prevents malformed huge-margin allocation. Duplicate assignments, wrong slot/order, Boolean phase and phase-root escapes are also covered.

Final parent validation records 107 passing tests: new direction canvas 13, unchanged optional 29, legacy import 50, coverage audit 6, identity link 9. root-logs/legacy50.log is a rejected invocation using a wrong discover pattern and explicitly records Ran 0 / NO TESTS RAN. It is retained as failed-attempt evidence and is not included in the 107. root-logs/legacy50-exact.log is the successful exact-filename rerun. Author verification summaries are separate from raw parent logs. Adversarial baseline and postfix receipts contain the code hashes actually probed; the final frozen root 107-test run and new regression tests cover the subsequent call-order hardening as well. No earlier receipt is relabeled as a test of later bytes.

Code snapshots are under code/, pre-change baselines under review/. implementation.diff is the reviewed tracked-file diff; the new untracked test has its complete snapshot separately in code/tests/ and review/new-direction-canvas-tests.py. The workflow snapshot preserves the parent's batch30 matrix and includes the three agreed path/test additions. This archive does not change the Git index or commit anything. Reproduction of tests that use production fixtures requires the existing repository checkout and Python Pillow, NumPy and SciPy; asset packs are deliberately excluded.
