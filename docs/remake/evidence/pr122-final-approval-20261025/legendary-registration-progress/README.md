It uses the original Player width convention, uniform raw-source scale and explicit projected ground origin; it never modifies clocks, facing, tint, damage or physics. A compiler must supply `semantic_review=PASS` and complete typed entries. No default asset currently supplies this new metadata yet; installation is still pending source/semantic review.
