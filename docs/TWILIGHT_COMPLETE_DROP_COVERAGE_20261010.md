# TWILIGHT PR #64 — 전체 470개 아이템 드랍 도달성 확보

**작성 기준:** 2026-10-10, `data/game_db_v17.json`의 163종 몬스터·470종 아이템.

## 실제 반영

- 458종 장비 중 140종은 기존 TWILIGHT 몬스터별 `drop` 또는 검증된 L1J 연결을 통해 기존부터 획득 가능.
- 미배정 **318종 장비**에 몬스터별 **636행**의 보완 배정(각 2개의 드랍 기회)을 추가.
- 11종 회복 아이템 중 2종 기본 물약은 기존 획득 경로 유지; 나머지 9종에 **27행**(각 3개의 몬스터 배정)의 보완 경로 추가.
- 1종 화폐 `아데나`는 기존 몬스터 처치 골드 지급 `gold += gained_adena`를 유지. 인벤토리형 바닥 아이템으로 중복 지급하지 않음.
- **총 470/470종**의 아이템에 코드상의 획득 경로가 존재함. 이는 '실제 플레이에서 쉽게 나온다'는 뜻이 아니며, 최고 등급은 매우 낮은 확률 때문에 장기간 드랍이 없을 수 있음.

## 출처 경계

기존 `data/monsters/l1j_drop_overrides.json`의 원본 SQL NPC ID/아이템 ID로 증명된 매핑과, 이번에 추가한 `data/monsters/twilight_drop_coverage.json`의 **TWILIGHT 게임 밸런스용 임의 배정**은 별개다. 후자는 리니지M 공식 드랍 사실 또는 인벤 검증 결과로 취급하지 않는다.

참조 자료:
- 리니지M 인벤 [아이템 DB](https://lineagem.inven.co.kr/db/item/) — 아이템 종류·등급 및 카테고리 확인.
- 리니지M 인벤 [몬스터 도감](https://lineagem.inven.co.kr/dataninfo/monster/list.php?minlevel=81) — 몬스터·지역·드랍 검색 체계 확인.
- 리니지M 인벤 [몬스터 DB](https://lineagem.inven.co.kr/db/monster/) — 몬스터 분류 참고.

현재의 배정 규칙은 인벤 표 전체를 복사한 것이 아니라 **TWILIGHT 세계의 몬스터·레벨·지역 테마에 맞춘 플레이용 보완 배정**이다. L1J SQL 원본 확률을 리니지M 공식 확률로 오인하지 않는다.

## 레벨 / 등급 적합성

- **일반 몬스터**: 일반·고급·희귀·영웅 장비만 배정. 일반(전체), 고급(레벨 9+), 희귀(레벨 32+), 영웅(레벨 70+)으로 후보를 좁힘.
- **보스 몬스터**: 전설(레벨 60+), 신화(레벨 90+), 유일(레벨 110+) 장비를 보완 배정. 기존 보스 고유 드랍은 전혀 제거하지 않음.
- 아이템 이름의 테베·오시리스·라스타바드·지룡·수룡·화룡·마계·천상계·시간의 균열·종말 등 관련 테마를 우선하며 두 번째 배정은 특정 몬스터 쏠림을 줄여 분산.
- 기존 검증된 L1J 원본 몬스터·등급 조합에는 보완 장비를 넣지 않아 원본 아이템의 상대 가중치 분포가 불필요하게 뒤섞이는 일을 줄임.
- 위 후보 기준은 **신규 보완 데이터**에만 적용되며, 이전부터 등록된 드랍 아이템의 레벨 조건은 바꾸지 않음.

## 기존 확률 보존

추가 데이터는 장비 등급 **추첨에 성공한 뒤** 동일 등급 후보 아이템을 정할 때만 사용한다. 원본 등급 확률은 그대로다.

| 등급 | 일반 몬스터 1회 추첨 | 보스 1회 추첨 |
|---|---:|---:|
| 일반 | 0.1% | 0.1% |
| 고급 | 0.1% | 0.1% |
| 희귀 | 0.1% | 0.1% |
| 영웅 | 0.015% | 1% |
| 전설 | 없음 | 0.2% |
| 신화 | 없음 | 0.025% |
| 유일 | 없음 | 0.001% |

- 일반 몬스터 장비 추첨은 1회, 보스는 독립 3회(한 번 처치에서 **장비 최대 3개**) 유지.
- 기존 물약 드랍 **한 번의 독립 판정**은 일반 45%, 보스 90% 유지. 새 회복 아이템은 그 단일 판정 안에서 조건부 가중치로 선별함. 따라서 보조 물약 확률을 전체 장비 확률에 곱하지 않으며, 회복 아이템마다 원작 공식 확률을 주장하지 않음.
- 바닥 생성 → 수동 줍기 또는 AUTO 줍기 → 인벤토리 지급, 기존 저장 데이터 형식 등은 그대로다.
