# Same-source-Land scheduled landing consumer — unexecuted candidate

PR285 continuation. The existing original AutoScheduleLandTeleport caller already
joins an explicit LandTeleport and a caller-selected LandTeleportTerritories.ID.
Its source_schedule owner authenticates the original projection/archive, category
and schedule enablement, original prerequisites, currency and price. This is a
separate typed route, never a Portal/World/NPC numeric-ID substitution.

Previously the local movement consumer only admitted legacy host field scripts
and a host spatial save override. Source sessions intentionally reject that
save override, so forwarding it directly would not be a valid connection.

World now dispatches an active generic source-field assessment/request to its
existing map controller. The controller requires exact current Land declaration,
explicit landing relation, existing local opt-in, original Adena cost and level
prerequisites, actor state, source and arrival condition contexts, actual source
floor clearance and the existing live occupancy predicate. Candidate ordering
and inclusive/exclusive bounds reuse the existing explicitly OWN policy. No
cross-Land loading, first-route choice, native formula, free admission or Portal
fee inheritance is introduced. Gem payment remains unsupported in this new
source branch; the existing legacy branch is unchanged.

The selected same-Land field is prepared from the held verified source catalog
with the current field's own policy. The original request, current position,
field/definition identity and exact candidate are requoted after rendering
preparation. Existing source cursor/session/renderer/physics commit and the
original prepared-cost save path own persistence and rollback; the host save
override and its source-session rejection remain unchanged. Uncertain saves
retain the existing reload protection rather than refund/retry.

Known scope: same-Land manual scheduled landing only, with original source data
and explicitly OWN geometry/activation. PR276 population and PR275 installation
remain their owners. Phone extraction, v30, 62ZIP/index, source banks and all
resource files/configurations/saves are untouched. No new images or sound.
