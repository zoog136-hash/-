# PR84 재개 지점 — 25개 맵 충돌 통로·자연 경계

기존 브랜치: `feature/twilight-reference-expansion-20261011`.
이 단위의 기준 원격: `bab7ba5aa1a074bc1d37c6b2500e2c0fcd11bc91`.
검증된 구현 저장 SHA: **`f55c2a6a95897054b566d345637549ad3078e03a`**.
이 파일과 증거를 담은 다음 커밋까지 포함하여 최신 원격 HEAD에서 재개한다.
과거 SHA로 브랜치를 되돌리거나 완료한 배치 생성 도구를 재실행하지 않는다.

실제 변경: `data/maps/`의 기존 25개 맵, `navigation/`의 25개 캐시와 카탈로그,
`playable_field.gd`, `field_renderer.gd`, `field_minimap.gd`, `renewal_map.gd`,
내보내기 설정, 배치·캐시·검증 도구와 테스트. 구현 커밋은 70개 파일을 담는다.
정확한 목록은 `git show --name-only f55c2a6`과 [변경 목록](changed-files.json).

적용·검증 범위는 **기존 25/25개 맵**의 객체 충돌 통로, 기존 입구·NPC·포털
접근, 유효한 스폰, 동일 좌표의 미니맵/상세 지도다. 모든 맵에서 실제 플레이어의
직진 차단과 반대편까지 우회 이동을 검증했다. 객체·텍스처 개수를 맵 완료율로
계산하지 않았다. 기존 그림·셰이더 바이트, 기존 객체와 좌표는 보존했다.

실제 Godot 4.7.2 검증:

- 충돌·이동·스폰 19,139 검사 통과 / 0 실패, 25개 맵의 실제 몸체 이동 기록.
- 캐시 없는 계산과 비교 225 검사 통과 / 0 실패; 실제 PCK 캐시 읽기 25맵 통과.
- 전체 프로젝트 검사 113개 실행. 최초 109 통과 / 1 실패 / 3 보류에서
  아덴 밀집 리젠 구역을 침범한 이번 수목 9개를 비워 수정했다. 몬스터 9,323
  검사와 관련 8개 테스트 재검증 후 **최종 110 통과 / 실패 0 / 보류 3**.
- 수정 후 재검증: `monster_world`, `hunting_paths`, `hunting_navigation_cache`,
  `reference_object_placement`, `world_structure`, `world_regions`, `field_world`,
  `world_region_portals`. 최초 실패와 수정 후 로그를 모두 보존했다.
- 보류: `original_map_catalog`, `original_world_runtime`, `source_first_map`.
  해당 원본 팩이 없어 실행하지 않은 검사다. 통과 또는 원본 복원으로 집계하지 않는다.
- 같은 실제 카메라 전후 150장, 실제 HUD·지도 50장, 전체 25개 Contact Sheet,
  충돌과 실제 이동 궤적 SVG, SHA-256 매니페스트 저장. [전체 증거](README.md).
- Linux 소프트웨어 OpenGL만 확인했다. Windows/Android 실기기 성능은 미검증이다.
- 723개 시트 / 41,442 프레임 / 233,420,026 bytes 무결성 통과.

최초 실패·환경 문제: 오만 출구를 막던 초기 배치, 압축 형식, 소수점 반올림
저장, 비교 worktree의 font import 누락, X11의 IPC 공유 메모리 오류를 수정했다.
기존 원좌표를 보존한 별도 캐시 저장을 사용한다. 최종 아덴 캡처는 MIT-SHM을
끈 별도 Xvfb에서 오류 없이 재실행했다. 실패한 화면·실행 로그를 성공으로 집계하지 않았다.

남은 작업: 현재 배치는 기존 TWILIGHT 구조에 참고 지도의 통로 방식을 적용한
지역별 근사 배치다. 특히 오만 2~10층·신념 1~4층·지배 정상의 원작 전체 구조,
정확한 객체·보스 좌표, 원본 타일 복원과 원작 그래픽 동등성은 추가 검증 대상이다.
게임은 기존의 로컬 Godot RPG이며 실제 온라인 서버 연결을 완료했다고 주장하지 않는다.
