# TWILIGHT 상세 인벤 도감 전수 연동 (2026-10-09)

## 범위
원본 `data/catalog_v19.json`을 유지하고, **원작 상세 도감의 모든 레코드**를 게임 도감에 로드·인덱싱한다.

| 범주 | Inven 원본 항목 |
|---|---:|
| 아이템 | 2,129 |
| 변신 | 413 |
| 마법인형 | 166 |
| 성물 | 144 |
| **합계** | **2,852** |

원본 `sourceOptions` 합계 **9,603개**는 데이터에서 지우거나 16개로 잘라내지 않는다. 실행 시 파서가 일반 수치를 **5,521개의 구조화된 수치 필드**로 구분한 것이 Godot 4.7.2 테스트에서 확인됐다. **구조화된 필드 수와 독립적인 전투 효과 구현 개수는 동일하지 않다.** 적용 안 된 옵션도 원문 그대로 검색·조회 및 `inven_unimplemented_options`으로 보관한다.

## UI
- 아이템 도감의 기본 탭을 **전체**로 변경하고 40개씩 페이지 탐색. 원작 2,129종과 TWILIGHT 전용 품목을 함께 제공하며 원본 개수는 위 표 그대로 유지한다.
- 검색에 이름·등급·종류·**Inven sourceId·설명 옵션** 포함.
- 도감 상세 보기의 `sourceOptions.slice(0,16)` 제한을 제거해 모든 옵션을 출력한다.
- 원작 출처 ID, 등급, 종류, 원본 옵션 개수 표시.
- 플레이 정책: PvP 표기는 PvE로 표시; 저주/손상·비손상 옵션은 UI에서 숨김(원본 데이터는 보존).
- 발동/전용·액티브 스킬의 설명은 보이되 **고유효과 보류**로 표시.

## 원작 수치의 실제 사용
- `scripts/inven_option_adapter.gd`는 *source=inven*인 레코드만 최초 로드 때 한 번 분석한다. **기존 typed 스탯이 유효하면 같은 설명 숫자를 중복 합산하지 않는다.**
- 생명력·마력, %HP, AC, MR, SP, STR·DEX·CON·INT·WIS·CHA, 근/원/마 대미지/명중, 치명타, 스턴·공포·홀드·독·출혈 내성, 물약 회복, 경험치, 대미지 리덕션, 이동/공속, 무게 보너스 및 원소 저항 등 명확한 일반 옵션을 기존 런타임 스탯 경로와 연동.
- `대미지 증가 +25%`는 성공 공격에 % 피해 증폭으로 적용. `리덕션 무시`는 사용자가 정한 동일 수치 추가 대미지로 전환.
- 원작의 `PVP` 옵션 숫자를 TWILIGHT 싱글플레이 **PvE** 방어·추가 대미지로 변환한다.
- 특정 변신의 `한손검 추가 대미지 +5` 등은 **해당 무기 종류일 때만** 적용한다. 비무장/다른 무기에 잘못 붙던 옛 테스트 기대값 수정.
- 장비 중 `sourceId` 또는 이름이 같은 기존 저장 아이템은 원본 상세 레코드의 능력치로 다시 조회한다. 인스턴스 ID·강화 레벨·각인·축복 표시 등 개체별 상태는 보존한다.
- 도감의 기본 수치가 옛 TWILIGHT 샘플 수치와 다르면 **상세 도감 수치 우선**. 예: `지식의 티셔츠`는 원본의 `INT +1 / SP +1 / AC -1`을 따르며 이전 가상 `MP +30`을 더하지 않는다. MP+30 기능 자체는 가상 장비로 별도 테스트한다.
- HP 흡수 성공 공격마다 1~3, MP/HP 자동 회복 +5/30초라는 사용자가 별도로 정한 런타임 예외는 그대로 유지.

## 미해결/보류 (원작 텍스트는 **전부 표시**)
- 고유 확률 발동 효과, 액티브·전용 스킬, 스킬 레벨·차징 같은 **스킬 효과**.
- 축복의 특수 스탯, 변신·마법인형·성물 각성 및 컬렉션 보너스.
- `마법 관통`, `MP 흡수`, `관통 효과`, 조건부 확률 판정 등 정형화되지 않은 세부 규칙은 **이름만 같다고 임의 숫자로 적용하지 않음**. `inven_unimplemented_options`에 보존되어 후속 구현 대상을 확인 가능.
- 아이템 획득 경로·몬스터별 드랍 테이블을 임의로 확대하지 않음. 기존 바닥 드랍/자동 줍기 규칙은 그대로 유지.
- 이 PR은 **원본 도감 전체 추가와 검증 가능한 일반 능력치 연동**, **원작 모든 효과가 100% 작동한다는 주장은 아님**.
