# 성물 스킬 레벨 보너스와 통합 main

PR248의 기존 체크포인트 `71ebbeaa4db69e66ba3b1daab6d7ad423deac3a9`를 보존하고, PR263이 반영된 main `918c8e84e6a5ecbe7a071b263751e10899c282a1`과 통합하고, 후속 main `00b84cfe19c05e01d30208384bf7fbcc4ae6bbf2`의 PR266 도구 보호 변경도 보존한다. 후속 main은 런타임 파일을 변경하지 않는다. PR231 소유 브랜치에는 쓰지 않는다. 기존 비용·소유 ID·원본 팩·세이브와 취소한 카드 본체 복원 범위를 보존한다.

우선순위는 원본 → 공개 자료로 확인 → 끝내 없으면 명시한 추정 수치다. 추정 수치를 원문이라고 표시하지 않는다. 사용자 제공 원본 UI를 임의 UI로 대체하지 않으며, 기존 성물/스킬 상세의 정보 표시 경로를 재사용한다.

## 실행 경로와 미완료 경계

119개 원본 스킬 바인딩에 비PvP 증가분35개의 계산/소비 연결이 있다. 최신 일반 스킬팩과 실제 생산 카탈로그를 통제된 소유·직업·무기 상태로 대조하면 **31개 적용 가능, 기존 PC 대상 계약 차단4개**다. 이 카탈로그 검사는31종 모두의 실제 시전을 뜻하지 않는다. 직접 피해·능력치·MP 회복·지속·상태 확률과 아래 발동3/회복3을 포함한다. PvP 감소2개는 별도 능력치로 보존하지만 실제 상대 플레이어 피해 소비자가 없어 완료로 집계하지 않는다. 따라서 현재 차단된 것은PC 대상4개+PvP 소비2개다. 과거37개/대기0개라는 보고는 자체 훈련을 포함한 이전 상태다.

발동 타입18/4의 원작 리덕션 후 증폭·타입1 자식 피해 전체 수식은 복원하지 않았다. 기존 TWILIGHT 패킷에 원문 확률 차이를 투영하는 CUSTOM_BALANCE이며 화면에서 기존 피해 동작 유지와 적용 조건을 표시한다. 미확인 공격 문맥은 증가분을 받지 않는다.

Restoration 정의 부재는 원본1065표·기존 보고서·공식 안내를 대조한 결과다. 기본5%는 확인된 드래곤 포스 증가20%의1/4인 보수적 로컬 설정이며 공식 계수가 아니다. `data/skills/relic_spell_effect_policy.json`의 `restoration_level_estimates`에서 각 enabled/basis/bonus_fraction을 조정하며0~25%로 제한한다. 정확한 root/child/기본·상위 정의 ID를 모두 검증한다. 기존 상세 화면에 ‘TWILIGHT 추정’과 참조·누락 필드를 표시한다.

블랙 핸드345·다크 핸드65638·파워 그립48611·데스 핸드63534는 원문 TargetKindID52(상대 PC)로 최신 일반 스킬 어댑터가 차단한다. NPC로 대상을 확대하거나 차단 이유를 지우지 않는다. 상대 플레이어 정체성·PC 대상 상태/피해 실행 API가 필요하다. `tests/relic_catalog_composition_audit.gd`가119개 바인딩과 실제 생산 카탈로그/일반 팩을 조합해 이 구분을 재생성한다.

과거 자체 PvP 훈련 버튼·HP 차감·전용 저장 우회 함수·정책을 제거했다. 별도 훈련을 원본 대전 소비자 구현으로 집계하지 않는다. 실제 상대 플레이어 정체성과 PvP 피해 엔진은 남은 의존이다.

## PR245/231/249 조합

- 스킬 카탈로그는 현재 main의 `source523.apply_to`로 원본 기본 동작·Category184 자기 회복·부모 비용을 구성한 뒤 성물 레벨 차이를 적용한다. 명시적 source523_block_reason은 강제로 지우지 않는다.
- 부모 MP/재료는 기존 시전 경로에서 한 번 지불한다. 하위 주문을 다시 시전하거나 비용을 한 번 더 청구하지 않는다. 원문/사용자 설정의 기본 회복과 성물 레벨 증가를 분리한다.
- 최신 main의 확장 공격 인자·ordinary_attack 문맥·기존 피해/추가타/장비·토템 처리를 유지한다. 성물 증가분만 확정된 일반 공격 문맥을 받는다. 기존 추가타의 ordinary_attack=false 분류는 바꾸지 않으며 미확인 추가타에 신규 증가분을 확대하지 않는다.
- 최신 main의 `_save_game(quiet, collection_override, movement_override)`와 사망·소유·원본 아이템·지도/저장 보호를 유지한다. 인벤토리 소모가 없는 카드 선택을 공용 퀘스트 성장 소유자 검사가 거부하던 조합 오류를 수정했다. 기존 생산자가 검증한 카드 namespace 하나+HP/MP의 정확한3필드 스냅샷만 호출 동안 소유권을 갖는다. 성공/실패 후 권한은 해제되고 재진입·변조·직접 재사용은 거부한다. 비용·보상·자격 규칙은 이 저장 연결에 추가하지 않는다.
- 임시 카드/슬롯 상태로 상한을 계산할 때 원본 스킬 캐시 갱신이 실시간 HP/MP·버프를 바꿀 수 있으므로, 계산 뒤 실제 기존 상태를 복원하고 저장 성공 후에만 결과를 게시한다. 상한이 실제로 낮아지는 성물 해제의 저장 실패도 검사한다.
- 주 성물의 소환·소유·원문 서버/기간·등급 조건만 일반 스킬 레벨에 사용한다. 추가 성물은 원문 secondary 슬롯 효과만 적용하며 주 성물의 레벨 보너스를 복제하지 않는다. 추가 슬롯 선택·해제·같은 등급 비활성·저장 실패/재진입은 기존 main 경로로 검증한다.

## 자료와 검사

원본 규칙 ZIP은25,031,173bytes, SHA256 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`다. 새 아트 팩을 만들지 않는다. 성물 화면의 ‘원본 규칙 자료 불러오기’로 `user://source_rules/relic-patch523.zip`에 설치한다. Drive 보관은 자동 게임 적용이 아니다.

원본 기본 회복·비용 조합에는 다음 일반 스킬 팩이 필요하다. 설치되지 않은 경우 기존 호스트 기본값에 증가분을 투영하는 호환 경로이며 원본 기본 동작 전체 적용이라고 표시하지 않는다. 현재 main과 조합하는 일반 스킬 팩은 `player_skills523_apply_v3.json` 4,415,307bytes/SHA256 `256f0ba0944e05b86134b40ed3aea97c71e1073b3947ea6e46cb018b6179926a`, 카드 슬롯 팩은 `TWILIGHT_card_slots523_runtime_v1.json` 952,204bytes/SHA256 `98cfdb4f604fba7dad2de41cb290aee3d35087e0d4b805d416a372570dc1cc66`다. 이미 승인된 비공유 Drive 사본을 정식 다운로드·해시/스키마 확인 후 사용한다. 원본·팩·세이브·비공개 링크·캡처를 공개 Git에 추가하지 않는다.

Godot4.7.2 실제 Main/current source84 지도에서 이번 발동3·회복3과 PvP 정보2/주·추가 성물 조합·상한 감소·저장 실패·재접속79검사, 기존 슬롯 터치 UI88검사, 원본 설치 UI26검사, 핵심 Main/저장47검사·동일 payload·deferred-save가 통과했다. 별도 원문 projection1605검사, 카드59매핑288검사, 카드 저장 소유권30검사, 슬롯28·팩 유무6/8검사, Python staging10검사를 확인했다. 실행 로그와 정확한 커밋/실행 파일 해시로 별도 기록한다. 이전 체크포인트의 결과를 새 통합 상태로 재사용하지 않는다. 동적으로 조회하는125개 기존 Git 스킬 SVG(90,970bytes)를 검증용 stage에 바이트 그대로 복원했으며 새 아트가 아니다. 원본 설치 UI/실행/그림 납품을 구분한다. 수동/전체 CI 실행·워크플로/보호 설정 변경은 하지 않으며 `[skip ci]`를 유지한다. 원작 전체 피해식·네트워크 PvP·새 원본 픽셀·실기기 통과를 주장하지 않는다.
