# 성물 레벨 보너스: 남은 8개 실행 연결

기존 PR #248의 같은 브랜치에서 이어 구현했다. 원본과 기존 분석 보고서, 일반 스킬 PR #245의 최신 조사·추정 실행 문서를 대조한 뒤 공식 공개 자료를 확인했다. 새 원본 ZIP을 추정값으로 덮어쓰거나 다른 PR을 병합하지 않는다.

이제 현재 main의 119개 스킬 바인딩 중 **37개에 실제 레벨 보너스 소비 경로**가 있다. 이전 29개에 발동 3개·확인된 자식 회복 1개·명시적 추정 회복 2개·로컬 PvP 훈련 소비 2개를 추가했다. 37개 모두가 원작 전체 실행과 동일하다는 뜻은 아니다. `pending_skills=0`은 아래 로컬 정책으로 실행 경로가 있다는 뜻이며, 원본 `Restoration` 정의 부재와 네트워크 PvP 엔진의 부재를 해결했다는 뜻이 아니다.

미스틱의 빗나감 경로는 원본 Param5=true를 근거로 새로 연결했다. 기존 게임에서 빗나감 발동의 기본 확률은 없었으므로, 이 경로에는 **원본 레벨 차이1%만** 사용한다. 기존 명중 발동 확률15%는 유지하고 성물로16%가 되며, 빗나감은 기존0%→추가1%다. 이 호환 정책을 원작의 전체9% 빗나감 발동 공식으로 표시하지 않는다. `proc_depth`가 재귀 발동을 막고, 취소된 모션은 기존 generation/target-life 검사로 실행하지 않는다.

공식 [마검사 가이드](https://lineagem.plaync.com/guidebook/view?title=마검사+마법)는 룬 블로우의 확률적 물리 증폭 역할을, [뇌신 가이드](https://lineagem.plaync.com/guidebook/view?title=뇌신+마법)는 미스틱의 낙뢰 피해·발동률 강화 역할을 설명한다. [공식 2021-11-24 강화 안내](https://lineagem.plaync.com/board/update/view?articleId=619d433980a0270dff23432e)는 드래곤 포스의 HP 회복량을 강화 대상으로 명시한다. 실제 증가 숫자와 조건은 공개 글의 추측이 아니라 검증된523 원문을 사용했다.

## 정의가 없는 회복 2개: 조정 가능한 추정 증가분

원본1065표와 기존 조사 보고서에 `Restoration` 정의표가 없다. 공개 가이드는 회복 역할을 설명하지만 이 두 레벨의 수치·기준·식은 확인되지 않았다. 따라서 다음 값은 **ESTIMATE / TWILIGHT 추정**이다.

| --- | --- | --- |
| 플라즈마 다이브69601 / 69631 | SpellBonus457871/465101, Restoration2→12 | 기존 회복120에 성물 레벨 +1일 때 최대 HP의5% 추가 |

기본5%는 확인된 드래곤 포스 증가폭20%의1/4로 정한 보수적인 로컬 레벨 증가 설정이다. 공식 숫자가 아니다. 라이프 스트림의 다른 자식95682/Restoration272는 파티원 회복이므로 자신에게 합산하지 않는다. 참조 ID12·242를 회복량으로 쓰지 않는다.

[뇌신 공식 가이드](https://lineagem.plaync.com/guidebook/view?title=뇌신+마법)는 플라즈마 다이브의 일부 HP 회복을, [마검사 공식 업데이트](https://lineagem.plaync.com/board/update/view?articleId=6671e038a12ede529779c000)는 라이프 스트림의 자신·파티 회복과 초과 회복의 보호막 전환을 설명한다. 이것은 역할의 근거이며5% 계수의 출처가 아니다.

설정은 `data/skills/relic_spell_effect_policy.json`의 `restoration_level_estimates`에 있다. 각 항목의 `enabled`, `basis=max_hp`, `bonus_fraction`을 변경할 수 있고 계수는0~25%로 제한한다. 다음 실행에서 읽는다. 정확한 root/child/기본·상위 정의 ID가 모두 일치할 때만 적용한다. 검증된 원본 회복 곡선이 있는 드래곤 포스에는 이 추정 경로를 적용하지 않는다.

실제 스킬 화면의 머리글과 사용 정보·출처 탭에 **TWILIGHT 추정**, 실제 추가 비율, 원본 정의 미확인을 표시한다. 원문 참조·누락 필드는 출처 탭에 남긴다. 기본 비용과 부족 시 무소모 거부, 쿨타임의 중복 시전 거부, 기존 보호막 규칙을 유지한다.

## PvP 감소 2개: 명시적 로컬 훈련 소비

- 브레이브 아머33162/주 버프53772, 썬더 프로텍션69711/주 버프70091의 원문 `PVPDamageReduction` 레벨 차이는 별도 `pvpDamageReduction` 능력치로 계산한다.
- 일반 NPC 피격 경로 `incoming_damage(TwilightMonster, ...)`에는 이 능력치를 추가하지 않는다. 명중·캐릭터 레벨·소유·소환 조건이 확인된 현재 증가분만 계산한다.
- 기존 스킬 상세에 **로컬 PvP 훈련 · 자체 규칙** 버튼을 연결한다. 기존 수량 확인 창에서 기본 피해를 정하고, 원본 성물 스킬의 PvP 감소 증가분만 차감한 HP 피해를 실제 캐릭터에 적용·저장한다. 실제 다른 사람과의 대전이나 원작 네트워크 PvP 엔진이라고 표시하지 않는다.
- 기본 피해100, 입력 상한1000, HP 하한1은 `pvp_training`의 **CUSTOM_RULE** 설정이다. 실제 PvP 대미지 공식의 추정값이 아니라 증가분을 시험하기 위한 로컬 훈련 규칙이다. 아이템·재화 소비와 보상은 없다.
- 전용 `_save_training_hp`는 HP1 이상이며 현재 HP보다 크지 않은 차감만 허용한다. 기존 `_save_game`의 자원 override 허용 목록은 유지하고, 공통 snapshot writer를 재사용한다. 저장 성공 뒤에만 실시간 HP를 바꾸며 실패/취소는 HP·자원을 차감하지 않는다. 기존 확인 창의 committed 보호가 중복 클릭의 이중 차감을 막는다.

`pvp_training.enabled`로 훈련을 끌 수 있다. HP 하한은1 이상으로 제한하고 기본 피해·입력 상한은 설정 가능하다. 낮은 HP에서 사망시키거나 소비 재화를 지급하는 도구가 아니다. 원본의 PvP 증가값과 이 소비 모드는 화면·설정·응답 `classification`에서 분리한다.

## 적용팩과 보관의 경계

이 변경은 새 이미지/음원 팩을 만들지 않는다. 코드·정책은 이 브랜치의 Git 버전으로 제공하고, 게임이 읽는 규칙 팩은 기존 검증 원본523 ZIP과 바이트가 같다. 적용용 파일명은 `relic-patch523.zip`, 원본 보존명은 `lineagem_patch523_all_content_validated_and_508_520_deltas.zip`이다. 둘 다25,031,173bytes, SHA256 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`이며, 별도 버전의 새 데이터가 생겼다는 뜻은 아니다.

승인된 비공유 Drive 프로젝트의 원본 보존 폴더와 성물 규칙 적용 폴더를 구분했다. 적용 사본을 정식 Drive raw-file 응답으로 새 소비 폴더에 내려받아 크기·SHA256·1,075개 ZIP 항목 전체 CRC를 확인했다. 비공유 파일 링크·보관 영수증·화면 캡처는 공개 저장소에 포함하지 않는다.

사용자는 적용 사본을 내려받은 뒤 실제 게임의 성물 화면에서 **원본 규칙 자료 불러오기**로 ZIP을 선택한다. 설치 위치는 `user://source_rules/relic-patch523.zip`이며, 설치 시 같은 고정 SHA를 검증한다. Drive 보관은 자동 다운로드/게임 적용이 아니다. 별도 테스트 프로필에서 실제 파일 선택 UI로 이 새 다운로드를 설치하고 소환·해제·소유/재화/세이브 보존을 확인한다. 원본 보관, Drive 사본 생성, 로컬 다운로드, 실제 설치/로드와 코드 게시는 각각 별도 증거로 기록한다.
