# 같은 지도 자동사냥 이동 정책

원본80개 메뉴·87개 착지와 원본 비용·명시적 최소 레벨을 유지한다.
사냥 영역과 착지 영역을 합치지 않으며 영역ID0에 임의 좌표를 만들지 않는다.

TWILIGHT 자체 좌표 대응은 Land4/Aden과 Land35/용의 계곡 던전5층만 명시적으로 연결한다.
이미 대응하는 활성 지도 안에 있어야 한다. 다른 지도 자동 진입은 지원하지 않는다.
이 대응을 원본 M 좌표·충돌의 동등성으로 주장하지 않는다.

기본 설정은 자체 이동 꺼짐, 끝 셀 포함, 중앙 우선이다.
Gem 잔액 연결과 입장점 주변 허용도 기본은 꺼짐이다.
기존 설정을 읽을 때 값을 보존하며 추가 옵션만 꺼짐으로 보충한다.
설정은 캐릭터 저장과 별도로 보관한다.

원본 착지 영역과 제공 지형의 교집합 안에서만 셀을 고른다.
기존 통행과4px 발 몸체 검사, 몬스터155px 간격, NPC·포탈의 기존64px 기준을 재사용한다.
큰 포탈은 실제 trigger반경과 발 반경도 반영한다.
입장점 옵션은 선언된 입장점의64px 예약만 허용하며 실제 NPC·포탈과 다른 예약은 계속 검사한다.

후보 검사는 최대4096셀이다. 선택한 셀은 기존 저장·재진입 경로 검사도 통과해야 한다.
검사 미통과는 기존 탐색 상한을 포함한 결과이며 지역 전체가 단절됐다는 증명은 아니다.
통행 비트나 기존 저장 검사를 바꾸어 이동을 통과시키지 않는다.

저장 직전에 자격·재화·점유·설정·목적지를 다시 확인한다.
목적지와 정확한 비용을 기존 원자적 저장기로 함께 저장한 뒤 실제 위치와 재화를 반영한다.
실패는 위치·아이템·재화·경로·실시간AUTO 및 기존 저장 바이트를 보존한다.
이미 같은 착지 범위 안이면 추가 비용과 저장 없이 거절한다.
원본 버프·소환을 지우는 전체 전투 초기화도 호출하지 않는다.

최종 실제 Main의 아데나185검사에서20목적지를 모두 실행했다.
정책·경계·설정·점유29검사와 UI10검사도 통과했다.
검증 요약은 [공개 검사 요약](source35_validation.json)에 있다.
