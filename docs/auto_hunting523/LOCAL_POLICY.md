# TWILIGHT 아덴 자동사냥 지역 이동

PR235의 기존 환경·브랜치에서 원본 계약 조사 뒤 추가한 자체 정책이다.
현재 아덴의 같은 맵 이동을 실제 게임 메뉴 → 자동사냥 화면에서 실행한다.
원본 M 좌표·통행·서버 입장 조건의 재현으로 주장하지 않는다.

## 사용과 설정

원본 팩 설치는 [상위 문서](../AUTO_HUNTING523.md)를 따른다. 기존 아덴 source-map 팩도 필요하다.
자동사냥 창에서 **TWILIGHT 자체 이동 사용**을 켜고 지역을 선택한다.
기존 AUTO 전투 스위치는 별도이며 지역 이동 성공/실패가 이를 켜거나 끄지 않는다.
비용/최소 레벨/현재 차단 사유를 확인한 뒤 **선택 지역으로 이동**을 누른다.
**조건 확인**으로 재화·상태·현재 점유를 다시 확인할 수 있다. 이동 클릭 때도 재검사한다.
이동 버튼은 지역 선택/결과 바로 아래에 있고, 기존 창의 스크롤로 나머지 설정을 사용할 수 있다.

별도 `user://auto_hunting_local_policy.json`에 다음 설정을 원자적으로 보관한다.
기존 캐릭터 저장의 스키마나 원본 팩에는 설정을 추가하지 않는다.

| 설정 | 기본 | 의미 |
| --- | --- | --- |
| 자체 이동 사용 | 꺼짐 | 현재 아덴에서 이 별도 정책을 사용한다. |
| 끝 셀 포함/제외 | 포함 | 원본 Start/End 정수를 현재 셀 범위로 해석하는 자체 선택이다. M 규약 확정값이 아니다. |
| 중앙 가까운 셀/좌표 순서 | 중앙 우선 | 범위와 제공 지형의 교집합에서 후보를 나열한다. 이동 경로 생성이 아니다. |

원본 Land4/AssetPath `Aden/`의 사각형 정수를 현재 아덴 셀에 대응하는 것은 자체 가정이다.
실제 활성 필드는 `source_map_runtime_field`의 로컬 아덴이어야 한다.
다른 Land, 다른 활성 지도, Gem은 이 정책에 묶지 않는다. 원본 비용/MinLevel은 바꾸지 않는다.
미해석 M `LandAttribute/Allow*` 및 실시간 자격을 원본과 같게 적용했다는 뜻도 아니다.
자체 설정의 손상/저장 실패는 비활성/이전 설정 유지와 실제 UI 결과로 표시한다.

## 셀·저장 보존

후보는 원본 착지 영역과 실제 제공 지형 안에 있어야 한다. 사냥 영역이나 0 센티널을 목적지로 쓰지 않는다.
기존 좌표 API의 셀 중심·4px 발 몸체, 활성 지형 통행/몸체 검사,
기존 순간이동의 몬스터155px 간격, NPC/포탈/입장점 예약 반경을 그대로 사용한다.
통행 비트·문 상태·맵 데이터·원본은 수정하지 않는다. 범위 밖 스폰/임의 좌표로 복귀시키는 대체 착지도 없다.

후보 탐색은 최대4096셀이다. 선택한 첫 안전 후보에 기존 `SOURCE_MAP84.valid_position`을 적용한다.
이 검사는 기존 시작점→착지 경로 탐색/캐시/탐색 상한을 포함한다.
실패는 **기존 저장·재진입 경로 검사 미통과**이지, 그 지역의 모든 셀이 물리적으로 단절됐다는 증명이 아니다.
다른 후보 순서를 선택할 수 있지만 모든 후보의 경로를 무제한 검사하지 않는다.
기존 저장 검사를 완화하거나 경로를 창작해 이동을 통과시키지 않는다.

성공 트랜잭션은 다음 순서를 지킨다.

1. 원본 소속/비용/최소 레벨, 자체 설정, 현재 지형/점유, 사망·스턴·공포·홀드·돌진, 저장 보호를 검사한다.
2. 저장 직전에 같은 판정을 재실행하고 같은 목적지/지형 revision/비용/설정인지 비교한다.
3. 기존 원자적 저장기로 목적지 픽셀·동일한 원본 좌표 표현과 `gold - 원본 비용`을 함께 저장한다.
4. 저장 성공 후 실제 위치/아데나를 반영하고 일시적 공격·이동 경로·타깃만 정리한다.

실패 시 위치·아데나·아이템·AUTO·경로·기존 저장 바이트를 유지한다.
이동 중 재진입 호출은 BUSY이며, 이미 같은 착지 범위 안이면 비용/저장 없이 거절한다.
맵 이전 후보 저장이 미활성 상태면 먼저 정상 저장을 요구한다.
버프/소환을 없애는 전체 전투 초기화는 호출하지 않으며 바닥 드랍 지급도 만들지 않는다.

## 실제 검증

Godot4.7.2 실제 Main·현재 아덴 팩·실제523 private팩과 별도 사용자 프로필로 실행했다.
Lv99/충분한 아데나, 끝 셀 포함·중앙 우선, 해당 시점 점유 상태에서87개 착지를 판정한 결과다.
이 집계를 모든 레벨/점유/선택 설정에서 고정된 허용 목록이라고 사용하지 않는다.

| 결과 | 착지 연결 수 |
| --- | ---: |
| 안전 셀·기존 저장 경로 통과, 실제 이동/원본 요금/저장 실행 | 20 |
| 선택한 셀의 기존 저장·재진입 경로 검사 미통과 | 20 |
| 제공 아덴 지형 밖 | 7 |
| 범위 안 안전 셀 없음 | 2 |
| 원본 Gem, 지원 재화 원장 없음 | 23 |
| 아데나이지만 다른 Land 필드 미연결 | 15 |

원본 아덴·아데나 메뉴49개 중20개가 위 설정에서 실행됐다. 다른 Land의15개 착지는8개 메뉴다.
모든 안전/저장 가능 목적지를 실제 action→원자적 저장 경로로 실행했다.
테스트 사이 actor만 이미 검증한 입장점으로 되돌려 겹치는 도착 영역이 실행을 생략하지 않도록 했다.
게임 런타임에는 이 시험 초기화나 좌표 강제 이동 코드를 넣지 않았다.

- 실제 Main/OpenGL/Xvfb/llvmpipe:186검사 통과. 전체87개 판정,20개 실제 이동·원본 비용·저장,
  비용 부족/스턴/홀드/공포/사망/이전 후보/점유 실패, 주입한 저장 실패에서 상태/바이트 보존,
  중복/재진입 거절, 실제 재로드, 기존 AUTO 창의 설정/실행/결과/다시 열기를 포함한다.
- 최종 추가 스크롤 연결: 실제 UI/창 클래스와 작은 대체 API를 사용한 집중10검사 통과.
  드래그 비용 지출/설정 변경 거절과 다음 정상 클릭/옵션 선택 복구를 확인한다. Main 이동 검사의 대체가 아니다.
- 자체 정책 합성 기하/설정21검사 통과. 경계 포함/제외, 범위 교집합, 빈 영역/모두 막힘,
  탐색 상한, 설정 손상/쓰기 실패/재개를 포함한다. 원본 M 통행 증거로 계산하지 않는다.
- 기존 실제 원문 Python7테스트, 카탈로그231검사, 정책 기본 꺼짐의 실제 Main/UI262검사 통과.
- 최종 기존 Main·맵·세이브32검사, 동일 저장 중복 쓰기/deferred-save 회귀 통과.
- 723시트/41,442프레임 실제 추적/바이트 SHA 무결성 통과.

OpenGL1280×720 캡처를 실제로 열어 이동 버튼·비용·자체 정책 문구·이미 도착 결과를 확인했다.
UI 조작은 엔진의 실제 컨트롤 신호로 검증했으며 OS 포인터/터치 실기기 시험은 아니다.
이동과 저장은 실제 Main 객체·실제 지형·실제 파일 쓰기를 사용한다.
경로 전수 검사 때문에 이 시험은 단일 목적지 시험보다 오래 걸린다. 기기 FPS 보증은 하지 않는다.

실패 진단도 남긴다. 초기 합성 fixture의 누락 메서드를 수정했고,
처음 전수 이동은 몸체 통행만 확인한 셀 일부가 기존 저장 경로 검사에 거부되어 중단했다.
그 실패가 저장 보호를 확인했으며, 최종판은 같은 검사를 활성화 판정에 추가했다.
최종 실행에는 파싱·리소스·런타임 오류가 없고, llvmpipe V-Sync 미지원 경고만 별도 기록했다.
검증 영수증: [local_policy_validation.json](local_policy_validation.json).

## 남은 연결

M 원작 좌표·영역 끝·충돌·발 위치 계약은 미확정이다.
최신으로 읽은 PR232 `ac18b15ed55256c99512836cd571745df73214f8`도 원문 설치/표시이며 별도 자체 플레이를 작업 중이다.
현재 아덴 기반20개 성공을 M 원문87개 이동 성공으로 승격하지 않는다.
기존 저장 경로 미통과20개는 원래 탐색의 한계/연결 여부를 더 조사해야 한다.
지형 밖7개와 안전 셀 없는2개는 다른 검증된 지형/범위 설정이 필요하며 셀을 임의로 열지 않는다.
다른 Land8메뉴는 원본 ID/AssetPath와 실제 필드의 명시적 대응·동일한 저장 계약이 필요하다.
Gem23메뉴는 실제 보유 재화/소모 트랜잭션이 필요하며 아데나로 환산하지 않는다.

main/다른 PR은 병합하지 않았다. 같은 draft PR235만 갱신하며 수동 CI는 실행/재실행하지 않는다.
커밋의 `[skip ci]`와 로컬 직접 검사는 별개이고, 원격 필수 CI 성공이나 병합 준비 완료를 주장하지 않는다.
