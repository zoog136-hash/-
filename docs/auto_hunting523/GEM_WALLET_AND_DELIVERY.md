# 원본 Gem 비용과 인벤토리 잔액 연결

확인한 원본 Gem은 CurrencyID4이고 한국어 이름은 다이아다.
원본 금액과 명시적 최소 레벨을 사용한다. 다른 재화로 환산하지 않는다.

기존 HUD는 인벤토리의 다이아 수량을 표시한다.
이 잔액을 Gem4에 대응하는 것은 별도로 표시한 TWILIGHT 자체 정책이다.
AUTO 창의 잔액 연결 옵션으로 켜고 끌 수 있으며 기본은 꺼짐이다.
코드·규칙팩을 설치한 뒤 옵션을 켜야 사용하며, 리소스 보관이 자동 설치를 뜻하지 않는다.

새 재화와 초기 잔액을 지급하지 않는다.
비음수 정수인 기존 잔액만 소모하고 사용자 잠금과 물리 아이템 ID가 연결된 다이아는 보호한다.
목적지와 수정된 인벤토리를 함께 원자적으로 저장한 뒤 실제 이동과 잔액을 반영한다.
0까지 소모하면 잔액 키를 지우며 재접속 때 다시 지급하지 않는다.
아데나·다른 아이템·물리 장비 ID는 유지한다.

원본 Gem23메뉴 모두 재화 조건을 판정한다. 지도·경로·점유 검사는 별도다.
같은 활성 아덴 지도에서 Gem3목적지의 이동·원본 비용·저장을 검증했다.
기존 Land35 안의 Gem1목적지는 [별도 지도 정책](SOURCE35_AND_ACTOR_CLEARANCE.md)을 따른다.

실제 Main Gem79검사에는 옵션 취소·부족·잠금·저장 실패·중복 차감·재접속·잔액0과
아데나 지출의 독립성을 포함한다. 실제 원문8테스트·카탈로그231검사·지갑108검사도 통과했다.
UI는 원본 비용과 현재 잔액, 실행 결과를 표시한다.
검증 요약은 [공개 검사 요약](gem_wallet_validation.json)에 있다.
