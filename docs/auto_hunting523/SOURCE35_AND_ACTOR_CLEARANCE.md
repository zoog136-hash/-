# 기존 Land35와 착지 점유 검사

원본 메뉴474/착지1412는 Land35, AssetPath35/, 용의 계곡 던전5층이다.
기존 게임의 source_35도 같은 이름과ID이며 이미 지도 정책에 등록돼 있다.
이 기존 지형과 원본 착지 영역을 대응하는 동작은 TWILIGHT 자체 정책이다.
이름·ID 일치와 게임 내 검사 성공을 원본 M 좌표·충돌 동등성으로 주장하지 않는다.

현재 source_35 안에 있어야 메뉴474를 사용할 수 있다.
아덴에서 누르면 지도 불일치로 거절한다. 기존 지도 이동 경로로 먼저 입장해야 한다.
맵 간 자동 진입이나 임의 도착점은 추가하지 않는다.
원본 Gem4와 비용10을 사용한다.

착지 영역의 셀은 통행·몸체·기존 저장 경로 검사를 통과하지만 입장점64px 예약과 겹친다.
별도의 입장점 주변 허용 옵션은 기본 꺼짐이며 그 예약만 선택적으로 허용한다.
지형·4px 몸체·몬스터155px·실제 NPC·포탈 및 다른 예약은 계속 검사한다.
기존 설정은 보존하고 새 옵션만 꺼짐으로 읽는다.

나중에 설치된 NPC가 예약 배열에 없을 수 있으므로 실제 설치 좌표 목록도 직접 확인한다.
기존64px 기준을 재사용하며 포탈에는 실제 trigger반경과 발 반경도 반영한다.
입장점과 같은 위치에 NPC·포탈이 있으면 옵션을 켜도 착지를 거절한다.

실제 Main/OpenGL28검사에서 같은 지도 이동·원본10Gem·저장 실패 보존·중복 차감 거절·
재접속·UI 재개를 검증했다. 아데나와 기존 아덴 Gem 이동의 독립성도 확인했다.
현재 코드의 아데나185검사는20목적지, 아덴 Gem79검사는3목적지를 모두 실제 실행했다.
정책·기하·점유29검사, Gem108검사, UI10검사가 통과했다.
UI는 엔진 컨트롤 신호 기반이며 OS 포인터·터치 실기기 시험과 구분한다.

나머지 Land와 맵 간 자동 이동, 원본 M 동등성은 미완료다.
안전한 셀이나 검증된 지도 대응이 없으면 계속 차단한다.
검증 요약은 [공개 검사 요약](source35_validation.json)에 있다.
