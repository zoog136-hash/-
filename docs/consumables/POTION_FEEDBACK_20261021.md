## 실제 적용 코드

`Main.tscn`은 기존 `scripts/world.gd`를 그대로 상속하는 작은 `scripts/potion_feedback_world.gd` 표현 어댑터를 사용한다. HP 계산·수량 차감·쿨타임·자동사용·세이브 코드를 복제하거나 수정하지 않는다. 원래 사용 함수를 먼저 실행한 뒤 실제 성공한 경우에만 빛을 재생한다.

- HP: 실제 HP 증가 + 정확히 1개 소모를 모두 확인한다. 일반 적색 / 고급 주황 / 강력·상급 백금빛.
- 마나 재생 물약: 버프 사용 성공 시 청색. 주기적인 MP 회복 틱에는 재생하지 않는다.
- 마녀의 마력 회복제: 인벤토리·퀵슬롯의 실제 소모와 MP 증가 확인 후 청색.
- 시간제 물약: 초록·가속 녹색, 용기 금색, 기타 물약 보라색. 음식·주문서·드래곤 보석에는 적용하지 않는다.
- HP 만땅 / 수량 없음 / 재사용 대기 / 사용 제한 등 실패에는 새 효과 없음.

`TwilightPotionFeedback`은 플레이어 자식 1개를 최초 사용 시 만들고 계속 재사용한다. 한 종류 반복 사용은 갱신, 동시 표시 최대 3개, 자체 조정 수명 0.48초. Additive 후광·작은 상승광이며 전체 화면 번쩍임 없음. 게임 RNG·카메라·전투 노드 풀·공격 타이밍 변경 없음. 기존 impact_intensity와 reduced_motion/effect_detail을 존중한다. 이동 중 플레이어를 따라가며 전투 세대 변경(맵/불러오기/사망), 사망 상태, 큰 순간이동에서 잔광을 제거한다.

## 원본과의 구분

기존 조사에 기록된 PC 계열 물약 색 분류를 참고한 **TWILIGHT 자체 코드 연출**이다. `189`~`198`의 원본 SPR 픽셀을 확보하거나 추출해 넣은 것이 아니다. 리니지M 원본과 동일한 색·시간·프레임 재현으로 표시하지 않는다. 새 외부 이미지·폰트·음원·바이너리 0개이며 기존 생성 글로우 캐시만 재사용한다. 기존 원본 전달 장부는 변경하지 않는다.
