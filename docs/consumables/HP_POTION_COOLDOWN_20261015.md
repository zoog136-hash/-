# TWILIGHT HP 물약 공통 재사용시간 (2026-10-15)

## 적용 규칙

- 일반 HP 회복 물약의 재사용시간은 **종류에 관계없이 1.0초 공통**이다. `item_use_cooldowns["__hp_potion_shared__"]`에 남은 시간을 저장하며 기존 버프/아이템 쿨타임 틱에서 감소한다.
- 퀵슬롯 자동사용, 인벤토리 수동사용, 기존 HUD 물약 버튼이 동일한 재사용 제한을 적용받는다.
- HP가 가득 차거나 수량이 없거나 재사용 대기 중이면 물약을 소비하지 않는다. 다른 HP 회복 물약으로 바꾸어도 기다려야 한다.
- 자동사용 후보 검색은 공통 HP 재사용 대기 중 HP 물약을 건너뛰므로, 다른 종류의 MP 회복제와 유지 버프까지 막지 않는다.
- **자동사용 검사 주기 0.2초**와 **HP 회복 물약 재사용시간 1.0초**는 서로 다른 값이다.
- 사용자는 설정 > 소모품 자동 사용에서 HP 사용 ON/OFF 및 HP 임계 비율 5~95%(5% 단위)를 조절할 수 있다. 기본값은 HP 70% 이하이다.
- 일반 MP 30% 이하, 긴 재사용 MP 20% 이하/기본 OFF 등 기존 설정을 유지한다. 마녀의 마력 회복제 1,800초 재사용 대기는 변경하지 않는다.
- `item_use_cooldowns` 저장과 복원은 기존 경로 그대로 사용하며 세이브 포맷은 확장하지 않는다.

## 자동 테스트

`tests/consumable_auto_safety_test.gd`에서 공통 1초 재사용 대기의 생성, 동일 물약 연속 사용 방지, 서로 다른 HP 물약 간 공유, 수동/자동 교차 차단, 1초 경과 후 재사용, 사용자 설정 50% 기준 작동을 검증한다.

## 검증 경계

GitHub PR의 `Consumable Validate` CI에서 Godot 4.7.2 import와 실제 `Main.tscn` 자동 테스트가 성공해야 완료로 간주한다. 모바일 실기기와 시각적 쿨타임 표시 여부는 이 변경 범위에서 검증하지 않았다.
