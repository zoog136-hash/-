# 원본 523 아이템 사용·장착 연결 점검

`00feac743da64ded8816608bcabec3f747ce31a7`의 아이템 경로를 기준으로, 해당 빌드에서 SHA가 고정된 원본 정의 ZIP의 `ItemClass`, `ItemCategory`, `ItemEquipSlot`, `ItemBonus → Bonus → BonusType`을 대조했다. 원본 파일은 저장소에 포함하지 않았다.

`ItemClass` 34,743행 중 `TestItem=false`는 30,398행이다. 이 중 `ItemEquipSlot`에 기록이 있는 고유 아이템은 2,964종이다. 이 수치는 원본 정의 수다. 기간이 만료되거나 더미 이름·선언이 남은 행, 설치된 자산이 없는 행, TWILIGHT가 그 효과를 실행하지 않는 행도 포함될 수 있다.

## 이번 변경

원본 `ItemClass 4151` 엘릭서는 `BonusStatRecharger` 분류이며, 레벨 50부터 자기 자신에게 사용하고 `ItemBonus → Bonus 93441`이 일반 스탯 +1을 명시한다. 기존 일반 엘릭서에는 선택 UI가 있었으나 원본 물리 수량은 `current523_native_stack`의 보관용 분기에서 막혔다. 원본 엘릭서를 기존 선택 화면으로 연결하고, 선택한 물리 수량 한 개 차감과 영구 스탯 +1 및 공용 사용 횟수를 같은 저장에 반영한다. 재확인 시 정확한 수량·영수증·잠금·사용 조건을 검증한다. 캐릭터당 10회, 스탯당 최대 45라는 기존 TWILIGHT 규칙을 공유한다. 이 한도는 원본 자료에서 확정한 수치가 아니다.

## Main 실행 표본

기사 캐릭터와 원본 정의 ZIP으로 32종을 실제 가방 경로에서 확인했다. 무기 2종·신발·목걸이는 선택한 물리 개체가 장착됐고, 속성 강화 주문서 #2711은 기존 강화 화면을 열었다. 원본 엘릭서 #4151은 아래 별도 거래 테스트에서 스탯 선택과 소비를 검증한다. 24종은 보관 또는 사용 보류로 응답했고 가방 수량이나 효과가 바뀌지 않았다. 테스트 표시가 있는 다른 성장 재료 2종은 지급 단계에서 거절됐다. 이 표본에서 장착을 통과한 아이템의 모든 착용 발동이나 강화 결과를 검증한 것은 아니다.

`tests/item_use523_owned_elixir_test.gd`의 22개 검증을 모두 통과했다. Godot 4.7.2 PC에서 실제 Main과 원본 ZIP을 사용해 레벨 제한, 선택 취소, 캐릭터·스탯 한도, 잠금, 저장 실패 시 저장 바이트 보존, 성공 시 1회 차감·1회 증가, 오래된 확인 재사용 거부, 재접속 후 보유량과 능력치 유지까지 확인했다. Android는 미검증이다.
