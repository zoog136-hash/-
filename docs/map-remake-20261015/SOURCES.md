## 공개 리니지M 자료 대조

- [신념의 탑 공식 JP 안내](https://lineagem-jp.com/guides/lm/guides/dungeon_TowerofBelief): 1층 어두운 석판/쇠사슬, 2층 녹색 유기적/거미줄 환경, 3층 장식 석판·보라색 궁전, 4층 붉은 카펫·청록 구체·금속 기둥을 화면에서 확인했다. 기존 TWILIGHT의 빛의 회랑/순례자의 정원 등 명칭과 장식은 동일하다고 입증되지 않았다. 아직 바꾸지 않았다.
- [지배의 탑 공식 JP 안내](https://lineagem-jp.com/guides/lm/guides/dungeon_TowerofDomination): 오만과 별도 콘텐츠임을 확인. 12862와 현재 KR 정상의 지형/좌표는 미검증이다.
- [에스카로스 공식 JP 안내](https://lineagem-jp.com/guides/lm/guides/Ezkaroze): 5개 조각상과 게이트 진행 규칙 참고. 기존 TWILIGHT 5구역의 상세 격자 대응 근거는 아니다.
- 알비노 공개 구역 자료는 1구 늪지, 2구 폭포, 3구 유황으로 표시한다. 기존 1구의 백색 수정굴과 4구 별빛 석실을 원작 특징이라고 간주하지 않는다. 현재 KR 4구역의 정확한 구조는 미확인이다.
- 제공 묶음의 `tower_of_insolence_01.jpg` 화면에는 `不信のシアー`가 나타난다. 파일명만 보고 오만 1층 지형 근거로 쓰지 않았다. Eodin 예배당 화면도 신념의 탑으로 재분류하지 않았다.

현재 참고 화면은 권리 확인 없는 상용 타일/스프라이트로 공개 Git에 넣지 않는다. 공개 저장소에는 출처·해시·검증 보고와 TWILIGHT 자체 아트로 실제 렌더한 증거만 보존한다.
