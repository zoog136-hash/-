## 좌표·판본의 한계

원본 파일 헤더의 정수 서버 원점은 검증했다. 기본 투영은 L1MapViewer를 근거로 `world = translation + (source-origin).x * (24,-12) + (source-origin).y * (24,12)`를 사용한다. 각 셀의 중심은 0.5 오프셋이며 발·충돌·NPC·포털에 같은 변환을 사용한다. 역변환, 반전·비정방 크기·별도 배율, 왕복 오차와 잘못된 행렬 거부를 검사한다.

101/102/103/110 원점은 (32704,32704), 104–109는 (32576,32768)이다. 모두 192×192이지만 10개 원본 해시는 서로 다르다. 오만 1층 출구 자료 세 행은 PC 원본 관측값이지 리니지M 기준점 세 개가 아니다. 2–10층의 시작점은 연결 영역에서 선택한 **임시 진입점**이다. 현재 리니지M과 대조한 독립 기준점은 모든 맵에서 0개다.

NPC, 일반/폭젠/보스 구역과 포털의 위치는 `provisional`이다. 기존 게임 설정의 종류·서비스·수량·조건을 원본 통행 영역에 옮긴 것이며 원작 스폰 좌표를 복원한 것이 아니다. 보스와 일반 구역을 분리하고 진입점·NPC·포털 예약 반경에서 생성하지 않는다.

## 시각 결과의 정확한 범위

기존 TWILIGHT 바닥 아틀라스를 재사용했다. 바닥 UV와 조명은 청크 경계를 가로질러 연속이며, 막힌 경계에는 낮은 석축을 표시한다. **실제 벽/철제 난간/절벽/잔해의 의미를 식별하지 못했으므로 이 석축 표현은 최종 아트가 아니다.** 원본 통행 차단만으로 금색 난간이나 반복 기둥을 배치하지 않았다. 현재 결과는 PR108의 구조물 시각 품질 기준을 충족했다고 평가하지 않는다.

캡처의 `full-map`, `placements`, `boss-area`, `same-camera-detail`은 기존 Main을 정지한 **2D 진단 렌더**다. 미적용 15개는 기존 맵 화면이다. 실제 이동·전투 캡처는 별도 `gameplay` 증거이며 테스트 캐릭터의 레벨/HP만 검증용으로 설정했다. 보스는 기존 DB와 AI를 사용했다. 전투 구역까지의 경로를 검사한 뒤 QA 좌표 이동을 사용했으므로 입구부터 보스까지 수동 완주한 영상은 아니다.

전후 확대 비교는 카메라의 **동일 월드 픽셀·줌·뷰포트**를 검증한다. 레이아웃 자체가 바뀌었으므로 같은 원작 지형 기준점의 정합 비교라고 주장하지 않는다. 전체 지도는 축소된 실제 렌더이며, 스트리밍 밖 세부 오브젝트까지 전수 검사했다는 뜻은 아니다.

## 재개 순서

1. [HANDOFF.md](HANDOFF.md)의 같은 브랜치를 사용한다. 최신 main과 PR100 상태를 다시 확인한다.
2. 원본 A3 ZIP 해시를 확인하고 비공개 팩을 복원한다. 기존 팩이 있으면 다시 1,000개를 복구하지 말고 검증/재사용한다.
3. 오만 1층의 구조물 의미와 시각 품질부터 보완한다. 현재 리니지M 기준점 3개 이상과 권한 있는 아트가 확보되기 전 정확한 원작 복원으로 표시하지 않는다.
4. 오만 그룹의 층별 벽/난간/기둥 및 배치 근거를 추가하고 검증한다. 이후 아덴의 지형 의미/S32 타일 참조와 현재 M 지리를 교정한다.
5. 지배 정상, 에스카로스, 알비노, 신념은 판본·지형 대응을 확인한 다음 적용한다. 무관한 1,000개 원본 ID를 끼워 넣지 않는다.
6. 변경 그룹 검사 → 실제 화면 → 공통 변경 시 전체 회귀 순서를 유지한다. 실패 로그는 삭제하지 않는다. 전체 25개 완료 조건 전에는 Draft를 해제하거나 main으로 병합하지 않는다.
