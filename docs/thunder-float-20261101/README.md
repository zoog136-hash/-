## 이동만 수정한 내용

사용자의 다리 과도 굽힘 지적에 따라, 종아리를 위로 접어 발을 무릎 높이까지 올리던 방식을 풀었다. 여성 원화의 골반·무릎·발목 위치에 맞춰 **무릎은 조금 굽히고 발은 무릎 아래·뒤쪽에 유지**한다. 완전히 선 자세를 평행 이동하거나 양발 교대 RUN을 사용하지 않는다.

앞서 수정한 창/허벅지 잔여 픽셀 분리와 망토의 다리 가림 원칙을 여성 원화에 맞게 유지한다. 여성의 두 다리를 각자 UV 영역으로 분리하여 창의 금색 테두리와 내부 망토가 다리와 함께 늘어나는 문제를 줄였다. 상체/창은 같은 변환을 받고 앞쪽 망토는 다리 위에 그려진다.

게임 이동속도·타격 시계·공격·대기 애니메이션·공통 RUN은 변경하지 않았다. 검수 장면의 210px/s 이동 구간, 진입/종료 시간과 부유 높이도 유지했다. 시작/끝의 그림은 기존 여성 왼쪽 시트 자세이며 새 대기 애니메이션이 아니다. 본게임 대기 연결 완료를 의미하지 않는다.

이번 동작은 기존 시트로 새로 제작한 부유 이동이다. 원작에서 추출한 부유 프레임이나 승인된 독립 8방향 동작으로 주장하지 않는다. 새 생성 이미지나 다른 캐릭터 아트는 사용하지 않았다.
