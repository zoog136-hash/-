# 신화 뇌신 283 — 왼쪽 부유 이동 보완 (Draft)

대상은 `transform:283`, `신화-뇌신(남)` 하나다. 기존 `assets/directional/transform/283.webp`의 왼쪽 방향 첫 칸 `(0,384,192,184)`을 읽어 **부유 이동만** 보완한다. 원본 시트와 원래 공격·대기·공통 RUN·게임 속도·타격 시계·저장 데이터는 변경하지 않는다. 기존 정면 그림을 회전하여 측면이라고 표시하지 않는다.

## 이전 실패와 이번 변경

Library 버전 0은 정면 사선 원화가 왼쪽으로 미끄러지고, 다리가 앞/아래로 접혀 앉거나 쪼그리는 자세처럼 보였으므로 실패로 유지한다.

이번에는 기존 시트의 실제 왼쪽 방향 그림을 사용한다. `existing_connected_source_count: 0`은 연결 목록이며 원화 부재 증거가 아니었다. 해당 목록과 파일명만으로 측면 자료가 없다고 한 초기 판단을 정정한다. 시트를 직접 펼쳐 왼쪽 방향의 얼굴·몸·장비·망토를 확인했다. 여성 신화 뇌신 `413`이나 다른 캐릭터를 대체하지 않았다.

- 무릎은 골반 아래/뒤쪽에 두고 두 종아리와 발을 진행 방향 반대인 화면 오른쪽으로 접는다. 발 교대 보행 위상은 없다.
- 망토를 별도 앞 레이어로 그려 뒤로 접힌 다리를 일부 가린다. 망토 끝과 머리카락은 상체보다 늦게 반응하고, 몸통은 작은 기울기/부유 변화를 받는다.
- 창은 동일한 몸통 변환을 받는 별도 레이어로 유지한다. 창 끝이 다리와 함께 접히는 현상을 방지한다.
- 검수 장면의 이동 위치는 접힘 진입 정도와 같은 smoothstep의 적분으로 진행한다. 210px/s 도달/감속이 부드럽게 이어진다. 게임 이동 코드는 변경하지 않는다.
- 시작/끝에는 기존 왼쪽 원화 자세를 그대로 표시한다. 새 대기 애니메이션이 아니다. 본게임의 대기 상태 연결 완료를 의미하지 않는다.

측면 보완 가능성을 조사하며 생성한 새 그림은 **채택하지 않았다**. 최종 장면·영상·커밋은 기존 283 시트만 사용하며 새 바이너리 아트를 추가하지 않는다. 최종 부유 동작은 새 제작이며, 원작 게임에서 추출한 부유 프레임이라고 주장하지 않는다.

사용자 지정 참조 `libfile_a5ae1e4a123081918cfe640831a7b2f2`, version 0을 현재 환경에서 직접 materialize했다. 7.10–7.55 및 8.30–9.05초의 왼쪽 이동과 뒤로 접힌 다리/망토를 확인했다. 날개 자료가 아니다. 자료명과 별도로 영상만으로 이름·등급·성별을 독립 확정했다고 주장하지 않는다.

남은 한계는 무릎/창 분리 경계의 작은 텍스처 왜곡, 기존 저해상도 시트의 확대 흐림, 실제 참고 영상과의 세부 실루엣/망토 양감 차이다. 몸과 장비의 동일 변환을 사용하므로 완전히 분리된 상체 관절 연기는 아니다. 자연스러움 최종 승인은 보류한다.
