# 신화 뇌신 283 — 부유 이동 연구 (Draft, 미승인)

대상은 저장소 `transform:283`, `신화-뇌신(남)`이다. 다른 부유 캐릭터를 대체하지 않았다. `assets/catalog/f82cc8301ecf2848b139f0d3.png`의 기존 108×132 RGBA 원화를 참조하며 원본 파일은 수정하지 않는다. 여성 신화 뇌신 `413`은 변경하지 않았다.

이 변경은 **부유 이동만** 다룬다. 공통 지상 RUN, 공격, 공격 시계, 이동 속도, 저장 데이터, 기존 대기 애니메이션은 변경하지 않는다. 검수 장면 시작/끝의 자세는 원화를 정적으로 표시한 것이며 새 대기 애니메이션이 아니다. PR215 코드나 미승인 `upper_body_targets.gd`를 가져오지 않았다.

## 참조와 구현

- 사용자 지정 참조 `libfile_a5ae1e4a123081918cfe640831a7b2f2`, version 0. 현재 환경에서 직접 내려받아 7.10–7.55, 8.30–9.05초 이동 및 9.20/9.80초 정지 구간을 프레임으로 확인했다. 양다리를 뒤로 접고 망토가 뒤따르는 모습이며 날갯짓 자료가 아니다. 영상 파일명이 신화 뇌신인 점과 별도로, 영상만으로 등급/이름/성별을 독립 확정하지는 않았다.
- 이동 시 두 무릎을 함께 접어 유지한다. 양발 교대 지상 보행 위상을 사용하지 않는다. 상체와 창은 동일한 기울기/부유 오프셋을 쓰고 망토는 작은 후행 변형을 받는다.
- `apply_movement(amount, elapsed)`는 0..1 이동 진입 정도와 연속 시간만 받는 독립 2D 표시 API다. 게임플레이와 연결하지 않는다.
- 새 원작 프레임을 얻은 것이 아니다. 기존 원화를 UV 메시와 창 마스크로 변형한 새 제작 동작이다.

## 실행

Godot 4.7.2 Compatibility:

```sh
godot --path . res://scenes/dev/MythThunderFloat283.tscn
```

6초/180프레임 30FPS 캡처:

```sh
godot --path . --write-movie /tmp/thunder283.avi --fixed-fps 30 res://scenes/dev/MythThunderFloat283.tscn -- --float-capture
ffmpeg -i /tmp/thunder283.avi -c:v libx264 -crf 18 -pix_fmt yuv420p -an /tmp/thunder283.mp4
```

상단은 현재 게임 캐릭터의 약 84px 가시 높이에 맞춘 작은 보기(원화 scale 0.70), 이동 210px/s다. 하단은 원화 3배 검수 보기다. 이동 진행 방향은 화면 왼쪽이며 **캐릭터 그림은 기존 정면 사선 투영**이다. 왼쪽 측면 원화나 독립 8방향으로 표시하지 않는다.

## 검수 결과와 미완료

Godot 4.7.2 OpenGL(llvmpipe)에서 1280×720, 30FPS, 180프레임/6초 영상을 렌더했다. 전체 구간 연락판과 진입/종료 30FPS 연속 프레임을 눈으로 검사했다. 동영상 플레이어를 통한 실시간 사람 검수를 완료했다고 주장하지 않는다. 창 끝이 다리 변형에 끌리던 오류를 분리 마스크로 수정했다. 진입/종료가 정적 원화 자세로 이어지고, 양발 교대 동작 없이 부유 자세가 유지된다.

**자연스러움 승인 실패/보류:** 정면 사선 원화를 접어 변형한 방식이므로 원본 영상의 측면 실루엣을 재현하지 못한다. 다리 겹침/무릎 주변 텍스처와 망토 분리 품질이 부족하며 108×132 원화는 확대 시 흐리다. 단순 관절/파일 검사를 시각 품질 승인으로 삼지 않는다.

**본게임 연결 미완료:** 최신 main의 `transform:283`은 `male_chain_chain_coif_longsword/SpriteFrames.tres` 공용 검병에 연결되어 있다. 현재 공격을 그대로 보존하면서 이 정면 뇌신 이동만 실제 게임에 대입하면 외형/방향이 바뀌는 문제가 생긴다. 따라서 프로필/플레이어/공격을 수정하지 않고 독립 검수 장면으로 남겼다. 본게임 뇌신 부유 이동 완성이라고 보고하지 않는다. 이어서 할 일은 같은 신화 뇌신의 이동 방향 원화와 겹침을 보완하고, 공통 표시 연결 담당과 기존 대기/공격 정체성이 일치하는 연결점을 정하는 것이다. 새 공격/대기 제작으로 범위를 확장하지 않는다.
