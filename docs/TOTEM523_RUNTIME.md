# 누적523 토템 실행 연결

기준 main은 `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`이며 PR237에서 이어간다. 다른 PR과 main은 병합하지 않는다. 공개 변경은 코드·검사·문서이고, 원본 데이터는 별도 private 팩이다.

## 실제 사용 경로

게임 메뉴 → 토템에서 지역별 활성화 진행도, 현재 레벨, 적용 능력치와 공명, 현재 지역 EXP, 레벨별 재료·옵션 후보를 확인한다. 실제 강화 버튼은 미리보기 선택과 별개로 현재 레벨의 다음 단계에 도전한다. 일반/각인 강화석 중 누를 재료를 명시적으로 선택한다. 초기화는 확인창을 거치고, 일반 강화석 제작은 일반/각인 주문서 중 하나를 선택한다. 각인 강화석 전환 3종도 유지한다.

원본 NpcClass.ID로 활성화 112종을 세며 파편 드롭 105종과 구분한다. 기존 사망 생명주기 가드로 중복 신호와 소환수 크레딧을 제외한다. 파편 드롭 확률·수량을 추가하지 않는다. 활성화 3000킬과 강화 레벨0은 별도 상태다.

## 원문과 TWILIGHT 실행 정책의 경계

원본 서버 실행 코드가 없으므로 다음 전이·추첨·보존 정책은 명시적인 `twilight_totem_v1` 로컬 정책이다. 원본 서버 절차로 주장하지 않는다. 현재 게임의 RandomNumberGenerator, 백만 단위 전투 비율 및 저장 후 거래 확정 경로를 사용한다.

2026-11-04에 [NC 토템 강화 확률](https://probability.plaync.com/lineagem/view?probCategoryId=6704e963981799627e573d48)과 [옵션 등장 확률](https://probability.plaync.com/lineagem/view?probCategoryId=6704e9a3981799627e573d4d)을 추가 조사했다. 공개 페이지가 호출하는 일반 공개 API의 실제 응답을 읽고 `tools/totems/verify_public_rates.py`로 원본 팩과 대조했다. 강화33행, 옵션 수치·선택 가중치94행이 모두 일치한다. Lv1~10 성공률은 30/25/20/15/10/25/20/15/10/5%이고, Lv10 발동률 후보의 등장 가중치는 55/35/10%다. 발동률 자체인 0.5/1/1.5%와 구분한다. 경험치0 후보의 50%도 공식 공개값과 일치한다. 강화 비용·확률을 자체 수치로 대체할 필요가 없어 추가 임의 경제값은 도입하지 않았다.

[NC 토템 시스템 가이드](https://lineagem.plaync.com/guidebook/view?title=%ED%86%A0%ED%85%9C+%EC%8B%9C%EC%8A%A4%ED%85%9C)의 공개 응답(수정 시각 `2024-11-13T14:24:50+09:00`)에서 활성화 조건, 지역 경험치, 강화석 제작 비용도 대조했다. 다만 이 오래된 가이드의 공명 설명을 최신523의 `PierceDamageReductionPercent` 대신 적용하지 않는다. 가이드와 확률표는 슬롯 간 독립성·서버 RNG·초기화 결제 우선순위·실패 절차 전체를 증명하지 않으므로 아래 로컬 경계는 유지한다. 경제 수치 조사 지시를 Shield454나 독의 기술적 수명·틱 처리 구현 승인으로 확대하지 않는다.

| 축 | 데이터 | 실행 |
| --- | --- | --- |
| 강화 성공 | 목표 Level의 TotemLevel.Probability | 다음 레벨 행 / 1,000,000. Lv0의 1,000,000을 최초 강화 확률로 쓰지 않음 |
| 옵션 선택 | 해당 LevelID·SlotIndex 후보 Probability | 슬롯별 가중 추첨. 각 슬롯에서 하나씩, 단계별 선택 ID를 보존 |
| 전투 발동 | 선택한 InvokeOption Bonus.Value | Percentage의 10,000 raw/1% 규칙. 5000/10000/15000은 0.5/1/1.5% |

강화는 선택한 종류의 재료만 해당 목표 단계 수량만큼 사용하며 혼합 소모하지 않는다. 성공 시 단계별 옵션을 누적 보존하고 실패 시 재료만 소모한다. 경험치0 후보6개도 실제 추첨·저장하며 양수 후보만 다시 정규화하지 않는다. 강화 비용과 확률 숫자는 원본에서 가져오며 새로운 피티·하락·파괴·환급을 만들지 않는다.

초기화는 source Currency2524→Item301694의 두루마리1개 경로만 지원한다. 현재 게임에 Gem 지갑이 없으므로 다이아400 결제는 지원하지 않는다. 두 비용의 표시 순서를 동시 지불 근거로 사용하지 않는다. 선택한 토템만 Lv0·선택 옵션 없음으로 바꾸며 활성화·처치 횟수·다른 토템은 유지하고 재료는 환급하지 않는다. 이 결제 경로 선택 역시 로컬 정책이며 원본 서버 결제 우선순위는 미확정이다.

## 재료와 제작

뷰가 있는 6개 제작만 사용한다. 파편25개 + 선택한 축복 주문서3장 + 아데나100만 → 일반 강화석1개이며, 일반 강화석1개 → 같은 지역 각인 강화석1개다. AlwaysSuccess와 단일 확정 출력을 함께 확인한다. 뷰 없는 교환6종은 노출하지 않는다.

원본 주문서 ID3581/65291와 초기화 두루마리301694를 정확한 ID로 등록한다. 기존 자체 제작 축복 주문서와 같은 이름으로 병합하지 않는다. 주문서는 각각 `(토템 제작)`/`(각인·토템 제작)`이라는 별도 인벤토리 이름을 쓰고 sourceId와 원문 ItemClass를 보존한다. 기존 아이템·세이브를 변환하거나 새 아이템을 자동 지급하지 않는다. 원본 아이콘 파일은 추가하지 않았다. 인벤토리 무게는 기존 게임 규칙을 따른다.

## 능력치와 전투

선택된 옵션만 AC, MR, 근거리/원거리/마법 명중·대미지, PVE 리덕션, 일반 리덕션, 경험치, 공격 종류별 감소율에 한 번씩 연결한다. 여러 후보를 전부 더하지 않는다. 공명은 총 레벨15/20/25/30의 도달 행을 누적한다. 1/2/3/4%를 기존 성공 타격의 양수 target reduction에 적용하며 자기 방어·flat 무시·최종 피해 증폭으로 바꾸지 않는다. target reduction이0이면 보너스 피해를 만들지 않고 음수 리덕션 약화도 확대하지 않는다. 완전한 원본 NPC 전투 공식은 아니다.

Lv10의 구현된 구성 요소:

- 테베라스: 원본 base400·dice1×1·AttackType1을 기존 물리 타격 경계로 보낸다. 401을 최종 피해라고 고정하지 않는다. CannotSee 시야 감소는 미지원이다.
- 티칼: 2~3초 범위에서 기존 호스트 지속시간 처리를 사용해 물약 회복률 감소15%를 적용한다. 독3%/750~950의 주기·캡 조합은 구현하지 않는다. `ImmuneNPC` 이름을 NPC 금지로 임의 번역하지 않는다.
- 아틀란티스: 공격이 아닌 방어 발동으로, BySpellAttack=false를 지키고 확인된 리덕션5를 5초 로컬 버프로 적용한다. 첫 피격과 유지 중 피격에 중복 차감하지 않는다. 미제공 Shield454의 흡수량·보호막 본체는 만들지 않는다. 원문의 IsEraseOnTimeEnd=false와 서버 수명 처리는 미확정이며 원문을 삭제하지 않는다.

CastDelay는 기존 카드 발동의 호스트 변환(`/1000`초)을 재사용한다. 이 시간 변환과 기존 성공 타격의 대상·사거리 경계는 로컬 호환 정책이며 원본의 추가 거리 단위·저항 판정·상태 수명 전체를 재현했다는 뜻이 아니다. 원본 VFX는 기존 private compositor에 바인딩이 있는 경우에만 요청하며 없으면 새 이펙트를 합성하지 않는다. 토템 디버프는 `totem:` namespace로 카드 디버프와 별도로 정리하고, 초기화·로드·풀 재사용 시 다른 기능의 효과를 지우지 않는다.

## 지역 EXP

제작기가 활성화 그룹 → NpcSpawnPackNpcClassView → NpcSpawnPackTerritory → Territories → Land를 대조해 3/2/2개의 정확한 Land 행을 private 팩에 보존한다. 시간의 균열 지역 도움말과 이 그룹의 출현 지역을 결합한 로컬 지역 바인딩이다. Totem에 별도 원본 Land 연결 행이 있는 것처럼 주장하지 않는다.

실행은 현재 native M 필드의 검증된 geographic_contract에서 Land.ID와 AssetPath가 함께 일치할 때만 +5%를 적용한다. 지역 이름, PC map number, PNG 파일명으로 판정하지 않는다. 활성화 직후 Lv0에도 적용하며 지역을 벗어나면 계산에서 즉시 빠진다. 세 지역 버프를 항상 합산하지 않는다. 현재 Aden 필드는 해당 native 계약이 아니므로 +0%다. 검사에서7개 Land의 계약 연결은 검증하지만, 세 균열 지역의 실제 맵 진입·렌더링·이동을 실행 검증한 것은 아니다.

## 저장과 실패 보호

v1 상태를 v2로 읽으며 실제 선택 결과를 다시 추첨하지 않는다. v2에 로컬 정책 ID와 revision을 저장한다. 화면의 이전 revision 요청과 재진입 요청을 거부한다. 인벤토리·아데나·토템 상태를 함께 원자적으로 저장한 뒤 live 상태를 교체한다. 실패하면 재료·성장·저장 바이트와 RNG 상태를 보존한다. 로드 검증은 live 상태 변경 전에 수행한다. private 팩이 없어도 이전 토템 저장은 보존하고 잘못된 새 상태로 덮어쓰지 않는다.
