# PR #70 — 제작 시스템 출처 검토 및 TWILIGHT 확장 (2026-10-10)

## 실제로 확인한 자료

- 리니지M 인벤 아이템 DB: https://lineagem.inven.co.kr/db/item/
  - 무기 / 방어구 / 장신구 / 재료와 일반·고급·희귀·영웅·전설·신화·유일 등급 분류가 있음.
  - 제작 비법서 계열이 별도 재료로 등재됨.
  - 인벤의 '오시리스 무기 제작 비법서' 설명에는 **비법서 10개로 오시리스 무기(각인) 한 종 제작 가능**이라고 명시되어 있음.
- 리니지M 공식 가이드북: https://lineagem.plaync.com/guidebook/list
  - 아이템/제작/장비 구분, 실제 리니지M 시스템 설명과 비교하는 용도.
  - 모든 구체적인 제작식·성공률·아데나 비용을 일괄 검증할 수 있는 출처는 아님.

**중요:** 위 자료를 읽었다는 이유만으로 아래 신규 제작식의 재료나 비용이 원작 리니지M에 존재한다고 주장하지 않는다. 표기된 장비 계열과 등급만 참고하며, 실제 제작 가능한 결과 이름은 현재 TWILIGHT `data/game_db_v17.json` 에 대조했다.

## PR #70 구현 내용

- 5개 기존 제작식 유지 + 76개 TWILIGHT 단독 플레이용 신규 제작식 = **81개**.
- 15개 무기 계열의 일반→고급→희귀 구간 로컬 합성 경로, 방어구 8종의 초반 2단계, 물약 2종 추가.
- **영웅/전설/신화/유일 장비 합성 레시피는 의도적으로 추가하지 않음.** 기존 보스/일반 몬스터의 드랍률과 드랍 테이블 자체는 건드리지 않음.
- 새 재료/결과 아이템을 생성하지 않고 현재 `game_db_v17.json` 실제 이름만 참조.
- 새 제작식마다 `source_type=twilight_local_balancing` 으로 원작 미검증 제작식임을 표시.
- 원작 확률·제작 비용으로 오인되지 않도록 제작창에서도 TWILIGHT 자체 제작식이라고 설명.
- 기존 원자적 인벤토리 변경, 실물 장비 ID, 장착·강화·속성 보호, 무게 및 아데나 검증 유지.
- 제작창 카테고리 필터와 결과 아이템명 검색 추가.
- 추가적인 제작 수량/방패 제작/희귀 제작 보호 회귀 테스트.

## 의도적 보류

- 원작 비법서 기반 희귀~유일 장비 제작 및 성공 확률: 진짜 비법서 아이템의 **획득 경로**, 공식 레시피 재료·수량·각인 결과를 별도 검증하기 전에는 적용하지 않는다.
- '오시리스 무기 제작 비법서 ×10' 사례는 참조 근거가 있으나 현재 TWILIGHT 기본 아이템 DB·획득 루프와 정확히 연결되지 않으므로 **아직 플레이 가능한 레시피로 구현하지 않음**.
- 창고/상점/드랍 시스템과의 출처별 정합성 및 Windows 실제 플레이 테스트는 별도 통합 검증 대상.
- 리니지M의 온라인 경제나 원본 수치를 100% 재현한다는 뜻이 아님.

## 검증 기준

- 정상 제작 시 재료 감소/결과 증가/아데나 차감/장비 물리 ID의 일치.
- 비정상 제작 시 인벤토리와 실물 장비 ID가 수정되지 않을 것.
- **PR #66 기반 Draft 상태 유지. 주 브랜치나 타 PR과 임의 병합 금지.**


## 2026-10-10 — 드랍 가능 제작 재료 실전 연동

- **신규 채집형 재료 10개 (480개 DB 아이템 총량):** 철 광석, 동 광석, 미스릴 원석, 가죽 조각, 정제된 목재, 천 조각, 마력 결정, 연마석, 약초, 정령의 가루.
- 전부 `type=제작재료, slot=consumable, crafting_material=true`. 회복 수치가 없어서 물약처럼 자동 사용되거나 장비 개체 ID를 만들지 않음. 기존 재료의 무게/이름/등급 DB와 함께 저장.
- 기존 제작법 **81개 전체**에 종류별 재료 요구량 추가. 장비 합성의 기존 하위 장비 및 기존 물약 입력은 유지; 새 재료로 대체하지 않음.
- `data/monsters/twilight_crafting_drops.json`에서 318종 몬스터별 재료 가중치와 **76종 장비 재료의 지정 몬스터**를 명시.
- 몬스터 처치 때 독립 판정으로 **일반 28% / 보스 65%** 수집 재료 하나까지 드랍 (미드·상급 광석과 마력 재료는 몬스터별 선택 가중치 적용). **이 수치는 원작의 확정 드랍률이 아니며 신규 TWILIGHT 로컬 재료 채널 전용**.
- 기존 장비 드랍률(일반 몬스터 1회, 보스 3회), 장비 등급별 수치, 45%/90% 물약 판정 그대로 유지. 제작에 쓰이는 하위 장비는 각 몬스터에 등록한 같은 장비 등급 내에서만 등장하며, 기존 해당 등급 명시 드랍 아이템이 있으면 기존 아이템을 먼저 선택해 희석하지 않음.
- 게임 처치 경로 `world._roll_drop()`에 몬스터 이름 전달. 새 재료도 모두 기존 땅바닥 드랍 / 수동 선택 / 자동사냥 자동줍기 / 세이브 복원 경로 이용.
- 단독 플레이 밸런스를 위한 신규 콘텐츠이며 **공식 리니지M 아이템-몬스터 귀속 표, 성공률, 재료 비용을 복제하거나 확정적으로 재현했다는 뜻이 아님**. 제작 비법서 등 공식 레시피는 검증 뒤 별도로 통합.
- 테스트 `tests/crafting_material_drop_test.gd` 및 기존 제작/루팅/창고/상점 회귀 검증. CI: `TWILIGHT Atomic Crafting`.
- PR #64의 L1J 드랍 커버리지와 **미병합**. 향후 병합 시 동일 이름 장비의 원작 검증 드랍 설정을 우선하도록 중복 충돌 정리가 필요함.

### 실제 PR #70 구현

- 비법서 5종 신규 DB 등록: `희귀 제작 비법서`, `영웅 제작 비법서`, `전설 제작 비법서`, `신화 제작 비법서`, `유일 제작 비법서`.
- 위 비법서는 `slot=consumable`, `crafting_scroll=true`, `drop_as_equipment=true`, `crafting_material=true`. **착용 불가, 물약 사용 불가, 장비 개체 ID 없음**, 인벤토리·창고·저장에서는 수량형 재료로 취급.
- 기존 희귀 장비 레시피에도 **해당 등급 비법서 1장**을 추가하고, 새로운 장비 레시피 332개를 확장. 총 **413개 레시피**, 희귀/영웅/전설/신화/유일 장비 **355개 고유 결과**를 모두 제작 가능.
- 누락·변조된 비법서 등급/소모 조건은 `local_crafting.gd`에서 실제 인벤토리 차감 전 재검증. 결과 장비만 새로운 물리 인스턴스를 만든다.
- 비법서 1장은 *동일 등급 장비 드랍 판정 중 1칸의 후보*이며 별도 드랍 기회를 추가로 만들지 않음. 일반 몬스터 장비 판정 1회/보스 3회 및 기존 등급별 확률과 독립 재료 판정은 그대로. 원래 같은 등급 명시 드랍 아이템이 있는 몬스터는 해당 아이템을 먼저 선정한다.
- `twilight_crafting_drops.json`에 지정 몬스터 **총 62곳**의 5개 등급 비법서 출처 추가. 일반 몬스터는 희귀·영웅까지, 전설 이상은 보스에만 지정. 원본 리니지M 특정 몬스터 비법서 테이블과 같다는 주장은 하지 않는다.
- 바닥에서는 등급에 맞는 빛기둥을 유지하며 제작 비법서는 양피지 형태의 전용 절차적 아이콘 사용. 수동 줍기/자동사냥 중 자동 줍기/바닥 드랍 저장은 기존 시스템 유지.
- 제작 UI에 물품 등급 필터 추가. 등급과 재료 부족 상태 확인 가능.
- 제작 성공률은 기존 TWILIGHT 로컬 제작이므로 **100%**(모든 재료와 아데나가 충족될 때 확정)이며, 원작 제작 성공률을 재현한다고 주장하지 않는다.
- PR #64/다른 PR과 병합하지 않고 Draft 상태 유지. 통합 시 드랍 후보 충돌을 점검.
