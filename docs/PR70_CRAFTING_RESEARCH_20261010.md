# PR #70 — 제작 시스템 출처 검토 및 TWILIGHT 확장 (2026-10-10)

## 실제로 확인한 자료

- 리니지M 인벤 아이템 DB: https://lineagem.inven.co.kr/db/item/
  - 무기 / 방어구 / 장신구 / 재료와 일반·고급·희귀·영웅·전설·신화·유일 등급 분류가 있음.
  - 제작 비법서 계열이 별도 재료로 등재됨.
  - 인벤의 '오시리스 무기 제작 비법서' 설명에는 **비법서 10개로 오시리스 무기(각인) 한 종 제작 가능**이라고 명시되어 있음.
- 리니지M 공식 가이드북: https://lineagem.plaync.com/guidebook/list
  - 아이템/제작/장비 구분, 실제 리니지M 시스템 설명과 비교하는 용도.
  - 모든 구체적인 제작식·성공률·아데나 비용을 일괄 검증할 수 있는 출처는 아님.

**중요:** 위 자료를 읽었다는 이유만으로 아래 신규 제작식의 재료나 비용이 원작 리니지M에 존재한다고 주장하지 않는다. 표기된 장비 계열과 등급만 참고하며, 실제 제작 가능한 결과 이름은 현재 TWILIGHT `data/game_db_v17.json` 에 대조했다.

## PR #70 구현 내용

- 5개 기존 제작식 유지 + 76개 TWILIGHT 단독 플레이용 신규 제작식 = **81개**.
- 15개 무기 계열의 일반→고급→희귀 구간 로컬 합성 경로, 방어구 8종의 초반 2단계, 물약 2종 추가.
- **영웅/전설/신화/유일 장비 합성 레시피는 의도적으로 추가하지 않음.** 기존 보스/일반 몬스터의 드랍률과 드랍 테이블 자체는 건드리지 않음.
- 새 재료/결과 아이템을 생성하지 않고 현재 `game_db_v17.json` 실제 이름만 참조.
- 새 제작식마다 `source_type=twilight_local_balancing` 으로 원작 미검증 제작식임을 표시.
- 원작 확률·제작 비용으로 오인되지 않도록 제작창에서도 TWILIGHT 자체 제작식이라고 설명.
- 기존 원자적 인벤토리 변경, 실물 장비 ID, 장착·강화·속성 보호, 무게 및 아데나 검증 유지.
- 제작창 카테고리 필터와 결과 아이템명 검색 추가.
- 추가적인 제작 수량/방패 제작/희귀 제작 보호 회귀 테스트.

## 의도적 보류

- 원작 비법서 기반 희귀~유일 장비 제작 및 성공 확률: 진짜 비법서 아이템의 **획득 경로**, 공식 레시피 재료·수량·각인 결과를 별도 검증하기 전에는 적용하지 않는다.
- '오시리스 무기 제작 비법서 ×10' 사례는 참조 근거가 있으나 현재 TWILIGHT 기본 아이템 DB·획득 루프와 정확히 연결되지 않으므로 **아직 플레이 가능한 레시피로 구현하지 않음**.
- 창고/상점/드랍 시스템과의 출처별 정합성 및 Windows 실제 플레이 테스트는 별도 통합 검증 대상.
- 리니지M의 온라인 경제나 원본 수치를 100% 재현한다는 뜻이 아님.
