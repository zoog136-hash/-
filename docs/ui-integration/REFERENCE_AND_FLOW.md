# 리니지M 참고 화면과 TWILIGHT의 대응

확인일: 2026-10-12. 공식 사이트에 현재 공개된 가이드와 최근 공지를 확인했다. 일본 공식 가이드의 일부 캡처는 과거 버전이며, **2026년 10월 한국 서비스의 모든 화면을 직접 확인한 것은 아니다**. 확인한 사실과 TWILIGHT에 맞춰 설계한 부분을 분리한다. 원본 이미지를 게임 자산이나 이 저장소에 복제하지 않았다.

현재 대응은 UI 코드 `b215b20`, main `cfbf0fb` 기준이다. 최신 main의 [PvE 전용 범위](../PVE_ONLY_SCOPE_20261012.md)에 따라 퀘스트·채팅·파티·혈맹·거래소는 UI에 복원하지 않았다. 아래의 공식 기능 존재와 TWILIGHT 제공 범위를 구별한다.

## 공통 상호작용과 확장 위치

`HUD 입력 → world.gd의 검증된 명령 → 기존 시스템 변경 → HUD/공유 상세창 갱신` 흐름을 유지한다. 창은 게임 데이터를 소유하지 않는다. UI 캐시는 표시용 스냅샷/선택 상태이며 슬롯의 내용·아이템 잠금은 게임 저장, 페이지/접힘/화면 옵션은 UI 설정 파일에 저장한다.

미지원 서버 기능은 `menu_registry.gd`의 capability 상태와 `renewal_hud.gd::_open_capability`를 교체 연결한다. 실제 서버 계약이 생긴 후 요청/대기/실패/결과 상태를 어댑터로 추가하고, 소유/거래/보상 확정은 서버 응답으로만 처리해야 한다. 현재 저장소에는 이 계약 자체가 없으므로 API를 추정 생성하지 않았다.

### 다음 기능 우선순위

1. 기존 설정의 내부 분류와 퀵슬롯 자동사용 정책 안내 개선.
2. 스킬 습득/레벨, 변신·인형·성물 소유/합성, 컬렉션 보상은 실제 모델이 추가될 때 연결.
3. Android 실기기 터치·키보드·안전 영역·성능 검증 및 최신 한국 리니지M 캡처로 메뉴 계층의 차이 재확인.
4. 구조 변경 없이 기존 자산의 아이콘/패널/애니메이션 품질 보완. PvE에서 제외된 기능은 별도 범위 변경 없이 복원하지 않음.
