## 실제 응답과 전수 수집 중단

`evidence/exchange/research-20261112/`의 원문과 receipt는 테스트 합성 데이터와 별개다. 가죽 10,000개 묶음 가격 50다이아를 확인했으며 동일한 수량·가격의 5행을 별도 매물로 보존한다. 로컬 서버 조회에는 월드 매물이 섞이므로 로컬 `world=false`, 월드 전용 조회 `world=true`를 분리한다. `blessedType=0`은 전체 조회이고 일반형 증거가 아니다. 일반형 1 명시 조회로 진명황의 갑옷 1개/14,000다이아 응답을 따로 보존했다.

공식 목록의 300서버·30월드를 확인한 뒤 재개 수집을 실제 실행했다. 첫 20요청의 성공 응답을 재사용해 전 범위 수집으로 재개했지만, 서버 1의 페이지 1은 총량 1,566(HTTP Date 05:11:40 UTC), 페이지 18은 1,567(05:13:27 UTC)로 바뀌었다. 성공 응답 총 21개(메타데이터 3개·카탈로그 18페이지)를 보존하고 `stopped_incomplete`로 중단했다. 이 관측으로 실제 stock 전수 수집이나 누락 없는 시점 스냅샷을 주장하지 않는다. `pagination_drift_summary.json`에 비교 원문과 SHA를 기록했다.

새 수집기는 최소 1초 간격, 명시적 요청 예산, 원응답/receipt SHA 검증과 재개 커서를 제공한다. 검색 cap은 공식 카테고리로 분할하고 부모 총량과 대조한다. 페이지 총량 변동·중복 카탈로그 키·상한·429·변조에서 중단하며 동일한 stock 행은 합치지 않는다. 기본값은 오프라인이고 운영 승격을 하지 않는다. 한 차례 전 범위 순회를 마쳐도 고유 매물 ID/원자적 스냅샷 토큰이 없어 `coverage.complete`를 자동 승인하지 않는다.
