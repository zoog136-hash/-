## 대표 서버 선정 근거

공식 서버 조회에는 공유 월드 상품이 섞인다. 사용한 지표는 `해당 서버 조회의 catalog pagination.total - 공유 월드 조회의 pagination.total`로 계산한 **로컬 상품 그룹 수 proxy**다. 매물 묶음 총수와 다른 지표이고 조회 시각 차의 영향도 받을 수 있다.

| 표본 후보 | 서버 조회 그룹 | 공유 월드 그룹 | 로컬 그룹 proxy |
| --- | ---: | ---: | ---: |
| 데포로쥬01 · server:1 | 1,570 | 432 | **1,138** |
| 다음 표본 후보 server:2 | 1,365 | 432 | 933 |

server:1은 이 표본의 proxy 최대 후보다. 300서버 전체의 실매물 수 최다를 확정했다고 주장하지 않는다. [공식 서버 목록](../../evidence/exchange/official_servers.json)의 서버·월드 관계와 후보별 원응답 URL·SHA를 스냅샷 `coverage.survey`와 `scope_proof`에 남겼다.

포함행은 모두 명시적 `blessedType=1` 조회에 근거한다. `0`은 전체 종류 조회이므로 일반형으로 해석하지 않는다. 카테고리 31 스킬카드와 나머지 기타·재료 전체는 수집 완료 범위에 포함하지 않는다.

제외 15행의 사유 코드는 모두 `original_id_label_or_exact_enchant_prefix_unmatched`다. 관측 이름에 화령·지령 등의 속성 강화 표현이 있어 현재 허용한 원본 이름 또는 정확한 `+N 원본 이름` 관계로 확정하지 못했다. 이 행을 단순 일반 강화 장비로 바꿔 지급하지 않는다.

이 15행은 **이미 받은 응답 안에서 제외한 수**다. 미조회 그룹, 요청 예산, stock 페이지 샘플링, 전송 시간초과로 받지 못한 매물 수는 알 수 없으며 이 수에 포함하거나 0으로 가정하지 않는다. 처음 두 stock 페이지만 보존한 그룹 11건은 보고서 `stock_page_sampling_events`에 관측 당시 미조회 페이지 범위와 `omitted_listing_count=null`을 남겼다. 건너뛴 전송 시간초과 1건도 별도 실패 근거로 보존하며 존재하지 않는 매물이나 0재고로 만들지 않았다.

재료 샘플의 분류는 [일반형 가죽 exact catalog 응답](../../evidence/exchange/representative-capture-20261112/server1-materials/raw/bf2e6455521adfaff7be8aa5d773d0a4eef3169b5a67626370ef1bbbd57c4497.json)으로 별도 확인했다. 이 응답의 SHA-256은 `5805a8cd82375cbce2f529e49651f67712df5edfeb8a0619ace02116db66bfe1`, HTTP Date는 06:32:47 UTC다. 이는 앞서 관측한 가죽 stock 10행에 카테고리 51 근거를 연결한 것이며 새 가격을 만든 작업이 아니다.

## 가격·묶음·관측 정체

각 행은 공식 stock 응답의 `salePrice`를 `bundle_price`, `quantity`를 `bundle_size`로 보존하고 `initial_bundles=1`로 둔다. 정수로 정확히 표현되는 값만 사용하며 반올림·평균·추정 가격을 넣지 않는다. 원래 응답과 receipt의 SHA, URL, 행 번호, 시각, 원문 행을 함께 보존한다.

원본 523 정의는 로컬에서 정확한 ItemClass ID와 한국어 이름을 대조하는 데 사용했다. 강화 이름은 관측 강화값과 `+N 원본 이름`이 정확히 일치할 때만 정규화하고 `observed_item_name`에 원문 이름을 남겼다. 원본 ZIP·전체 추출 정의·파생 정의 팩·캐시·시험 저장·인증정보는 공개 자료에 포함하지 않는다.

같은 값이 다시 나타난 **추가 547행**을 합치거나 지우지 않았다. 서로 다른 판매분일 수 있고 페이지 위치 이동으로 겹친 관측일 수도 있으나 이를 판별할 고유 매물 ID를 확보하지 못했다. URL·원응답 SHA·행 번호에 따른 `observation:` 식별자는 관측 정체이며 판매자의 등록 ID가 아니다.

이 최종 입력에서 기록된 페이지 pagination 변동은 0건이다. 총량이 같아도 페이지 내 등록 위치가 고정됐다는 근거는 되지 않는다. 수집 기간이 있는 비원자 관측이며, 특정 순간 무누락·무중복이나 고유 1,506매물이라는 주장은 하지 않는다. [이전 전 서버 시도](CONTINUATION_20261112.md)의 1,566→1,567 총량 변동 증거도 그대로 보존했다.

## 런타임 적용 계약

한 번 설치한 파일의 가격·품목·묶음 크기를 고정하고 네트워크 재수집 없이 읽는다. 매일 한국시간 05:00에 관측된 초기 묶음 재고만 복원한다. 열린 화면은 다음 1초 갱신 때, 종료된 앱은 다음 조회·구매 때 적용한다.

원본 공급자는 일반형과 확인된 매핑 장비의 관측 강화값을 정확한 물리 개체로 지급한다. 강화 수치를 새로 굴리거나 별도의 능력치를 지어내지 않는다. 공급 영수증에 관측 강화값·일반형·고정 스냅샷·가격·묶음 수량을 남기고 기존 상점의 한 원자 저장으로 다이아·개체·소비 재고를 반영한다.

미확인 축복·저주·속성·추가 API 변형, 원본 정체 불일치, 기간·서버 조건 미확인, 원본 공급자가 지원하지 않는 소모품은 구매를 잠근다. 설치된 원본 정의가 없으면 구 아이템으로 대체 지급하지 않는다. 따라서 포함 1,506행 모두의 구매 가능성을 주장하지 않는다. 첫 거래 이후 스냅샷 SHA 변경, 저장 실패·불확실 응답, 시계 역행은 기존 보유를 보존하도록 방어한다.

최종 1,506행 운영 파일을 읽는 집중 3개 suite와 원본 실제 구매 시험을 통과했다. [검증 영수증](evidence/representative-20261112/validation.json)과 [실제 운영 구매 영수증](evidence/representative-20261112/production-native-receipt.txt)에 범위와 스냅샷 SHA를 남겼다. 실제 운영 시험은 지갑·저장 프로필만 격리했고 상품·coverage는 대체하지 않았다.

별도 일반 강화 장비 29개 시험은 실제 관측 강화 매물에 합성 coverage·시험 지갑을 사용한 다른 범위다. 추가 runner 자체 검사 47개 중 PR122 종료 영수증 관련 3건은 실패했다. 최신 main `b488fb3`의 파일만 분리한 환경에서도 같은 3건이 재현되어 거래소 변경과 별개인 기준선 실패로 기록한다. [기준선 로그](evidence/representative-20261112/runner-baseline.txt)를 보존했고 이 검사를 통과로 집계하지 않았다.

실제 서비스 계정에서 매매하지 않았으며 시험 자금과 시험 저장을 운영 데이터로 사용하지 않는다. 기존 필수 core/리소스 게이트와 추가 거래소 집중 CI를 유지한다. 전체 역사 suite, GPU·Android 실기기, 원작 아트 전체 전달·시각 동등성은 검증 완료 범위로 집계하지 않는다.
