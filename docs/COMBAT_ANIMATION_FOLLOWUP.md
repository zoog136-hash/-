## 이번 수정

1. 방향별 `animation_names`와 관례적 `walk_0`/`attack_0` 또는 `walk_down` 등의 이름을
   실제 프레임 재생에 연결했다. 전용 방향 아트를 다시 좌우 반전하지 않는다.
2. 대기 반복, 상대 프레임 길이, 네이티브 FPS, 비반복 마지막 포즈, 피격·사망 진행,
   시체의 마지막 사망 포즈를 처리한다. 전용 사망 아트에는 절차적 낙하를 중복 적용하지 않는다.
3. 방향별 공격 이름만 지정해도 타격 프레임이 진행된다. 준비/타격/복귀와 기존 공격 시계는
   유지한다. 타격 비율이 0.7보다 늦은 전용 공격도 타격 전에 복귀로 넘어가지 않으며,
   마커가 발생한 틱에는 전용 타격 포즈를 표시한다.
4. 몬스터는 기존 `Sprite2D`에 선택적 `SpriteFrames`를 샘플링한다. 추가 노드나 씬 교체가
   없다. 전역/레코드별 시각 좌표 설정을 보존하고 `marker_for()`로 개별 타격 비율을 사용한다.
   왼쪽 원거리 공격의 발사 오프셋도 방향에 맞춘다.
5. 성물도 기존 부유·발광·발 기준 정렬을 유지하면서 네이티브 프레임을 사용할 수 있다.
6. 변신·인형·성물에서 없거나 비어 있는 선택적 리소스는 실제 기존 이미지로 대체한다.
   빈 기본 애니메이션을 가진 유효한 네이티브 리소스도 안전하게 로딩한다.
7. 프레임 선택과 누적 길이를 캐시한다. 기존 균일 시트에는 별도 경량 경로를 사용해
   가중 프레임 계산과 전용 명칭 탐색의 부담을 줄였다.

이동·AUTO·전투 수식·몬스터 AI의 판단/경로·맵·카메라·HUD와 모든 기존 씬을 유지했다.
`scripts/world.gd`, `scripts/maps/`, `scripts/ui/`, `scenes/`, `assets/`, `data/`,
`project.godot`, `Main.tscn`은 시작 main 대비 변경이 없다.

## 리소스와 남은 범위

실제 활성 변신 413, 인형 166, 성물 144의 선택된 이미지 경로가 모두 존재하는 것을 확인했다.
래스터 아트를 새로 제작하거나 실제 게임의 외부 에셋을 추가하지 않았다. 따라서 전용 아트의
수량은 시작 main과 같다. 변신 78종/인형 59종의 기존 방향 시트는 **4방향**이며, 모든 종에
전용 8방향 공격·피격·사망 아트가 있다고 주장하지 않는다. 몬스터 163종은 계속 기존 6종
텍스처와 공통 모션을 사용하며, 이번에 전용 리소스를 연결할 수 있는 코드 경로를 완성했다.

실제 추가된 `SpriteFrames`만 `animation_profile.frames_path`로 등록하고, 필요하면
`animation_names`에서 상태/방향을 매핑한다. 방향 번호는 E/SE/S/SW/W/NW/N/NE = 0~7이다.
현재 파일이 없는 경로를 생산 프로필에 등록하지 않았다. 변신 335종의 방향 보행 및 각 종의
전용 공격·피격·사망 아트는 별도 제작이 필요하다.

192마리 시뮬레이션의 AI/물리 P95 지연이 관찰됐다. 제한된 VFX 표시 예산은 피해 판정을
버리지 않으며 캐시/풀의 반환은 확인했지만, Linux 헤드리스/소프트웨어 GL 결과로 Windows
실제 GPU의 60 FPS나 장시간 메모리 안정성을 보장하지 않는다. 실제 PC의 장시간 프로파일링과
모든 도감 외형의 사람에 의한 전방향 검수는 남아 있다.
