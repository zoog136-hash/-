# 아덴월드·오만 1~10층·지배 정상 몬스터 배치 보완 — 2026-10-18

## 구현 대상 및 기존 배치 재사용

- 대상은 현재 TWILIGHT에 실제 존재하는 12개 맵: 아덴월드 1, 오만의 탑 1~10층, 지배의 탑 정상 1개. 지배의 탑 추가 층은 존재하지 않으므로 임의 신설하지 않음.
- 실제 사용되는 배치는 `TwilightMonsterCatalog.apply_map()`에서 과거 `world_spawn_profiles.json`, 현재 맵 정의, `renewed_map_spawn_rules.json`을 결합해 산출한다.
- 이 변경은 기존 **아덴 12개 지역 몬스터 명단**을 유지하고, 기존에 전역 위협도 순서에 따라 섞이던 **오만 각 방과 지배 정상 각 방의 로스터를 본래 방 단위로 유지**한다. 단, 전투/드롭 시스템상 보스인 종은 일반몹 및 폭젠에서 제외.
- 오만 1~10층과 지배 정상 보스는 현재 지도 `review_points.boss`를 앵커로 하는 전용 방에서 등장하게 재계산한다. 오만 1층의 기존 960×720 구역을 유지하며, 2~10층 및 지배 정상은 기존 640×640 방 크기를 유지.
- 입장 지점·귀환 착지·NPC·포털·안전구역·주요 길, 폭젠과 보스 간 배제 거리, 실제 통행 가능한 지형/충돌 판정은 기존 `renewed_map_spawns.gd` 규칙을 유지.
- 전투 스탯/AI/드롭/시각 아트/원본 지형은 수정하지 않음. 보스 ID·저장 상태·기존 시간 정책(아덴 8시간/탑 24시간의 로컬 벽시계)을 보존.
- 사용자 제공 원본 파일이나 리니지M 소스 리소스를 이 공개 PR에 복사하지 않음. 해당 배치는 TWILIGHT 자체 PvE 설계이며 실제 원작 서버의 출현 좌표·주기를 보증하지 않음.
