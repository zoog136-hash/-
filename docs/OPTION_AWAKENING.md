# TWILIGHT 옵션 각성

변신·마법인형·성물의 **옵션 각성**을 기존 카드 보유·중복 수량, 실제 능력치, 저장, 도감 UI와 연결한다. 스킬 각성은 이 변경에 포함하지 않는다.

## 사용 흐름

1. 변신·마법인형·성물 도감에서 획득한 영웅 이상 카드를 선택한다.
2. 선택 상세의 **옵션 각성**을 연다.
3. 같은 종류의 허용 등급 중복 카드를 선택하고 수량과 소모 내역을 확인한다.
4. **경험치 주입**으로 100을 채운다. 첫 획득 카드는 남고 중복 수량만 줄어든다.
5. 확률·아데나·실패 환급을 확인한 뒤 **각성 시도**를 누른다.
6. 성공한 카드는 지원하는 일반 수치 옵션을 장착 중 적용한다. 도감 표식·장식과 필드 오라도 함께 표시한다. 아래에 명시한 미적용 특수효과 5종은 별도 발동하지 않는다.

실패 시 대상 카드를 잃지 않는다. 주입한 재료와 각성 시도 비용은 소비되며, 현재 영웅·전설·신화 정책에서는 경험치가 20으로 돌아간다. 경험치 주입과 각성 시도는 별도 저장 작업이다. 이미 각성한 카드는 재시도할 수 없다. 기존 도감의 시험용 자유 장착 정책과 카드 뽑기·합성 규칙은 유지하며, 각성 대상은 실제 획득 카드로 제한한다.

## TWILIGHT 밸런스 설정

아래 재료 경험치·비용·환급은 원작의 일반 규칙 수치를 확정하지 못한 항목이다. **TWILIGHT용으로 선택한 값**이며 `data/cards/option_awakening_policy.json`에서 조정한다. UI에도 이 구분을 표시한다.

| 대상 등급 | 재료 1장당 경험치 | 각성 시도 비용 | 실패 시 경험치 |
|---|---|---:|---:|
| 영웅 | 희귀 25 / 영웅 100 | 100,000 아데나 | 20 |
| 전설 | 영웅 25 / 전설 100 | 500,000 아데나 | 20 |
| 신화 | 전설 25 / 신화 100 | 1,000,000 아데나 | 20 |
| 유일 | 전설 10 / 신화 100 | 5,000,000 아데나 | 0; 성공률 100% |

필요 경험치는 100, 재료 주입 비용은 0이다. 넘치는 경험치는 버리고, 실패 보장·천장은 없다. 모든 재료는 같은 종류여야 한다. 이 설정의 성공률과 카드 옵션 수치는 위 공식 데이터에서 별도로 읽는다.

## 적용 능력치

HP·HP%·공격속도·이동속도·STR/DEX/INT·명중·방어·무게·경험치·축복 소모 감소·리덕션 무시·성물의 기존 쿨타임 감소 항목을 실제 World 계산에 연결했다. 기존 원본 카드 기록은 수정하지 않고 별도 보너스 기록을 합산한다.

- `hpPct`, `xp`는 비율(5% → 0.05), 공격속도와 `speedBonusPct`는 퍼센트(3% → 3)다.
- 각성 이동속도는 카드·장비 배율 계산 뒤에 퍼센트포인트를 더하고, 기존 버프·무게 배율을 적용한다. 독립적인 `1.03` 배수를 곱하지 않는다.
- 명중은 설명 문자열 파서에 이어 붙이지 않고 스타일별 추가 값을 한 번 더한다.
- 물약 회복량 컬렉션은 카탈로그 수치 경로에서 한 번 반영한다.

유일 카드의 `얼티밋 리덕션`, `어비스 하트`, `얼티밋 리벤지`, `어비스 리벤지`, `얼티밋 카오스`는 발동의 전체 동작을 확정하지 못했으므로 **미적용 특수효과**로 표시한다. 이 이름을 활성 수치나 전투 효과로 바꿔 넣지 않았다. 해당 카드의 검증된 일반 수치 옵션은 적용한다.

## 각성 컬렉션

아래 4종은 카드 소비 없이 조건을 만족하면 장착과 관계없이 적용한다.

| 컬렉션 | 조건 | 보너스 |
|---|---|---|
| 사랑의 용기 | 각성 시어 + 서큐버스퀸 보유 | 물약 회복량 +3 |
| 공중부양 | 각성 이프리트 + 드레이크·바다 하피 보유 | AC -1 |
| 고대의 마법사 | 각성 리치 + 머미로드·아누비스 보유 | INT +1 |
| 어디서나 마법을 | 각성 부아크·리치·뱀파이어 + 다크스타 조우 보유 | SP +1 |

## 이펙트와 입력

성공 결과는 중앙 카드, 원형 문양, 금빛 광선·잔광으로 표현하고, 실패 결과는 대상 카드를 유지한 채 결과와 경험치 환급을 알린다. 연출의 기하·색·시간은 TWILIGHT 구현값이다. 원작 영상 전체를 그대로 재현했다는 의미가 아니다. 이미 저장된 결과만 표시하며 연출 모듈은 확률·소모·보상에 접근하지 않는다.

도감에는 각성 표식과 테두리를 표시하고, 장착한 변신·인형·성물에는 몸체 중심을 따르는 오라를 표시한다. 성물의 발 좌표와 떠 있는 그림의 offset을 구분하고, 기존 모션·스케일을 바꾸지 않는다. 장착 해제 시 오라를 끈다. 기존 `reduced_motion`, `effect_detail`, `impact_intensity` 설정을 사용하고 입자 수를 제한한다.

재료 수량과 최종 소모 확인은 별도 단계다. 화면이 갱신되면 오래된 확인을 취소하고, 전송 중 입력·결과 연출 중 중복 요청을 막는다. 터치 버튼은 손가락을 뗄 때 실행하고 스크롤·취소·중복 해제를 구분한다.

## 저장 경계

새 키는 `card_option_awakening`, 버전은 1이다. 카드별 경험치·완료 여부·시도/실패 횟수, revision, RNG 상태를 저장한다. RNG의 64비트 상태는 JSON 숫자 오차를 피하기 위해 십진 문자열로 보관한다.

재료·골드·각성 진행·RNG를 임시 상태에서 계산한 뒤 기존 원자적 전체 저장 writer로 한 번 기록한다. 저장에 성공해야 라이브 값을 바꾸고 결과창을 연다. 실패 시 카드·아데나·진행·RNG·기존 저장 파일을 유지한다. 외부에서 바뀐 저장은 기존 SHA 보호를 통해 덮어쓰지 않는다.

새 키가 없는 구버전은 검증한 SHA 백업을 만든 후 빈 각성 상태로 시작한다. 알 수 없는 같은 버전의 필드와 카드 ID는 보존하며, 미지원 버전·손상된 수치는 저장을 막고 기존 정상 라이브 상태를 유지한다. 데이터 파일에서 ID·이름·등급이 일치하지 않는 항목은 활성화하지 않는다.
