# 원본 실물 경험치 보상 5종
다섯 원본 ItemClass는 셀프 사용, 비테스트, 원본 레벨 조건,
IsPossession=false 적용과 한 개의 Experience / Value 효과, 그리고 한국어
설명 수치가 일치한다. 기존 보관용 수량도 실물 영수증 없이 이름만으로
경험치를 주지 않는다.

| ItemClass | 원본 이름 | 최소 레벨 | 원본 EXP | TWILIGHT EXP | ItemBonus → Bonus |
|---:|---|---:|---:|---:|---|
| 170184 | 경험의 열매 (1위) | 40 | 2,000,000 | 242,160 | 283204 → 969234 |
| 170194 | 경험의 열매 (2위) | 40 | 1,500,000 | 181,620 | 283214 → 969244 |
| 170204 | 경험의 열매 (3위) | 40 | 1,000,000 | 121,080 | 283224 → 969254 |
| 181273 | 용자의 표식 (월드 보스) | 45 | 2,000,000 | 242,160 | 315283 → 1046803 |
| 234598 | 승리의 열매 (1위) | 40 | 4,000,000 | 484,320 | 449418 → 1413528 |

원본 양은 현재 게임의 성수 경험치와 같은 TWILIGHT 경험치 단위로
환산한다. 획득 경로, 랭킹 지급, 레벨 규칙, 재화, 아인하사드 축복,
정상 스탯 세이브와 별도 경험치 아이템은 변경하지 않는다. 새 연결은
기존 레벨 성장 계산을 사용하며 경험치ㆍ레벨ㆍ스탯 포인트ㆍ실물 차감이
한 저장으로 함께 반영된다. 몬스터 도감 메뉴를 다시 활성화하거나 별도
레벨 상한을 도입하지 않고, 저장 정수 범위를 넘는 사용은 막는다. 보상
이름이 같은 아이템을 대신 소모하지 않는다.

170214 경험의 열매 (4위)는 표의 500,000 EXP와 설명의 1,000,000 EXP가
충돌하고, 3062는 표의 532,607,817 EXP와 이름의 10만 EXP가 충돌한다.
둘 다 이 사용 대상이 아니다. 정합한 1~3위/승리 열매는 원본 상자 참조가
있으나 플레이어에게 지급되는 실제 랭킹/NPC 시스템까지 추가한 것은 아니다.
Main 테스트는 원본 지급자(개발 검증 지급), 실제 가방 신호, 정상 저장
경계를 사용하는 것으로 새 상점 판매 또는 현재 사용자 소지를 의미하지 않는다.

검증: 고정된 원본 523 정의로 `native_exact_experience_main_test` 26/26.
각 아이템의 실제 가방 사용과 수량 1 차감, 레벨 조건 두 종류, 기존
성장 규칙으로 45→46 및 미배분 포인트 1점, 축복 수치 유지, 같은 실물
재사용 거부, 정수 범위 초과 거부, 저장 실패 시 파일ㆍ성장ㆍ아이템
보존, 성공 후 디스크 재로딩을 독립 저장 디렉터리에서 확인했다. 원본
정의가 없는 Core 환경에서는 미승인 저장 권한과 제외 ID 검사 2/2만
수행하며 실제 원본 Main 실행을 대신하지 않는다.
