# 원본 스킬창 스크롤과 퀵슬롯 드래그

원본 `Skill_All.csb`의 탭별 스크롤 영역과 `Slot_Skill.csb`의 타일은 그대로 쓴다. 슬롯 위나 목록 여백에서 시작한 입력은 가방과 같은 `PointerTransfer`가 같은 손가락/마우스의 종료·취소까지 맡는다. 기존 가방과 같은 시작 거리(터치 10, 마우스 8)를 쓰고, 첫 실질 움직임이 세로 우세면 목록을 움직인다. 스크롤로 정해진 뒤에는 손가락이 범위를 나가거나 퀵슬롯에 닿아도 등록·선택·시전하지 않는다. 다른 손가락은 이 입력을 가로채지 않는다. 기존 탭, 휠 스크롤, 위·아래 끝과 가상화된 행 수는 그대로다.

짧은 탭은 원래의 선택이다. 장착/사용을 호출하지 않는다. 스킬 타일에서 가로로 끌거나 기존처럼 0.3초 길게 누르고 옮기면 퀵슬롯 드래그다. 캐릭터가 배웠고 등록이 허용된 스킬만 등록되며, 이름이 아닌 현재 타일의 정식 스킬 ID를 기존 등록 및 저장 함수에 보낸다. 화면/탭이 바뀌거나, 스킬을 쓸 수 없거나, 퀵슬롯이 아닌 곳에 놓거나 입력이 취소되면 기존 바인딩을 건드리지 않는다. 원본 가방과 원본 스킬창의 창 전체 위치는 바꾸지 않는다. 기존 폴백 창 제목줄 이동은 변경하지 않았다.
