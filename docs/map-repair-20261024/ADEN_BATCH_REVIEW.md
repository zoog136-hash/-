# 아덴 18개 기존 통행 구역 일괄 검수

기존 18개 통행 다각형을 현재 원본 PNG 위에 한 차례 대조해 문제 목록을 만든 후, 오등록과 누락이라는 공통 원인별로 묶어 수정했다. 다른 판의 지도, A3, 13366/13022 좌표를 사용하지 않았다. PR152의 발 반경/대각선 보정 코드는 그대로 보존했다.

## 분모와 완료 범위

- **1차 PNG 대조 완료 18/18**, 이 수준에서 미검토 0/18. 분모는 이미 존재하는 18개 통행 구역이며 전체 아덴 PNG 면적을 뜻하지 않는다.
- **국소 오류 수정·검증한 구역 5/18**: 사막, 설원, 산적 야영지, 사막 보스, 폐허 보스 접근로. 다른 13/18은 기존 경계를 유지했다.
- 이번 배치 **16개 오브젝트 수정**: 잘못 놓인 기존 blocker 7개 재등록, 누락 blocker 9개 추가. 직전 오두막 1개 포함 누적 17개. 모든 오브젝트를 검수했다는 뜻이 아니다.
- **구역 전체 지형·전경 정밀 검증 완료 0/18**. 가려진 줄기, 지붕과 벽의 가림, 절벽 단차, 현재 다각형 밖 도로는 남아 있다. 전체 재구성 완료라고 보고하지 않는다.

## 수정 원인과 실제 판정

기존 사막 충돌원은 바위/수정에서 벗어나 빈 땅을 막았다. 기존 5개를 눈에 보이는 바위/수정 발 영역으로 옮기고 크기를 줄이거나 hull로 바꿨다. 설원의 작은 나무 1개와 사막 보스 구역 바위 1개도 빈 땅을 막는 중심을 재등록했다. 분명하게 구분되는 큰 수정 8개와 폐허 접근로 낮은 담장 1개에는 새 차단을 넣었다. 작은 그림자/색상만 보고 자동으로 차단하지 않았다.

변경 전/후 동일 좌표에서 검사한 빈 땅 표본 7개는 모두 막힘→통행 가능으로 바뀌었다. 새 물체 중심 16개는 최종 모두 격자 및 실제 물리에서 차단된다. 그중 바위 하나는 종전 큰 원에도 포함됐으므로 원래 전부 통과 가능했다고 주장하지 않는다. 실제 원자료는 `evidence/aden-batch/before/results.json`, `after/results.json`이다.

원본 픽셀·59청크·6배 균등 배율·월드 경계·77슬롯·38포탈은 유지한다. 코드 수정은 흐림을 해결하지 않는다. 전후 화면은 4개 변경 구역 × 2해상도(1280×720/854×480) × 전후이며 동일 카메라, 48MiB 모바일 청크 정책의 PC OpenGL이다. 충돌 데이터만 바뀌므로 배경 그림은 동일하다. Android 실기는 아니다.

## 남은 작업에 필요한 근거/선택

현재 PNG로 뚜렷한 물체는 계속 수동 검수할 수 있다. 하지만 수관 뒤 줄기·건물 아래 발 경계는 그림에서 가려져 있고, 절벽 음영만으로 고저차/계단 여부를 확정할 수 없다. 해당 구역은 발 경계 주석이나 같은 판의 상세 그림이 있으면 원형을 더 정확히 복원할 수 있다. 자료 없이 진행한다면 원본 동작 복원이 아닌 **새로운 통행 규칙을 설계**해야 한다(가려진 부분을 보수적으로 막을지, 현재처럼 통행시킬지). 이 선택을 임의로 적용하지 않았다. 현재 구역 사이 모든 도로 연결도 별도 설계/수동 검수 범위다.

`ADEN_ZONE_REVIEW.json`에 각 구역의 원본 좌표 범위와 상태를 보존한다. `tests/aden_batch_review_probes.json`은 이번 16개 변경의 원본 좌표와 검사점을 담는다. source/base SHA 고정 검수 레이어에서만 적용하며, 새 ID 중복/범위 밖 좌표/비정상 반경/잘못된 다각형은 거부한다. 기존 원본과 불변 계획을 덮어쓰지 않았다.

## 최종 검증

배치 대상 검사 133개 PASS: 수정점 격자/물리, 38포탈 위치, 17개 사냥터의 다음/귀환 경로 34개, 변경 구역의 스폰 후보 표본, 기존 오두막 및 월드 경계/77슬롯 유지. 마지막 선택 통합 6/6 PASS, skip0: import, boot, 배치 검사, 기존 Main 보행/포탈/저장 138, PNG 전체 격자 동등성, 레이어 소유권. 최초 렌더 검사 98개와 경로 검사를 추가한 최종 검사를 구분 보존했다. 구역별 전체 CI 반복 없이 최종 통합 한 번만 실행했다. 전체 원격 CI 완료 주장은 하지 않는다.
