# 아덴 PNG와 충돌 경계의 구역별 후속 대조

원본 TIL이 없어도 현재 PNG의 보이는 지형을 수동 검수할 수 있다. 해상도 부족과 충돌 좌표 오류를 분리해서 조사했다. 원본의 6배 확대에 따른 흐림은 남지만, 실제 충돌 오류 한 곳은 기존 PNG만으로 수정했다. 원본·청크·월드 크기·배치를 바꾸거나 다시 청크화하지 않았다.

## 완료한 범위: 산적 야영지 오두막 한 곳

현재 SHA c0af339cbc2dbba5fb2e65c3c7f01d9467507545d7b91cbb331f5bbd51128730 원본의 `(8750,4960,130,130)` 구역을 원본 픽셀로 확대해 대조했다. 기존 `bandit_hut` 다각형은 건물 북서쪽 빈 마당을 막고 남동쪽 벽을 놓쳤다. source 좌표 `(8820,4990)`은 빈 마당인데 막혀 있었고 `(8853,5053)`은 벽인데 통과했다. 실제 Main의 CharacterBody2D도 동쪽에서 벽으로 이동할 때 충돌하지 않았다.

`aden_png_display_review.json`의 SHA로 고정된 검수 레이어에 벽 하단 다각형을 추가했다. 기존 불변 계획/원본과 기존 동부 나무 전경은 보존한다. Registry가 검증된 polygon 교체도 읽도록 확장했으며 source 범위/삼각분할 검사와 알려진 ID 검사에 실패하면 적용하지 않는다. 수정 후 마당은 통행 가능, 벽은 격자/실제 캐릭터 모두 통과 불가다. 지붕을 새 전경으로 분리한 작업은 아니다.

| 실제 판정 | 전 | 후 |
| --- | --- | --- |
| 북쪽 빈 마당 통행 | 불가 | 가능 |
| 남동쪽 벽 통행 | 가능 | 불가 |
| 벽으로 이동하는 실제 몸체 충돌 | 없음 | 있음 |
| 아덴 슬롯 | 77 | 77 |
| 월드 경계 | (11802,2214,72240,45708) | 동일 |

전후 1280×720 및 854×480 PC OpenGL 화면은 `evidence/aden-hut/`에 있다. 빨간 선은 검사 도구가 실제 런타임 충돌 다각형을 그린 것이며 일반 게임에 추가된 선이 아니다. 동일 위치/카메라, 몬스터 움직임 정지, 48MiB 모바일 청크 정책으로 촬영했다. Android 실기 결과가 아니다.

## 조사했지만 완료로 간주하지 않은 범위

18개 기존 통행 다각형을 원본 위에 표시해 개요 대조했다. 아래는 전체 정밀 검수 완료 목록이 아니다.

| 구역 | 상태/남은 작업 |
| --- | --- |
| 궁전 광장·성문 초원 | 통행 다각형이 광장/성문 밖 바닥을 제한적으로 덮는다. 외곽 도로/성벽 전체 연결과 전경은 미검수. |
| 동쪽 숲 공터 | 작은 원형 blocker만으로 목조 구조물 전체를 설명하지 못하는 후보 발견. 구조물의 기둥/통과 가능한 틈/발 기준을 정밀 검수해야 한다. 이번에는 추정으로 확대하지 않았다. |
| 강변 폐허·중부 폐허·동부 숲 | 유적 및 나무의 그림/발 영역 구별 필요. 기존 동부 나무 전경만 유지. |
| 산적 야영지 | **오두막 한 곳의 마당/벽 오류만 수정 완료**. 다른 나무·남쪽 건물·지붕 가림은 미검수. |
| 사막·사막 보스·설원 | 암석/수정/나무별 발 경계와 전경 미검수. |
| 용의 계곡·드레이크·흑장로·바람 능선 | 절벽의 높이/통과 경계 정밀 검수 필요. |
| 화염 지대·화염 보스 | 용암 및 현무암 가장자리 정밀 검수 필요. |
| 서부 숲·폐허 보스 | 수목·성벽의 전경/발 경계 정밀 검수 필요. |

원본 18개 구역 사이 전체 도로와 연결은 아직 복원하지 않았다. 현재 38개 포탈 연결 유지. 전체 작업에 추가 원본이 반드시 필요한 것은 아니지만, 현재 개요도에서 식별이 어려운 구조물은 상세 원본이 있으면 도움이 된다. 미검수 구역까지 통행을 임의 확장하거나 전경으로 자동 분리하지 않았다.

PR152 최신 `native_png_field.gd` 패치를 읽기 전용으로 비교했다. 해당 PR는 모든 PNG 격자의 4px 발 반경 및 대각선 이동 보정이며 source collision을 변경하지 않는다. 이번 오두막은 검수 데이터와 Registry만 변경해 해당 보정을 덮어쓰지 않는다. 기존 PR155의 alpha raster와 PR152를 통합할 때 재검사는 여전히 필요하다.

## 집중 검증

`tests/aden_hut_collision_test.gd` 실제 OpenGL 실행에서 6,533개 검사 통과. 마당/벽 격자와 실제 몸체 충돌, 우회 경로, 기존 벽 안 좌표의 유효 셀 보정, 38개 포탈 위치, 전체 스폰 후보, 실제 귀환/출발 포탈 이동을 확인했다. 수정 전의 잘못된 판정도 별도 실행 결과로 보존했다. 원본 리소스 검사 723개 atlas/41,442프레임 통과.

최종 집중 통합 6/6 PASS, skip0: import, boot, 아덴 배율 저장 이전, 기존 Main 맵 회귀 138, PNG 전체 셀 비교, 전경/지면 레이어 소유권. 로그는 evidence/aden-hut/integration에 보존한다. 전체 원격 CI 완료를 뜻하지 않는다.
