정지 화면으로는 대각선 광택의 방향·주기·밝기나 신화 회전의 축을 검증할 수 없다. 공개 플레이 영상 후보도 검색했으나, 이 세션에서는 아이템 슬롯의 연속 프레임을 신뢰할 수 있게 추출하여 원작의 주기를 측정하지 못했다. 따라서 아래 수치는 **사용자의 연출 요구를 TWILIGHT에 적용한 설정**이며 원작의 측정값이라고 주장하지 않는다.

| 등급 | TWILIGHT 구현 | 원작과의 차이/검증 한계 |
|---|---|---|
| 일반·고급·희귀 | 원본 텍스처 그대로, 상시 효과 없음 | PNG에 원래 포함된 광채·워터마크·숫자는 그대로 남음 |
| 영웅 | 좌상→우하 광택, 4.8초 주기 중 1.25초 통과, 최대 혼합 0.27 | 원작 시간·밝기 일치 미검증. 원본 RGB/알파를 지우지 않고 추가 광택만 마스킹 |
| 전설 | 같은 방향, 4.1초 주기, 최대 혼합 0.43 | 흰색 덮임을 제한한 별도 조정값 |
| 신화 | 약 8초 깊이 회전 표현, 옆면 폭 최소 42%, 작은 기울기와 명암 변화 | 실제 3D 모델이 아닌 UV 기반 양면 회전 모사. 원작 축/속도 일치 미검증 |
| 유일 | 신화 회전 + 청록 발광과 공전하는 작은 반짝임 | TWILIGHT 기존 등급 색상에 맞춘 자체 표현 |

아이콘마다 sourceId/이름으로 결정한 8개 위상 중 하나를 공유하여 고등급 목록 전체가 동시에 하얗게 번쩍이는 현상을 줄였다. 영웅~유일 4등급 × 8위상, 최대 32개 재질이며 슬롯마다 Tween이나 매 프레임 스크립트를 생성하지 않는다. 목록/퀵슬롯/드래그/월드 바닥은 정적으로 유지한다.

원본 PNG가 불투명한 배경·INVEN 워터마크·장식 숫자를 포함한 경우 이 내용도 아이콘 그림의 일부로 회전한다. 슬롯 배경과 게임의 실제 강화·장착·잠금·수량 표시는 별도 UI이므로 움직이지 않는다. 원본 이미지를 임의 지우거나 저해상도로 다시 저장하지 않았다. 배경 없는 허가 원본으로 교체하는 작업은 권리와 파일이 확보된 후 같은 PR에서 진행한다.

인터넷에서 열 수 있다는 사실은 공개 재배포 허가가 아니다. 이번 원본 연결 집계는 **기존 Git 자산의 아이템 신원 확인**이다. 새 외부 원본 파일 0개, 원본 팩 전달 완료 0건이며 `data/resource_delivery_ledger.json`의 기존 `not_delivered` 상태를 유지했다.
