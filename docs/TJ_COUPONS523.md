# TJ 카드 쿠폰의 로컬 거래와 검증 범위

이 변경은 최신 523 원본의 카드 쿠폰 139개와 재도전 정책 10개를 읽습니다. 원본 ZIP은 해시와 1,065표 구조를 확인한 뒤 비공개 사용자 경로에 보관합니다. 원본 표, 아트, 보고서와 보관 링크는 이 변경에 포함하지 않습니다. 원본 설치 검증은 백그라운드에서 수행하며 일반 Main 시작을 막지 않습니다.

공통 입력은 `lineagem_patch523_all_content_validated_and_508_520_deltas.zip`의 523 스냅샷이며 크기는 25,031,173바이트입니다. SHA256은 `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`입니다. 기능별 복제 팩을 만들지 않습니다. 메뉴에서 이 파일을 선택하면 같은 바이트를 `user://tj523-source.zip`에 검증해 설치하고, 재시작 후 해당 메뉴를 열 때 다시 검증해 읽습니다. 설치 파일의 보관과 실제 소비, 플레이어 저장을 별도로 취급합니다.

Main 메뉴의 **TJ 쿠폰**에서 원본을 설치하고 실제 서버 지역과 월드 번호를 선언할 수 있습니다. 소유 쿠폰, 실제 실패 기록, 후보 선택, 확인과 취소를 거쳐 쿠폰 소모와 결과를 기존 전체 저장 파일에 원자적으로 기록합니다. 저장이 실패하면 쿠폰, 보상, 재화와 난수 상태를 발표하지 않습니다. 선택 이후 상태가 바뀌거나 같은 확인을 반복하면 거부합니다. 손상된 TJ 저장은 기존 파일을 덮어쓰지 못하게 보호합니다. 기존 임시 퀘스트와 즉시 완료 기능은 보존합니다.

## 원본을 적용하는 범위

- 변신, 마법인형과 성물의 일반·스페셜 합성은 기존 정상 합성의 실제 실패 이벤트와 당시 실제 엔진 후보를 기록합니다. 카탈로그에서 실패 이력이나 소유권을 만들지 않습니다.
- 옵션 각성의 실제 실패 이벤트는 기존 각성 거래와 함께 저장합니다. 쿠폰 재도전은 현재 각성 엔진의 비용, 경험치 주입, 소유권과 적용 효과를 유지합니다. 각성에 스페셜 합성의 실패 후보 다섯 개 조건을 붙이지 않습니다.
- 이력은 `HistoryType`으로 연결하며 행 ID로 연결하지 않습니다. 이력 최소 등급과 쿠폰 최소 등급, 계정과 캐릭터 범위를 따로 검사합니다. 현재 단일 플레이어 저장의 계정·캐릭터 구분은 명시적인 로컬 어댑터이며 온라인 계정 인증이 아닙니다.
- 시즌 번호를 시즌 행 ID로 사용하지 않습니다. 이력 종류, 시즌 값, 서비스 지역과 월드 튜플로 유일한 기간을 선택합니다. 이력 조회 기간과 쿠폰 소멸일은 별도로 검사합니다.
- 기존 옵션 각성 엔진의 입력은 최신 523 원행과 거래 시점에 대조합니다. 비용·경험치 99행, 카드 289행과 그룹 369행은 현재 입력과 같지만, 효과 연결 1,966행 중 세 행은 변경됐습니다. 변경된 입력을 쓰는 대상은 과거 값으로 실행하지 않습니다.

스킬 합성 정책 한 개의 두 예외 플래그도 그대로 읽지만, 현재 Main의 일반 카드 합성 엔진은 스킬 덱을 지원하지 않습니다. 기존 스킬 저장은 해시 기반 스킬 ID를 사용하며 최신 원본의 스킬 카드 소유권·실패 엔진과 동일하지 않습니다. 이를 이름이나 숫자 일치로 조인하거나 일반 카드 보상으로 대체하지 않습니다. 이 경로는 실행 어댑터 연결 전까지 쿠폰을 소모하지 않습니다.

전체 `PlayerValueReturn` 정의 18개 중 카드 범위는 10개입니다. 나머지 장비 복구 정의는 카드 후보로 확대하지 않습니다. 기존 장비 카탈로그의 외부 도감 ID를 원본 장비 ID로 간주하지 않으며, `ItemEnchantEquipGroupID`와 실제 소실 개체의 검증된 연결이 필요합니다. 사망 복구 기능과 별개입니다.

## 공급과 미확정 실행 규칙

전수 감사 도구는 전체 1,065표를 읽어 직접 타입이 있는 쿠폰 참조를 대조합니다. 카드 쿠폰에 연결된 제작 입력 42행, 제작 출력 10행, 상자 결과 29행과 NPC 드롭 한 행이 있습니다. 이 감사는 해당 제작·상자·NPC 공급기가 현재 게임에서 실행된다는 뜻이 아닙니다. 현재 UI의 쿠폰 지급 버튼은 명시적인 디버그 도구이고 출시용 공급 경로가 아닙니다. 실패 기록을 지급하는 버튼은 없습니다.

네이티브 서버의 후보 구성과 추가 신비 보상은 복원됐다고 주장하지 않습니다. 현재 로컬 합성 재도전은 기록된 실제 후보에서 성공 후보 한 개와 정책에 맞는 실패 후보를 고르고, 원본 성공 확률로 결과 한 개만 받는 TWILIGHT 어댑터입니다. 스페셜 합성의 실패 후보는 서로 다른 다섯 개입니다. 기본 추가 아데나 비용은 명시적인 로컬 설정 0이며 원본이 무료라는 해석이 아닙니다. 각성은 기존 엔진 비용과 경험치 조건을 추가로 지킵니다.

`user://tj523-policy.cfg`의 `[local_policy]`에서 다음 로컬 정책을 조정할 수 있습니다. 원본 값은 변경하지 않습니다.

- `utc_offset_minutes=540`은 시간대 없는 원문 날짜를 비교하는 TWILIGHT 기본 시간대입니다.
- `retry_gold_cost=0`은 추가 거래 비용입니다.
- `allow_no_season=false`는 시즌 없는 81개 입구에 최신 시즌을 임의 지정하지 않습니다. 명시적으로 허용하면 같은 소유자·서버의 실제 로컬 기록만 조회하며, 기록이 없는 보상을 만들지 않습니다.
- `allow_unknown_expiry=false`는 소멸 효과가 없는 12개를 영구 쿠폰이라고 선언하지 않습니다.
- `legacy_time_mode="blocked"`는 구형 양수 시간 37개를 Unix 초나 날짜 행 ID로 바꾸지 않습니다. 운영자가 명시적으로 `"calendar_yyyymmddhh"`를 선택하면 그 형식으로 해석하는 로컬 정책을 사용합니다.

현대식 날짜 적용대상 90개는 `Value=0`이어도 실제 날짜 행을 확인합니다. 만료·서버 불일치·기록 없음·미확정 규칙은 소유 쿠폰을 보존한 채 거부합니다. 이력이 없는 희귀 기본 보상도 임의로 생성하지 않습니다.

## 재현과 실제 검사

`tools/audit_tj523_source.py`에 비공개 원본·보고서 ZIP과 저장소 밖 출력 경로를 전달하면 전체 원문과 전용 보고서를 대조합니다. 테스트는 전용 사용자 프로필을 사용해야 합니다.

```bash
python tools/audit_tj523_source.py --source-zip "$SOURCE_ZIP" \
  --report-zip "$REPORT_ZIP" --output "$LOGS/source-audit.json"

TWILIGHT_TJ_TEST_ROOT="$PROFILE" XDG_DATA_HOME="$PROFILE/data" \
  XDG_CACHE_HOME="$PROFILE/cache" XDG_CONFIG_HOME="$PROFILE/config" \
  TWILIGHT_SOURCE_MAP_PACK="$MAP_INPUT" \
  godot --headless --path "$STAGE" --script tests/tj_coupon_main_test.gd -- "$SOURCE_ZIP"
```

실제 Main 검사에서는 원본 쿠폰의 과거 이력 기간을 재현하는 격리된 fixture 시계를 사용합니다. 운영체제 시각이나 사용자 세이브를 바꾸지 않습니다. 서비스 검사, 실제 저장기 검사, Main 메뉴 거래 검사와 기존 옵션 각성 회귀 검사를 구분합니다. Linux Godot 4.6.3 실행 결과는 기준 Godot 4.7.2 또는 Android 실기기 검증을 대신하지 않습니다. 필수 CI, 보호 규칙과 APK 워크플로는 변경하지 않습니다.
