# 현행523 SP2 추정 재생

사용자가 원문·보고서·공개 자료를 우선하고 남은 게임 내부 해석은 설정 가능한 추정으로 구현하도록 승인했다. 이어서 리니지M 엔진/APK 조사 중단을 요청했다. 이 기능은 TWILIGHT의 Godot에서 정상 확보한 SP2를 직접 읽는다. 기존 엔진 부재 조사 기록은 이 기능의 실행 조건이 아니다.

## 사용 경로

**메뉴 → 설정 → 현행523 표준 이미지 · 원문 → SP2 추정 재생**에서 사용한다. 기존에 제공된 76,907,660-byte 원문 ZIP을 설치하면 같은 파일을 다시 받을 필요가 없다.

1. `추정 미리보기 사용`을 직접 켠다. 초기값은 꺼짐이다.
2. 원문 SP2 파일과 저장 그룹 bit를 선택한다. 검색·그룹 선택·재생/일시정지·이전/다음 프레임·진행 막대를 사용할 수 있다.
3. FPS, 반복/1회, RGB 확장, 색인0 투명 처리, 합성, 불투명도, 확대를 조절한다. 미리보기는 즉시 반영된다.
4. `게임 안 추정 표시`를 켜고 `플레이어 옆 샘플` 또는 `플레이어 외형 직접 선택`을 고른 뒤 설정을 저장한다. 플레이어 외형을 고르면 호스트 기준 오프셋을 0으로 제안하며 사용자가 다시 조절할 수 있다.

게임 안 표시에도 추정 문구가 남는다. 플레이어 외형 선택은 표시 노드만 바꾸며, 해제하면 기존 외형을 복구한다. 파일이 현재 클래스·변신·NPC·이펙트와 같은 정체라고 자동 판정하지 않는다. 선택된 저장 프레임의 순차 재생이며 Walk/Run/Attack 또는 세계 방위를 복원한 애니메이션은 아니다.

## 적용 입력과 원본 보관

승인된 비공유 프로젝트의 `PR236_01_실제적용팩`과 `PR236_02_원본백업`을 분리했다. 적용 파일은 `TWILIGHT_PR236_current523_SP2_estimated_runtime_input_v1.zip`, 보존 사본은 `TWILIGHT_PR236_current523_SP2_989_PNG2_original_source_v1.zip`이다. 둘 다 검증한 인계 원문을 Drive 안에서 복사한 76,907,660-byte 입력이며 기준 SHA-256은 `b6f665d03e84e7cd01b3dd15b60d94091b3ff762cdc58fcfd820c724aa622182`이다. 추정 PNG를 새로 담은 팩이 아니다. 백업 사본은 별도 재다운로드하지 않았고, 적용 사본은 새 소비 폴더로 정식 다운로드해 동일 SHA·전체 ZIP CRC·내부 1,012개 항목을 확인했다.

checkpoint 01~04의 기존 8개 조각은 파일 ID와 링크를 유지해 백업 폴더로 옮겼다. 합친 ZIP은 Work에 있으며 Drive에는 순서가 있는 두 조각씩 보관된다. 전체 이름·크기·원문 SHA는 기존 원문 검사 기록을 유지한다. 공유 권한은 넓히지 않았고 무관한 보고서·감사자료·캡처를 새로 업로드하지 않았다.

Drive 보관 후 사용자가 ZIP을 선택해야 설치된다. 새 실제 프로젝트 사용자 폴더에서도 적용 사본 설치 1,006개 검사와 새 프로세스의 확정 PNG 2종·추정 SP2 텍스처 로드를 확인했다. 992개 입력 파일과 생성 영수증을 포함한 설치 결과는 `user://lineagem_current523_versions/pack-*` 아래에 있다. Work의 설치 폴더는 임시이며 사용자 PC/Android의 설치 완료나 새 실행본 전달을 뜻하지 않는다. 실제 Main/OpenGL 검사와 새 Drive 사본의 소비 폴더 검사를 별도로 기록한다. 비공개 파일·폴더 링크는 소유자 인계 기록에만 남긴다.

## 원문과 추정의 경계

| 항목 | 보존·검사 | 표시 정책 |
| --- | --- | --- |
| 입력 | 고정 레지스트리 SHA 및 선택 원문 크기/SHA-256 | 원문을 덮어쓰지 않음 |
| palette | 원시 u16과 marker 유지. marker1은 1/3색 후보 중 구조 전체가 유일하게 맞는 경우 선택 | RGB565 비트 복제/선형 확장은 추정 선택 |
| 그룹 | 원시 mask의 bit 유지, 모든 그룹 메타데이터 뒤 샘플 스트림 처리 | bit를 동서남북으로 자동 변환하지 않음 |
| 프레임 | 원시 four-i16, type, 명령, 참조 순서 및 u16 누적 wrap 보존 | commandwise 및 floor-half 후보 배치. 비빈 샘플의 half-open 범위가 원문과 달라지면 거부 |
| index0 | 커버된 index0과 빈 공간 구분 | 기본은 커버 샘플 불투명. index0 투명은 별도 추정 옵션 |
| 합성 | 원시 type/attr을 임의 합성식으로 바꾸지 않음 | mix/add/multiply·불투명도를 사용자가 선택 |
| 빈 프레임 | 61개 빈 레코드와 해당 원문 범위 보존 | 투명 표시. 보이는 픽셀을 만들지 않음 |
| 속도·순서 | 원문 SPR 선언을 새로 만들거나 변경하지 않음 | 저장 레코드 순서, 기본 12 FPS는 호스트 미리보기 선택. 1~60 FPS 및 반복 여부 조절 |
| 배치 | 프레임별 원문 범위와 오프셋 유지 | 호스트 원점·확대·표시 위치는 사용자 설정. 발 앵커·외형 정규화·보간 없음 |

12 FPS, alpha, RGB, 합성, 저장 순서, 호스트 배치를 M 원본의 실행 규칙으로 표시하지 않는다. 원문 구조 검사·추정 픽셀 렌더·실제 TWILIGHT 화면 검증·M 시각 동등성은 서로 다른 결과다. 기존 확정 PNG 2종은 계속 별도 표준 이미지 경로로 표시한다.

## 실행과 보존

`current523_sp2_decoder.gd`는 2 MiB 입력, 32 MiB Brotli 출력, 참조/명령/샘플/캔버스 한계를 둔다. 각 palette 후보의 정확한 디코딩 본문 EOF, 참조와 색인 범위, 비빈 프레임의 원문 범위를 확인한다. Godot의 잘린 입력에 대한 동적 Brotli 경로에서 종료되지 않는 사례를 확인해, 유한 버퍼의 one-shot 해독을 사용했다. 실패는 UI 오류로 반환하고 이전 게임 표시와 설정을 유지한다. 런타임 입력은 고정 레지스트리의 원문 해시를 먼저 검증한다.

UI와 게임 안 표시의 텍스처 캐시는 각각 최대 8개다. source type에 따라 밝기 alpha나 프레임 보정을 자동 적용하지 않는다. `current523_playback.gd`는 `user://current523_estimated_playback.json`에 별도 설정을 기록하고, 쓰기·flush·원자적 전환이 성공한 뒤에만 활성 설정과 리비전을 바꾼다. 실패하면 게임 안 표시는 이전 설정으로 유지되고 조작 중인 UI 값은 남는다. 재진입은 저장에 성공한 값을 복원한다.

게임 세이브, 클래스/변신 정체, 아이템·재화·중복 지급 보호, 충돌·이동·공격 속도는 이 표시 설정에 쓰지 않는다. 기존 base508 팩이나 승인된 게임 규칙을 바꾸지 않는다. 기존 원본 ZIP·SP2 및 설치 영수증을 보존하고, 생성 이미지·원본·화면 캡처·비공개 입력 주소는 공개 PR에 넣지 않는다.

## 근거와 검증

원문 인계와 정정, [독립 원문 검사](current523-source-audit.json), [공개 구현의 반례 조사](current523-replay-investigation.md)를 먼저 대조했다. 공개 [SP2 구현](https://github.com/tony1223/PakViewer/blob/fbad69239e3e3c12ec18dfc7722bed284be093cc/src/Lin.Helper.Core/Sprite/L1SP2.cs)의 marker1 고정3색·그룹 수·grouped RLE를 그대로 채택하지 않는다. [Godot의 압축 API](https://docs.godotengine.org/en/stable/classes/class_packedbytearray.html)로 표준 Brotli를 읽는다. 공개 프로그램 실행파일이나 외부 엔진을 게임에 포함하지 않는다.

`tests/current523_sp2_decoder_local.gd`의 실제 원문 검사는 989개 파일, 17,115개 후보 레코드 전체를 읽고 렌더한다. 17,054개 비빈 범위 일치와 61개 빈 프레임, marker1의 두 구조, mask3, 원문 index0 보존을 확인한다. 합성 사례는 u16 wrap·제어단어1024·잘린 입력·큰 출력·잘못된 참조·표시 옵션을 별도로 검사하며 이를 실물 M 사례로 계산하지 않는다.

`tests/current523_estimate_main_local.gd`는 실제 Main/설정/플레이어를 사용해 재생 시간 진행, 일시정지, 프레임 이동, 저장 오류, 재진입, 플레이어 표시 교체·복구와 세이브/원문 바이트 보존을 확인한다. 실제 원문을 요구하는 두 검사는 `_local.gd` 이름으로 수동 직접 검사에 남기며 자동 CI에 비공개 원본 다운로드를 요구하지 않는다. 최신 실행 기록은 `current523-estimate-validation.json`에 남긴다.

## 현재 한계

검증된 M 캐릭터·몬스터·이펙트의 정체별 자동 연결, 원래 SPR 동작/방향/속도, 최종 내부 픽셀 순서·색·alpha·합성의 M 동등성은 미완료다. 지금 확인한 것은 정상 원문에서 계산한 **추정 재생이 TWILIGHT UI와 선택한 플레이어 표시에서 동작한다는 것**이다. Android 실기기나 기존 사용자 APK에 새 코드가 설치됐다는 결과도 아니다. M 엔진/APK 탐색은 사용자 요청으로 중단했으며 이 기능 재개의 전제로 요구하지 않는다.
