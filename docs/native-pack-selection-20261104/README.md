# 원본 팩 선택 경로 및 스냅샷 보호

현재 범위: 사용자 지시로 최신523 신규 변신16루트의 추가 연결을 취소했다. 해당16루트는 이 브랜치의 게임 카탈로그나 적용팩에 등록되지 않았으므로 삭제할 실행 항목은 없고, 추가 제작·원문 탐색·미완료 대상으로도 남기지 않는다. PR217의701종과 기존434변신루트, 기존 카드에 붙은 외형은 그대로 재사용한다. 아래26종 비교 경로 역시 기존434루트에 포함된다. 신규 인형4종·성물1종은 이번16루트 제외와 별개이며, 카드 정의·스탯은 PR249 담당 범위를 따른다. [제외 대상과 유지 범위](current523-identity-playback.md#pr217-reuse-and-current523-delta-scope)에 기록했다.

최신 후속은 [기존 변신26종의 정확한 정체 연결](current523-identity-playback.md)이다. 전체69 DAT의10,338개 SP2를 대조해 원문328개와 무기별304개 프로필·183개 달리기 트랙을 별도 비공개 팩으로 연결했다. 실제 Main/OpenGL1,579검사, 새 프로세스11검사, Drive 적용 사본을 받은 새 소비 폴더11,820검사가 통과했다. 장착/해제·이전 표시 복귀·저장 실패·파일 손상·세이브 보존을 확인했으며 픽셀/합성은 추정이다. [정확한 검증 집계](current523-identity-validation.json)와 [ID별 누락](current523-identity-coverage.json)을 따른다. 아래의 앞선 조사·원문 보관 단계는 당시 이력이다.

기준 main: `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`. 별도 브랜치 `feature/native-pack-selection-20261104`. 중단된 `catalog-main-validation` 브랜치를 병합하지 않았고, 호환 도감팩이나 source3을 원본 캐릭터팩의 필수 조건으로 추가하지 않았다. 맵 지형·포탈·스폰·각성 정의는 수정하지 않는다.

기존 `--lineagem-original-preview=/absolute/path/custom.json`은 Player의 캐릭터 경로만 바꿨다. 카드 UI는 별도로 기본 설치 경로를 읽어 서로 다른 팩을 섞을 수 있었다. 이제 명시한 선언 파일 및 부모 디렉터리를 공유하며, 파일명도 그대로 유지한다. 명시 선택, 최신 설치 버전, 구형 사용자 설치 위치 순으로 선택하고 세션 중에는 바꾸지 않는다. 명시 선택의 누락·손상·지원하지 않는 스냅샷을 다른 팩으로 숨기지 않는다. 증분의 해시 검사와 신뢰 가능한 이전 설치 경로 제한은 유지한다.

현재 캐릭터·카드·이펙트 소비자는 base508 정의와 ID를 사용한다. 캐릭터 로더와 주문/전역 이펙트 진입부는 이제 선언의 스냅샷을 검사한다. patch523 선언이나 버전 없는 선언을 base508의 같은 숫자 ID로 해석하지 않는다. 이 변경은 523 디코더나 720카드 실행 연결의 완성이 아니다. 구형 진단용 빌더도 자신이 다루는 base508 스냅샷을 선언하도록 맞췄다.

실제 게임의 **메뉴 → 설정 → 리니지M 원본 팩**에 선택 상태와 지원하지 않는 버전의 이유가 표시된다. ZIP 선택·진행·취소·실패 후 재사용 경로를 유지한다. 명시 선택 옵션을 사용한 상태에서 설치하면 새 팩을 사용하기 위해 그 옵션을 해제하고 재실행해야 한다는 안내를 표시한다. 상태 표시만으로 원본 픽셀 전체 전달이나 원작과의 시각적 일치를 주장하지 않는다.

## 검증과 미완료

`check_resource_integrity.py --root .`은 변경 전후 723개 시트, 41,442프레임, 233,420,026 bytes와 기존 해시를 확인했다. `--source-dir`은 장부에 기록된 과거 `a1.zip`이 현재 환경에 없어 실패했다. 이를 원본 전체 검증 통과로 계산하지 않는다. 이번 수정은 원본 아트 재변환이나 세이브 스키마 변경을 하지 않는다.

Godot 4.7.2에서 합성 이미지의 실제 텍스처 로딩, 명시 선택 우선순위, 사용자 지정 선언 파일명, 누락·빈 경로·523 거부 및 설정 상태 표시를 검사한다. 기존 설치기 검사는 손상·경로 탈출·중복·누락·취소·증분 기반·세션 고정·세이브 보존을 확인한다. `lineagem_pack_settings_main_test.gd`는 실제 Main의 설정 창에서 파일 선택 실패와 제어 복구 및 저장 바이트 보존을 검사한다. 새 두 검사는 기존 핵심 3검사를 유지한 채 핵심 CI에 추가했다.

실제 설정 창을 열어 프레임이 진행되자 기존 축소 검증 환경에서 `l1j_tw380_npc_45027/portrait.png` 누락이 드러났다. 검증 환경의 현재 맵 리소스 선택에 같은 지도·격자·리비전의 기존 추가 출현 및 서식지와 해당 검수 레코드를 포함해 해결한다. 게임 출현 데이터·NPC 정의·원본 파일은 바꾸지 않는다. 이 오류가 있던 초기 실행과 오디오 장치가 없는 환경의 초기 렌더 실행은 통과로 계산하지 않는다.

최종 실행 결과는 같은 디렉터리의 `validation.json`에 기록한다. Android 실기기와 523 원본 화면의 시각적 일치는 이 작업 범위에서 검증하지 않았다. 검증된 523 실행팩과 해당 버전의 레지스트리/디코더가 이 소비자에 연결되기 전에는 523 원본 통합 완료로 보고할 수 없다.

## 현행523 실물 연결 후속

사용자가 새로 제공한 비공개 Drive 사본을 공식 인증으로 내려받았다. checkpoint 01~04의 8개 조각을 각각 순서대로 결합하고 조각·전체 SHA-256, ZIP CRC, 내부 파일별 크기·해시를 확인했다. 중복 없는 현행 M Sprite DAT는 69개다. 이 접근은 정상이며, 별도로 재현된 Library 전송 도우미의 `hosted apps tools/list HTTP 401`이 복구됐다는 의미는 아니다.

`TWILIGHT_current523_M_map_integration_989actual_SP2_validated_PNGs_risks_20261104.zip`은 이름과 달리 PNG 989개가 아니다. 실제 내용은 **SP2 원문 989개와 확정 표준 PNG 2개**다. 픽셀 경계 정정 자료에 따라 과거 PC 참고 해독기의 픽셀·알파·타이밍·방향 해석을 M 원본 정답으로 사용하지 않는다.

실제 게임의 **메뉴 → 설정 → 현행523 표준 이미지 · 원문 → 523 원문·PNG ZIP 선택**에서 이 ZIP을 설치한다. 프로그램은 전체 ZIP과 원문 목록의 고정 SHA-256을 확인한 뒤 989개 SP2 및 두 PNG의 개별 크기·해시, PNG 디코딩·치수를 검사한다. 새 사용자 폴더에 기록하고 설치 영수증을 모두 쓴 뒤 버전 폴더로 원자적으로 전환한다. 누락·손상·취소는 기존 완료 버전과 세이브를 유지하며, 미완료 staging 폴더는 선택하지 않는다. 실패한 staging 파일은 자동 삭제하지 않는다. 설치에는 원문 약 76 MB와 별도 여유 공간이 필요하다.

두 이미지는 원문 PNG 바이트에서 Godot `ImageTexture`로 로드되어 설정 화면에 표시된다. `Map_Icon_Forge.png`는 60×60 RGBA, `normal_cloud.png`는 768×768 RGB다. 설치 직후와 설정 재열기에는 새 버전 미리보기를 표시하고, 일반 소비자의 선택은 재시작 전까지 세션 중 고정한다. 기존 base508 선택이나 캐릭터·도감·맵 소비자의 스냅샷 보호를 변경하지 않는다. 표시 화면의 `캐릭터 재생 미연결`은 현재 한계를 그대로 알린다.

이 기능은 사용자 소유 로컬 ZIP 선택 방식이다. Drive 토큰이나 비공개 URL을 게임에 저장하지 않는다. PR에는 텍스트 코드·검증 기록만 포함하고 원본 SP2·PNG·DAT·ZIP 및 게임 화면 캡처는 포함하지 않는다. 원문은 사용자가 제공한 비공개 Drive에 보존되어 있으며, Work의 설치 결과는 임시 검증 프로필에 있다. 실행본/APK나 원본 전체 배포 팩을 새로 전달한 상태는 아니다.

실물 수동 검사(자동 CI에서 비공개 ZIP을 요청하지 않음):

```bash
# 별도 XDG_DATA_HOME을 사용한 Godot 검증 프로젝트에서 실행
godot --headless --path <검증 프로젝트> --script res://tests/current523_pack_install_local.gd -- --pack=<사용자 ZIP>
godot --headless --path <동일 프로젝트> --script res://tests/current523_pack_install_local.gd -- --read-installed
# 실제 Main 및 확정 소스맵 파일이 있는 검증 프로젝트에서 실행
godot --path <Main 검증 프로젝트> --audio-driver Dummy --rendering-method gl_compatibility --script res://tests/current523_pack_main_local.gd -- --pack=<사용자 ZIP>
```

새 실물 검증·원문 해시는 [current523-validation.json](current523-validation.json)에 별도로 기록한다. 523 캐릭터/몬스터/이펙트 전체 재생에는 현행 M만으로 확인된 프레임·하위이미지·픽셀·알파·방향·타이밍 및 소비자별 레지스트리 연결이 여전히 필요하다. 원문 확보나 표준 PNG 2종 표시를 전체 523 통합으로 계산하지 않는다.

중단 작업 재개 후 원문·공개 구현·기존 소비 경로를 추가로 대조했다. DAT 69개의 내부 SP2 10,338개와 표준 Brotli 종료 989개는 정상이며, 공개 해독기를 그대로 채택할 수 없는 실물 반례를 확인했다. [재생 재조사와 정확한 재개 입력](current523-replay-investigation.md), [원문/표준 압축 독립 검사 집계](current523-source-audit.json)를 참고한다. 이 후속은 조사 기록이며 새로운 523 SP2 재생 사례나 실행 코드 변경은 없다.

이후 사용자의 추정 구현 허용 및 M 엔진 조사 중단 지시에 따라 [SP2 추정 재생·설정·플레이어 표시](current523-estimated-playback.md)를 추가했다. 원문 구조와 추정 표시 정책을 구분하고 모두 설정 가능하게 한다. 새 실행 증거는 `current523-estimate-validation.json`에 기록한다. 원본 M 표시가 검증됐거나 모든 캐릭터·몬스터·이펙트가 자동 연결됐다는 뜻은 아니다.
