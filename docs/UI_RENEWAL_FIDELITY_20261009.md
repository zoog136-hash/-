# TWILIGHT UI 리뉴얼 — PR #50 후속

## 기준과 범위

기존 PR #50 head `eefaf37b241216e5df209a53d1e26d4d8aaf3d9a`를 보존하고 최신 main `67d69efd62f3b97561f89dad16ab3c780ba89020`을 부모로 통합했다. main에는 병합하지 않는다. 몬스터 월드, 장비 개체 ID, 저장 스키마, 도감 원본 데이터, 아이템 수량/강화/축복, 아인하사드와 드래곤 아이템의 최신 구현을 그대로 사용한다. UI가 별도의 게임 상태나 아이템 거래를 생성하지 않는다.

## 이미지 미표시 재발 방지

아이템 원본 전경을 만드는 `Image.adjust_bcs`의 brightness는 1.0이 중립이다. 기존 0.025는 전경을 거의 검게 만들어 알파 컷아웃에서 지웠다. 1.025로 수정하고 실제 아이템 프리뷰의 중앙 밝은 전경 픽셀 수를 검사한다. 이름만으로 sourceId를 덮어쓰거나 원본 이미지 데이터를 교체하지 않는다.

## 검증 및 증거

이 커밋에서 GitHub Actions를 재실행한다. 이전 eefaf37의 성공 결과를 새 코드의 통과로 간주하지 않는다.

- `tools/test_project.py`: 최신 main의 전체 회귀를 그대로 실행
- `ui_renewal_integration_test.gd`: 원래 UI/개체 ID/터치 검사에 최신 축복 상품과 720px 도감 행 가시성 검사 유지
- `ui_fidelity_regression_test.gd`: 자체 아이콘, 네이티브 인벤토리 swipe/tap, 장비 슬롯, 상세 높이, compact 전환, 공격/AUTO, 모달/Esc
- `item_icon_art_smoke_test.gd`: 전경 픽셀 회귀 검사
- 기존 72개 OpenGL 화면 + 추가 26상태 × 6해상도 = 156개. 총 228 PNG
- 추가 해상도: 1280×720, 960×540, 854×480, 720×720, 1920×1080, 2400×1080
- 192마리 몬스터 전투와 전투 애니메이션은 기존 전용 CI를 유지

위 크기는 요청한 창 크기이다. 기존 `canvas_items / keep` 종횡비 설정을 보존하므로 캡처된 게임 텍스처는 아래처럼 레터박스 영역을 제외한다. 파일명만으로 정사각형/울트라와이드 전체 화면 렌더링을 주장하지 않는다. `render-results.json`에 요청한 창 크기, 실제 viewport, PNG 크기, aspect 설정을 함께 기록한다.

| 요청 창 | 실제 게임 텍스처 |
| --- | --- |
| 1280×720 | 1280×720 |
| 960×540 | 960×540 |
| 854×480 | 853×480 (1px 종횡비 반올림) |
| 720×720 | 720×405 |
| 1920×1080 | 1920×1080 |
| 2400×1080 | 1920×1080 |

실제 캡처 QA에서 발견한 확인창과 퀘스트 패널의 초기 텍스트 최소 높이 과다 계산, AUTO 제목의 글자별 세로 줄바꿈을 수정했다. AUTO 설정은 스크롤과 화면 안의 실제 토글 버튼을 제공한다. 후속 세부 UI 검사는 75개이며, 긴 확인 메시지와 네이티브 설정 AUTO 동작도 검사한다. 기존 지급/저장/개체 ID/PC·터치 드래그 16개 검사는 64×64 headless 기본 창 대신 실제 1280×720 크기에서 실행한다.

새 테스트와 캡처는 실제 프로젝트 씬에서 실행한다. 캡처 fixture는 검증용 실제 도감 장비를 기존 지급 경로로 넣으며 일반 플레이의 지급/저장에는 적용하지 않는다. 스크린샷 메타데이터에 fixture와 renderer를 기록한다.

로컬 환경 단절 전의 이전 후보에서는 전체 51/51, UI 통합, 57개 세부 UI 검사, 아이템 이미지 검사와 156개 캡처를 확인했다. 현재 최신 main 통합 및 원격 재구성 이후의 검증 근거는 이 PR의 새 SHA에 연결된 CI와 산출물로 교체한다. 결과 및 URL은 후속 증거 파일/PR 본문에 기록한다.
