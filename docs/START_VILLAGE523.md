# 523 시작 마을: 기란 (사용자 결정 2026-11-17)

사용자 지시 "시작지점을 아덴마을이 아닌 기란으로 해줘"를 반영했다. 코드:
`scripts/maps/current523_start_village.gd`.

## 좌표와 근거 (원본 523 표)

| 항목 | 값 | 출처 |
|---|---|---|
| 기준점 | Land 4 `(33441, 32813)` | `Locations` 473 "[리스타트 좌표] 기란 마을" (원본 행) |
| 기란 마을 영역 | Land 4 X 33332..33548, Y 32630..32900 | `TerritoriesVillage` 1367 (IsVillage) |
| 같은 마을의 다른 원본 행 | 159 "[맵텔] [마을] [기란] 기란" `(33426,32817)`, 902 "[월드보스]리스타트" `(33433,32813)` | `Locations` |
| 주변 원본 NPC 위치 | 265 통합 창고지기 노딤 `(33433,32817)`, 703 변신술사 라윈 `(33441,32808)`, 814 텔레포터 멀린 `(33430,32825)` | `Locations` |

원본 Location 행이 있으므로 TWILIGHT 근사 좌표는 쓰지 않았다. 실제 착지는 기준점부터
Chebyshev 고리 0~8(`aden_return_radius`)에서 원문 바닥·자체 발 공간을 만족하는 첫 셀이다
(기존 아덴 귀환과 같은 규칙).

## 원본 표의 지역별 귀환 규칙 조사

- `Locations`에는 마을마다 "[리스타트 좌표] … 마을" 행(아덴 477, 기란 473, 글루딘 467 …)이 있지만,
  필드 `Territories`를 해당 마을 리스타트 Location에 잇는 표는 없다
  (`RestartLocationID`는 `AutoScheduleCategory` 6행뿐, `Observer.ReturnTerritoryID`·
  `InfluenceWarTeam.RestartTerritoriesID`는 관전·세력전 전용).
- `Class.CreateTerritoryID`는 클라우디아·튜토리얼·초보존을 가리키며 게임은 쓰지 않는다(튜토리얼 삭제 결정).
- 따라서 범용 마을 귀환(523 귀환 주문서, "기란 마을로" 버튼)은 원본 규칙이 아닌 사용자 정책이며,
  아덴 `Locations`166에서 기란 `Locations`473으로 바꿨다. 정책 이름 `OWN_GIRAN_LOCATION473_CLEAR_RING_V1`.
- 원본 지역 지정이 있는 `잊혀진 귀환 주문서`(ItemClass 126424, 지역 표 사용)는 바꾸지 않았다.
- 523 팩이 없는 옛 그림 아덴(`aden_world` 구형)의 귀환 문구·위치는 그 맵 자체 규칙이라 그대로다.

## 바뀐 곳

- 새 캐릭터: 523 호스트 Aden(Land 4)의 시작점이 기란 마을이다 (`current523_host.load_field`).
- 위치 보정(#593): 24칸 안에 통행 가능한 셀이 없을 때의 마을 폴백이 기란 마을이다.
- 저장 위치 재개 보류(#485 후속): "기란 마을에서 시작합니다".
- 튜토리얼 Land 세이브(#590): 커서를 기란 마을 원문 좌표로 명시 이전, `tutorial523.relocated`에 목적지 기록.
- 옛 지도 세이브(#485): 1회 이전 시 커서를 기란 마을 원문 좌표로 명시.
- 정상 저장 위치가 있는 기존 캐릭터는 옮기지 않는다.
- 사망 부활은 기존대로 현재 지역 시작 지점(`_spawn_position`)이다.
