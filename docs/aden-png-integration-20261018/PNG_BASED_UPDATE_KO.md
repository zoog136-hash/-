# 원본 PNG 기준 구현 — 2026-10-18 추가 작업

후속 사용자 지시로 오만 정상 `111.png`를 우리 `domination_summit`의 기준으로
확정하고 실제 연결을 추가했다. 아래 지배 PNG 미확정 항목은 그 지시 이전의 조사
기록이다. 최신 범위는 [지배의 탑 구현](../domination-111-20261018/README.md)을 따른다.

사용자 지시에 따라 실제 PNG를 지형의 시각 기준으로 연결했다. 아래 결과는
기존 리메이크 그림의 검사가 아니라 **원본 PNG가 표시되는 기존 Main.tscn**의
실행 결과다. 지형과 충돌의 정합 검수는 미완료이며 완성 복원으로 표시하지 않는다.

## 확보 및 연결

- `Aden.png`: 15,728×7,987, 107,435,138바이트. 기존에 확보한 동일 SHA 파일을 재사용.
- `101.png`~`110.png`: 각 9,216×4,608. 10개 모두 원본 다운로드, 이미지 디코딩,
  SHA-256 확인. 실제 해시는 `data/maps/png_map_sources.json`에 기록.
- Drive 원본 링크는 사용자의 기존 맵 PNG 확보 목록에서 확인했다.
- `111.png`와 `12851.png`도 조사했다. 111은 오만 정상 자료이며 지배 정상이라고
  임의 지정하지 않았다. 지배 정상 L1J 후보 12862의 통행 형상도 별도로 비교했다.
  현재 **지배의 탑 PNG 파일의 정체가 미확정**이므로 사용자에게 정확한 파일명/링크를 요청했다.

## 실제 코드 경로

`tools/map_restore/build_png_review_pack.py`가 확보된 원본에서 384개 실제 PNG 청크를
생성한다. 아덴은 기란 검수 구역 24청크, 오만은 10층×36청크다. 픽셀을 다시 그리지
않고 원본의 정수 영역을 자른다. 렌더러가 측정 좌표로 기존 월드에 투영한다.

`source_png_review_pack.gd` → `remake_renderer.gd` → `aden_png_chunk.gd`를 거쳐
기존 World/Player/몬스터/HUD 안에서 표시한다. 아덴 PNG 팩의 검수 구역 바깥에
기존 리메이크 그림을 대신 그리지 않는다. 원본 통행 바이트와 방향별 규칙은 유지한다.
`--png-collision-overlay`로 원본 통행 경계를 실제 PNG 위에 표시한다.

아덴의 지역 아핀 후보는 기존 여섯 기준점의 측정값을 사용한다. 최대 잔차
25.7576월드픽셀로 4픽셀 발 반경보다 크다. 이는 확정 행렬이 아니다. 오만 PNG의
캔버스 크기는 192×192 원본 48×24 투영과 같지만 **내부 벽·오브젝트의 판본까지
같다는 증거로 사용하지 않는다**. 전역/층별 장애물 정합과 전경 분리는 추가 검수 대상이다.

## 실행과 저장 보호

외부 그림은 공개 Git에 넣지 않았다. 개인 팩 루트에 `map_png/`와 `topology/`를
놓고 다음으로 기존 게임을 실행한다.

```bash
bash tools/run_png_review.sh /개인/팩/경로 /공식/Godot_v4.7.2-stable_linux.x86_64
```

팩을 설치한 것만으로 일반 저장 게임의 그림이 바뀌지 않는다. 현재는 명시적인
`--png-review`에서만 활성화하며, 실행기는 세션 저장 디렉터리도 분리한다.
이 모드에서는 기존 저장 파일을 덮어쓰지 않는다. 일반 게임의 저장·재진입 검사와
PNG 검수 실행은 구분한다. 캐릭터 scale=1, 이동속도 210, 원본 필드 발 반경 4를 유지한다.

## 증거와 남은 일

실제 PNG를 사용한 11개 맵 런타임 검사, 실제 1280×720 및 모바일 모양 1560×720
윈도우 캡처, PNG 위 원본 충돌선, Godot MovieWriter 녹화는 개인 리소스 영역에
보관했다. 공개 Git에는 원본 그림이나 그 파생 화면을 올리지 않는다. 공개 가능한
수치/로그는 이 폴더의 `PNG_*` 자료에 둔다.

검사는 원본 통행 규칙에서 배우와 몬스터가 물리 경계를 뚫지 않는지를 확인한다.
**PNG의 모든 건물·나무를 정확히 막았다는 검사로 바꾸어 보고하지 않는다.**
수동 전경 컷, 출입구, 문턱, 나무줄기의 픽셀/격자 대응, 지배 PNG 확정이 남았다.
PNG 검수 팩은 로컬 결과이며 장기 보관소로 전달 완료한 배포본이 아니다.

## 실행 검사 수치

- 실제 PNG 11개 맵: 365검사, 실패 0 (`PNG_RUNTIME.json`).
- PNG 화면에서 실제 변신 스프라이트/공격 재생: 80검사, 실패 0 (`PNG_TRANSFORM_RUNTIME.json`).
- PNG 위 원본 충돌선: 68검사, 실패 0. 실제 모바일 모양 창/엔진 녹화 실행: 72검사, 실패 0.
- 일반 게임의 관련 회귀 14개: 13통과, 1개는 개인 오만 팩 없는 기본 환경에서 건너뜀.
- 개인 오만 팩을 설치한 별도 전체 회귀: **5,953검사, 실패 0**, 10층 보스 전투·포털·드랍·저장 포함 (`PNG_OMAN_REGRESSION_FINAL.json`).
- 위 회귀의 첫 실행은 5,951검사 중 1개 실패였다. 아덴이 여전히 구형 캡슐 지형이라는 오래된 테스트 가정이다. 기준 main과 feature의 실제 발 도형을 별도 실행해 같은 결과를 재현했다 (`PNG_BASELINE_FOOT_EXPECTATION.json`). 아덴 원형 유지와 실제 구형 `domination_summit` 캡슐 복원을 각각 검사하도록 테스트를 바로잡았다. 초기 실패 결과도 보존했다.
- 일반 세션에서 후보 PNG 팩의 자동 활성화를 막는 계약 검사: 22통과. 공식 4.7.2 프로젝트 import/parse 오류 0. 기존 723시트 무결성 및 아덴 1,994파일 전달 검사 통과.

공개 CI는 원본 PNG 개인 팩을 받지 않으므로 실제 PNG 화면 검증을 대신하지 않는다.
Android 실제 기기와 전체 PNG 장애물/전경 대응은 미검증이다.
