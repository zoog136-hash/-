## 실제 수정

`scripts/maps/source_prop_anchor.gd`와 두 기존 기란 렌더링 경로에서, 나무의
그림 기준점을 해당 나무의 **기존 원본 차단 셀**에 연결한다. 기존 33개 나무 중
24개의 줄기 기준점이 통행 셀에 있었다. 그 24개를 12.48~37.12 월드 픽셀
이동하고, 이미 차단 셀에 있던 9개는 원래 위치를 유지한다. 71개 배치 원본 JSON,
원본 격자, 이미지 및 나무의 크기는 바꾸지 않았다.

`scripts/maps/field_population.gd`에서는 몬스터 `setup/_setup_animation` **뒤에**
원본 필드용 발 도형을 적용한다. 이전에는 먼저 적용한 4px 도형이 애니메이션
초기화 때 16/19/26px로 덮어써졌다. 별도 main 실행에서 359마리의 반경이
16px 39마리, 19px 317마리, 26px 3마리였고, 수정 후 실행에서는 359마리 모두
4px였다. 풀 재사용 시 이전 맵 도형을 먼저 복원해 다음 레코드의 정상 도형도
보존한다. 원본 필드의 이동 검사에는 같은 4px 발 여유를 확인한다.

기존 `Main.tscn → TwilightWorld → RemakeSourceRenderer`에 선택적 개인 PNG 팩
경로를 연결했다. `aden_png_pack.gd`는 원본/격자/정의/이미지 해시, 최소 5개의
확정된 비공선 기준점, 실제 잔차 ≤4 월드 픽셀, 지역 충돌/전경 검수 상태를
검사한다. 미설치·미검수·오차 초과 팩은 기존 렌더러를 유지한다. 지도 ID는
`aden_world`다. 게임 좌표, 저장 좌표 및 레이아웃 리비전은 그대로여서 새 좌표
마이그레이션은 필요하지 않다.

기란 광장의 서로 다른 화단 6개를 S32 바닥 가족 3611~3614와 대조해 **수동
기준점 후보**를 기록했다. 이는 확정된 원본 타일 앵커 6개를 뜻하지 않는다.
후보의 관측 불확실성은 PNG 약 3px이며 좁은 광장 안의 점들이므로 전역 정합을
증명하지 못한다. 최소제곱 지역 아핀 후보는 다음과 같다(행 우선 2×3).

```text

PNG.y = 0.0005599140460513454 * world.x + 0.1566058464216859 * world.y - 74.4322375826446
```

PNG RMS 잔차 2.5689px, 역변환 최대 잔차 **25.7576 월드 픽셀**이다. 이는 현재
후보 측정의 오차이며 PNG 전체가 다른 지도라는 증명도 아니다. 4px 발 기준의
승인 조건을 만족하지 않아 일반 저장 게임에 적용하지 않는다. 추가 구현의 명시적인
PNG 검수 세션에서만 후보 투영을 실행한다. 전역 아핀은 미확정이고, 아덴·켄트·
하이네·오렌 등은 별도 JSON에서 미확정/판본 검토로 남겼다. **현재 확정된
고유 기준점 최소 3개 요건은 충족하지 못했다.**

원본 PNG와 원본 픽셀을 포함한 충돌 오버레이는 공개 Git에 넣지 않았다.
현재 개인 경로는 `/workspace/private-resources/aden/`이며 정합 오버레이는
`survey/giran_plaza-source-collision.png`다. 원본은 이 환경에서 한 번만 받았다.
재배포 권한은 확정되지 않았고, Work 로컬 파일은 장기 전달 완료로 집계하지 않는다.

## 스케일과 레이어

실제 기사 초기화에서 플레이어 월드 스케일 `(1,1)`, 이동속도 **210px/s**,
클래스 스프라이트 스케일 `(1,1)`, 보이는 픽셀 높이 **80 월드 픽셀**, 카메라 줌
1을 측정했다. 원본 아이소메트릭 기준은 `(24,-12)`, `(24,12)`다. 씬의 기본
캡슐 반경 15/높이 42는 보존하고 이 원본 필드에서만 4px 발 원으로 교체한다.
클릭 이동·변신 및 애니메이션 리소스의 스케일을 별도로 절반으로 줄이지 않았다.

PNG는 단일 합성 이미지다. Ground/Water/Structure/Props 원본 레이어나 숨은 바닥
픽셀이 복원되었다고 표시하지 않는다. 개인 팩 컴파일러는 수동으로 검수한
지붕/잎 마스크만 바닥에서 제거하고 같은 픽셀을 발 기준 Foreground에 옮기며,
합성 복원이 원본 픽셀과 정확히 같은지 확인한다. 원래 Actors·물리 Collision·
Navigation은 기존 게임이 담당한다. Water 등 미분리 부분은 합성 Ground에 남는
상태를 명시한다. **실제 PNG의 마스크와 발 기준점 검수 자료는 아직 없다.**

## 재현

검사마다 별도 사용자 디렉터리를 사용한다. 실제 사용자 저장은 사용하지 않는다.

```bash
python3 tools/check_resource_integrity.py --root .
python3 tools/check_aden_world_delivery.py
python3 tools/map_restore/test_aden_png.py
godot --headless --editor --path . --import
godot --headless --path . --script res://tests/aden_png_pack_test.gd
XDG_DATA_HOME=/tmp/twilight-aden-qa godot --path . --script res://tests/aden_png_source_integration_test.gd -- --capture --output=/tmp/twilight-aden-evidence
```

실제 PNG 정합 조사는 공개 저장소 밖으로 출력한다.

```bash
python3 tools/map_restore/aden_png.py survey --png /private/Aden.png --a3 /private/a3.zip --output /private/aden-survey
python3 tools/map_restore/aden_png.py build --png /private/Aden.png --survey /private/verified-survey.json --output /private/aden-png-pack
TWILIGHT_ADEN_PNG_PACK=/private/aden-png-pack godot --path .
```

현재 저장된 후보로 `build`하면 검수 미확정 오류로 중단하는 것이 정상이다.
승인되지 않은 이미지로 플레이를 허용하는 우회 플래그는 만들지 않았다.

## 남은 작업과 필요한 근거

1. PNG 생성 판본·맵 ID·크롭 원점, 넓게 분산된 5개 이상의 정확한 바닥 기준점.
   현재 6개 근사 화단 중심만으로 전역/지역의 원본 통행 정합을 승인할 수 없다.
2. 같은 판본의 원본 TIL/오브젝트 이미지 및 ID/발 앵커 자료, 또는 작은 검수
   구역의 건물 바닥·출입구·줄기·전경 마스크에 대한 직접 수동 검수.
3. 성벽/출입구/다리/계단/수역을 PNG와 원본 통행선 양쪽에서 확정하고 불일치를
   보류할 구역 경계. 원본 통행을 임의로 열거나 새 성 대상 맵을 만들지 않는다.
4. PNG 샘플의 실제 씬 활성화, 이동/전투/변신/저장·재진입 및 전경 합성 재검사.
5. Android 빌드 결과와 별개로 Android 실제 기기·터치·GPU·개인 팩 설치 검증.
6. 개인 원본/팩의 허용된 장기 보관·전달. 공개 업로드 권한을 가정하지 않는다.

원본 PNG 플레이 샘플, 전체 아덴 복원, Android 실기 및 병합 준비 완료로 표시하지 않는다.
