# TWILIGHT 원작 옵션 전수 비교 및 비스킬 기능 마감 점검
작성: 2026-10-09 · 기준 main HEAD 82dbbdb · 작업 PR #41 (main 미병합)

## 지시 번호와 실제 처리
- **1 장신구 강화**: 모든 반지에 도펠겡어 반지의 강화표를 잘못 적용하던 범용 공식을 제거. 출처 확인된 4종 룸티스 귀걸이와 도펠겡어 보스 오른쪽 반지의 개별 +0~+8 강화표 적용. 방어·HP·MP·대미지·명중·SP·물약회복 보너스를 실제 전투/회복에 연결. 미확인 개별 장신구에는 임의 강화 보너스 미지급.
- **3 특수 방어구 강화**: 마법 방어 투구, 마법 방어 사슬 갑옷, 마법 망토, 은색 망토의 강화당 MR+2; 거대 여왕 개미의 금빛/은빛 날개와 뱀파이어 망토의 강화당 MR+3; 리치 로브 +3부터 SP 증가를 일반 AC 보너스 외에 별도 계산. 실제 MR·SP 스탯 계산 경로에 추가. 출처 시점/아이템 범위가 다를 수 있으므로 2026 원작 모든 변형 장비 완전 대조 주장은 하지 않음.
- **8 최대 MP**: 마녀의 마력 회복제의 회복 상한을 기본 `max_mp`에서 장비/인형 반영 `_effective_max_mp()`로 변경. 지속형 MP 회복도 동일한 최대 MP 사용.
- **5 속성 강화**: 무기 개체별 속성/단계 저장에 더하여 **속성 변경 주문서**(선택한 개체의 단계 보존, 속성만 교체) 및 **속성 초기화 주문서**(선택한 개체만 속성·단계 삭제) 구현. 기존 1~5단계 성공률 30/10/5/2/1%는 확정된 TWILIGHT *게임 규칙*이지만 원작에서 전 단계 공식 확률 검증된 것은 아니며 특히 4~5단계는 TWILIGHT 밸런스 수치. 미확인 값을 원작값이라고 주장하지 않는다.
- **6 크기**: 전투 DB 몬스터 163종을 `data/monster_sizes_v1.json`으로 명시적으로 small/large 지정(대형 36종, 소형 127종). 보스 여부만으로 크기 판정하지 않음. Inven 원작 장비의 `stat: "54 / 35"`, `작은 대상 대미지` 및 `큰 대상 대미지`를 실제 크기별 무기 보정에 반영. 163종 크기 중 다수는 TWILIGHT 저작 판정이며 **원작 크기 전수 검증과 구분**해야 함.
- **7 무게**: 원본 상세 아이템 2,129개가 쓰는 **40개 아이템 타입**, 그리고 런타임 추가 5개 타입까지 무게 정책 보완. 타입 누락 및 소지품의 0무게 누락 방지; 개별 확인 출처는 다마스커스 검 무게 45, 도펠겡어 보스 오른쪽 반지 무게 3. 상세 도감 자체에는 숫자 무게 필드가 없어 나머지 타입 무게는 원작 검증값이 아닌 TWILIGHT 규칙임을 명시한다.

## 2번: 저장된 원작 상세 도감과 기본 DB 이름/옵션 문구 비교

기본 파일 `data/game_db_v17.json`과 출처가 기재된 `data/catalog_v19.json` **원본 2개를 변경 전 상태 그대로** 비교하였다. 런타임에서 기본 DB 항목 및 소모품 레코드를 상세 도감에 병합한 수치는 이 표와 다르다.

| 범주 | 기본 DB | 원작 상세 도감 | 정확한 이름 일치 | 일치 이름 중 설명 다름 |
|---|---:|---:|---:|---:|
| 아이템 | 470 | 2,129 | 79 | 79 |
| 변신 | 184 | 413 | 38 | 37 |
| 마법인형 | 184 | 166 | 38 | 38 |
| 성물 | 195 | 144 | 42 | 42 |

상세 도감의 각 레코드는 `source=inven` 및 `sourceUrl`을 가진다. 이름 불일치 항목의 상당수는 TWILIGHT 임시 생성 이름/자체 카드이므로 **자동으로 미구현 수로 환산하면 안 된다**.

숫자형 원작 옵션 전용 오버레이 `data/lineagem_verified_base_options.json`는 인형 **16종**, 성물 **5종**에 한정한다. 나머지는 일부 범용 숫자 파서와 원작 상세 데이터 필드를 이용하므로 **전 옵션 완성으로 판단할 수 없다**.

### 정밀 재현이 되지 않은 실제 예시(비교 결과, 이번 PR 수정 대상 2번은 '보고만')
1. **군터의 단도**: 원작 상세에는 `무기 명중 +4`, `근거리 대미지 리덕션 무시 +2`, `근거리 회피력 무시 +2`, `발동: 군터의 절망` 등 추가 옵션이 있으나 기본 설명에는 생략. '근거리 대미지 리덕션 무시' 변종 문구는 현재 전환기에서 `대미지 리덕션 무시`와 같은 형태로 항상 파싱된다고 보장되지 않음.
2. **기르타스의 단검**: 원작 상세 `대미지 증가 +25%`, `HP 흡수`, 다수의 서로 다른 특수 발동. 범용 수치 효과와 발동 메커니즘은 구분 필요(고유 발동은 사용자 보류).
3. **마법인형 발라카스·파푸리온·할파스**, 다양한 성물의 소모량 감소·디스펠 면역·스킬레벨 옵션은 단순 기본 DB 텍스트보다 상세하며 구조화된 효과 적용 여부가 별도 검증되지 않음.
4. **변신의 시전 속도·무기 종류 전용 추가 피해·차징 시간 감소**, 성물의 스킬레벨 보너스 등은 상세 문구와 실제 적용 엔진의 완전 일치가 확인되지 않음. 스킬 자체는 이번 감사 범위 외.
5. **아이템 HP/MP 회복(틱)** 및 방어 관련 원작의 여러 텍스트 형식은 마법인형·성물에 대한 일부 전용 구현만 존재. 아이템 전체 자동 적용을 주장하면 안 됨.

즉, 이번 PR은 2번 **실제 비교 및 차이 보고**이지 상세 도감 2,129종의 모든 옵션을 자동으로 구현한 PR이 아니다.
