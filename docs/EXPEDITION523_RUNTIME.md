# 누적523 탐험의 게임 연결

기준 main: `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`. 기존 PR을 병합하지 않은 독립 구현이다.

## 실행되는 범위

기존 Main → 메뉴 → **인형 탐험**에서 인형 탐험·변신 파견·성령 수집의 장소를 선택한다. 기존 카드 보유 상태와 스킬각성의 실제 저장 ID를 읽으며, 임시 카드 이름/등급으로 원본 ID를 추정하지 않는다. 출발 정적 조건 결과와 선택한 보상표 그룹은 독립적으로 표시한다. 메뉴 열람은 재화·세이브·RNG를 변경하지 않는다. 서버·기간의 추가 제한이 없는 1장 인형/성물 장소는 소유·덱·등급·스킬각성과 아데나를 확인해 실제 로컬 출발을 지원한다. 해당 원본 장소 정의는22곳이며 플레이어의 카드 조건 충족과는 별도다.

확정된 원본 정의를 사용하는 부분:

- 최신523의 29장소(기란성 포함), 30그룹, 위치 원값, 등급 순위, 필요 카드 수, 비용 통화·수량, 28,800초, 휴식·부활 원값.
- 원본 카드의 정확한 덱·등급과 스킬각성 레벨5~19 / 20. Grade71을 영웅 그룹에 편입하지 않는다. 기존 일반 카드 레벨·옵션 각성은 사용하지 않는다.
- 이벤트 보상4,487행/284풀. `IsSpecial`과 타입0/4/14/24, 중복, 원가중치를 보존한다. 타입별 재정규화나 특수 확률 공식을 만들지 않는다.
- 별도 완주 표시290행/상자29종, 첫 단계 상자 후보193행. 같은 아이템의 서로 다른 수량 후보는 별도 행이다. 상자를 열거나 모든 후보를 지급하지 않는다.
- 장소 이벤트201연결의 최소 등급·레벨과 특별 보상91조합. 전역 부활·물약 이벤트는 장소에 임의로 붙이지 않는다.
- 변신 시너지7개와 카드36행, 명시적 Bonus→탐험Buff→효과 원값. 서버 제한274와 구성/판정의 미확정을 유지한다.
- 동시/일일 횟수·주기 원상수. 초기화 시간대나 이벤트 간격으로 실행 횟수를 만들지 않는다.

완주 보상 표가 있는 18조합은 장소 최소 등급보다 낮다. 성물 장소202/212는 낮은 등급에도 이벤트 보상풀이 있지만, 인형 장소223에는 낮은 등급 풀이 없다. 어느 경우에도 보상 존재가 출발 허가를 덮어쓰지 않는다. 위치는 탐험 지도 표의 좌표이며 월드 통행 좌표로 해석하지 않는다.

## 아직 실행하지 않는 범위

1장 인형/성물의 지원 조건은 확인창에서 원본 아데나 비용을 명시하고, 실제 저장 성공 후에만 아데나를 차감해 진행 기록을 만든다. `expedition523_local`은 명시적인 TWILIGHT 저장키이며 원본 프로토콜/저장키라고 주장하지 않는다. 첫 출발 전에 기존 저장의 SHA256 백업을 보존한다. 저장 실패·중복 출발은 재화·횟수·작업을 변경하지 않는다. 잘못된 저장은 플레이어 상태 변경 전에 거절한다. 원본 표의 제한0을 공식 운영 서버 활성의 증거로 설명하지 않는다.

로컬 접속 중 `delta`로 28,800초를 진행하고 남은 시간을 저장/복원한다. 오프라인 경과 시간은 추정하지 않는다. **시간이 끝나면 `awaiting_outcome`이며 성공이나 완주 상자를 자동 지급하지 않는다.** UI는 출발 전에 이 제한을 확인시키고 실제 진행/정산 대기 결과를 표시한다. 원본 동시5곳 상한은 적용한다. 일일15회의 초기화 시간대가 미확정이므로 저장된 시도15회 상한을 유지하고 자동 초기화하지 않는다. 이 보수적인 로컬 경계는 원본 일일 정책 재현이 아니다. 정산 대기 작업의 카드/장소도 임의로 풀거나 환불하지 않는다.

변신4장의 대표 그룹·시너지 판정, 비0 서버/기간 조건은 출발을 보류한다. 이벤트 추첨과 정산은 다음 필수 실행 근거가 없어 미완료다.

- EventRate50의 단위·발생 시점/횟수, 이벤트별 추첨과 특수 발견/일반 후보의 분기.
- 보상 타입4/14/24 및 시너지/행운에 따른 가중치 보정식과 몬스터 선택·전투 승패/HP 처리.
- 실패·사망·부활·일시 중단 이후 성공 판정 및 부분 회수·완료 지급 조건.
- `CompleteRewardView`는 완료했을 때 연결되는 보상이지, 시간 종료만으로 항상 성공한다는 증거가 아니다.

이 근거 없이 기본 이벤트를 생략하고 성공/상자를 보장하면 원본에 없는 보상을 만들게 된다. 보상 후보 그래프는 실제 조회하며, 지급 실행은 성공 판정 계약과 함께 이어야 한다. 실제 탐험 전체 완주 구현이나 공식 서버와의 동등성은 미완료다.

획득 경로 감사에서 확인된 코인 제작·선택상자·연결구매·상품·뽑기풀은 후속 작업이다. ItemBonus의 연결구매를 아이템 사용/결제로 실행하지 않는다. 완주 상자 이후 373카드나 이벤트·제작 그래프212카드를 직접 보상으로 지급하지 않는다.

## 별도 원본 데이터 팩

코드·검사·문서만 Git에 넣는다. 원본/파생 표는 사용자 Library의 `expedition523.private.json`에 별도 저장하며, 공개 diff와 GitHub Actions에는 넣지 않는다. 제공 원본3ZIP은 정식 Library materialize 경로로 내려받고 SHA256·전체 ZIP CRC를 확인했다.

```sh
python3 tools/build_expedition523_pack.py /private/lineagem_patch523_all_content_validated_and_508_520_deltas.zip /private/expedition523.private.json
Godot_v4.7.2-stable_linux.x86_64 --path . -- --expedition523-pack=/private/expedition523.private.json --expedition523-sha256=39f075e3aea122080b060c8682c81dc6b43e3cb97e886504bdefd9dfc2034991
```

- 누적523 원본 ZIP SHA256: `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`.
- 획득 경로 ZIP SHA256: `d5d87e6a77f672acbbe4fac81688100c94ceb5a97917407ed3f75a7bafc23a3b`.
- 시간/완주 ZIP SHA256: `5903210f6e50be3f4e4061b2e41c49d489ab0570462fa0d5a5145f6639ee15ff`.
- 런타임 팩: 2,880,431bytes, SHA256 `39f075e3aea122080b060c8682c81dc6b43e3cb97e886504bdefd9dfc2034991`.

컴파일러는 원본 ZIP SHA와 입력27표의 원본 index SHA/CRC/바이트/행수를 확인하고 선택 원행을 보존한다. 가중치 합100,000,000과 상자 합10,000,000은 원합 검사이며 서버 RNG 분모를 증명하지 않는다. 소비자는 명시적 팩 SHA, 형식·참조·행수·풀 합을 검사한다. 잘못된 교체 팩은 기존 카탈로그를 유지한다. 팩 부재 시 기존 게임은 계속 열리며 탐험 화면에 미설치를 표시한다.


`tests/expedition523_main_ui_test.gd`는 실제 Main의 메뉴 타일→화면→선택→비용 확인→출발→진행/정산 대기 경로, 원본 팩 유무, 원자적 아데나 차감, 실패 원복·중복 차감 거절·기존 저장 백업·남은 시간 복원·손상 저장 거절과 카드·아이템·RNG 보존을 검사한다. `--expedition523-capture=/private/capture`는 OpenGL 환경에서1280×720과960×540 화면 및 출발/정산 대기 캡처 검사를 추가한다. 필수 core gate에는 원본 팩 부재 검사와 실제 Main 메뉴 연결 검사를 추가한다. 비공개 원본 검사는 별도 로컬 실행이다.

현재 필수 원본아트 검사기의 `--source-dir`는 별도 역사적 `a1.zip`을 요구한다. 이번3ZIP의 SHA/CRC 검증과 구분하며 원본아트 전체 전달로 주장하지 않는다. 기존 리소스 장부를 승격하지 않는다. 전체 시각/전체 게임플레이/Android 실기기와 미확정 탐험 실행은 별도다.

로컬 최종 확인: Python 원본 회귀9개, core staging 회귀7개, 실제 Main/current source-map·역사적 저장32검사 및 동일 저장/지연 저장 게이트 통과. Godot4.7.2의 원본 카탈로그·저장 형식35검사는 실패0이다. 실제 Main의 비공개 원본 팩+OpenGL UI41검사(1280×720/960×540 및 출발/정산 대기4캡처)는 실패0이다. 캡처를 직접 열어 선택·비용·진행·대기 표시를 확인했다. llvmpipe 환경이며 Android/사용자 기기의 증거가 아니다.

사용자의 최신 지시에 따라 커밋에 `[skip ci]`를 사용하고 수동 원격 CI는 실행/재실행하지 않는다. 원격 CI 미실행은 통과로 보고하지 않는다. 저장·실행 코드 변경 후의 로컬 필수 검사는 위와 같이 별도로 완료했다.
