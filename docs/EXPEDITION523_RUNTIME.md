# 누적523 탐험의 게임 연결

기준 main은 `7d550a78a8fd1a95a50ebb18b38c3134380c3fa6`이다. PR #243의 같은 브랜치에서 메뉴·출발·진행·사망/부활·완주/중단 정산·상자 개봉·인벤토리 수령을 연결한다. 원본 자료를 우선하고, 공개 자료에도 없는 경제/확률은 사용자의 2026-11-04 지시에 따라 **TWILIGHT 자체 추정**으로 구현한다. 공식 서버 수식 재현을 주장하지 않는다.

## 플레이 경로

실제 Main → 메뉴 → **인형 탐험** → 소유 카드/장소 선택 → 비용 확인 → 출발이다. 현재 소환/추가 소환 중인 카드, 이미 탐험·사망·완료 정산 대기 중인 카드, 중복 장소는 다시 출발하지 못한다. 탐험 중인 카드를 일반/추가 슬롯으로 소환하는 경로도 막는다. 실제 카드 보유와 스킬각성 저장을 사용한다.

기록에는 HP·남은 시간·진행/사망/완주 상태를 표시한다. 사망하면 부활하거나 중단하고, 살아서 원본8시간을 채우면 완료 보상을 수령한다. **보상 받기**는 발견 아이템과 원본 완료 상자를 탐험 보관함에 넣고 경험치를 카드에 반영한 뒤 예약을 해제한다. 중단은 발견 보상의 일부만 정산하고 완료 상자를 주지 않는다.

보관함의 **상자1개 열기**는 상자1개를 소모하고 원본 후보/수량/가중치로 추첨한다. **인벤토리로**는 보관함에서 기존 게임 인벤토리로 옮긴다. 인벤토리로 옮긴 완료 상자도 기존 아이템 사용 경로에서 개봉된다. 정산 내역 조회와 원본·추정 규칙 안내는 상태·재화·아이템·난수를 변경하지 않는다. 탐험 창은 전체 화면이며 작은 화면의 왼쪽 선택/보관함 영역은 스크롤된다.

## 유지하는 기술적 경계

추정 경제 수치 승인은 미확정 활성 조건의 허가가 아니다. 원본에 제한이 없는1장 인형/성물22장소가 실행 대상이며, 실제 카드의 서버·기간 조건과 보상 연결까지 통과해야 한다. 변신4장 파견의 대표 그룹/시너지 판정, 비0 서버·기간 제한 장소는 조회할 수 있으나 출발은 제한한다. 파견 전용 보상 타입4/14/24를 다른 탐험에 확대하지 않는다. 보상표가 있어도 출발 조건을 충족한 것으로 간주하지 않는다. 원본18개 낮은 등급 완료표와 특수 등급71도 그대로 보존한다.

선택적 HP/행운 버프 구매, 물약 사용 자동화, 파견 시너지 활성은 구현 범위 밖이다. 보관함에서 넘긴 원본 아이템은 ID/수량/축복/강화를 유지하지만, 코인 제작·선택상자·연결구매·상품 그래프의 모든 후속 기능까지 자동 활성화하지 않는다. 예를 들어 원본 획득 그래프에 카드373종이 보여도 즉시 카드를 지급하지 않는다. 원본 아데나 상자/주화도 명시적 사용 규칙 없이 골드로 환산하지 않는다. 다른 PR의 제작/각성/카드 기능과는 별도다.

기존 인벤토리는 이름을 키로 사용하므로 신규 탐험 품목은 표시명에 `탐험 ID:축복:강화`를 붙여 동일 이름의 다른 원본 아이템과 섞이지 않게 한다. 저장한 issued 정의를 복원해 재시작 후에도 출처를 찾는다. 팩이 빠지면 수량은 보존하고 임의 대체 품목을 만들지 않는다.

## 저장과 이전

`expedition523_local` version2는 명시적인 로컬 저장 공간이다. 원본 서버 프로토콜/저장키라고 주장하지 않는다. 작업별 HP·시간·스냅샷 규칙·난수·발견품, 일일 횟수, 보관함, 인벤토리 연결, 수령 영수증을 보존한다. 전투/카드 뽑기의 난수는 소비하지 않는다.

출발 비용/작업, 부활 비용/HP, 정산/경험치, 상자 소비/추첨 난수, 보관함/인벤토리 이동을 각각 한 번의 기존 원자적 저장으로 확정한다. 저장 실패 시 관련 라이브 상태/난수를 바꾸지 않는다. 같은 작업은 수령 후 제거되고 영수증을 남긴다. 이미 받은 작업의 재수령과 이전 revision의 상자 확인은 거절한다. 진행 중인 지도 저장 활성화는 경제 거래를 보류한다.

첫 출발 전 `.pre-expedition523-<SHA>` 백업을 만든다. 이전 version1의 유료 탐험도 읽고, 원본 그룹의 최소 레벨을 보수적인 하한으로 채택해 현재 모델로 이행한다. 이미 경과한 시간은 같은 초기 난수로 재생하고 **입장비를 다시 받지 않는다**. 최초 쓰기 전에 `.pre-expedition-estimate-<SHA>` 백업을 남긴다. 로드만으로 기존 파일을 다시 쓰지 않는다. 팩 부재 시 기존 version1은 비활성 상태로 보존한다. 손상된 저장은 플레이어 상태를 변경하기 전에 거절하고 덮어쓰기를 차단한다.

## 비공개 원본 팩과 복원

Git에는 코드·검사·문서와 자체 설정 JSON만 넣는다. 원본 표/파생 JSON/이미지는 공개 diff에 포함하지 않는다. 원본3ZIP은 정식 Library 경로로 materialize한 뒤 SHA256·전체 ZIP CRC를 확인했다.

- 원본 ZIP SHA256: `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`.
- 획득 경로 ZIP SHA256: `d5d87e6a77f672acbbe4fac81688100c94ceb5a97917407ed3f75a7bafc23a3b`.
- 시간/완주 ZIP SHA256: `5903210f6e50be3f4e4061b2e41c49d489ab0570462fa0d5a5145f6639ee15ff`.
- 런타임 팩: 2,880,431bytes, SHA256 `39f075e3aea122080b060c8682c81dc6b43e3cb97e886504bdefd9dfc2034991`.
- 런타임 팩 Library: `libfile_7c9564a9c63c8191af8b54788b9adef0`, version0. 별도 재materialize한 바이트/해시 일치.

```sh
python3 tools/build_expedition523_pack.py /private/lineagem_patch523_all_content_validated_and_508_520_deltas.zip /private/expedition523.private.json
Godot_v4.7.2-stable_linux.x86_64 --path . -- --expedition523-pack=/private/expedition523.private.json --expedition523-sha256=39f075e3aea122080b060c8682c81dc6b43e3cb97e886504bdefd9dfc2034991
```

컴파일러는 원본 ZIP SHA와27표의 index SHA/CRC/바이트/행수를 검사한다. 소비자는 명시한 팩 SHA·형식·참조·행수·풀 합을 검사하며 잘못된 교체 팩으로 현재 카탈로그를 덮어쓰지 않는다. 팩 부재 시 기존 게임은 계속 열리고 탐험 화면에 미설치를 표시한다.

## 검증 방법

필수 core gate는 실제 Main/current source-map 저장 보존, 동일 저장, 지연 저장, 카탈로그 형식, 추정 모델의 기본 검증, 팩 부재 메뉴 경로를 수행한다. 비공개 원본을 쓰는 검사는 로컬에서 별도로 실행한다.

```sh
Godot_v4.7.2-stable_linux.x86_64 --headless --path . --script res://tests/expedition523_estimate_model_test.gd -- --expedition523-pack=/private/expedition523.private.json --expedition523-sha256=39f075e3aea122080b060c8682c81dc6b43e3cb97e886504bdefd9dfc2034991
Godot_v4.7.2-stable_linux.x86_64 --path . --script res://tests/expedition523_completion_test.gd -- --expedition523-pack=/private/expedition523.private.json --expedition523-sha256=39f075e3aea122080b060c8682c81dc6b43e3cb97e886504bdefd9dfc2034991 --expedition523-capture=/private/completion
```
