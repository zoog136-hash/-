# 전체 제작 규모와 첫 샘플 위치 검토

현재 월드 경계는 (11802,2214,72240,45708)이다. 1px/world 밀도의 1536×1024 고유 PNG로 직사각형 전체를 덮으면 **48열×45행=2160구역**이다. 마지막 행/열은 잘라야 한다. 경계 연결용 128px 겹침을 포함하면 stride1408×896으로 **52×51=2652개 생성 창**이다. 이는 직사각형 커버 계산이며 최종 지형/바다/외곽 공백을 제거한 제작량이 아니다.

전체 직사각형은 3,301,945,920픽셀, RGBA만 13,207,783,680 bytes(약12.3GiB)다. 단일 텍스처로 만들지 않는다. 첫 샘플 면적은 1,572,864 world square units, 전체 직사각형의 약0.0476%다. 현재 엔진 미리보기는 그 한 영역만 로컬로 보여준 것이며 실제 전체 월드 커버를 완료하지 않았다.

## 첫 샘플은 기존 위치 관계를 보존했는가?

**아니다.** 첫 town_forest_01은 새 스타일/밀도 견본으로 생성했고, 실제 Main의 궁전 위치에 임시로 표시했을 뿐이다. 원본의 궁전 광장과 성벽 대신 작은 주택과 숲길이 있어 기존 주요 지형/마을 배치를 보존했다고 할 수 없다. 기존 정상 원본과 실제 게임 배치는 교체하지 않았다.

동쪽 인접 후보 제작에서는 원본 SHA c0af…의 (11843,2832)~(12099,3003) 영역을 읽기 전용으로 잘라 레이아웃 참조로 사용했다. 신규 palace_east_garden_01은 원본의 북서 궁전, 정원 교차로와 네 화단, 남서 광장, 남쪽 분수, 남동 건물의 상대 배치를 참고해 새로 그렸다. 저해상도 그림을 확대/샤프닝한 산출물이 아니다. 스타일 기준에는 첫 PNG를 사용했다.

## 경계 검토 결과

첫 PNG 오른쪽 경계는 숲/마을 길인데 동쪽 후보 왼쪽 경계는 궁전/정원이다. **직접 연결은 불합격**이다. 억지 블렌딩이나 첫 샘플 반복 타일링을 하지 않았다. 동쪽 후보도 정확한 랜드마크 좌표/발 경계의 정합은 아직 완료하지 않았으므로 현재 게임의 통행 데이터 위에 덮어쓰지 않았다.

두 PNG는 생성됐으나 역할이 다르다: 스타일 견본1, 원본 배치 참조 후보1. 위치 정합과 인접 이음새까지 검증된 production 구역은 **0/2160**, 남은 구역2160. 원본 배치 후보조차 없는 나머지는2159구역이다. 이미지 생성 한도/거절은 발생하지 않았다. 다음 미술 작업은 원본 궁전 광장/서쪽 성벽에 맞춘 서쪽 정합 구역과 동쪽 후보의 경계를 함께 고정하는 것이다. 첫 스타일 PNG는 버리지 않고 견본으로 보존한다.

## Library 저장 상태

요청한 두 파일을 Library 스킬의 일괄 저장 절차로 제출했으나 준비 단계의 도구 인증에서 `HTTP 401`이 발생했다. 정확한 오류: `library upload failed: hosted apps tools/list request failed with HTTP status 401`. 실제 준비/업로드/최종 저장 단계는 시작하지 못했으며 두 파일의 library_file_id는 없다. 다른 경로로 인증 실패를 우회하거나 중복 생성하지 않았다. 파일은 기존 PR 브랜치와 로컬 경로에 보존돼 있다. 인증이 정상인 환경에서 이 두 파일을 저장해야 사용자용 Library ID를 반환할 수 있다.
