이름을 보고 카드를 추정하지 않는다. 기존 퀘스트 소비 소유자는 폴 4종과 두 전역 제한이 동시에 있는 경우만 인식했으므로 다른 4종은 예전 보상이거나 미연결 지급일 때 보관용으로만 남을 수 있었다. 이제 정확한 등급·덱·원본 카드 행·원본 제한 및 안정 저장 ID가 실제 소유자에 존재할 때 연결한다. 효과에 미지원 서비스/기간 조건이 있는 원본은 여전히 거부한다.

현재 새 보상은 기존 물리 지급/소비 경로에서 소지 개체 1개 차감과 해당 덱 소유를 한 저장에 반영한다. 기존 [원본 보상]으로 남은 물리 개체는 원본 퀘스트 영수증을 검증하고 그대로 소비한다. 훨씬 오래된 이름 수량의 경우 역사 PIN, 실제 획득 퀘스트·원본 보상·수량이 검증된 경우에만 별도 경로에서 소비한다. 최신 물리 개체를 이름 수량으로 바꾸지 않는다. 네 폴의 기존 옵션 재료 보존 정책은 유지하고 다른 카드에 자동 확장하지 않는다. 아이콘은 별도 작업이다.

매직 솔져 #139781의 지급 퀘스트 #77381은 사용자 지시로 삭제된 튜토리얼이다. 이 변경은 해당 퀘스트를 다시 열거나 보상을 새로 지급하지 않는다. 이미 받은 영수증·소지품만 쓸 수 있게 한다. 신규 발급 경로의 실제 시험 대상은 현행 마검사 #60311 → 다크 블레이더다.
