# 원본 선택상자·직업 상자·스킬북의 퀘스트 소비 연결

기준 공개 체크포인트는 `050525ff711b07e81169e53af0bb806adb9c9785`다. 원본 3,621개 정의와 자동 획득/완료, 레벨 목표 104행 교정, 기존 보상·사용자 저장 보호를 유지한다. 이번 변경은 이미 지급된 정상 영수증의 선택 소비와 새 자동 지급분을 기존 공개 소비자에 연결한다. 과거 822개 완료 저장본은 변환하거나 재지급하지 않는다.

기존 859/1281/239/233에 두 상자(368202/369002)를 연결했다. 별도 검증된 스킬 v3 입력이 있으면 기존 스킬에 대응하는 여덟 스킬북(177192/177202/177212/177222/177232/177252/177332/177452)도 연결한다. 여섯 기본 소비자 상태의 완료 811개/일부 보상 사용 연결 대기 369개와, v3 입력을 함께 설치한 상태의 811개/366개를 구분한다. 366은 아이템 종류 수나 미구현 퀘스트 전체 수가 아니다. 전체 기능 완료를 뜻하지 않는다.

## 두 상자의 실제 범위

- 368202는 원본 직업별 상자다. 원본 13개 출력 관계를 그대로 두고 실제 기사 ClassID1이 368182 한 개를 받는 것을 확인했다. 기존 지급분의 5개 실제 스택과 새 자동 지급분을 각각 사용했다. 출력 스킬 카드 뽑기팩 자체의 추첨·스킬 획득은 연결하지 않았다.
- 369002는 기존 PR238 선택 UI를 사용한다. 원본 4개 선택을 유지하며 실제 원본 선택 행 ID 59062로 226318 룬을 한 개 받는다. 결과 ItemClass ID를 선택 행 ID로 받지 않는다. 원본 강화 값이 없는 경우의 +0은 기존의 명시적 호스트 설정이며 원작 확정값으로 바꾸지 않았다.
- 선택창은 실제 world를 참조한다. 열기·취소 때 소비하지 않고, 확정 순간 현재 잠금·원본 소지 영수증·원본 행·잔량을 다시 읽는다. 짧은 소비 후보에서 입력 차감과 실제 출력 개체, 원본 출력 증명, 입력의 불변 퀘스트 영수증을 한 번에 저장한다.
- 룬 **소유 개체 출력**을 검증했다. 룬 착용·전투 효과는 장비 소유자 범위이며 이번 검증에 포함하지 않는다.

## 스킬 입력과 기존 학습 소유자

공개 PR245 `655355575705f42036c6169341047dd288247819`의 builder와 public bindings를 그대로 사용한다. 원본 ZIP은 이미 보유한 25,031,173바이트/SHA `d5192c3c735ff95c6b181bf2d4d77448d8b562fdb28dbd43f897fa4eae1f4832`를 재사용했다. 다운로드를 반복하지 않았다.

`tools/skills/build_player_skills523.py`(Git blob `67c867ff03e46fc4026fa34f77e1ff0589645116`)로 저장소 밖에서 재생성한 **player_skills523_apply_v3.json**은 4,415,307바이트, SHA256 `256f0ba0944e05b86134b40ed3aea97c71e1073b3947ea6e46cb018b6179926a`이며 441개 증명 프로필을 담는다. **LOCAL_ONLY**다. Drive v3 전송 거절 상태를 바꾸거나 새 업로드를 하지 않았다. 이 파일의 존재는 441개 스킬 실행 구현을 뜻하지 않는다.

```sh
python3 tools/skills/build_player_skills523.py \
  --source-zip /private/current523.zip \
  --bindings data/skills/player_skills523_bindings.json \
  --output /private-outside-repository/player_skills523_apply_v3.json
```

실행 인자는 `--player-skills523-pack=<외부 파일 경로>`와 `--player-skills523-sha256=256f0ba0944e05b86134b40ed3aea97c71e1073b3947ea6e46cb018b6179926a`다. 입력이 없거나 잘못되면 새 학습 어댑터를 등록하지 않는다. 기존 소지·영수증은 보존하고 학습을 거부한다. 게임에 Drive 자동 다운로드 기능을 추가하지 않았다.

좁은 `quest_skillbooks523.gd`는 입력 크기/SHA·원본 ZIP SHA·공개 bindings SHA·전체 441개 행 ID/JSON SHA를 먼저 검사한다. 변경 없는 PR238 `patch523_skill_book.resolve`와 `source_limit_problem`, 현재 실제 catalog의 `record_for/reason/export_state`를 재사용한다. 스킬 엔진이나 전체 PR245를 복제하지 않고 현재 기존 스킬의 학습 상태에 연결한다.

실제 원본 학습 직업·레벨·선행/변신/카드·마스터리, ItemClass TestItem/사용/은신/서버/기간 조건과 잠금을 유지한다. 실제 기사 캐릭터에서 원본 2/65/1/80은 이미 학습되어 책을 보존했다. 정상 클래스 선택 UI를 거쳐 마법사로 바꾼 후 원본 74/73/1113/81은 실제 퀘스트 소지 책으로 기존 디크리즈 웨이트·큐어 포이즌·어스 재일·턴 언데드를 학습했다. 이 검사는 원작 주문의 모든 피해/시전 공식을 구현했다는 뜻이 아니다.

선택 물리 개체는 불변 원본 지급 수량과 현재 잔량·출처 영수증을 검증하고 차감한다. 정상 새 지급분은 정확한 원본/축복 소지 키와 실제 지급 영수증을 확인한다. 책 차감·기존 학습 상태·source_skill_book_receipts·원본 사용 영수증·재사용 대기를 하나의 원자 저장 후보로 쓴다. 저장 성공 또는 오류 후 실제 기록과 후보의 완전 일치를 확인한 뒤에만 라이브 상태를 채택한다. 불확실한 저장 결과는 재사용/저장을 보호한다. 학습 때문에 기존 퀵슬롯·아카이브를 다시 마이그레이션하지 않는다.

스킬북 177292/177322/177342/177432의 원본 347/358/1133/70은 public bindings에 있지만 `lmref_` 참조 ID다. 이 어댑터는 네 종류 모두를 계속 거부한다. 현재 카탈로그에 일부 참고 실행이 있더라도 이번 계약에서 활성화하지 않는다. 상세 대조는 [skillbook-source-audit.json](skillbook-source-audit.json)에 기록했다.

## 고정 카드의 정확한 남은 제약

공개 PR243 `957b8853b2986109b8fa747573cf6d18496f46c4`에 `receive_source_card(category,record,receipt)`와 후보 저장 예제가 있다. 더 이상 단순히 API 부재로 분류하지 않는다. 실제 Main 카탈로그에서 31개 대상 모두 정확한 원본 카드 한 개와 대응했다.

원본 ItemClass 전체 행을 다시 읽은 결과 27개는 TestItem=true다. 비시험용 4개(306611/306621/306631/306641)의 원본 카드에는 IsNoSwapOut와 IsNoMergeOut가 모두 true다. 영수증에 플래그를 저장하는 것만으로 실제 합성/교환 소비자의 집행이 증명되지는 않는다. 따라서 31개 모두 보존하고 카드 소유를 새로 지급하지 않았다. 원본 ItemCannotSwap=false인 27개를 모두 허용하지 않는다. [fixed-card-source-restrictions.json](fixed-card-source-restrictions.json)에 실제 원본 플래그와 카탈로그 대응을 기록했다. 미게시 PR243 파일을 복사하거나 재게시하지 않았다.

## 검증과 전달 구분

[consumer-followup-validation.json](consumer-followup-validation.json)에 각 실제 입력·출력/학습·오류·저장·재접속 검사와 해시를 기록한다. 원본 소지는 fixture로 만들지 않았다. 잠금, 미지원 클래스 플래그, 부족 레벨, 저장 오류는 복사한 검증 프로필에서 통제한 조건이다. 새 클래스의 기본 스킬 퀵슬롯이 재접속 때 안정 ID로 정규화되는 초기 테스트 비교 실패는 신규 QA 프로필에만 명시적인 유효 50칸 편집 설정을 넣어 교정했다. 기존 실제 저장본의 사용자 슬롯은 수정하지 않았다.

퀘스트 v1 Drive ZIP(570,245바이트/SHA `77866c180d4224eff6d7e578759ec0820d6e50515e5c6bd8a67dc92421c20063`)과 PR238 정상 아이템 BIN(SHA `38ee3ec74d12adaa9847c507f6fb093c41a4f7a8c5c1cefcd08c3a9629920d27`)은 그대로다. 새 팩·원본·보고서·캡처를 외부 전송하지 않았다. 기존 Drive 팩 보관 완료, 새 코드 공개, 스킬 v3 로컬 입력, 실제 소비/학습 검증은 서로 다른 상태다. 맵 환경·활성팩·PR232/263 브랜치를 변경하지 않았다.
