# Half elixir

Main → 메뉴 → 하프 엘릭서에서 소유한 523 전체 Content ZIP을 선택합니다. 설치기는 표 버전, 필수 표 SHA-256, 참조와 전체 규칙 범위를 검사합니다. 원본은 공개 저장소에 포함하지 않으며, 기존 비공개 공통 ZIP을 그대로 재사용합니다. 새 기능별 리소스팩을 만들지 않습니다.

설치된 ZIP은 `user://half_elixir523/packs/<SHA-256>.zip`에 보관되고 저장 데이터에는 해시와 진행 상태가 기록됩니다. 재접속 시 같은 ZIP을 다시 검증합니다. 파일이 없어지면 기존 진행을 유지하고 효과와 거래를 비활성화합니다. 같은 ZIP을 다시 설치하여 복구할 수 있습니다.

지역과 월드를 선택한 뒤 실제 소유 충전 아이템을 사용하고, 투자할 능력치를 확인하여 확정합니다. 충전과 투자는 별개입니다. 확장은 원문에 있는 열 단계만 지원하며 현재 확장 좌표의 상한을 사용합니다. 초기화는 원문 초기화 아이템을 소비하고 투자 포인트만 반환합니다. 일반 엘릭서와 일반 스탯 초기화는 변경하지 않습니다.

전체 투자 규칙, 확장 좌표와 서버별 네 프로필을 읽습니다. 빈 회원 서버 집합은 허용하지 않습니다. 관련 공급·소비 표는 전체 행을 읽어 정확한 아이템 참조를 감사하지만 제작, 케플리샤 결과와 마일리지 실행은 별도 제작 기능의 책임입니다. 이 기능은 아이템을 무료로 지급하지 않습니다.

원문의 비용, 제한, 보너스 값과 단위는 보존합니다. 확률 분모, 실패 시 비용 차감, 전체 확장 용량, 투자 단위와 피해 감소 결합 순서는 `data/growth/half_elixir_policy.json` 및 런타임에 명시된 TWILIGHT 정책입니다. 리니지M 서버 계산 공식을 복원했다는 뜻이 아닙니다. 만료·테스트 초기화 아이템은 명확한 실행 조건이 없으므로 차단합니다.

HP, AC, MR, 무게, 공격력, 명중, 회피 무시, SP, PvE 피해 및 저항은 기존 소비 경로에 연결합니다. PvP, 암흑 상태, 마법 보호막처럼 기본 게임에 없는 전투 문맥은 별도 조건부 계산 API로 남기며 PvE 효과로 바꾸지 않습니다. 모든 원본 효과가 현재 기본 PvE에서 발동한다는 뜻은 아닙니다.

거래는 소유권과 상태 개정을 재검증하고 저장 성공 후에만 메모리 상태를 바꿉니다. 중복 요청은 한 번만 소비합니다. 저장 실패와 손상된 기능 상태는 기존 진행을 덮어쓰지 않습니다.

검사는 사용자 실제 세이브와 분리한 프로필에서 실행합니다.

```sh
TWILIGHT_HALF_ELIXIR_SOURCE=/private/content523.zip godot --headless --path . --script tests/half_elixir_source_test.gd
TWILIGHT_HALF_ELIXIR_SOURCE=/private/content523.zip godot --headless --path . --script tests/half_elixir_main_test.gd
```
