# S02 보조 스프라이트 레이어 연결과 복구

원본 Windows 복원 EXE의 P13 그림자·의상 분석에서 `0x01C8F2D0`은 본체 요청과 별개로 그림자 및 의상을 갱신하고, `0x01C96150`은 의상을 원문 순서로 수집해 첫 null에서 멈춘다. 현재 523 뱅크에서 같은 프레임으로 선택되는 인라인 레이어와, 레거시 팩이 별도 트랙으로 선언한 보조 레이어를 구분한다. 이번 변경은 후자의 연결을 보완한다. 인라인 레이어의 원본 선택, 첫 null 규칙, 무결성 검사, 색과 합성 순서를 그대로 유지한다.

- 실행 중 `OriginalSourcePreview._advance_reference_children`에서 독립 레이어를 그리다가 검증이 실패하면 자식의 뱅크가 해제된다. 이전에는 부모가 실패한 노드를 보유해 원본 입력이 복구돼도 재설정할 수 없었다. 검증 실패 노드를 제거하고 다음 프레임에서 검증된 뱅크로 다시 구성한다. 보조 레이어가 잠시 비어도 기존 본체 보존 정책을 따른다.
- 액터 변환기는 라이브 카드·NPC 소유자 컨텍스트 없이 미리보기를 만든다. 이때 독립 레이어 추적이 초기에 반환돼, 실제 유효한 그림자까지 변환 파일에서 빠질 수 있었다. 변환하는 동안 요청의 핀과 소비자 문맥을 제공한다. 초기 상태, 프레임마다 채집할 때, 마지막 유지 포즈에서 누락된 독립 레이어가 있으면 부분 결과를 저장하지 않는다. 중첩 자식의 실패도 검사한다.
- Linux Godot에서 수정 전에는 운영 미리보기의 그림자 재연결 검사 3개와 변환 검사 2개가 실패했다. 수정 후 레이어 검증 시험은 일반/프레임 캐시 경로 각각 25개 통과, 변환 시험은 headless 308개 및 OpenGL 324개 통과(합성 픽셀 비교 81개, GL 비교 4개). 원본 선언·인스턴스·copy-free 합성 검사 126개와 레이어 누락 Python 검사 8개도 통과했다.

테스트는 실제 소스 검사·변환·렌더 경로에 합성 SP2를 넣은 결과다. 기존 Twm 변환 팩을 교체하지 않았으며 해당 팩에 이전에 빠진 레이어를 넣으려면 원본 팩에 대한 재변환이 필요하다. 실제 원본 액터 팩 및 Android에서 특정 캐릭터의 화면은 미검증이다.
