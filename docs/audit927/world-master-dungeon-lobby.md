# 523 월드/마스터 던전: 원본 입구의 오프라인 이동

`메뉴 → 던전 → 월드 던전 / 마스터 던전`은 원본 분류 274/284의 23개/4개 행을 표시한다. 이름은
`CompetitionDungeonView.TitleDescId`의 원본 한글 텍스트다. 같은 이름의 서로 다른 ID는 따로 표시한다.
글로벌 마스터(322)는 별도 분류이며 원본 미공개라 활성 탭·이동으로 바꾸지 않는다. 시즌·공성·파티 등도 이 범위에 포함하지 않는다.
기존 원본 Mission 탭/카드 UI를 두 탭에도 재사용한다. 전용 원본 대전 화면이나 입장 서버 UI의 복원으로 표시하지 않는다.

## 실제 이동의 범위

TWILIGHT는 단독 오프라인 게임이다. **원본 입구 탐방에서 레벨 조건은 유지**하고 서버 분류, 영업 시간,
이벤트·시즌, 보스·입장 선행 아이템 조건은 검사하지 않는다. 원본 정의는 수정하지 않으며 서버, 전투·보상,
시즌 및 던전 세션을 시작하지 않는다. 이 정책은 정확한 월드·마스터 도착 Land에서만 적용한다.

입구는 `CompetitionDungeon.LandTeleportId → LandTeleport → LandTeleportTerritories → Territories → Land`를
정확히 연결한다. 목적지 관계가 없거나 여러 개면 임의로 선택하지 않는다. 이동표와 도착 Land의 실제
MinLevel/MaxLevel을 적용하며, 지역 범위 제한과 실제 지형은 지도 컨트롤러가 최종 검증한다.
이번 원본 27행에는 도착 Land 최소 레벨이 모두 있고, 최대 레벨이 선언된 행은 없다.

- 월드 23개 중 **22개**가 이동 대상이다. 보물섬 낚시터(501)는 계속 제외한다.
  고대의 사막 두 행의 원본 1,000 명예 코인은 Currency 21 → ItemClass 3631의 기존 지갑으로 지불한다.
- 마스터 4개 중 **3개**가 이동 대상이다. 지배의 탑 입구·마족들의 땅·에오딘 성채는 최소 85레벨과 500,000 아데나를 유지한다.
  이계의 성지(221)의 비용은 별도 선행 조건이 아닌 원본 Currency 952 입장권 1개다.
  기존 소지품 소유자가 `[테스트]` 원본 ItemClass 159992를 결제할 수 없어 이 행은 결제 미연결로 표시하고 무료 전환하지 않는다.

## 저장 및 미디어

확인 창은 입구 이동이라는 사실과 정확한 비용을 표시한다. 실행 때 다시 가격·조건·리소스·기존 저장 보호를 확인한다.
도착 렌더·착지와 기존 원자적 저장에 성공할 때만 아데나와 도착점이 적용된다. 쓰기 실패 시 같은 저장 바이트/잔액/위치를
유지하는 기존 롤백을 이용한다. 검증된 입구에서 기란 마을로의 귀환은 무료이며 같은 이동 저장기를 사용한다.
같은 입구에 이미 있다면 재구매할 수 없다.

그림은 `CompetitionDungeon.ID → CompetitionDungeonAsset.CompetitionDungeonId → EntranceAssetId → AssetView`의
타입 11·정확한 파일명을 기존 `source523_image_assets` 리더에 넘긴다. 실제 원본 그림이 없거나 사용 중인 UI 팩에 외부 슬롯
선언이 없다면 해당 그림 자리는 비워 둔다. 보완 그림을 생성하거나 저장소에 원본 파일을 넣지 않는다.

검증 스크립트 `tests/competition_dungeon523_test.gd`는 원본 정의가 없을 때 없는 행을 합성하지 않는지, 원본 정의가 있으면
전체 원본 route/art join, World 실행·가격 재확인, 실제 Main 저장 및 실패 롤백을 검사한다.
`--competition-terrain=<검증한 원본 맵·타일 폴더>`와 기존 world-links pin을 함께 넘기면 실제 지형에서 입구와 귀환을 검사한다.
Godot 4.7.2 Linux headless에서 523 정의 ZIP, 고정 world-links, 실물 S32/TI2로 아래 동작을 검사한다:
85 미만 에스카로스 거절과 저장 보존, 기란→에스카로스 입구 이동·실제 쓰기 실패 롤백,
정확한 위치 재불러오기·무료 기란 귀환, 서버 조건이 있던 마스터 던전 마족들의 땅 원본 입구 이동.
원본 이미지 메타데이터 및 대상 파일을 설치한 별도 시험은 기존 파일 검사·디코더에서 고유 21개 PNG 모두를 열었다.
Android 실기기, 원본 서버 던전의 동작, 이미지를 포함한 전체 원본 UI 렌더는 별도다.
