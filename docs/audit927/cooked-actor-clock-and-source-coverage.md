# 변환 액터 재생 비용과 Twm 변환 실패

## 재생 비용

`OriginalSourcePreview._advance_selected_source`는 변환 액터의 현재 방향에 속한 모든 프레임 길이를 매 틱 합산했다. `CookedActorStore.load_actor`가 프레임을 구성할 때 같은 순서로 방향별 길이를 한 번 합산하고, 번들을 사용하는 인스턴스는 그 값을 공유한다. 변환 액터가 읽지 않는 문자열 토큰 생성도 제거했다. 프레임 탐색 순서, 경계 허용치, 프레임 안의 포즈 시각, 걷기 위상과 기존 이미지 형식은 유지한다. 방향 8개에 대해 트랙마다 64바이트의 길이 값과 배열 관리 비용이 추가된다.

Godot 4.7.2 Linux에서 실제 미리보기 경로에 합성 128프레임 루프를 넣고, 30Hz 간격으로 방향을 바꾸며 25,000회씩 7회 재생했다. 준비 회차를 제외한 중앙값이 호출당 78.96µs에서 25.05µs로 줄었고, 7회 모두 선택된 프레임들의 체크섬이 수정 전후 동일했다. 이미지 로드와 화면 합성 비용을 제외한 합성 검사다. Headless 310개, 소프트웨어 OpenGL 326개, SP2 메타데이터 85개와 보조 레이어 바인딩 24개를 통과했다. Android 실기기 프레임 및 메모리는 미검증이다.

## 실제 Twm 변환 누락

게임 핀에 대응하는 Twm `pack-63fb1355`의 1/8·2/8 ZIP을 다운로드해 ZIP CRC를 확인했다. 추출한 뱅크 매니페스트의 SHA-256은 게임 핀 `587b419b38fd9e66639b315788011c986439a005b2525942162ff71febc81eeb`과 일치했다. 아래 세 액터의 액션 JSON SHA-256도 해당 매니페스트와 일치했다. `cooked-63fb1355-v2`에 기록된 17개 실패 중 대표 사례를 확인한 범위다.

| 사례 | 실행 연결 확인 |
| --- | --- |
| `effect:spell:16322:0` | 원본 액션의 네 SP2 크기는 각각 7,095,709, 10,393,889, 2,268,608, 5,505,416바이트다. 모두 2MiB 제한을 넘는다. 핀을 통과한 실제 매니페스트를 사용해 `ReferenceSp2Bank._member`가 네 항목을 파일 접근 전에 `Invalid raw member identity`로 거부하는 것을 재현했다. 변환 집계가 이 오류를 멤버 불일치로 분류한다. 나머지 같은 분류 13개의 사유는 개별 확인이 필요하다. |
| `effect:spell:26691:0` | 원본 액션에서 `26691 → 26694`와 `26691 → 26693 → 26694`가 각각 선언된다. 두 의상 인스턴스가 동일한 `list_26.spr` 11635행 선언과 attr 128을 참조한다. 실제 액션 DTO를 넣어 `ReferenceSp2Bank._attributes`의 모호성 거부를 재현했다. 복구 시 두 의상 경로의 소유자·순서·합성을 보존해야 한다. |
| `npc:3136` | 액션 0은 `Sprite/51-0.sp2`를 참조한다. 원본 액션과 핀은 확인했다. 해당 SP2 바이트 및 실패 레이아웃은 미검증이다. |

위 두 재현은 각각 메타데이터와 크기 판단의 실행 증거다. 원본 이미지 바이트, 디코더 입력 한도, 레이어 무결성 규칙이나 Twm 출시 팩은 변경하지 않았다.
