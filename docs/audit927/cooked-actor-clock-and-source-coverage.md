# 변환 액터 재생 비용과 Twm 변환 실패

## 재생 비용

`OriginalSourcePreview._advance_selected_source`는 변환 액터의 현재 방향에 속한 모든 프레임 길이를 매 틱 합산했다. `CookedActorStore.load_actor`가 프레임을 구성할 때 같은 순서로 방향별 길이를 한 번 합산하고, 번들을 사용하는 인스턴스는 그 값을 공유한다. 변환 액터가 읽지 않는 문자열 토큰 생성도 제거했다. 프레임 탐색 순서, 경계 허용치, 프레임 안의 포즈 시각, 걷기 위상과 기존 이미지 형식은 유지한다. 방향 8개에 대해 트랙마다 64바이트의 길이 값과 배열 관리 비용이 추가된다.

Godot 4.7.2 Linux에서 실제 미리보기 경로에 합성 128프레임 루프를 넣고, 30Hz 간격으로 방향을 바꾸며 25,000회씩 7회 재생했다. 준비 회차를 제외한 중앙값이 호출당 78.96µs에서 25.05µs로 줄었고, 7회 모두 선택된 프레임들의 체크섬이 수정 전후 동일했다. 이미지 로드와 화면 합성 비용을 제외한 합성 검사다. #760 통합 이후 같은 팩 회귀 테스트에서 headless 319개와 소프트웨어 OpenGL 338개를 통과했다. 여기에는 합성 픽셀 비교 81개와 GL 비교 7개가 포함된다. 이전 기반의 SP2 메타데이터 85개와 보조 레이어 바인딩 24개도 통과했다. Android 실기기 프레임 및 메모리는 미검증이다.

## 실제 Twm 변환 누락

게임 핀에 대응하는 Twm `pack-63fb1355`의 1/8·2/8 ZIP을 다운로드해 ZIP CRC를 확인했다. 추출한 뱅크 매니페스트의 SHA-256은 게임 핀 `587b419b38fd9e66639b315788011c986439a005b2525942162ff71febc81eeb`과 일치했다. 아래 액션 JSON의 SHA-256 및 3/8·5/8·6/8의 범위 읽기로 추출한 SP2 멤버의 크기·CRC·SHA-256도 해당 매니페스트와 대조했다. `cooked-63fb1355-v2`에 기록된 17개 실패 중 대표 사례를 확인한 범위다.

| 사례 | 실행 연결 확인 |
| --- | --- |
| `effect:spell:16322:0` | 원본 액션의 네 SP2 크기는 각각 7,095,709, 10,393,889, 2,268,608, 5,505,416바이트다. 모두 2MiB 제한을 넘는다. 핀을 통과한 실제 매니페스트를 사용해 `ReferenceSp2Bank._member`가 네 항목을 파일 접근 전에 `Invalid raw member identity`로 거부하는 것을 재현했다. 변환 집계가 이 오류를 멤버 불일치로 분류한다. 나머지 같은 분류 13개의 사유는 개별 확인이 필요하다. |
| `effect:spell:26691:0` | 원본 액션에서 `26691 → 26694`와 `26691 → 26693 → 26694`가 각각 선언된다. 두 의상 인스턴스가 동일한 `list_26.spr` 11635행 선언과 attr 128을 참조한다. 실제 액션 DTO를 넣어 `ReferenceSp2Bank._attributes`의 모호성 거부를 재현했다. 복구 시 두 의상 경로의 소유자·순서·합성을 보존해야 한다. |
| `npc:3136` | 핀에 등록된 액션 10개가 참조하는 SP2 멤버 6개를 운영 디코더에 넣었다. 5개를 파싱했고, 액션 8의 `Sprite/51-24.sp2`만 경계 검사에서 실패했다. 진단용 복사본에서 그룹 5의 두 프레임이 기록된 경계를 벗어났다. 기록 경계는 각각 `[-3,-75,43,-30]`, `[-2,-77,42,-30]`이고 샘플의 반열린 범위는 둘 다 X `[-48,70)`, Y는 각각 `[-75,11)`, `[-77,11)`이다. 원본 클라이언트가 이 샘플을 잘라내는지 또는 확장해 그리는지는 추가 확인이 필요하다. |

위 결과는 원본 데이터에 대한 TWILIGHT 검증 경로의 재현이다. 남은 실패를 해소하려면 대형 SP2 예산, 의상 경로의 인스턴스 구분, 강제 경계 밖 샘플 처리의 원본 근거를 각각 확인해야 한다. 디코더 입력 한도, 레이어 무결성 규칙 및 Twm 출시 팩은 기존 그대로다.
