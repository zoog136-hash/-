# 원본 실행 경로 대조와 UI 키프레임 최적화

## 현재 게임에 적용한 변경

Windows code524 복원 분석의 ActionTimeline step(DLL `0x00246F70`)은 재생 시계와 현재·끝 프레임 처리를 분리한다. 공개 [Cocos Timeline](https://docs.cocos2d-x.org/api-ref/js/v3x/symbols/src/_Users_chukong_Chukong-Inc_cocos2d-x_web_extensions_cocostudio_timeline_Timeline.js.html#195)의 키프레임 탐색도 정렬된 키 사이의 구간을 찾는다. 이 두 자료는 설계 근거다. TWILIGHT는 기존 60프레임 시계, 보간, 중첩 클립 및 콜백 계약을 그대로 사용한다.

`sprite_scene.gd`는 재생 시 모든 트랙의 프레임 값 타입을 매번 해석했다. 이제 장면 검증 중 8개 이상이며 정렬된 트랙에만 키 참조를 모아 둔다. 재생 중 이분 탐색으로 마지막 이전 키와 최초 다음 키를 찾아 기존 방식으로 적용한다. 같은 시각에 있는 키의 원본 순서를 유지하며, 짧거나 비정렬인 트랙은 기존 순회 경로를 사용한다. 참조는 해당 장면 소유이며 다른 장면에 공유하지 않는다.

## 다른 시스템의 적용 상태

| 경로 | 정적 근거와 현재 실행 코드 | 판단 |
| --- | --- | --- |
| 로딩·이미지 | Android `0x5544460`은 텍스처 적중 시 디코딩 전에 반환하고 `0x5543594 → 0x554389c → 0x5543c44`는 요청·읽기·완료 처리를 분리한다. Windows `0x0208DEDB`도 텍스처 캐시를 먼저 조회한다. | TWILIGHT UI의 캐시는 이미 텍스처를 재사용한다. 별도 `source523_image_pack` 호출은 활성 팩 멤버 바이트를 검사하므로 원본의 무검사 적중을 적용하는 데에는 별도 무결성 계약이 필요하다. |
| 맵 | Windows `0x01CC2220 → 0x01CC1F10`은 배치 큐를 나누어 소비한다. 현재 S32 렌더러는 작업 스레드에서 청크를 준비하고 블록 결과를 유지한다. #746은 아틀라스 중복 해독을 줄인다. | #746과 겹치는 지도 변경은 이 작업 범위에서 제외했다. 원본의 분할 횟수는 시간 예산 근거가 아니다. |
| 액터·전투 | Windows RawSpriteFile과 SpriteAsset의 분리, Android `0x326e144 → 0x2813d78 → 0x326b3d0`은 캐시·읽기·파싱 경계를 보여 준다. 현재 게임은 SP2 파싱 캐시와 변환 액터 팩을 사용한다. | 원본의 캐시 저장 바이트 상한은 Godot 프로세스 메모리와 단위가 다르다. 충돌, 공격 이벤트, 지연을 바꿀 근거는 확인되지 않았다. |
| 자동 사용 | Android `0x31ccac4/0x31d0ce0`의 0.5초, strict `>`, 콜백당 1회 차감은 `World`의 M81 호출에 이미 연결돼 있다. | 동작이 연결된 항목으로 기록한다. |
| 데이터·UI 연결 | UI 셀렉터가 실제 Twm 팩을 열어 검증하고, 실제 장면 플레이어가 CSB에서 파생된 장면을 구성한다. | 이번 변경은 렌더러 소비 지점에 적용했다. 신규 데이터 테이블이나 원본 파일은 추가하지 않았다. |

## 검증

Linux Godot 4.7.2 OpenGL Compatibility 소프트웨어 렌더러에서 실제 Twm UI 팩을 사용했다. 장면별 워밍업 후 임의 순서의 프레임 240개를 전후 교대로 찾았다. 노드 위치·가시성·색·텍스처가 각 프레임에서 일치했고, 각 장면의 프레임버퍼 표본 5개가 바이트 단위로 일치했다.

| 팩 장면 | 기존 중앙값 | 변경 중앙값 |
| --- | ---: | ---: |
| Fx_Change_Outline_Loop.csb | 1.314ms | 0.247ms |
| Fx_Enchant_Start.csb | 1.485ms | 0.373ms |

위 두 장면은 독립 렌더러 벤치마크다. 강화 창에서 해당 효과가 실제로 시작된다는 증거로 쓰지 않았다. 지배석 장면의 직접 마운트에는 원본 아이템 슬롯의 게임 소유자 바인딩이 필요했다. 실제 팩과 원래 지배석 창 경로를 사용한 별도 검사 16개는 통과했다. 합성 프레임 선택 1,798개, 생명주기 279개도 통과했다. Android 기기 전체 프레임과 원본 실행 시간은 미측정이다.
