# 전체 플레이어블 지역 확장

기준 원본: GitHub `zoog136-hash/-`, `main` **0f2dd88101518e7c7ed75c7d1ce0cefe08807528**.
로컬 아덴 작업 커밋의 파일 트리가 최신 main과 동일함을 확인한 뒤 확장했다.
과거 ZIP을 사용하거나 기존 프로젝트를 재작성하지 않았다.

## 순서와 구현 범위

| 순서 | 지역 | 실제 플레이 가능 범위 | 구조/분위기 |
|---|---|---|---|
| 기존 | 아덴 | 12,288 × 8,192 | 기존 은빛 변경, 숲·강·다리·폐허 보존 |
| 1 | 오만의 탑 1–10층 | 각 7,168 × 6,656 | 10종 방/복도 그래프, 석벽·묘실·서고·제단, 층별 색조/몬스터 |
| 2 | 지배의 탑 정상 | 8,192 × 7,168 | 검은 성채, 두 성문, 분리된 안뜰, 기념 기둥과 왕관의 제단 |
| 3 | 에스카로스 1–5구역 | 9,216 × 7,168; 습지는 7,168 × 9,216 | 협곡, 가로 하천/세로 다리의 습지, 붕괴한 전초기지, 용암 경계, 십자 분화구 |
| 4 | 알비노 1–4구역 | 각 7,168 × 6,656 | 서로 다른 가지 동굴, 백색 암석, 청색/유황 웅덩이, 수정/별빛 |
| 5 | 신념의 탑 1–4층 | 각 7,168 × 6,656 | 중앙 회랑, 회랑 순환길, 성당 날개, 최종 성소, 제단·금빛 깃발 |

기존 **25개 맵 ID 전부 유지**. 아덴 외 24개 맵을 실제 필드 정의로 연결했다.
새 지역마다 안전한 입구, 여러 사냥터, 보스 사냥터, 이전/다음 지역과 아덴 귀환 이동진이 있다.
입구↔중앙 사냥터 이동석은 개체수를 초기화하지 않는 실제 지역 내 텔레포트다.
전체 순환: 아덴 → 오만 1–10 → 지배 → 에스카로스 1–5 → 알비노 1–4 → 신념 1–4 → 아덴.
기존 맵 메뉴에서도 모든 지역으로 이동할 수 있다.

## 좌표와 지형

모든 값은 동일한 월드 픽셀 좌표와 발 위치 기준을 사용한다.
터치·카메라·미니맵은 기존 `world_coordinates.gd`를 공유한다.
던전은 방/복도 바닥의 합집합과 그 여집합(벽)을 64px 단위로 정확히 분할한다.
그 **동일한 벽 사각형을 화면·물리 충돌·AStar 장애물에 사용**한다.
내비게이션은 기존 32px 격자와 반경 24 / 여유 47px, 코너 절단 금지를 유지한다.
물/용암/웅덩이도 화면과 충돌에 같은 폴리곤을 사용한다.

## 저장 / 성능

- 아덴 layout revision 1 유지. 새 지역 revision 2는 옛 개요도 좌표만 안전 입구로 이전한다.
- 레벨·경험치·금화·아이템·장비·퀵슬롯 등의 진행 데이터는 유지한다.
- 메뉴에는 지역 경로와 크기만 보관. 전체 지역 이미지나 지형 JSON을 한꺼번에 로드하지 않는다.
- 공유 아틀라스 두 장과 글꼴 재사용, 소품은 1,024px 구역 단위 스트리밍.
- 몬스터는 지역별 최대 개체수와 사망 후 재생성, 원거리 AI sleep을 사용한다.
- pooling / 지형 물리 chunking / Android GPU 프로파일링은 이번 구현에 포함하지 않았다.

## 테스트 기록

- 오만 10층 첫 검사: **2,495항목 통과**.
- 24지역 첫 검사: **5,463항목 통과**.
- 동굴 윤곽과 습지 수직 다리 수정 후: **5,594항목 통과**.
- 기존 아덴 검사: **1,452항목 통과**, 기존 smoke test 11개 통과.
- 전체 순환 포탈·역방향·접근 트리거·카메라 가장자리: **244항목 통과**.
- 지역 내 이동석 검사 추가 시 알비노 입구의 수정과 이동석 간 몸체 여유 부족을 발견해,
  이동석을 실제로 빈 진입부로 옮겼다. 충돌을 지우거나 검사를 약화하지 않았다.
- Godot **4.7.2** headless import/parse 및 Main.tscn boot 통과.
- 로컬 작업 환경은 GL 디스플레이 소켓을 열 수 없어 신규 GL 캡처를 실행하지 못했다.
  GitHub 임시 검증 브랜치에서 실제 GL 화면 28장을 렌더링했다. 오디오 없는 검사 서버는
  명시적 Dummy 오디오 드라이버로 실행한다. 리뷰 캡처를 확인한 뒤 main에 반영한다.
- 최종 지역/내부 이동석 **5,834항목**, 아덴 **1,452항목**, 포탈/카메라 **244항목** 통과.
  로컬 전체 실행 단계 **16/16 통과**. 활성 지역의 JSON 재생성 결과도 동일하다.
- 동일 석재 바닥 위에 방/복도를 중복해서 그리던 부분을 제거했다. 물리/경로/화면 형태는
  바꾸지 않고 중복 fill rate와 draw call만 줄인다.
- `git diff --check` 검사, 생성 데이터 재현성 검사를 함께 수행한다.

```bash
# 전체 데이터 재생성 (고정 시드)
python3 tools/build_world_regions.py
# 전체 headless 검사 (독립된 임시 저장 경로)
python3 tools/test_project.py --godot /path/to/godot
# 실제 게임 화면 검토 (GL 디스플레이 필요)
godot --path . --script res://tests/capture_regions.gd
```

## 아직 완료됐다고 주장하지 않는 부분

Android 실기기 FPS·발열·배터리·실제 손가락 입력과 최종 상용 게임 수준의 아트 판정은
이 환경에서 검증할 수 없다. 공유 환경 아트와 코드 네이티브 악센트는 독자적으로 만든
플레이어블 아트 세트이며 리니지M 공식 지도/자산을 추출한 것이 아니다.
실제 사용자 플레이 리뷰에 따라 지역 아트/몹 밸런스를 계속 보완할 수 있다.
