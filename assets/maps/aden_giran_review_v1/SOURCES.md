# 기란 검수용 독자 제작 아트 v1

2026-10-15, 사용자 요청으로 생성한 별도 검수용 리소스다. 기존
`assets/maps/aden/`, 오만 아트, PR #100 캐릭터/애니메이션은 덮어쓰지 않는다.

- `props.png`: 1254×1254 투명 PNG, 4×4의 16개 오브젝트 슬롯. 석조/목조
  상점, 열린 문, 회관, 참나무/침엽수, 두 방향 돌담, 기념주 분수, 화단,
  노점, 등불, 바위, 절벽, 물가, 상자/자루를 독자 생성했다.
- `terrain.png`: 1254×1254 PNG, 2×2의 포장석·잔디·흙·물 재질.
  실제 크기는 전달 매니페스트를 따른다.
- 제작: 이 세션의 image generation 도구. 원작 게임 이미지 파일을 입력으로
  제공하거나 잘라서 텍스처로 사용하지 않았다. 낮은 채도의 석재, 부채꼴
  포장, 사선 지면, 어두운 지붕 등의 관찰을 텍스트로 기술해 생성했다.
- `sprites.json`: 실제 알파 경계를 측정한 아틀라스 영역/발 위치.
  건물 크기·높이는 시각 검수 후보 값이다.

실제 사용 슬롯과 화면 검증은 [검수 보고서](../../../docs/aden-giran-review-20261015/README.md)를
따른다. 파일에 물/절벽/노점 그림이 있다는 사실은 그 구조물이 게임에
원작 위치로 배치되었다는 뜻이 아니다. 현재 물·절벽·성 전체의 위치 대응은
미구현이다. 원작과 동일한 아트 또는 원작 타일 ID의 복원으로 집계하지 않는다.

참고 화면은 [REFERENCE_MANIFEST.json](../../../docs/aden-giran-review-20261015/REFERENCE_MANIFEST.json)에
출처와 바이트 해시를 기록했다. 원작 화면의 저작권은 해당 권리자에게 있으며,
이 디렉터리는 NCSOFT 원본 이미지에 대한 재배포 허가를 부여하지 않는다.

이전 PR #120에서 확인된 공개 업로드 권한은 기존 아덴 팩 5개 파일에 관한
사용자 확인이다. 그 확인을 S32 원본 아트 전체에 확대 적용하지 않았다.
