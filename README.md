# 황혼의 기사 · Offline RPG V17 (Godot 4.x)

Godot 4.x에서 바로 Import할 수 있는 모바일/PC 겸용 프로젝트입니다.

## Android에서 실행
1. 이 저장소의 **Code → Download ZIP**
2. Android 파일 앱에서 ZIP 압축 해제
3. Godot Android Editor 실행
4. **Import**
5. 압축 푼 폴더의 **project.godot** 선택
6. **Import & Edit**
7. 상단 **▶** 버튼으로 실행

## 모바일 조작
- 왼쪽 아래: 가상 조이스틱
- 오른쪽 아래: 공격
- AUTO: 자동사냥 ON/OFF
- 오른쪽 물약: HP 회복
- 캐릭터 HUD 터치: 장비/스테이터스
- 우측 상단 인벤: 인벤토리
- 우측 상단 ≡: 메뉴 / 저장 / 불러오기

## PC 조작
- 이동: WASD / 방향키
- 공격: Space
- 자동사냥: T
- 인벤토리: I
- 메뉴: M
- 물약: Q
- 저장: F5
- 불러오기: F9

현재 버전은 V17 HTML의 HUD/메뉴/자동사냥/전투/드랍/인벤토리/스테이터스 흐름을 Godot 4.x용으로 옮긴 스타터입니다.
