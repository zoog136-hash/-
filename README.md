# 황혼의 기사 · Offline RPG V17 FINAL (Godot 4.x)

모바일/PC에서 서버 없이 실행하는 로컬 RPG 프로젝트입니다.

## 이번 FINAL에 포함된 내용
- 아덴 월드 1종
- 오만의 탑 1~10층
- 지배의 탑 정상
- 에스카로스 1~5구역
- 알비노 분지 1~4구역
- 신념의 탑 1~4층
- 총 25개 맵의 충돌 데이터를 실제 이동 판정에 사용
- 맵별 절차적 비주얼 렌더링(충돌 구조와 정확히 정렬)
- 캐릭터 이동 / 모바일 가상 조이스틱
- 몬스터 / 전투 / 자동사냥 / 타겟 HUD
- 경험치 / 레벨업 / 아데나 / 아이템 드랍
- 인벤토리 / 물약
- 캐릭터 스테이터스 / 장비창
- 변신 / 마법인형 / 성물 메뉴
- 월드맵 선택 UI
- 미니맵
- 저장 / 불러오기
- 인벤 DB에서 추출한 470개 아이템 이름 풀
- Godot 4.7.x의 Variant 타입 추론 경고 문제를 피하도록 `:=` 미사용

## Android에서 실행
1. GitHub 저장소에서 `Code → Download ZIP`
2. ZIP 압축 해제
3. Android용 Godot 4.x 실행
4. `Import`
5. 압축 푼 폴더의 `project.godot` 선택
6. `Import & Edit`
7. 상단 ▶ 실행

## 모바일 조작
- 왼쪽 아래: 이동 조이스틱
- 오른쪽 아래 `공격`: 공격
- `AUTO`: 자동사냥
- 우측 물약 버튼: 회복
- 좌측 상단 캐릭터 HUD: 스테이터스/장비
- 우측 상단 `인벤`: 인벤토리
- 우측 상단 `≡`: 전체 메뉴
- 전체 메뉴 → `월드맵`: 25개 맵 이동

## PC 키보드
- WASD / 방향키: 이동
- Space: 공격
- T: AUTO
- I: 인벤토리
- M: 메뉴
- Q: 물약
- F5: 저장
- F9: 불러오기
- PageUp/PageDown에 해당하는 키맵이 아닌 `[` / `]`: 이전/다음 맵

## 데이터 출처 구조
`data/maps_compact.json`은 이전에 제작한 `lineage_maps_v2_20261005` 충돌 데이터에서 게임 실행에 필요한 맵 크기/스폰/충돌을 압축한 런타임 데이터입니다.

`data/item_db.json`은 아이템/몬스터/스킬/변신/인형/성물 이름 및 등급/타입 인덱스이며, 제3자 이미지 바이너리는 포함하지 않습니다.
