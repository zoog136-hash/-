# Twilight Offline RPG

Godot 4 기반의 서버 없는 PC용 로컬 RPG 프로토타입입니다.

## 현재 구현
- 캐릭터 이동: WASD / 방향키
- 몬스터 추적 AI
- 자동사냥: T
- 근접 전투
- 경험치 / 레벨업
- 아이템 드롭 및 자동 획득
- 인벤토리
- 저장: F5
- 불러오기: F9

## 실행
1. Godot 4.x에서 이 저장소 폴더를 Import
2. `project.godot` 선택
3. F6/F5로 실행
